# @deguboard/core

[deguboard](https://github.com/brainpad-whiterabbit/deguboard) のドメインモデル・ストレージ・Git 操作・ワークフロー・コマンド定義。CLI（[`packages/cli`](../cli)）・[`packages/server`](../server)・VS Code 拡張（[`packages/vscode`](../vscode)）が共通に使う部品で、版はこれらと揃える。

deguboard を使うには、このパッケージではなく VS Code 拡張（VSIX）を入れる。使い方は[リポジトリの README](https://github.com/brainpad-whiterabbit/deguboard#readme)、仕様は[要件定義書](https://github.com/brainpad-whiterabbit/deguboard/blob/main/docs/requirements.md)。
