# @deguboard/server

[deguboard](https://github.com/brainpad-whiterabbit/deguboard) の HTTP サーバー。[`@deguboard/core`](https://www.npmjs.com/package/@deguboard/core) のコマンド定義を HTTP に写し、画面を配信する。CLI（[`deguboard`](https://www.npmjs.com/package/deguboard)）の `dg serve` と `dg mcp` が使う部品で、版はこれらと揃える。

deguboard を使うには、このパッケージではなく CLI の `deguboard` を入れて `dg serve` を呼ぶ。使い方は[リポジトリの README](https://github.com/brainpad-whiterabbit/deguboard#readme)、仕様は[要件定義書](https://github.com/brainpad-whiterabbit/deguboard/blob/main/docs/requirements.md)。
