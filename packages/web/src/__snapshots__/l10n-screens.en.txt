Get Started with deguboard
This repository does not use deguboard yet. If
dg
is on your PATH, start with the steps below. Copy each command and run it in a terminal.
1. Initialize
Create a place for tickets in this repository. Run it in a terminal.
dg init
[title] Copy dg init
[aria-label] Copy dg init
2. Create a ticket
Turn what you want to do into a ticket.
dg ticket create "First ticket"
[title] Copy dg ticket create "First ticket"
[aria-label] Copy dg ticket create "First ticket"
3. Ask an agent
With the Skills installed, agents read the steps and work on tickets.
dg skill install
[title] Copy dg skill install
[aria-label] Copy dg skill install
After step 1, the usual view appears without reopening.
