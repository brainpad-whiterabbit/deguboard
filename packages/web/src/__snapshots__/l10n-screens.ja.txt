## dg init 前の始め方
[aria-label] 画面
カンバン
バックログ
履歴
deguboard を始める
このリポジトリはまだ deguboard を使っていません。
dg
が PATH にあれば、次の順で始められます。コピーしてターミナルで実行してください。
1. 初期化する
このリポジトリにチケットを置く場所を作ります。ターミナルで実行します。
dg init
[title] dg init をコピー
[aria-label] dg init をコピー
2. チケットを起こす
やりたいことを 1 件のチケットにします。
dg ticket create "最初のチケット"
[title] dg ticket create "最初のチケット" をコピー
[aria-label] dg ticket create "最初のチケット" をコピー
3. エージェントに頼む
Skill を入れると、エージェントが手順を読んでチケットを進めます。
dg skill install
[title] dg skill install をコピー
[aria-label] dg skill install をコピー
1 を済ませると、開き直さなくてもいつもの画面に変わります。
