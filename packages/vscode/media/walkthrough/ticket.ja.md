# 2. チケットを起こす

やりたいことを小さなチケットに分けます。いちばん簡単なのは、Claude Code で `/dgimport` を使ってエージェントに起票を頼むことです。使う Skill は手順 1 で入っています。

1. 下のリンクで依頼の入力欄を開き、**起票する** を選んで、やりたいことを書きます。
2. 依頼文をコピーして Claude Code に貼るか、開いているターミナルを選んで **送る** を押します。エージェントがチケットの案を出し、承認すると起票されます。

[エージェントに頼む入力欄を開く](command:deguboard.askInSidebar)

ターミナルから 1 件起こすこともできます。これには `dg` が PATH にあることが要ります。`dg` が見つからないときは、先に [dg コマンドを入れる](command:deguboard.installDg) を実行します。

```sh
dg ticket create "最初のチケット"
```

起こしたチケットは、サイドバーのバックログとカンバンに出ます。行を押すと詳細がエディタに開きます。
