# 1. Initialize the repository

In the repository you want to manage, run this once from a terminal. It creates the place where tickets are stored (`.git/deguboard/`).

```sh
dg init
```

If `dg` is not found, build it as described in the README's [“Getting started before release” (「公開前に使い始める」)](https://github.com/brainpad-whiterabbit/deguboard#%E5%85%AC%E9%96%8B%E5%89%8D%E3%81%AB%E4%BD%BF%E3%81%84%E5%A7%8B%E3%82%81%E3%82%8B) section and put `dg` on your PATH (it is not on npm yet).

Once it finishes, the sidebar switches to the usual views without reopening.
