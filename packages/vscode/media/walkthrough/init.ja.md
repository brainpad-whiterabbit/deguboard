# 1. リポジトリを初期化する

管理したいリポジトリで、ターミナルから一度だけ実行します。チケットを置く場所（`.git/deguboard/`）ができます。

```sh
dg init
```

`dg` が見つからないときは、README の「[公開前に使い始める](https://github.com/brainpad-whiterabbit/deguboard#%E5%85%AC%E9%96%8B%E5%89%8D%E3%81%AB%E4%BD%BF%E3%81%84%E5%A7%8B%E3%82%81%E3%82%8B)」のとおりにビルドして、`dg` を PATH に通します（npm にはまだ公開していません）。

実行すると、開き直さなくてもサイドバーがいつもの画面に変わります。
