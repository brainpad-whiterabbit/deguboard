# 1. リポジトリを初期化する

管理したいリポジトリで、一度だけ行います。チケットを置く場所（`.git/deguboard/`）ができます。

いちばん簡単なのは、deguboard のサイドバーのチェックリストです。フォルダ・OS・git・Git リポジトリ・ボードを上から確かめ、満たしていない最初の項目にボタンとコマンドを出します。**ボード** の項目のボタンを押すと、ターミナルで拡張に同梱した dg が `dg init` を実行するので、`dg` が PATH になくても動きます。チームのボードがリモートにあるときは、同じボタンで取り込みます。チームがボードを別のリポジトリに置いているときは、**チームのボードは別のリポジトリにある** を選び、データのリポジトリ（URL か remote 名）とブランチを入れて確かめると、ボタンが `--data-remote`・`--data-branch` 付きで `dg init` を実行します。

自分でターミナルから実行するなら、次のコマンドを実行します。

```sh
dg init
```

ターミナルで `dg` が見つからないときは、サイドバーのボタンを押します。または、コマンドパレットの **dg コマンドを入れる**（`deguboard.installDg`）を実行して、`~/.local/bin/dg` を張ります。

必須の項目を満たすと、開き直さなくてもサイドバーがいつもの画面に変わります。その上の帯に、残っている推奨の項目（Skill とフック・dg コマンド・`.claude/.gitignore`）が出ます。
