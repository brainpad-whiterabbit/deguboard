# 1. リポジトリを初期化する

管理したいリポジトリで、一度だけ実行します。チケットを置く場所（`.git/deguboard/`）ができます。

いちばん簡単なのは、サイドバーの始め方の画面の **このリポジトリで始める** を押すことです。新しいターミナルで `dg init`・`dg skill install`・`dg hooks install` が順に実行されるので、`dg` が PATH になくても動きます。後ろの 2 つは、このマシンの Claude Code の Skill とフックを書き、`.claude/.gitignore` に足します。この `.gitignore` はコミットします。clone した人は、同じボタンを押して自分の分を入れます。

自分でターミナルから実行するなら、次のコマンドを実行します。

```sh
dg init
```

ターミナルで `dg` が見つからないときは、サイドバーの始め方の画面の **このリポジトリで始める** を押します。または、コマンドパレットの **dg コマンドを入れる**（`deguboard.installDg`）を実行して、`~/.local/bin/dg` を張ります。

実行すると、開き直さなくてもサイドバーがいつもの画面に変わります。
