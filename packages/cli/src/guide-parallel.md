# 着手できるチケットを並べて進める（parallel）

`next` の手（`implement`・`review`・`fix`・`ready`）がまだ待っているチケットが複数あり、サブエージェントを起動できるなら、チケットごとに起動して同時に進めてよい。`dg` は順を示すだけで、起動と待ち合わせはこの手順で行う。進めるセッション（親）は進行・承認・`dg` の読み書きだけを行う。

- **上限**：同時に 3 件まで。人が数を指示したらそれに従う。検査が負荷で落ちるなら減らす
- **始める前**：開いた Plan と PR を見て、同じファイルを直すものがないか確かめる。互いに同じファイルを変えるチケットは並べず、`after` で順にすることを人に提案する
- **親**：チケットごとに `dg guide work` の「claim の前後」と「流れ」の `implement` の手（claim は `--no-run`、worktree の作成）を 1 件ずつ行い、済んだらサブエージェントを起動する。返ったら `dg guide work` の「実装の結果を受け取る」を行い、見直しと修正ループ（`dg guide review`）を回し、直さなかった軽い指摘を PR の本文に書き足し、PR を ready にする。`plan show` を読み直して、空いた枠で次を起動する。PR を出したチケット（マージ待ち）は枠に数えない
- **モデル**：サブエージェントは Plan の段階のモデル（`dg guide work` の `models.*`。空なら親のモデル）で起動する
- **渡す文**：`next` の `brief` を書き換えずに渡し、後ろに一時ファイルの置き場所を足す。手直しは `brief --role fix --findings <指摘の一覧>` で組んだ文を渡す（`dg guide review`）
- **1 件でほかを止めない**：`CLAIM_LOST` ならそのチケットを飛ばす。実装が失敗したら `ticket unclaim` で todo に戻し（開いたままの実装の Run は unclaim が閉じる）、worktree は残して、同じ流れでは claim し直さない。見直し・手直しが失敗で返ったか返らないときは、`dg guide review` の「終わり方」に従い、unclaim しない。待つのは `after` でつながるチケットだけ
