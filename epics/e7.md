## 概要

KanbanForge の kf* にならい、起票・割り当て・点検・計画・作業・完了・見直し・リリース・一気通しの段階ごとに Claude Code の Skill（/dgimport など 9 本）を配る。各 Skill は dg guide <topic> を読む薄い包みで、手順の正本は CLI に同梱する（ADR-004）。機械的に判定できる点検は dg lint の規則にする。--auto と自動マージは e4。
