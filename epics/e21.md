## Summary

フックの機能がない AI コーディングエージェントや、フックが届かない環境では、印で頼んだサブエージェントの Run が開かず、見直しの結果が保留に残って dg next と dg gate が進まない。フックがなければ Run は記録せず、見直しの結果だけを見直しの記録として残して、ゲートが通るようにする。
