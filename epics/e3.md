## 概要

README の「AI の実行を Run として記録し、トークン使用量と結果をチケット・イテレーション・プロジェクトで集計する」。Run の型は core に置いてあり（`packages/core/src/model/run.ts`）、コマンドと Adapter と集計を実装する。

## 含む要件（requirements.md）

- 5.9 Run（RN-1〜3）：`runs/` の 1 Run 1 ファイル、取れない値は null、Git に入れるのは完了時の集計だけ。`runs/` の命名はこのときに決める（ADR-002）
- 6.6 作業の実績（MT-1〜4）：`dg run start / finish`、会話記録からの補完（`metrics.read_transcripts`）、Run・Ticket・Epic・Iteration・Project・Agent/Model 単位の集計、Git に入れる記録の制限
- CL-2 の `run start / finish / list`、`metrics show`
- WF-5 Workflow の `steps`（Run の step の語彙）と、step ごとの Action・承認の要否（ADR-003）
- AG-5 Adapter による使用量の取得、AG-6 登録済みの Action（worktree・ブランチ・テスト・PR・マージ）、AG-7 `actions.shell: true` のときだけの任意のシェル
- EX-1・EX-2 Run の open 一覧と `finish --result interrupted`
- SY-5 Run の二重起動を `deguboard-local/locks/` で防ぐ
- UI-4 チケット詳細の Run 一覧、UI-9 Run の実行状況と実績の画面
