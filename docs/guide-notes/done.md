After `git pull --ff-only` brings a merged PR into the main worktree, run `mise run build` there before you run `dg` again, because the hooks and `mise run dg --` run the built dist of the main worktree and `git pull` does not rebuild it. When dg warns that the built CLI in dist/ is old, run again, after the rebuild, the command that printed the warning if its result matters.
Basis: in s35 the dist stayed at an older build, so the merged fix of t944 did not take effect and later writes of dg failed on index.lock. Drop this rule when, for 3 Iterations in a row, no failed or interrupted Run has an error (the error of the Run in dg run list) that comes from dg running an old dist.
