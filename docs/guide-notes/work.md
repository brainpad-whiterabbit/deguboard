When a document or a comment you write tells how to run a command, run the command once exactly as you wrote it (same arguments, from the same directory) before you commit, and write only what actually worked. Do not write a form you have not run.
In a test that compares times, take the expected value from what the test prepared (such as the modification time of the file or record it wrote), not from Date.now() or a new Date() taken separately. Two clocks read at different moments can fall on either side of a second boundary, and the test fails only sometimes.
Basis: in s35, t951 wrote `mise run test -- -u <file>` in development.md without running it, and the review found that it does not narrow to the file; t961 took the expected time from Date.now(), which can differ by a second from the time of the record it prepared.
