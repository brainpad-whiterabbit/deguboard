# ADR-023 画面の入口は VS Code 拡張にし、ブラウザは開発用にする

- ステータス：承認
- 更新日：2026-11-08

## 背景

[ADR-006](ADR-006-ui-and-writes.md) は、画面を `dg serve` が配信するブラウザの画面と VS Code 拡張の両方から最初の版で提供すると決めた。ブラウザを残した理由は、VS Code を使わない業務の利用者がいることだった。e13 で対象をソフトウェア開発に絞ったので、この理由がなくなった。

人が使う画面と、エージェントの入口（CLI と MCP）を分けて決め直す。ブラウザの画面を利用者向けに保つと、ブラウザと VS Code の作りの差、Run の画面、ブラウザだけの書き込みの扱いを 2 か所で保守し続けることになる。

## 決定

### 画面の入口は VS Code 拡張だけにする

- 人が使う画面は VS Code 拡張（サイドバーとエディタのパネル）だけにする。エージェントは CLI（`dg`）と MCP（`dg mcp`）から使う
- `dg serve` は利用者向けの入口から外し、開発用（配置の確認とスクリーンショット）に残す。`test:layout`・`gifs`・Playwright MCP の `?surface=sidebar` が使い、それを支える server パッケージも残す
- Run の画面はなくす（UI-9 を消す）。Run はチケット詳細の Run の節で見て、実績の集計は `dg metrics show` で見る
- 画面の中身（React のアプリと `CommandClient`）は、これまでどおり VS Code の Webview に載せる。書き込みの範囲は [ADR-010](ADR-010-ui-writes-and-agent-requests.md) のまま
- ブラウザ向けに分けていた作り（`surface` の分岐、Run の画面、ブラウザの値の層）は、コードの削除を別の作業で行うまで残るが、利用者向けの約束には含めない

### ADR-006 と ADR-010 の一部を置き換える

- [ADR-006](ADR-006-ui-and-writes.md) の節「Web UI と VS Code 拡張を最初の版から両方提供する」のうち、ブラウザを入口とする部分（「Web ではローカル HTTP サーバー（`dg serve`）が配信し、」・「Web ではそれに値を与える層を 1 枚置く」・「ブラウザは前のまま（…）」）を置き換える。節「画面の書き込みは Core を通す」のうち、画面のタブの Run（UI-9）の項も置き換える。VS Code の `surface`・`CommandClient`・書き込みを Core に通す項は残る
- [ADR-010](ADR-010-ui-writes-and-agent-requests.md) の次の 3 か所を置き換える。頼む小窓の項の「ブラウザと同じくコピーだけ」の部分、入力欄の項の「（ブラウザでは画面）」の部分、「ブラウザ（`dg serve`）も同じ画面の部品で、吹き出しから頼む」の項

## 理由

- e13 で対象をソフトウェア開発に絞り、ADR-006 がブラウザを残した理由（VS Code を使わない業務）がなくなった
- 人の画面を VS Code 拡張の 1 つにすれば、ブラウザと VS Code の作りの差と、利用者向けの画面の保守が 1 つになる
- エージェントの入口は CLI と MCP のままで、`dg` の実体が 1 つである ADR-006 の理由も変わらない
- `dg serve` を開発用に残せば、配置の確認・録画・MCP での確認の経路を失わない
- Run の一覧と実績は、チケット詳細の Run の節と `dg metrics show` で足りる。ブラウザにだけあった Run のタブを残す理由がない

## 採らなかった案

- **Web UI を利用者の入口に残し、両方を提供する（ADR-006）**：VS Code を使わない業務はなくなり、残すと作りの差と二重の保守が続く
- **ブラウザだけを入口にする**：通知・ターミナルへの送信・worktree を VS Code で開く操作（ADR-010・UI-4・UI-12）が使えなくなる
- **`dg serve` を削除する**：配置の確認・録画・Playwright MCP での確認が止まる。開発用に残す
- **Run の画面を VS Code に作る**：左パネルは Run を除く 3 つにしている（ADR-006）。Run は詳細と `dg metrics show` で見れば足りる
