# ADR 一覧

設計判断の記録。書き方と運用は [ADR-001](ADR-001-doc-strategy.md) に従う。

今の仕様の正本は[要件定義書](../requirements.md)で、ADR は判断の理由が要るときだけ番号で引く。ADR は判断ごとに 1 本で、決めたら書き換えない。判断を変えるときは新しい ADR を書き、古い ADR を「置き換え」にして、有効な ADR の表から外し、「置き換え済み」の表に移す（表がなければ作る）。
