# ADR 一覧

設計判断の記録。書き方と運用は [ADR-001](ADR-001-doc-strategy.md) に従う。

今の仕様の正本は[要件定義書](../requirements.md)で、ADR は判断の理由が要るときだけ番号で引く。ADR はテーマごとに 1 本で、小さな変更は本文を直接書き換える。新しい ADR を書くのは大きな方針変更と、1 本が 2 つのテーマに育って分けるときだけ。方針変更では古い ADR を「置き換え」にして残し、下に「置き換え済み」の表を足す。分けるときは元の ADR のテーマを狭めて書き換える。
