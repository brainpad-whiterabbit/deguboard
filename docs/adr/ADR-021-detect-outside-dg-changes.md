# ADR-021 データの dg の外の変更は事後に見つけて書き込みを止め、フックは .git/deguboard の語を含む Bash を粗く止める

- ステータス：承認
- 更新日：2026-11-08

## 背景

t532 で、ツールを使う前のフック（PreToolUse）が Bash のコマンドを字句に分け、`.git/deguboard/` への書き込みだけを見分けて拒む形にした。`python -c`・エディタ・スクリプト・変数を通した書き込みは見分けられない。字句の手がかりを足し続けても塞ぎきれないことは、`gh pr ready`・`merge` の判定で [ADR-019](ADR-019-pr-advance-through-dg.md)・[ADR-020](ADR-020-hook-coarse-raw-command.md) が確かめた。ADR-019 は、守り方を「正しい道の dg のコマンド＋粗い拒否＋事後の検査」の 3 つで組み、事後の検査を後続のチケット（t546）に任せた。

データのリポジトリ（deguboard worktree）には、dg 自身も作業ツリーに変更を残す（`commit.mode` が batch・manual のまとめ待ち）。dg の外の変更は、作業ツリーの変更があることだけでは見分けられない。

## 決定

### dg の外の変更を事後に見つける

- dg が作るコミットは、メッセージの末尾に印のトレーラー `Deguboard-Commit: dg` を持つ。基準の HEAD より後で、リモートの deguboard ブランチにまだないコミットのうち、印のないものを dg の外のコミットとする。リモートから取り込んだコミットは見ない（書いた人の dg が確かめている）
- 作業ツリーは、書き込みのロックを放す前の状態を基準に記録する。記録するのは、変更のあるファイルとその中身のハッシュ。今の作業ツリーが基準と違えば、違うファイル（足した・書き換えた・消した、dg が残した変更が戻された）を dg の外の変更とする
- 基準（最後に確かめた HEAD と作業ツリー）はマシンごとに `deguboard-local/outside-baseline.json` に置く。基準がなければ（初めて確かめるとき・この版に上げたとき）、今の状態を基準にする。dg の外の変更があったまま書き込んだときは基準を進めない
- 確かめるのは、コマンドを実行するたび（runCommand。CLI・MCP・HTTP・VS Code の全入口が通る）。書くコマンドは `OUTSIDE_CHANGES` で止め、読むだけのコマンドは警告を返す。どちらも、どのファイル（とコミット）かと戻し方・取り込み方を示す
- ほかの dg が書き込みのロックを持つ間は作業ツリーが書きかけなので、ロックの外では作業ツリーを見ない（コミットだけ見る）。ロックの中では作業ツリーも見る
- 確かめない場面：ストアを開かない文脈（PreToolUse。t554）、初期化の前に動く `init`、自分で扱う `adopt` と `hook`
- Stop のフック（エージェントが応答を終えたとき）でも確かめ、見つけたら止まらずに続けさせて、エージェントにファイルと戻し方・取り込み方を返す。続けさせた後の Stop では返さない（直せないときに続けさせ続けない。次の書き込みが同じことを伝えて止まる）。ほかのイベントのフックは、dg の外の変更があっても作業を止めない
- 取り込みは `dg adopt` で行う。`dg validate` と同じ検査でエラーがなければ、今の状態を基準にする。未コミットの変更は、まとめ待ちの変更として次の `dg commit`・`dg sync` で dg のコミットに入る。捨てるのは人で、deguboard worktree で `git restore` と `git reset --keep <基準の HEAD>` を使う（基準の HEAD は検査の文に出る）

### フックは .git/deguboard の語を含む Bash を粗く止める

- PreToolUse のフックは、Bash のコマンドを字句に分けて書き込みを見分けない。生のコマンドに `.git/deguboard` の語（区切りは `/` と `\`。`.git/deguboard-local` も含む）がどこかにあれば、読むだけのものも、引用符・コメントの中でも止め、dg の読み書きのコマンドへ案内する。書くツールの `.git/deguboard/` の下への書き込みを拒むのは変えない
- 語として現れない書き込み（`cd .git && rm deguboard/x`・変数・ファイルに書いたスクリプト・任意の言語のコード）は通る。取りこぼしは上の事後の検査が見つける

### 置き換えるもの

- [ADR-020](ADR-020-hook-coarse-raw-command.md) の「フックは字句を伏せずに粗く止める」の節のうち、`.git/deguboard/` への書き込みを拒む判定（t532）を変えない、とした項を、この決定で置き換える

## 理由

- 書かせないことは、シェルの外（エディタ・スクリプト・フックのない環境）まで含めて閉じない。書いたら必ず見つかる形なら、すり抜けても次の dg のコマンドで止まり、データが黙って壊れたまま共有されない
- コミットの印と作業ツリーの基準を組むと、dg 自身のまとめ待ちの変更と dg の外の変更を、`commit.mode` によらず見分けられる。基準をロックの中で記録するので、同じマシンで並べて動く dg の書きかけを取り違えない
- 書くコマンドだけを止めるのは、読むコマンドまで止めると、戻し方を調べる手段（`ticket show`・`validate`）までなくなるため
- フックの判定を語の有無だけにすると、読み違えて通す余地がなく、止めすぎの側にしか倒れない。データを読むのも dg のコマンドで足りるので、止めすぎの害は小さい

## 採らなかった案

- **dg が書いたファイルの一覧を残し、作業ツリーと照らす**：dg がデータに書く場所が多く（ストア・Run の記録・振り直し・マージドライバ）、どれかで記録を漏らすと dg 自身の変更を外の変更と取り違える。書き込みのロックを放す前の状態を丸ごと記録すれば、書く場所によらない
- **リモートにまだない、印のないコミットだけを見る（基準の HEAD を持たない）**：リモートのないリポジトリでは、この版より前の印のないコミットをすべて外のものとみなしてしまう
- **dg の外のコミットを dg が自動で戻す**：人やエージェントが意図して直した変更まで消す。戻すか取り込むかは人の判断にする
- **t532 の字句の見分けを直し続ける**：ADR-019・ADR-020 と同じく、読み違えが通す側に倒れる限り閉じない

## 制限

- 権限管理や偽装の防止はしない（同じリポジトリに書ける人を信頼する。ADR-019）。印のトレーラーを付けたコミットや、基準のファイルを書き換えたものは見つけない
- リモートに push 済みの dg の外のコミットは、取り込んだ側では見つけない（書いたマシンの dg が、push の前の書き込みで見つける）
- 基準はマシンごとなので、同じデータのリポジトリを別のマシンから書き換えたものは、そのマシンの dg が見つける
- dg の外の変更があったまま dg が書いたもの（`hook` など止めないコマンド）は、外の変更と一緒に示される。取り込むか捨てるかを、示されたファイルで決める
