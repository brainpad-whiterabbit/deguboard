# ADR-024 react(immutability) の指摘を直したので oxlint を最新に上げ、版を留めない

- ステータス：承認
- 更新日：2026-11-08

## 背景

[ADR-008](ADR-008-tech-stack.md) は、新しい版の oxlint で増えた React Compiler 系の規則 `react(immutability)` が web の既存コードで失敗するので、oxlint を上げずに留め、「直す作業を起こしてから上げる」と決めた。その作業のチケットがなく、版は 1.90.0 のまま残っていた。

t450 で 2026-11-08 の oxlint 1.92.0 にかけると、失敗は `packages/web/src/components/ask-composer.tsx` の 1 か所だけだった（t360 の 1.91 では 3 か所）。その 1 か所を直し、oxlint を 1.92.0 に上げた。

## 決定

- oxlint は最新の版に上げ、版を留めない。版は今までどおり package.json に固定する（[ADR-008](ADR-008-tech-stack.md)）
- 新しい版で増えた規則が既存のコードで失敗したら、その指摘は上げる PR の中で直す。上げるのを指摘の直しの後に回す形は取らない

### 置き換えるもの

- [ADR-008](ADR-008-tech-stack.md) の「lint は oxlint、整形は oxfmt」の節の項のうち「oxlint は、新しい版で増えた React Compiler 系の規則（`react(immutability)`）が web の既存コードで失敗するので上げずに留める。直す作業を起こしてから上げる」を、この決定で置き換える

## 理由

- 留めた理由は、直す作業を起こしたら解ける。t450 で作業が済んだので、留める理由はなくなった。残すと、版を留める理由がないまま判断だけが残り、版を上げる手順が決まらない
- 版を留めると、新しく増えた規則の指摘（今回は React の不変性の違反）を lint が出さず、web のコードの誤りが検査で見つからない
- 指摘の直しを上げる PR に含めると、版の上げと直しを 1 つの変更で追え、留める判断を次の版ごとに持ち越さずに済む

## 採らなかった案

- **ADR-008 の項を消す**：[ADR-001](ADR-001-doc-strategy.md) は、決めたあとの ADR を書き換えないと決めている。項を消すと、留めていた判断と理由が読めなくなる。失効の印を付けて残す
- **ADR-008 の項を「1.92.0 に上げる」と書き換える**：決めたあとの判断を書き換えることになり、同じく ADR-001 に反する
- **版は留めたまま、規則 `react(immutability)` を off にする**：web の React の不変性の違反を検査で見つけられなくなる

## 制限

- 版を上げても、どの規則を有効にするかは `.oxlintrc.json` が決める。この ADR は版の扱いだけを決め、規則の集まりは決めない
