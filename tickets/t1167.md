## Summary

観点：テスト。tip-merge.test.ts の `blockWorktrees` は `.git/worktrees` を chmod 555 にして一時の worktree を作れなくし、merge-tree の経路が worktree なしで tree を作ることを確かめる。root は権限を無視するので worktree を作れてしまい、「古い経路が null を返す」の確かめで落ちる（コンテナや devcontainer で root のまま回すと起きる）。

## Acceptance criteria

- [ ] root で回しても、このテストが落ちない（権限に頼らずに作れなくするか、作れてしまう環境では理由を書いて飛ばす）
- [ ] root でない環境では、今と同じく merge-tree の経路が一時の worktree なしで tree を作ることを確かめている
