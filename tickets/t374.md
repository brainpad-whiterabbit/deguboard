## 概要

コメント・Markdown・コミットメッセージに書いた t123・s15・e3・p12 などの ID から、チケットの要約を見て詳細を開けるようにする。

## 受け入れ条件

- [ ] エディタの中のチケット ID にマウスを載せると、タイトル・Status・担当が出る
- [ ] Iteration・Epic・Plan の ID にも、それぞれの要約が出る
- [ ] Ctrl/⌘+クリックで、その ID の詳細のパネルが開く
- [x] 存在しない ID には、ホバーもリンクも付かない
- [ ] ソース管理のコミットメッセージの入力欄でも同じように効く
