## 概要

頼む小窓の依頼文を、コピーして貼る代わりに、すでに開いているターミナルの入力に入れられるようにする。ターミナルもエージェントも起動しない（EX-1）。

## 受け入れ条件

- [x] 頼む小窓で、開いているターミナルから送り先を選んで「送る」を押せる
- [ ] 送ると依頼文がそのターミナルの入力に入り、Enter は押されない
- [x] 開いているターミナルがなければ「送る」は出さず、コピーだけになる
- [x] 拡張がターミナルやエージェントを起動しない
- [x] ADR-010 と requirements.md の UI-15 が、送れることに合わせて書き換えてある
