## Summary

s44 の見直し（観点：文書と実装）と t1195 の見直しの範囲外の指摘。t1195 で `ticket list --label` と画面の絞り込みは大文字小文字の違いを同じ名前と読むようになった（`hasAnyLabel`）。ところが packages/core/src/model/labels.ts の `judgeLabelMerge`（書き換えの対象と置き換え）、`judgeLabelRemove`（チケットが持つかの判定）、`labelListView`（count）は、チケットのラベルを完全一致で比べる。そのため、前から `UI` を持つチケットがあるボードでは、`dg label merge ui frontend` がそのチケットを書き換えず（lint が指摘しても呼び直しで直らない）、`dg label remove ui` が通り、`dg label list` の `ui` の count に入らない。usage の「Merge and rename」と ADR-037・TK-13 は、統合は持つチケットをすべて書き換え、絞り込みは大文字小文字を同じ名前と読む、と書く。

## Acceptance criteria

- [ ] チケットのラベルと名前を大文字小文字を区別せずに比べる判定が 1 つの関数にあり、`judgeLabelMerge`・`judgeLabelRemove`・`labelListView` がそれを使う
- [ ] `UI` を持つチケットがあるとき、`label merge ui <to>` がそのチケットを書き換え、`label remove ui` が拒まれ、`label list` の `ui` の count に入ることを、純粋な関数のテストで確かめている
