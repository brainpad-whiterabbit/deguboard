## 概要

見直し（audit-s11、観点：README・文書と実装）。s11 で画面からの書き込みをチケット詳細・設定・同期に限り（UI-7、ADR-010）、ほかの変更はエージェントへの依頼文を作って頼む形にした（UI-15、AG-8、dg ask）。README はそれに追いついていない。

- README.md 12 行の「何ができるか」は画面で「見て操作する」とだけ書き、画面で何でも操作できると読める。dg ask と、画面から頼む入口がない
- README.md 12 行の括弧書き「VS Code のチケット詳細は属性をその場で直す」は、ブラウザのチケット詳細では属性を直せないと読める（実際は編集ボタンからまとめて直せる）
- README.md 56 行の仕様の参照が「UI-2・UI-12〜14」で、UI-7・UI-15 がない
- packages/vscode/README.md（Marketplace 向け）は、右クリックの「エージェントに頼む」がバックログの行だけにあるように書く（13 行）。行・見出し・詳細のタイトルの吹き出し、カンバン・履歴・詳細の右クリックのサブメニュー、タイトル行の「エージェントに頼む」（5 行の説明にない）、コマンドパレット、Ctrl/⌘・Shift+クリックの複数選択と帯、下の入力欄で依頼文を作ってコピーすることが書かれていない

文書と実装のどちらに合わせるかは計画で決める（実装が正本のつもりなら README を直す）。

## 受け入れ条件

- [ ] README.md の「何ができるか」が、画面で直せる範囲（チケット詳細・設定）と、ほかの変更はエージェントに頼むこと（画面の吹き出し・右クリックと dg ask）を書いている
- [ ] README.md のチケット詳細の説明が、ブラウザでも属性を直せることと食い違わない
- [ ] README.md の仕様の参照に UI-7 と UI-15 がある
- [ ] packages/vscode/README.md に「エージェントに頼む」の項があり、吹き出し・右クリック・タイトル行・複数選択・入力欄でコピーすること・データには書き込まないことを書いている
- [ ] mise run check が通る
