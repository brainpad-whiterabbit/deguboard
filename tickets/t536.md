## 概要

ADR-001 の新しい方針に合わせ、`scripts/check-docs.mjs` の大きさの予算を、正本の照らし合わせの検査に置き換えるか足す。コードとテストが参照する要件 ID（`TK-1` など）が requirements.md に存在すること、guide どうしで同じ節が重複していないこと、コードの先頭コメントが指す文書の節が存在すること。見直し役の目で拾っていた文書のずれの一部を機械で拾う。

## 受け入れ条件

- [x] コードとテストが参照する要件 ID が requirements.md にないとき、`mise run check:docs` が指摘する
- [x] guide どうしの同じ見出しの節、または同じ段落の重複を指摘する
- [x] 大きさの予算の扱いが ADR-001 の決定に合っている（残すなら理由、置き換えるなら消す）
- [x] 今のリポジトリで `mise run check` が通る（出た指摘は直すか、別のチケットに起票して理由を書く）
