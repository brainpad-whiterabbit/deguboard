## 概要

観点：設定ファイル。actions.test の describe と英訳は「run_tests の Action が呼ぶコマンド。空なら run_tests は拒否する」だけだが、dg gate の check と dg pr merge の品質ゲートもこの値で回し、空なら判定しない（通す）。設定画面にそのまま出るので、空の意味を取り違えうる。

## 受け入れ条件
