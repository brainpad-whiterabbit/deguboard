## 概要

多言語で使えるよう、dg guide と Skill の文面を英語に統一する。日英の 2 本立ては guide の変更の多さからずれるので採らない。エージェントが書く文章（チケット・PR・コミット・人への返答）は、手順の言語ではなくリポジトリの既存の文章と人の依頼の言語に合わせる。この方針を ADR と要件と規約に書く。

## 受け入れ条件

- [ ] ADR-004 に、guide と Skill を英語で書くことと、2 本立てを採らない理由が書いてある（更新日と一覧も直してある）
- [ ] ADR-004 に、エージェントが書く文章の言語はリポジトリの既存の文章と人の依頼の言語に合わせると書いてある
- [ ] requirements.md の AG-2 が guide と Skill の文面の言語を約束している
- [ ] CLAUDE.md の言語の規約に、guide（packages/cli/src/guide-*.md）と Skill の雛形を英語で書く例外が書いてある
- [ ] mise run check が通る
