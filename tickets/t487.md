## 概要

多言語で使えるよう、dg guide と Skill の文面を英語に統一する。日英の 2 本立ては guide の変更の多さからずれるので採らない。エージェントが書く文章（チケット・PR・コミット・人への返答）は、手順の言語ではなくリポジトリの既存の文章と人の依頼の言語に合わせる。この方針を新しい ADR と要件と規約に書く。ADR は決めたら書き換えないので（ADR-001）、ADR-028（エージェントと状態の記録）を直接書き換えず、新しい ADR に判断を書く。ADR-001 の言語の項（文書は日本語で書く）と食い違うなら、ADR-001 は直接書き換えてよい例外なので ADR-001 を直す。

## 受け入れ条件

- [ ] 新しい ADR（番号はマージ前に main の最大番号を確かめる）に、guide と Skill を英語で書くことと、2 本立てを採らない理由が書いてあり、docs/adr/README.md の有効な ADR の表に足してある
- [ ] 同じ ADR に、エージェントが書く文章の言語はリポジトリの既存の文章と人の依頼の言語に合わせると書いてある
- [ ] 既存の ADR（ADR-001 の言語の項など）と食い違わない。ADR-001 以外の ADR の判断を変えるときは、ADR-001 の書き方で置き換えの印を付けてある
- [ ] requirements.md の AG-2 が guide と Skill の文面の言語を約束している
- [ ] CLAUDE.md の言語の規約に、guide（packages/core/src/guide/guide-*.md）と Skill の雛形を英語で書く例外が書いてある
- [ ] mise run check が通る
