## 概要

Adapter（AG-5）が Claude Code のフックの定義を持ち、`dg hooks install` がそれを設定に書く。SessionStart で `DEGUBOARD_ACTOR=agent` を環境に入れる。サブエージェントの開始と終了のフックで、そのサブエージェントの Run を開き閉じ、フックの入力から取れるセッション ID と記録のパスを Run の `transcript` に残す。Stop で、このセッションが開いたままの Run を閉じる。フックのハンドラは `dg hook <event>` のコマンドで、標準入力の JSON を読む。使えるイベントと入力の項目は実装時に Claude Code の版で確かめ、取れない項目は null で残す。dg はエージェントを起動も監視もしない（EX-1）。

## 受け入れ条件

- [x] `dg hooks install` が Claude Code の設定にフックを入れ、もう一度実行しても重複しない。`dg hooks uninstall` で外せる。フックの定義とハンドラ（`dg hook <event>`。標準入力の JSON を読む）は claude-code の Adapter に閉じ、ほかの Adapter は持たなくてよい（AG-5）
- [x] SessionStart のフックが `CLAUDE_ENV_FILE` に `export DEGUBOARD_ACTOR=agent` とセッション ID・記録のパスを export 付きで書き、そのセッションの `dg` の既定の主体が agent になる（`--actor human` で上書きできる）。`run start`・`ticket claim` は、明示されなければその値を Run のセッション ID と記録の場所に使う。環境変数はサブエージェントの Bash にも届く（2026-11-07 に Claude Code 2.1.318 で確かめた）
- [x] PostToolUse（matcher は Agent）のフックが、tool_input.prompt の先頭の印 `deguboard: ticket=<id> step=<step>` と tool_response.agentId を読み、印があればチケット・step・agent（claude-code）・モデル（resolvedModel）・セッション ID・agent_id を埋めた Run を開き、記録の場所を `<親の記録のディレクトリ>/<session>/subagents/agent-<agentId>.jsonl` にする（同じチケット・step の二重起動は拒否されて警告）。印がなければ何もしない。SubagentStart は使わない（並べて起動すると、その時点で親の記録にもサブエージェントの記録にも呼び出しがない）
- [x] SubagentStop のフックが、agent_id で Run を引き、agent_transcript_path の最初のメッセージの印でチケットと step を照合し、違えば正しい方に直し、記録の場所を agent_transcript_path にする。そのファイル全体から使用量・モデル・ツールの回数を取り、step ごとの事実の規則（見直し：結果が記録されていれば success。実装：PR があれば success。手直し：開始より後の push があれば success）で結果を決めて閉じる。印のある Run がなく、サブエージェントが自分で run start を呼んでいたら（移行期）、記録の中の run start・ticket claim の結果に ID が出た Run のうち、同じセッションで記録の最初の行より後に始まり、ほかのサブエージェントの記録に結び付いていないものに記録の場所を結び付け、閉じていれば取り直す。前景の起動で先に結び付いていれば、PostToolUse はもう 1 本開かない
- [x] SessionEnd のフックが、このセッションの見直しと手直しの Run のうち開いたままのものを `interrupted` で閉じる。実装の Run は PR の記録で閉じる今の形を残す。Stop のフックは使わない
- [x] 数える範囲は、サブエージェントの記録ならファイルの先頭から、親の記録なら Run の started_at から finished_at まで（t529 の形）
- [x] フックを入れていない環境（フックのない製品を含む）では主体は今の申告（`--actor`・`DEGUBOARD_ACTOR`）に落ちる。ADR-004・AG-1 の書き方と合う
- [x] `run start`・`ticket claim` の `--transcript`（HTTP・MCP の入力を含む）が読ませられるパスを、その Adapter の会話記録の置き場所の下に限るかを決め、限るなら置き場所の外のパスを拒否する
- [x] requirements（RN-5・RN-6・AG-1・MT-2 など）と ADR-005 の該当の記述が新しい形と矛盾しない（ADR は ADR-001 の書き方で積む）。guide-overview と README に `dg hooks install` と印の書き方の案内があり、`mise run check` が通る
