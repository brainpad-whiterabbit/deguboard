## 概要

Adapter（AG-5）が Claude Code のフックの定義を持ち、`dg hooks install` がそれを設定に書く。SessionStart で `DEGUBOARD_ACTOR=agent` を環境に入れる。サブエージェントの開始と終了のフックで、そのサブエージェントの Run を開き閉じ、フックの入力から取れるセッション ID と記録のパスを Run の `transcript` に残す。Stop で、このセッションが開いたままの Run を閉じる。フックのハンドラは `dg hook <event>` のコマンドで、標準入力の JSON を読む。使えるイベントと入力の項目は実装時に Claude Code の版で確かめ、取れない項目は null で残す。dg はエージェントを起動も監視もしない（EX-1）。

## 受け入れ条件

- [ ] `dg hooks install` が Claude Code の設定にフックを入れ、もう一度実行しても重複しない。`dg hooks uninstall` で外せる
- [ ] SessionStart のフックで、そのセッションの `dg` の既定の主体が agent になる（`--actor human` で上書きできる）
- [ ] サブエージェントの開始と終了のフックが Run を開き閉じ、セッション ID を Run に、記録のパスをマシンごとのローカル（ADR-005）に残す。開くときの step とチケットは、フックの入力か環境から決め、決められなければ開かずに警告する
- [ ] Stop のフックが、このセッションが開いたままの Run を `interrupted` で閉じる
- [ ] フックの定義とハンドラは Adapter に閉じ、ほかの Adapter は持たなくてよい（AG-5）
- [ ] SessionStart のフックが、そのセッションの会話記録のセッション ID と記録のパスを、そのセッションの `run start`・`ticket claim` が Run に残せるように渡す（サブエージェントは開始のフックの入力から取り、親の値は使わない）
- [ ] Stop のフックが Run を閉じることと、照合が手直しの Run を区切りで閉じる約束（RN-6）が矛盾しないよう requirements を書き換えている
- [ ] ADR-005 の「見直し役は見直しの前に run start で開く」と guide-review の見直し役の Run の開け閉めが、フックが開閉する形に書き換わっている
- [ ] フックを入れていない環境（フックのない製品を含む）では主体は今の申告（`--actor`・`DEGUBOARD_ACTOR`）に落ちる。guide と Skill の `--actor agent` を外すなら、その環境で agent の操作が human として通らないようにしている（ADR-004・AG-1 の書き方も合わせる）
- [ ] guide-overview と README に `dg hooks install` の案内があり、`mise run check` が通る
