## Summary

今の品質ゲートは作業ブランチの先端だけを検査し、main に入る形（main を取り込んだ後の組み合わせ）は検査していない（`--for merge` が見るのは衝突がないことの mergeable だけ）。`dg gate --for merge` に「作業ブランチの先端が base（main）の今の先端を含む」の条件を足し、その先端で `actions.test` が通ることを求める。マージした後の全体の検査はしない。

## Acceptance criteria

- [ ] `dg gate --for merge` が、作業ブランチの先端が base の今の先端を含まないときに、満たさない条件と理由を返す（判定の組み合わせを純粋な関数のテストで網羅する）
- [ ] 条件を満たした先端での `actions.test` の結果が check の判定に使われ、`dg pr merge` はその先端に固定してマージする
- [ ] requirements.md の EX-6 と ADR-026 を、マージの条件が変わったことに合わせて直す
