## Summary

手順で行う段階（check・audit・retro・リリースの手順）を `dg checkpoint` の関所で判定し、通った記録を Iteration に根拠付きで残す。記録が会話・人・マシンをまたいで効くので、`dg flow next` の resume をなくす。

## Acceptance criteria

- [x] `dg checkpoint <段階>` が段階の値で判定し、通ったら Iteration の `checkpoints` に名前・日時・主体・承認者・根拠が足されることがテストで示されている
- [x] `dg flow next` が記録と根拠（決定版 06 の表）で段階を終えたかを決め、根拠が変わった記録と `iteration reopen` より前の記録は数えない
- [x] `--resume` がなくなり、止まる判定（同じ段階が事実も変わらずに続いたら止める）が `deguboard-local/` に置かれている
- [x] Iteration のない流れは assign で Iteration を決め、assign の記録だけがローカルに書かれる。Epic への audit がなくなっている
- [x] check・audit・release・retro の guide が関所を呼び、requirements の EX-8・IT-1 と ADR-030 が直っている
- [x] 関所の記録が消さずに足され、`dg history` に出る
- [x] 関所を呼び忘れると `dg flow next` が同じ段階を返し続け、止まる判定が止めることがテストで示されている
