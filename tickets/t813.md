## Summary

設定画面の各項目で説明の全文を出すのをやめ、core が渡す要約・例・空のときの動き・選択肢ごとの説明で短く出す。全文は「詳しく」に残し、情報は減らさない。guide.notes.* はまとまりの説明 1 つと表にする。

## Acceptance criteria

- [x] 各項目は要約 1 行をいつも出し、全文は「詳しく」で開ける
- [x] 例は入力欄のプレースホルダに、空のときの動きは欄の下の 1 行に出る
- [x] 選択肢のある項目は選んでいる値の説明だけを出し、値を変えると説明も替わる
- [x] guide.notes.* は説明 1 つと、差し込む先ごとの行の表で出る（左パネルの幅でも読める）
- [x] 検索は表示名・キー・要約・詳しい説明のどれにも当たり、詳しい説明だけに当たった項目は「詳しく」を開いて出す
- [x] PR の本文に、エディタ幅と左パネル幅のスクリーンショットを載せる
