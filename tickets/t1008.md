## Summary

今の始め方のボタンは引数なしの dg init を流すので、データを別のリポジトリに置くチームの新しいクローンでは、origin にボードがないと新しいボードを作ってしまう。チェックリストのボードの項目で、別のリポジトリのボードを指定して取り込めるようにする。あわせて README の導入の手順を、チェックリストで進む形に直す。

## Acceptance criteria

- [ ] remote にボードがないとき、ボードの項目は「新しいボードを作る」と「チームのボードは別のリポジトリにある」を選ばせ、後者はデータのリポジトリ（URL か remote 名）とブランチを入れて --data-remote・--data-branch 付きで dg init する
- [ ] remote にボードがあるときも、別のリポジトリのボードを指定する道を条件付きの別の道として出す
- [ ] README.md と README.ja.md の導入の節が、左パネルのチェックリストで進む手順になり、dg コマンドがエージェントにも要ることが分かる（今の「Terminal users only」の書き方を直す）
- [ ] 別のリポジトリを選んだときに渡す引数をテストで確かめる
