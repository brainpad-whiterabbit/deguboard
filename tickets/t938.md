## Summary

設定画面の振り返りの節だけが、三角の開け閉めで 2 段に畳む別の作りになっていて、ほかの項目と見た目がそろっていない。読むだけ（入力欄を置かない）のまま、観点をほかの項目と同じ行で、指標をその下の子の行で出す。UI の案は会話で作った artifact「deguboard 設定画面：振り返りの節をそろえる案」。

## Acceptance criteria

- [ ] 観点の行に名前・ID・指標の数が出て、問いが途中で切れずに出る
- [ ] 指標は ID と数え方の最初の文を出し、全文・出どころ・測れないものは「詳しく」に畳む
- [ ] 観点と指標は config の値を書いたまま出し、表示言語で訳さない
- [ ] 指標のない観点に「指標なし」の札と、振り返りで提案されて承認すると出ることの 1 行が出る
- [ ] 検索が観点と指標に今と同じく当たり、当たった指標の「詳しく」を開いて出す
- [ ] PR の本文に、変えた画面のスクリーンショットを載せる
