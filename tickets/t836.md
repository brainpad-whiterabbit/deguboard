## Summary

見直し（s30、テスト）。test/layout/ask-menu.layout.ts の「帯を押すと…詳細を開き選択を外す」は、行が出た直後に boundingBox で 1 度だけ測った座標を page.mouse.click で押し、そのあとの属性や URL も 1 度しか読まない。s30 でカンバンの見出しが目標・何日目・件数を非同期に出すようになり、行が動くとクリックが行の本体に当たって詳細へ移り、次の操作が 60 秒のテストのタイムアウトまで待って落ちる（負荷のある中で 1 度起きた）。page.close も finally にない。

## Acceptance criteria

- [x] 帯を押す前に、描画が落ち着くのを待ってから座標を測る
- [x] 押したあとの選択と URL を、待って確かめる形で読む
- [x] 外れたときに短い時間で理由の分かる失敗になり、失敗してもページを閉じる
- [x] `mise run test:layout -- test/layout/ask-menu.layout.ts` が通る
