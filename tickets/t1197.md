## Summary

s43 の見直し（観点：構成）の指摘。`dg label axis remove` の判定（名前と `--all` は片方だけ、軸がなければ見つからない、語彙が残る軸は拒む）が、packages/core/src/commands/label.ts の `labelAxisRemove` の書き込みの中に直に書かれている。組み合わせは git を通す label.test.ts でしか確かめていない。規約は、事実から結果を決める処理を git・gh・ファイルを読まない関数に置き、組み合わせをその関数のテストで網羅し、git を通す結合テストは経路の代表だけにすると定める。同じファイルの語彙の操作は model/labels.ts の `judgeLabel*` に判定を分けてあり、軸の操作だけがこの形から外れている。振る舞いは変えない。

## Acceptance criteria

- [x] `dg label axis remove` の判定（名前と `--all` の組み合わせ、軸がない、語彙が残る）が、git とファイルを読まない関数にあり、コマンドの定義はそれを呼ぶだけになっている
- [x] 判定の組み合わせを、その関数のテストで確かめている。git を通すテストは経路の代表だけになっている
- [x] `dg label axis remove` の結果と誤りの文が、変更の前と同じである
