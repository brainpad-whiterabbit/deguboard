## Summary

観点：アーキテクチャ。CLAUDE.md は dg の出力（エージェントと利用者が読む文字列）を英語で書くと決めている。一方、core の `ResolvedField.field`・`ConflictedField.field` は本文を日本語の識別子 `本文` で表し、`dg sync --json` の `data.resolved[].field` と `data.conflict_fields[].field` にそのまま出る（警告の文だけは `body lines` に読み替えている）。v0.24.0 より前からある。識別子は `body` にする（ticket show の body と同じ名前で、frontmatter の鍵とぶつからない）。JSON の出力だけでデータには保存しないので、移行は要らない。
