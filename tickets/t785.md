## Summary

観点：アーキテクチャ。CLAUDE.md は dg の出力（エージェントと利用者が読む文字列）を英語で書くと決めている。一方、core の `ResolvedField.field`・`ConflictedField.field` は本文を日本語の識別子 `本文` で表し、`dg sync --json` の `data.resolved[].field` と `data.conflict_fields[].field` にそのまま出る（警告の文だけは `body lines` に読み替えている）。v0.24.0 より前からある。JSON の形が変わるので、読み手（guide・Skill・VS Code）と要件 SY-4 への影響を決めてから直す。

## Acceptance criteria

- [ ] `data.resolved` と `data.conflict_fields` の本文の識別子をどうするかが決まり、そのとおりになっている
- [ ] 識別子を変えるなら、guide・VS Code の通知・テストが新しい識別子で動く
