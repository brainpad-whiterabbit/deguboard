## 概要

左パネルのカンバンの行は担当の名前（例 eiki.kitajima/agent）に約 84px を取り、タイトルが途中で切れる。 担当を右端の印にし、人は頭文字の丸、agent は持ち主の丸と agent の種類のアイコン（Claude Code・Codex・汎用）を並べて、誰のどの agent かがわかるようにする。 種類は主体 ID に入っていないので、チケットの実行中か最後の Run の agent（RN-1）から取る。自分のものも出すので、自分以外だけ頭文字を出すバックログの t159 とは規則が違う。 案は https://claude.ai/artifact/VEkpp9mLBhWix864ZNFUtw の L

## 受け入れ条件

- [ ] 左パネルのカンバンの行は担当の名前の列を出さず、右端の上の段（Plan の番号の左）に担当の印を出す
- [ ] 担当が人なら頭文字の丸だけを出し、担当が agent なら持ち主の人の頭文字の丸と agent のアイコンを並べる
- [ ] agent のアイコンは、Run の agent が claude-code なら Claude、codex なら Codex、それ以外か Run がなければ汎用のエージェントのアイコンにする
- [ ] チケットごとの agent の種類（実行中の Run があればその agent、なければ最後の Run の agent）は core のコマンドの出力に載り、CLI・HTTP・Webview の 3 経路で同じ値が返る
- [ ] 印にホバーすると担当の主体 ID と agent の種類（例「eiki.kitajima/agent · claude-code」）を読める
- [ ] Claude・Codex のアイコンは各社の公式の画像を、使い方の決まりに沿って拡張と web に同梱する
- [ ] requirements.md の UI-2 と、該当する Run・チケットの出力の約束を直す
- [ ] 変えた画面の幅 300px のライトとダークのスクリーンショットを PR に載せる
