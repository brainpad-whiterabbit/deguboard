## 概要

t444 で、`ticket update --pr`・照合の PR 発見・unclaim・`--without-branch` の done/review で実装の Run を閉じるようにした。しかし `ticket move <id> abandoned`（branch の有無によらず）と、branch のあるチケットを PR なしで人が `ticket move done` にしたときは、実装の Run が開いたまま残る。これらの契機でも閉じる（abandoned は `failure`、done は `success`）。p63 の t444 の見直しで出た範囲の外の指摘。

## 受け入れ条件

- [x] `ticket move <id> abandoned` で、開いたままの実装・手直しの Run が `failure` で閉じる
- [x] branch のあるチケットを PR なしで `ticket move <id> done` にしたとき、開いたままの実装の Run が `success` で閉じる
- [x] 閉じた Run はチケットの変更と同じ書き込みに入り、`ticket move --help`・RN-6・ADR-005 に契機を書く
- [x] bare リモート付きのテストで確かめる
- [x] mise run check が通る
