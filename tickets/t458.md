## 概要

README の使い方の GIF 5 本は、日本語の画面と日本語のチケット名で録っている。README を英語にすると（readme の票）英語の文に日本語の画面が並ぶので、画面の文言・チケット名・Iteration 名・ターミナルの台詞を英語にして録り直す。dg serve の画面は data-language がないと日本語になるので、録る仕組みが言語を渡せるようにする。

あわせて、今の GIF は 760x460 の等倍で撮っていて README の表示幅（560px）では文字がにじむので、文字がくっきり読める解像度で作る。実画面の録画でなく、実際の UI に近い画面を生成した GIF でよい。README.ja.md も同じ英語の GIF を使う（t468 を統合）。

## 受け入れ条件

- [ ] 台本のチケット名・Iteration 名・受け入れ条件・ターミナルの台詞が英語
- [ ] 録った画面の見出し・ボタン・ラベルが英語で出ている（mise run gifs が英語で撮れる）
- [ ] GIF の幅が 1120px 以上（README の表示幅 560px の 2 倍以上）で、文字の輪郭がにじまない
- [ ] 画面は実際の deguboard の UI（左パネル・チケット詳細）と同じ配置・色・部品になっている
- [ ] packages/vscode/images/ の 5 本が決めた秒数と大きさの上限に収まり、mise run check が通る（大きさの上限を変えたら、スクリプトのコメントと docs/development.md も直す）
