## 概要

ストアを開くと、全チケットの frontmatter をコメントを保つ YAML の Document として解析し（約 330ms）、Run の JSON もわざわざ Document に載せ替えている（約 120ms、JSON.parse 自体は 7ms）。Document は書き込みにしか要らないので、読みは素のデータにし、書くときにファイルから Document を作る。CLI と常駐の入口の最初の読み込みが速くなり、索引をディスクに残すチケットの前提になる。検討書の案 B。

## 受け入れ条件

- [x] 読み込んだ Doc は YAML の Document を持たず、読みの結果（data・body・Issue）は今と同じ
- [x] 書き込みは今と同じくコメントとキー順を保つ（今のテストが通る）
- [x] Run の JSON は YAML の Document を経ずに読み書きする
- [x] ストアを開く時間を入れる前と比べて測り、PR の本文に書く
