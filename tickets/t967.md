## Summary

guide のトピック `config` と Skill `/dgconfig` を足し、左パネルの上の Ask（対象なし）の候補に出す。項目の説明（意味・今の値・既定の値・範囲。おすすめの値は、リポジトリから根拠を示せるときだけ根拠と一緒に出す）と変更をエージェントに頼める。変更はどれも、前と後の差とチームか個人（`--local`）かを見せて人の承認を得てから書く（設定画面の `CONFIRM_KEYS` は動かさない）。

設定画面の行から頼む分は t968 に分ける。

## Acceptance criteria

- [x] `dg guide config` が、項目の説明（意味・今の値・既定の値・範囲。おすすめの値は、リポジトリから根拠を示せるときだけ根拠と一緒に出す）と変更の手順を出す。変更は、項目ごとの前と後の差とチームか個人（`--local`）かを見せて人の承認を得てから `dg config set` で書き、`retro.perspectives` は `dg retro` に回す
- [x] `dg skill install` が `/dgconfig` を配り、`SKILL_SUMMARY` に説明の文がある
- [x] 左パネルの上の Ask（対象なし）の候補に設定を頼む候補が出て、`/dgconfig` を呼ぶ依頼文を返す。候補の名前は画面の表示言語に訳される
- [x] 変えた約束が requirements.md の該当の項（UI-15・AG-2 など）に反映されている
- [x] guide・候補・依頼文をテストで確かめている
