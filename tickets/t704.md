## Summary

t703 の左端の帯を押したまま上下になぞり、通った行をまとめて選ぶ・外す（UI 案 B の後半）。なぞって選べるのは左端の帯から始めたときだけにし、行の本体を押したときのクリックや文字の選択と取り違えない。なぞって選ぶのはマウスとペンだけで、タッチはスクロールのままにする。UI 案: https://claude.ai/artifact/RDUothivMbJrmhtxkquLYP

## Acceptance criteria

- [x] 帯を押したまま上下になぞると、通った行をまとめて選ぶ
- [x] 選んである行からなぞり始めると、通った行を外す
- [x] 帯の外（行の本体）から始めたドラッグでは行を選ばない
- [x] なぞって選べるのはマウスとペンだけ。タッチで帯をなぞっても選ばず、一覧のスクロールになる
- [x] なぞりながら一覧の上端・下端に来ると一覧がスクロールし、見えている範囲の外の行まで続けて選べる
- [x] t703 と同じ 4 か所の行（カンバン・バックログ・詳細の中の行・履歴）でなぞって選べる
- [x] 上の動きを画面のテストで確かめる
