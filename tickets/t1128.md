## Summary

テストを回す時間がチケットの処理のボトルネックかどうかを、s41 では会話記録（transcript）を手で集計しないと判断できなかった。Adapter が会話記録から数える値（使用量・ツールの回数・待った秒数、MT-1）に、検査とテストのコマンドを前景で回していた秒数を加え、dg metrics show で Iteration やチケットごとに集計できるようにする。数えるコマンドは config に足す一覧で決める（既定は actions.test・actions.light_test・dg gate --only check。このリポジトリは mise run test:related と mise run test を足す）。数えるのは claude-code の Adapter だけで、背後で回したコマンドは数えない。

## Acceptance criteria

- [ ] claude-code の実装・手直し・見直しの Run に、数えるコマンドを前景で回していた秒数が残り、ほかの Adapter の Run では null になって欠けた数に入る（RN-2）
- [ ] dg metrics show で、秒数の合計と作業時間（active_seconds）に対する割合が出る
- [ ] 数えるコマンドの一覧を config の項目として足し、既定は actions.test・actions.light_test・dg gate --only check にする。このリポジトリの config に mise run test:related と mise run test を足す
- [ ] requirements.md の RN-1・MT-1・MT-3 と 5.10 の設定の項を、約束の範囲で直す
- [ ] どのコマンドを検査とテストに数えるかの見分けを、会話記録を読まない関数のテストで網羅する
