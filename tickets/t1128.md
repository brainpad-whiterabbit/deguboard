## Summary

テストを回す時間がチケットの処理のボトルネックかどうかを、s41 では会話記録（transcript）を手で集計しないと判断できなかった。Adapter が会話記録から数える値（使用量・ツールの回数・待った秒数、MT-1）に、検査とテストのコマンドを回していた秒数を加え、Run と dg run recent で見られるようにする。

## Acceptance criteria

- [ ] 実装・手直し・見直しの Run に、検査とテストのコマンドを回していた秒数が残る
- [ ] dg run recent で、チケットごとの秒数の合計と、Run の時間に対する割合が見える
- [ ] requirements.md の RN-1 と MT-1 を、約束の範囲で直す
- [ ] どのコマンドを検査とテストに数えるかの見分けを、会話記録を読まない関数のテストで網羅する
