## Summary

見直し（s41 の 2 回目）の観点「README」。docs/usage.md の Count tokens の節と docs/how-it-works.md は、会話記録から数えるのが使用量（とツールの回数）だけと読める。一方、要件 MT-1〜MT-3 では、metrics.read_transcripts が決めるのは使用量・ツールの回数・待った秒数・検査とテストを前景で回した秒数（check_seconds）で、check_seconds は claude-code の Run だけが数え、数えるコマンドは config の metrics.check_commands で足せる。dg metrics show は check_seconds と check_ratio を出す。日本語版も同じ。t1128 の変更で利用者に見える計測が増えたのに、usage を同じ PR で直していない。
