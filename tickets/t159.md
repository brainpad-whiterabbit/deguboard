## 概要

左パネルのバックログの行は、どれも同じ担当者（自分）の名前を約 90px で出し、そのぶんタイトルが 2 行目の途中で切れる。 画面は操作している人のユーザを知らないので、core のコマンドの出力に載せ、自分のものは出さず、別の人だけ頭文字の丸で出す。 案は https://claude.ai/artifact/NvxvcWgWWfh9ReCwbaZsQE の A3

## 受け入れ条件

- [ ] 画面は操作している人のユーザを core のコマンドの出力から知り、CLI・HTTP・Webview の 3 経路で同じ値が返る
- [ ] 左パネルのバックログの行で、担当者が自分か自分の agent のときは担当者を出さない
- [ ] 担当者が別の人のときは頭文字の丸で出し、全名をツールチップで読める
- [ ] 担当者を出さない行では、空いた幅がタイトルに回る
- [ ] requirements.md の該当の約束を直す
- [ ] 変えた画面の幅 300px のライトとダークのスクリーンショットを PR に載せる
