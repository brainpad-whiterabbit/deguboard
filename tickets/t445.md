## 概要

人のレビューの後の手直しはチケットの操作がなく、手順書の `run start fix` に頼っている。自分が claim 済みのチケット（in_progress か review で PR あり）をもう一度 claim すると手直しの開始とみなし、fix の Run を開く。閉じ損ねた Run は Git の事実の区切りで閉じる。修正ループでサブエージェントが直すときは今までどおり `run start fix`。

## 受け入れ条件

- [x] 自分が claim 済みで PR のあるチケットを claim すると、step のうち `opens_on: reclaim` のもの（なければ `fix`）の Run が開く。ほかの主体の claim は今までどおり拒否する
- [x] claim で `--retry-reason` を渡すと Run の `retry_reasons` に入る
- [x] 開いたままの手直しの Run を、`dg sync` が次の区切り（次の Run の開始・PR の ready・マージ）を見たときに、それまでの最後の push の時刻で閉じる
- [x] 同梱のテンプレートの手直しの step に `opens_on: reclaim` が付く
- [x] `dg guide` の review・run と requirements・ADR-005 を合わせて直し、振る舞いを bare リモート付きのリポジトリでテストする
