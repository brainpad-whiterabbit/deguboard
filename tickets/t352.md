## 概要

観点=テスト。対象=packages/web/src/components/ask-composer.test.tsx の「続けて押したコピーは最後の 1 回だけ」（setTimeout 100ms）と「開き直しの復元ではコピーしない」（setTimeout 50ms）。食い違い：コピーが来ないことを固定の待ち時間で確かめているので、遅れてコピーが来る不具合を遅い環境で見逃し、全体が遅いと拾えないこともある。copySeq の判定は非同期の then の中にある。

## 受け入れ条件

- [x] 2 つのテストが固定の待ち時間を使わず、解決を制御できる Promise などで順序を決めて、すべて解決した後に回数を数える
- [x] copySeq の破棄を壊すと、そのテストが落ちる
- [x] mise run check が通る
