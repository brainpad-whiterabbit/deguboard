## Summary

拡張は起動時に入れてある古い dg の Skill を更新するだけで、新しく増えた Skill（dgexplain など）は案内しない。dg の Skill を 1 つ以上入れてある置き場所（リポジトリと個人）で、同梱の dg にあって入っていない Skill を info 通知で案内し、人が選べば足りない Skill だけを書く。自動では足さない。dg next・brief・hooks check の警告は変えない。

## Acceptance criteria

- [x] dg の Skill を 1 つ以上入れてある置き場所で、同梱の dg にあって入っていない Skill があると、起動時に置き場所ごとに 1 件、その置き場所と Skill の名前を並べた info 通知が出る
- [x] dg の Skill を 1 つも入れていない置き場所と、dg が配らない Skill（利用者が自分で作った Skill）は案内の対象にならない。同じ agent のほかの置き場所（リポジトリと個人）に入っている Skill も案内の対象にならない
- [x] 通知の Install を選ぶと足りない Skill だけを書き、入れてある Skill（手を加えたものも）は変わらない
- [x] 通知の Don't show again を選ぶと、その Skill の名前を拡張の globalState に覚え、以後その名前の Skill は案内しない。別の名前の Skill が増えたときは案内する
- [x] dg next・dg brief・dg hooks check の出力は変わらない
- [x] requirements.md の AG-2 に、拡張が入れていない同梱の Skill を案内することが書かれ、skill-files.ts の「足りないことは知らせない」旨のコメントが今の振る舞いに合っている
