## Summary

dg metrics show は Run だけを数えるので、フックの失敗などで Run がまるごと欠けた done のチケットは、合計にも欠けの数にも出ず、使用量が実際より少なく見える。lint の「PR があるのに実装の Run がない」は、終わっていないチケットと閉じていない Iteration に限られる。

## Acceptance criteria

- [ ] metrics show は、絞り込みに合う done のチケットのうち、実装の Run が 1 件もないものを示す
- [ ] 閉じた Iteration で絞り込んだときも示すことをテストで示す
- [ ] requirements.md の MT-3 に、Run のないチケットを示すことを 1 文で足す
