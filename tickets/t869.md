## Summary

見直し（s31、依存・設定ファイル・文書と実装）。ADR-008 と ADR-027 は dg を npm に出さないと決めているが、packages/cli（`@deguboard/cli`）・core・server の package.json に `"private": true` がなく、誤って `pnpm publish -r` すると出せる。cli には npm に出すための `files`（`!dist/guide-*.md` など）・`keywords`・`homepage`・`bugs` が残る。npm に出さない判断は ADR-008 と ADR-027 の両方の「採らなかった案」に書かれ、skill-files.ts のコメントは「npm の dg」と書く。

## Acceptance criteria

- [ ] cli・core・server の package.json が private で、npm に出すためだけの設定が残っていない（残すなら理由がコメントか文書にある）
- [ ] npm に出さない判断の「採らなかった案」が 1 つの ADR にだけある
- [ ] コードのコメントが npm から配る dg を前提にしていない
