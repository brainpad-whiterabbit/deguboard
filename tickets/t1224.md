## Summary

rule で置く規則（in_progress・review のチケットの Iteration は active）を、着手のほかの経路でも守る。作業中のチケットを planned・closed の Iteration に移す操作と、作業ブランチを見て todo を in_progress に進める照合が、今は Iteration を見ない。

## Acceptance criteria

- [ ] iteration add と ticket update --iteration は、in_progress・review のチケットを active でない Iteration に入れるのを拒否する
- [ ] 照合は、Iteration が active でない todo のチケットを前に進めず、条件を満たさない境目と同じ形で報告する
- [ ] iteration add と ticket update のヘルプに規則を書く
