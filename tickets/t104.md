## 概要

観点はテスト。packages/core/test/helpers/git-fixture.ts の cleanup は git の終了を待ってから rm するが、git 2.55 は push を受けた receive-pack と commit・fetch で git maintenance run --auto --detach を起動し、呼んだ git の後も動く。並列に検査を走らせたとき merge.test.ts が ENOTEMPTY（remote.git/info）で落ちた。receive 側には環境変数が渡らないので remote.git の設定が要る

## 受け入れ条件

- [ ] fixture の bare リモートに receive.autogc false などを入れ、clone 側の環境で maintenance.auto と gc.auto を止める
- [ ] 後片付けの rm が再試行する
- [ ] development.md の fixture の説明が合っている
