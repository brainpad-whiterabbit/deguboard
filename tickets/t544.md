## 概要

照合が終わったチケット（done・abandoned）に開いたままの Run を閉じるのは fix だけで、implement は閉じない。別のマシンで abandoned になった・強制の unclaim で todo に戻った・別の主体の claim になったチケットの implement の Run は、このマシンで PR も来ないまま開いたまま残る。RN-6 のチケットの操作による閉じ方は、操作したマシンの実行中の Run にしか効かない。

## 受け入れ条件

- [ ] 照合が、終わったチケットに開いたままの implement の Run を閉じる。abandoned は failure、done は ticket move と同じ結果（t499 と揃える）（テストで確かめる）
- [ ] todo に戻ったチケットか、別の主体の claim になったチケットの implement の Run も failure で閉じる（テストで確かめる）
- [ ] sync --help と RN-6 の記述がコードと一致する
- [ ] mise run check が通る
