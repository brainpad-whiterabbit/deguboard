## 概要

SY-4。今は同期で競合すると rebase を中止して報告するだけ。同じチケットの別々のフィールドを変えた競合を自動で解けるよう、 frontmatter のフィールド単位のマージドライバを入れる。

## 受け入れ条件

- [ ] dg init（と既存リポジトリでの sync）がマージドライバを git config と deguboard ブランチの .gitattributes に登録する
- [ ] 同じチケットの別のフィールドを双方で変えた競合を、dg sync が両方の変更を残して自動で解く
- [ ] 同じフィールドを双方で変えた競合は、従来どおり rebase を中止してローカルのコミットを残し報告する
- [ ] bare リモート付きの一時リポジトリでテストしている
- [ ] requirements.md の SY-4 の「予定」を外している
