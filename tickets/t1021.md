## Summary

t1007 の見直しで範囲の外として残した件。左パネルの帯で「このリポジトリでは出さない」を押すか、推奨の項目（Skill と hooks・dg コマンド・.claude/.gitignore）をすべて満たすと、導入のチェックリストを開く入口がなくなる。帯を出さない間は、dg のメジャー版が拡張と違うようになっても帯は出ない。

2026-11-16 に人と UI 案を比べて決めた（UI 案のページ https://claude.ai/artifact/Tr69yibz2GPTmoq3p7an34 の案 A）：

- 左パネルのビューのタイトル行の左端（頼む・同期・設定の前）に、チェックリストのアイコンのセットアップのコマンドを足す。押すと、サイドバーの中でセットアップの画面と来る前の画面を切り替える（歯車の設定画面の toggleInSidebar と同じ行き来）。コマンドパレットからも開ける
- 開いている間はタブを選んでいない見た目にし、タブを押しても戻る
- 帯を出さないと決めていたら、セットアップの画面に「帯をまた出す」を出す

採らなかった案：推奨が欠けている間だけアイコンの形を替える（タイトル行のアイコンには数も題の変化も出せず、手間に見合わない）、Webview のタブの行の右端に置く（狭い左パネルでタブと場所を取り合い、同期・設定と入口が分かれる）。

セットアップの画面の中の見た目（戻るボタンをなくす・確かめ直しをアイコンにする・満たした推奨も並べる）は、この後のチケットで行う。

## Acceptance criteria

- [ ] 左パネルのタイトル行の左端（頼む・同期・設定の前）のアイコンとコマンドパレットから、いつでも導入のチェックリストを開け、もう一度アイコンを押すと来る前の画面に戻る
- [ ] チェックリストを開いている間はタブを選んでいない見た目で、タブを押すとその画面に戻る
- [ ] 帯を出さないと決めたリポジトリでは、チェックリストに「帯をまた出す」が出て、押すと帯を出す状態に戻り、自動の確かめ直しが帯を出している状態と同じに動く
- [ ] docs/requirements.md の UI-12 に、導入のチェックリストをタイトル行からいつでも開けることを足す
- [ ] 上の 1〜3 をテストが確かめる
