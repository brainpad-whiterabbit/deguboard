## 概要

Iteration が大きいと止まった行がスクロールの下に隠れる。左パネルの見出しの歯車の隣に注意アイコンを 1 つだけ出し、かざすと人が動くべき Run の一覧を出す。カンバンの縦の幅は使わない。

UI 案（案 2）：https://claude.ai/artifact/4uh7s7Dr2X2MEcdDHRWYq6

## 受け入れ条件

- [ ] あなたの番か止まっている Run が 1 件以上あるときだけ注意アイコンが出て、0 件なら出ない
- [ ] かざすと、行と同じ印・ID・題・経過時間の一覧が出て、行を押すとチケット詳細を開く
- [ ] 空回りの Run は数えない
