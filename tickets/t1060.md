## Summary

README の観点（監査 s39）。利用者向けの文書に、次の細かいずれがあります。
- 拡張の description（package.nls.json と package.nls.ja.json）が「inside your Git repository」のままで、README の冒頭の「inside VS Code」に追従していない
- packages/core/README.md と packages/server/README.md が、拡張を「VSIX を入れる」とだけ案内していて、Marketplace を書いていない
- SECURITY.md の「最新の版」に Marketplace がない
- README と Walkthrough の agent.md が、帯を消した後にサイドバーのタイトル行のチェックリストのアイコンから戻れること（t1021）を書いていない
- usage.ja.md の見出し「Claude Desktop から使う」に、英語版にある（MCP）がない
- usage.md と usage.ja.md の同期の競合の節が、Workflow を `workflow.yaml` と呼んでいない
