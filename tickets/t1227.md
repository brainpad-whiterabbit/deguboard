## Summary

監査（文書と実装）の指摘。要件 IT-2 は「閉じた後に todo に戻したチケットも外す」と約束するが、守るのは ticket move だけで、ticket unclaim（in_progress → todo）は iteration を外さない。直接の編集やマージで閉じた Iteration に残った作業中のチケット（lint_iteration_not_active の対象）を unclaim すると、閉じた Iteration に todo が残り、lint は todo を指摘せず、次の claim は拒否される。どちらに合わせるか（unclaim も外す／IT-2 を ticket move に狭める）は計画で決める。

## Acceptance criteria

- [x] 閉じた Iteration の作業中のチケットを todo に戻す経路（ticket move と ticket unclaim）が、IT-2 の約束と同じ扱いになる
- [x] その振る舞いをテストで示し、unclaim のヘルプ（または IT-2）を振る舞いに合わせる
