## Summary

行を複数選んだときに画面の下に出る帯（SelectionBar）に「ID をコピー」と ▾ を足し、選んだチケットを ID・ID とタイトル・Markdown のリストの形でコピーできるようにする。今の帯には「頼む」と「選択を外す」しかない。UI 案は https://claude.ai/artifact/WvA3mzruCs3BZ9a4T3Ce4L の案 B。

## Acceptance criteria

- [x] 帯の「頼む」の右に「ID をコピー」を置き、押すと選んだ ID を一覧に見えている順に半角の空白で区切ってコピーする（host.copy）。選択は外さない。コピーの後は帯の中に何件の何をコピーしたかを少しの間出し、失敗したらそのことを出す
- [x] 「ID をコピー」の右の ▾ のメニューで「ID」「ID とタイトル」（1 行に 1 件）「Markdown のリスト」（`- t12 タイトル`）を選んでコピーできる。メニューの項目には先頭の 1 件の見本を出す
- [x] 行を選んでいて文字を選んでいないとき、Ctrl/⌘+C で選んだ ID を空白区切りでコピーする
- [x] 左パネルの幅で帯が 1 行に収まるよう、「選択を外す」を × のアイコンにする（ツールチップと aria-label で名前を出す）
- [x] コピーする文字を作る処理を描画から分けた関数に置き、3 つの形と並びの順をテストで確かめる
- [x] docs/requirements.md の UI-15 に、選んだ行の ID をコピーできることを足す
