## Summary

今の dg hooks install とマージドライバの登録は、動いている node と dg.js の実パスを書く。起動ファイル経由で動いたときにそのまま書くと、拡張の版付きフォルダと VS Code の node を書いてしまい、更新で切れる。起動ファイル経由のときは起動ファイルを書くようにする。

## Acceptance criteria

- [ ] 起動ファイル経由の dg hooks install は、node と dg.js の絶対パスではなく起動ファイルを書く
- [ ] dg init・dg sync が登録するマージドライバも、起動ファイル経由のときは起動ファイルを書く
- [ ] dg hooks check は起動ファイルを指すフックを正しいとみなし、起動ファイルがなければ警告する
- [ ] clone して mise run dg:link した dg は、今のまま node と dg.js の絶対パスを書く
- [ ] 上の 4 点をテストで示す
