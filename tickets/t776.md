## Summary

拡張の同期で競合すると、今は警告の通知が出るだけで、解くには会話か CLI（`dg sync --resolve`）が要る。t774 で値が載った警告の通知にボタンを付けて、VS Code だけで解けるようにする。パネルや帯は作らない（競合を解くのにリッチな画面は要らないと判断した）。

## Acceptance criteria

- [ ] 拡張の同期が競合で止まると、警告の通知が t774 のフィールドと両側の値を示し、［remote を採る］［local を採る］のボタンを持つ
- [ ] ボタンを押すと `dg sync --resolve` が 1 回走り、採った値と捨てた値が通知で示される
- [ ] 通知を閉じたときは何も解かず、次の同期でまた同じ通知が出る
