## 概要

VS Code のパネルの Iteration 詳細は、期間と目標が 1 行につながり、期間が未設定だと「? 〜 ?」が出る。進み具合も表を数えないと分からず、Epic 詳細の進捗バーと見え方がそろっていない。見出しの下を期間・目標・進捗に分けて、進みが一目で分かるようにする。

## 受け入れ条件

- [ ] 期間を短い形（11/17–11/30）で出し、active なら残り日数、終了日を過ぎていれば超過日数を添える
- [ ] 期間の開始・終了がどちらも未設定なら、期間の行を出さない
- [ ] 目標を期間と別の欄に出す
- [ ] `iteration.show` が Epic と同じ形の `progress` を返し、詳細に ProgressBar と done / 全件を出す
- [ ] closed の Iteration は完了・持ち越しの件数を進捗と同じ位置に出す
- [ ] 残り日数の計算と `iteration.show` の `progress` に単体テストがある
