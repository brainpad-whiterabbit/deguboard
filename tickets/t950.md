## Summary

見直し（s35）の観点「テスト」。t943 で、dg が Run に書く error（`STALE_SESSION_ERROR`・`NO_PR_ERROR`・`OPEN_AT_SESSION_END_ERROR`・`UNCLAIMED_ERROR`・`REVIEW_UNRECORDED` など）を core の定数にし、画面は `CORE_MESSAGES` で訳すようにした。しかし `l10n.test.ts` が確かめるのは「表の鍵が core のソースにある」という片方の向きだけで、定数を足したり文を書き換えたりして表を直し忘れても落ちない。その場合、日本語の画面に英語の error がそのまま出る（UI-11）。
