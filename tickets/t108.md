## 概要

観点は設定ファイル。mise.toml の release:version と release:publish が pnpm -r exec npm version と pnpm publish を直接書いていて、CLAUDE.md と ADR-008 の「タスクは pnpm scripts を呼ぶだけ」と食い違う

## 受け入れ条件

- [ ] package.json に release:version と release:publish の scripts があり、mise のタスクはそれを呼ぶだけ
- [ ] development.md のリリースの手順と合っている
