## 概要

観点=文書と実装。対象=docs/requirements.md の UI-15、README の「エージェントに頼む」、ADR-010。食い違い：(1) UI-15 と README は「Enter は押さない」と言い切るが、ADR-010 と terminals.ts では保証するのは 1 行のときだけで、複数行は VS Code の貼り付けに任せる（対応しない入力では VS Code の警告に頼る）。(2) UI-15 と ADR-010 はキーの割り当ての正本として README を指すが、ADR-001 と CLAUDE.md では細部の正本はヘルプ・コード・テストで、実装は row-nav.tsx・ask-menu.tsx にある。

## 受け入れ条件
