## 概要

PR の要らない作業。段階のモデルの対応がマージされた後、このリポジトリの `config.yaml` に段階ごとのモデルを設定する（`mise run dg -- config set models.<段階> <名前>`）。値は Claude Code の Agent ツールの `model` に渡す別名にする。

- light は haiku：調べものと文書・設定だけのチケット。規約の漏れは親のモデルの見直し役が拾う
- standard は sonnet：普通の実装
- heavy は opus：今の親と同じなので、heavy のチケットは今までどおり親が実装する

## 受け入れ条件

- [ ] `config show` で `models.light` が `haiku`、`models.standard` が `sonnet`、`models.heavy` が `opus` になっている
