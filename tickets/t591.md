## 概要

ADR-011 は 1 枚のチケットの手続き（段階・次の 1 手・修正ループ・品質ゲート・brief）をコードに移した。この判断を Iteration の流れ全体（dg flow next・--resume）と、guide を節の本文として返す形に広げる。カスタマイズを config の項目と guide.notes に限る判断も、合わせて新しい ADR にする。core の dg next・dg brief が節の本文を返すには、CLI に同梱した guide-*.md（CL-5）を core から読める必要がある。ADR-007 では core は CLI に依存しないので、guide の読み込みの置き場所もこの ADR で決める。

## 受け入れ条件

- [ ] 新しい ADR が、流れの段階の判定と自動で選べる判断の可否をコードが持ち、会話の中にしかない事実は dg が返した resume を写して渡すと決めている
- [ ] guide の読み込み（節の切り出し・choices・config の埋め込み）を core に置くか CLI に残すかと、その理由が ADR にある
- [ ] カスタマイズは config の項目と guide.notes の枠で行い、SKILL.md と guide の書き換えは前提にしないと決め、修正ループと並列の上限を config に置かない（ADR-011）ことを変えないと書いている
- [ ] 採らなかった案（フックで強制・dg がエージェントを起動・流れの Run に印を残す・セッションごとに deguboard-local に残す）と理由がある
- [ ] ADR 一覧と、約束が変わる要件の項（CL-5・EX-3）を直した
