## Summary

観点：設定ファイル。すべての package.json の `engines.node` は `>=24`、mise.toml は node 24.22.2 で、依存の commander 15 も `>=22.12.0` を求める。一方、`packages/cli/bin/dg.js` は `#!/usr/bin/env node` で版を確かめず、`mise run dg:link` で張った `dg` は、ほかのリポジトリでは PATH の Node（例：v20）で動く。VS Code 拡張の起動ファイル（launcher.ts）は major が 24 以上かを確かめているので、入口によって扱いが違う。

## Acceptance criteria

- [x] Node の major が 24 より小さいとき、bin/dg.js は要る Node の版と切り替え方を英語で伝え、0 でない終了コードで終える（launcher.ts と同じ扱い）
- [x] `dg:link` の説明が、必要な Node を示している
- [x] 入口ごとの扱いの違いがなくなるか、違う理由がコメントにある
- [x] Node の major が 24 より小さいとき、`hook PreToolUse` は終了コード 2 で止め（fail closed）、フックの守りを黙って外さない。ほかのコマンドは 0 でない終了コードのまま
