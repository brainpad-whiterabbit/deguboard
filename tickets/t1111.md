## Summary

見直し（実装。t1092 のレビューで範囲の外とされたもの）：t1092 で packages/web/src/host.tsx の HostBridge は reload と onSetupEvent を useLayoutEffect で ref に写すようにしたが、event の購読は今も useEffect の中で request・current・openAsk・closeAsk を閉じ込め、それらが変わるたびに passive effect で張り直す。入力欄の開閉の描画のコミットと副作用の間に toggle つきの ask の event が届くと、古い request を見て、閉じるはずの欄を開く（current つきの ask は古い current を読む）。まれにしか起きないが、製品の画面でも起きうる。

## Acceptance criteria

- [x] 描画のコミットの後、副作用より前に届いた ask の event（toggle つき・current つき）が、最新の request と current で開閉を決める
- [x] その順序で ask の event が届く場合をテストが確かめる
