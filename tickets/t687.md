## Summary

観点：README。README.md・README.ja.md の 83 行は「作りたいものを `/dgall --auto` に頼むと起票・計画・実装まで進む」と書き、scripts/record-gifs.mjs の run-all.gif も `/dgall --auto add CSV export` で起票から始まる。一方、guide-all.md の argument-hint は `<Iteration|ticket ID...>` で、段は assign → check → plan → work → audit → release と起票（import）を持たず、`dg flow next` も Iteration・Plan・チケットを対象に取る。言葉で頼むと起票されず Iteration を聞き返される。同じ節の止まるところ（「deleting, abandoning, or closing tickets」）も、guide-all の「Decisions a human makes」（閉じる・再開は Iteration・Epic・Plan、done の取り消し、Plan の待ちと範囲の変更など）と合わない。人の判断（2026-11-11）で /dgall に起票の段は足さず、README を今の振る舞いに合わせる。作りたいものから始めるときは、先に /dgimport で起票すると示す。
