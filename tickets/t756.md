## Summary

dg hook の中の警告（Run を開けなかったなど）は、終了コード 0 で標準エラーに出るだけで、エージェントにも人にも届かない。拒否と続行は標準出力の JSON で届き、フックが 1 つも届かない場合は next などが知らせるが、「届いたが中で失敗した」ことはどこにも残らない。「フックが届く」の判定はどれか 1 種類が届けば真なので、SubagentStop だけが届かないと、印で頼んだ Run が閉じないまま誰も気づかない。

## Acceptance criteria

- [x] フックの中で出た警告を、Git の外（deguboard-local）にセッションごとに書き残す
- [x] dg next・dg brief・dg hooks check が、まだ知らせていないフックの警告を出す
- [x] セッションごとに届いたフックの種類を記録し、印で Run を開いたのに SubagentStop が届かなかったことを後で警告する
- [x] 上の 3 つをテストで示す
- [x] requirements.md の AG-9 の項を、知らせる範囲に合わせて直す
