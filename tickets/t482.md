## 概要

`reconcileAll` が PR の発見や区切りで `closeOpenedRun` を呼ぶとき、別のプロセス（`dg serve` の同期や別のマシンの sync）が同じ Run を先に閉じていると `REJECTED` が投げられ、sync 全体が止まる。t444 で `run finish` 側は閉じた Run に対して警告だけ返すようにしたが、照合の側は同じ扱いになっていない。照合は閉じられなかった Run を警告に出して、ほかのチケットの照合を続ける。p63 の t444・t445 の見直しで出た範囲の外の指摘。

## 受け入れ条件

- [ ] 照合が閉じようとした Run が既に閉じていても、sync は失敗せず、その旨を `warnings` に出す
- [ ] 同じ sync のほかのチケットの照合と Run の閉じ方は影響を受けない
- [ ] bare リモート付きのテストで確かめる
- [ ] mise run check が通る
