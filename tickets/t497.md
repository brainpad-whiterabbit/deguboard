## 概要

ブラウザを利用者向けの入口から外した（文書のチケット）のに合わせて、Run の画面とブラウザだけの作りを消す。`dg serve` と server パッケージは、`mise run test:layout`・`mise run gifs`・Playwright MCP の `?surface=sidebar` が使うので残す。

## 受け入れ条件

- [ ] Run の画面（ナビの Run とルート `runs`）を消す。チケット詳細の Run の節は残す
- [ ] surface から `browser` をなくす。Webview の外（`dg serve`）は `?surface=` の指定に従い、指定がなければ sidebar で出す
- [ ] ブラウザだけの作りを消す（チケット詳細の属性のまとめての編集・Status を全部並べる選択・右の列の依存先・履歴の行の Space と a・l10n の「ブラウザは日本語」）
- [ ] `dg serve` と `dg open` の `--help` に開発用と書く
- [ ] `mise run test:layout` が通る
- [ ] `mise run check` が通る
