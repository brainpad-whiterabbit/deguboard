## 概要

requirements.md の「1. 目的」を、Microsoft の Agentic-Agile を実践するためのツールという位置づけに書き換える。人はエージェントのパートナーとして設計・見直し・承認を担い、エージェントは仕様（チケットと受け入れ条件）に沿って実行する。対象は基本ソフトウェア開発で、ほかの業務は Workflow で広げられる、とする（いまの「1. 目的」はコンサルティング・調査・資料作成も並べている）。Microsoft 公式や推薦と受け取られない書き方にする。

ADR は決めたら書き換えない（ADR-001）。位置づけの判断を残すなら新しい ADR に書き、既存の ADR（ADR-028 など）の判断と食い違う項があれば、ADR-001 の書き方で置き換えの印を付ける。

## 受け入れ条件

- [ ] requirements.md の「1. 目的」に、Agentic-Agile を実践するためのツールであることと、マニフェスト（microsoft/agentic-agile-template の MANIFESTO.md）へのリンクがある
- [ ] 「1. 目的」が、人をエージェントのパートナー（設計・見直し・承認を担う）として書き、対象を基本ソフトウェア開発としている
- [ ] 有効な ADR が「1. 目的」と食い違わない。判断を変えたときは新しい ADR があり、古い ADR の該当の節か項に置き換えの印があり、docs/adr/README.md の一覧が直っている
- [ ] Microsoft 公式や推薦と受け取られる書き方がない
- [ ] `mise run check` が通る
