## 概要

見直し（audit-s5、観点：テスト）の指摘。

- packages/web/src/app.test.tsx:671「広い画面のカンバンのカードには Run の印を出さない」：mount() が StoreProvider に `readRunning` を渡さないので run.list が呼ばれず、印は必ず出ない。テスト名の約束を確かめていない
- packages/web/src/store.tsx の runningSeq（古い読み直しの結果で上書きしない）：読み直しが重なり、順が入れ替わって返る場合のテストがない
- store.tsx の run.list の `.catch(() => {})`（読めなければ前の値のまま）：run.list が失敗する場合のテストがない
- t156 の取り消し線：plan-band.test.tsx は、done のノードとチップに `status-done` のクラスが付き、done 以外には付かないことを確かめていない

## 受け入れ条件

- [x] 広い画面のテストが `readRunning` 付きで描き、run.list が呼ばれたうえで印と「実行中」が出ないことを確かめる

- [x] run.list が失敗しても前のリングが残り、エラーの通知が出ないことを確かめるテストがある
