## 概要

Run に `transcript`（セッション ID と会話記録のパス。null 可）と `agent_id`（サブエージェントの ID。null 可）を足す。`run start`・`ticket claim` は渡された値を記録し、省けば SessionStart のフックが環境に入れた値（t530）を使い、それもなければ null。Adapter の `claude-code` は、記録の場所があればそのファイルから数え（サブエージェントの記録は 1 つの依頼で 1 ファイルなので先頭から、親の記録なら Run の `started_at` から `finished_at` まで）、場所がなければ今の「ID が最初に出た記録」の推測に落ちる。ticket・step は今までどおり必須で、null 可にはしない（開くのはフックが親の記録の brief から埋めて開く。t530）。

## 受け入れ条件

- [ ] Run のスキーマに `transcript`（セッション ID・記録のパス）と `agent_id` があり、`run start` と `ticket claim` が受け取って記録し、省けば環境の値、それもなければ null になる
- [ ] `claude-code` の Adapter は、`transcript` があればそのファイルから数え（`subagents/` の記録は先頭から、親の記録は Run の期間で）、なければ今の推測で数える。それぞれのテストがある
- [ ] `run refresh` も同じ探し方で取り直す
- [ ] 記録の場所が別のマシンで読めないときは警告して null で残す
- [ ] requirements.md の RN-1・MT-2 と ADR-005 の記述が実装に合い、`mise run check` が通る
