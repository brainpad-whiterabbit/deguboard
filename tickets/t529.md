## 概要

Run に `transcript`（セッション ID と記録のパス。null 可）を足し、`run start`・`ticket claim` が渡された値を記録する。Adapter の `claude-code` は、記録の場所があればそのファイルの先頭（サブエージェントの記録は 1 つの依頼で 1 ファイル）から finished_at までの応答を数え、場所がなければ今の「ID が最初に出た記録」の推測に落ちる。見直し役が見直しを終えた後に `run start` を呼んでも、見直し全体が使用量に入る。

## 受け入れ条件

- [ ] Run のスキーマに会話記録のセッション ID（null 可）があり、`run start` と `ticket claim` が受け取って記録し、省けば null になる。記録のパスは Git に入る Run に入れず、マシンごとのローカルの置き場所（RN-3 の deguboard-local の下など）に持つ
- [ ] `claude-code` の Adapter は、ローカルに記録の場所があればそのファイルの先頭から finished_at までを数え、なければ今の推測で数える。両方のテストがある
- [ ] `run refresh` も同じ探し方で取り直す
- [ ] 記録の場所が別のマシンにあって読めないときは警告して使用量を null で残す
- [ ] requirements.md の RN-1・MT-2 と ADR-005 の記述が実装に合い、`mise run check` が通る
