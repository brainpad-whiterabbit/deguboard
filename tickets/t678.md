## Summary

頼むことの書き換え（/dgchange）の候補は、表示名が「直す」/「Fix」、鍵が `edit` のままで、Skill の名前 dgchange とずれている。表示名を ja「変える」/ en「Change」に、鍵を `change` にする。Iteration・Epic 向けの「名前・目標・期間を直す」「題・概要を直す」も「〜を変える」に揃える。

## Acceptance criteria

- [ ] `dg ask` の候補の鍵が `edit` から `change` になり、`--action change` で /dgchange の頼む文が返る
- [ ] 候補の表示名が ja「変える」・en「Change」で、Iteration・Epic 向けの表示名も「〜を変える」になっている
- [ ] Web と VS Code の画面の吹き出しが新しい表示名で出る（スナップショットを更新した）
- [ ] ask の候補にもう `edit` の鍵がないことをテストで確かめている
