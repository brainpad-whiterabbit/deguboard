## Summary

見直し（テスト）：test/vscode/onboarding.vscode.ts のテスト「項目が欠けている間はタイトル行のセットアップのアイコンが点付きになって件数をツールチップに出し…（t1084）」が、s40 の作業中に 1 回だけ回した `mise run test:vscode` で `expected 'Setup (2 items missing)' to be 'Setup (1 item missing)'` で落ちた（回し直していない）。コードを読む限り前のテストの状態が残る経路は見つからず、件数の数え方（packages/vscode/src/setup.ts の missingSetupCount）も誤りではない。テストは欠けている項目がどれかを特定も確認もせずに件数だけを確かめるので、落ちたときに原因がわからない。また、同じファイルのテスト「帯を開くと推奨の項目が出て、「Skill と hooks を入れる」でその場で入れられる」は、項目が満たされたことの代わりにボタンが消えたことを見ている。packages/web/src/components/setup-checklist.tsx は --force だけの fix ではボタンを出さないので、項目が欠けたままでもボタンが消えうる。

## Acceptance criteria

- [x] 件数のテストが、欠けている項目の id を確かめてから件数を確かめ、落ちたときに欠けている項目の id がわかる
- [x] 件数のテストが落ちた原因（2 件目に欠けていた項目）が PR の本文に書かれ、その原因がテストかテストの環境で直っている
- [x] インストールのテストが、ボタンが消えたことではなく項目が満たされたことを確かめる
- [x] mise run test:vscode で onboarding.vscode.ts が通る
