## 概要

見直し（テスト）。packages/core/src/git/lock.test.ts:182-224（t129 から）は `await sleep(20)` の間に持ち主がロックを取る前提で順序と経過時間を確かめていて、check が多数のワーカーで並べて動くと順序が入れ替わって落ちうる。:110-121 の「5 秒未満」も同じ種類

## 受け入れ条件

- [x] ハートビートのテストは、持ち主がロックを取った合図（Promise）を待ってから待ち手を始め、`sleep` に頼らない
- [x] 経過時間を確かめる箇所は、負荷が高くても落ちない上限にするか、時間に頼らない確かめ方にする
- [x] `mise run check` が通る
