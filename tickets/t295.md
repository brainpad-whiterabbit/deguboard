## 概要

対象（チケット・Iteration・Epic・Plan。複数可）・頼むこと・指示・形式（Skill か文章だけ）から、エージェントに貼る依頼文を返す読み取りだけのコマンドを core に置く。web は core を実行時に取り込めないので、CLI・HTTP・Webview から同じコマンドで呼ぶ。頼むことと Skill の対応は案のページの表のとおり（起票・直す・分けるは dgimport、割り当てる・作るは dgassign、計画は dgplan、進めるは dgwork、最後まで進めるは dgall、片付けるは dgdone、点検は dgcheck、リリースは dgrelease）。

案のページ：https://claude.ai/artifact/DsZs7PgafyAdNmmb64k6q5

## 受け入れ条件

- [ ] packages/core/src/commands/ にコマンド定義があり、CLI・HTTP・Webview から同じ結果を返す
- [ ] 依頼文に入れる対象は ID とタイトル（と Status・Iteration）だけで、本文を含めない
- [ ] Skill 形式は 1 行目が Skill の呼び出し（例 /dgdone t265）、文章だけの形式は 1 行目の代わりに dg の呼び方（--json --actor agent）を添える
- [ ] 起票・Iteration を作る・Epic を作るの依頼文には --created-by human を付ける指示が入る
- [ ] 閉じる・再開・done の取り消しの依頼文には「人の指示」と書き添える
- [ ] 頼むことの操作が actor.human_only に入っていれば、依頼文の代わりに人が打つ dg のコマンドを返す
- [ ] 対象の種類と状態から、頼むことの候補とおすすめ（先頭）を返す（review は片付ける、止まった in_progress は再開する、着手可の todo は進めるなど）
- [ ] 依頼文に使う Skill の名前がすべて dg skill install で配る名前（guide のトピック）にあることをテストで確かめる
