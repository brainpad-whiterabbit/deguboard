## Summary

Marketplace に初めて出す前に、VS Code 拡張の `name` を `deguboard-vscode` から `deguboard` に変え、拡張の ID を `deguboard.deguboard` にする。公開したあとに変えると別の拡張になるので、初回の手でのアップロードより前に入れる。

CLI のパッケージ（packages/cli）が今 `deguboard` という名前で、pnpm workspace の中で名前が重なる。GitHub Releases の VSIX で `deguboard.deguboard-vscode` を入れている人は、新しい ID の拡張と別の拡張として 2 つ入ることになる。

## Acceptance criteria

- [ ] packages/vscode/package.json の `name` が `deguboard` で、VSIX の拡張の ID が `deguboard.deguboard` になる
- [ ] workspace の中でパッケージの名前が重ならず、build・`mise run vsix`・`mise run vsix:install`・`mise run check` が通る
- [ ] 旧い ID（`deguboard.deguboard-vscode`）を入れている人が、旧い拡張を外す方法を Release の本文か README で知れる
