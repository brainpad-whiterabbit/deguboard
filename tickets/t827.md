## Summary

Marketplace に初めて出す前に、VS Code 拡張の `name` を `deguboard-vscode` から `deguboard` に変え、拡張の ID を `deguboard.deguboard` にする。公開したあとに変えると別の拡張になるので、初回の手でのアップロードより前に入れる。

CLI のパッケージ（packages/cli）が今 `deguboard` という名前で workspace の中で重なるので、`@deguboard/cli` に変える（npm には出していないので利用者には見えない）。VSIX のファイル名は `deguboard-vscode.vsix` のままにする。
