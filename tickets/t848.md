## Summary

s29 の振り返りで、PR どうしで重なったファイルと、リリース前の見直しからのすり抜けを、git log の変更ファイルとチケットの本文の ID から手で数えた。振り返りの指標（t847）をエージェントが毎回同じ手間をかけずに計算できるよう、元のデータを dg から読めるようにする。どのコマンドに出すかは計画で決める。

## Acceptance criteria

- [ ] 各チケットの PR が変えたファイルの一覧を、dg の JSON で読める
- [ ] チケットの本文と題に書かれた、ほかのチケットの ID（参照）を、dg の JSON で読める
- [ ] 取れないもの（gh がない・PR が main にないなど）は不明として返し、推測で埋めない
- [ ] requirements.md の該当の項と、コマンドのヘルプが直っている
