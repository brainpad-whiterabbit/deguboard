## 概要

run finish はモデル名を「明示 > start > 会話記録」の順で選ぶので、段階のモデルのサブエージェントが --model sonnet のような別名を渡すと、会話記録にある正式な ID（claude-sonnet-…）でなく別名が残る（2026-11-05 時点で 76 件）。会話記録から取れた名前を最優先にし、取れないときだけ明示・start の名前を使う。

## 受け入れ条件

- [ ] 会話記録からモデル名が取れたときは、start・finish で別名を渡していても会話記録の名前を記録する
- [ ] 会話記録から取れないときは、今までどおり finish・start で渡した名前を使う
- [ ] run.test.ts に両方の場合のテストがある
- [ ] dg run start と dg run finish のヘルプの model の説明と ADR-005 が新しい優先順に合っている
