## Summary

終わった Plan を閉じる手順は guide done にあるが、flow next と guide release にない。guide all は Plan を閉じるのを人の判断とし、guide done は聞かずに閉じる書き方で食い違う。「集まりが終わった」の判定も flow・lint・ask で、消したチケットと abandoned だけの扱いがずれる。1 件消して残りが done の Plan は、どこも閉じるよう言わない。p90 が開いたまま残った。

## Acceptance criteria

- [ ] すべてのチケットが終わった承認済みの Plan があるとき、flow next の手に plan close が入る
- [ ] guide release に、終わった Plan を閉じる手順がある
- [ ] guide all と guide done の、終わった Plan を閉じるときに人に聞くかどうかがそろう
- [ ] Epic・Plan・Iteration が「終わった」かの判定を 1 つの関数にまとめ、flow・lint・ask がそれを使う
- [ ] 消したチケットと abandoned だけの集まりでの判定を、表で比べるテストで示す
