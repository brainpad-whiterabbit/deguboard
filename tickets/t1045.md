## Summary

rebaseInProgress（packages/core/src/git/rebase.ts）は呼ばれるたびに rev-parse --git-path を rebase-merge と rebase-apply の 2 回起動する。何もすることのない dg sync で 16 回、commands-flow-reconcile.test.ts では git の起動 9,112 回のうち 2,732 回（30%）を占める（2026-11-16 に PATH に数える git を挟んで測った）。

## Acceptance criteria

- [ ] 1 回の dg のコマンドの中で、rebase の途中かの確認のための git の起動が 1 回以下になる
- [ ] rebase の途中の状態の見分け方（dg が残したものは取り消し、人が始めたものは止める。SY-9）が変わらないことを既存のテストが確かめている
- [ ] push が拒否された後のリモートの変更の取り込みの途中で作業が止まった場合も、rebase の途中の状態を正しく見分けることをテストが確かめる
- [ ] 何もすることのない dg sync と commands-flow-reconcile.test.ts の、git の起動の回数と時間の変更前後を PR に載せる
