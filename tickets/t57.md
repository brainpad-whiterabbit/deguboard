## 概要

画面のチケット（t54〜t56 など）で、エージェントが見た目を自分で確かめられるようにする。リポジトリの .mcp.json に Playwright MCP を置き、dg serve の画面をブラウザで開いてスクリーンショット・クリック・幅の変更を行う。画面は起動時に html の data-surface を読むので、ブラウザでもサイドバーとパネルの配置を開ける入口（開発用のクエリなど）を足す。VS Code の Webview に固有のこと（テーマの色・CSP・拡張ホストとのメッセージ）は対象外で、今までどおり人が見る

## 受け入れ条件

- [ ] リポジトリの .mcp.json に Playwright MCP があり、Claude Code で使える（版を固定する）
- [ ] ブラウザで dg serve の画面をサイドバーとパネルの配置で開ける（例：?surface=sidebar）。既定のブラウザの配置は変わらない
- [ ] docs/development.md に、dg serve を立てて Playwright MCP で画面を確かめる手順と、確かめられないこと（Webview に固有のこと）を書く
- [ ] mise run check が通る
