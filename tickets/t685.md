## Summary

並列の上限は、今は guide-parallel の文の中に「up to 3」とあるだけで、ADR-011・ADR-030 の「上限は config に置かず Core が持ち、guide に書かない」と食い違っている。人の判断（2026-11-10）で、上限を config の項にして利用者が変えられるようにする。

## Acceptance criteria

- [x] 並列の上限を config の work.parallel（1〜10 の整数、既定 3）として読み書きでき、範囲の外の値は検証で拒否される。scope は local で、個人の deguboard-local/config.yaml で上書きできる
- [x] guide-parallel は上限の数字を書かず、config の今の値を差し込んで示す
- [x] ADR-011 と ADR-030 の本文が、上限を config に置く判断と理由に書き換えてある。Core が持つ案は「採らなかった案」に 1 行で残り、修正ループの回数の扱いは変えていない
- [x] 設定画面に work.parallel が、ja と en の表示名と説明つきで出る
