## Summary

見直し（s30、構成）。s30 で足した web の部品に、そろわない書き方と重複が残った。期間（formatPeriod・shortPeriod の monthDay）は月日をゼロ埋めせず、同じ履歴の画面の日付（formatShortDay の 11/03）とそろわない。暦の日数の差を formatShortDay・formatPeriod・activeDay の 3 か所で計算する。本文から ID を見つける正規表現（parts.tsx の TEXT_ID）が vscode の ids.ts と境界の規則が違う。backlog の Iteration の見出しは「カンバンと同じ部品」とコメントにあるが別のマークアップで、目標に ID のリンクがない。テストでしか使わない export（fieldMatchesQuery・isNoteKey・PriorityGlyph・prRowClass）、古いコメント（iteration-parts.tsx の冒頭、styles.css の history-empty）、空の行のマークアップの重複（IterationItem・EpicItem）がある。

## Acceptance criteria

- [ ] 履歴とカンバンの月日の書き方が 1 つの部品から出てそろい、暦の日数の差を 1 つの関数で計算する
- [ ] web の ID の正規表現が vscode の ids.ts と同じ境界の規則で、そのことがコメントに書かれている
- [ ] backlog の Iteration の見出しの目標がカンバンと同じく ID をリンクにし、見出しのコメントが実装と合う
- [ ] guide.notes.* のどのトピックにも NOTE_LABELS の名前があることをテストが確かめる
- [ ] テストでしか使わない export がなくなり、iteration-parts.tsx の冒頭と history-empty のコメントが今の使い方を書く
