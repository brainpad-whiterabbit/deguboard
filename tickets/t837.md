## Summary

見直し（s30、構成）。s30 で足した web の部品の書き方がそろわない。期間（date-time.tsx の formatPeriod、iteration-parts.tsx の shortPeriod の monthDay）は月日をゼロ埋めせず、同じ履歴の画面の日付（formatShortDay の 11/03）とそろわない。暦の日数の差を formatShortDay・formatPeriod・activeDay の 3 か所で計算する。本文から ID を見つける正規表現（parts.tsx の TEXT_ID）は、vscode の ids.ts と境界の規則が違う（`feat/t12` などがカンバンではリンクになり、エディタではならない）。backlog の Iteration の見出しは「カンバンと同じ部品」とコメントにあるが別のマークアップで、目標の ID がリンクにならない。後片付け（使われない export・古いコメント・NOTE_LABELS のテスト・空の行の重複）は別のチケットに分けた。

## Acceptance criteria

- [x] 履歴とカンバンの月日が 1 つの部品から同じ書き方で出て、暦の日数の差を 1 つの関数で計算する
- [x] web の ID の正規表現が vscode の ids.ts と同じ境界の規則になり、そのことがコメントに書かれている
- [x] backlog の Iteration の見出しでも目標の ID がリンクになり、見出しのコメントが実装と合う
