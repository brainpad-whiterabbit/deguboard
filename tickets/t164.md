## 概要

見直し（audit-s5、観点：README）の指摘。

- README.md:38 と packages/vscode/README.md:9 は、使い始めの最初の手順を `npm i -g deguboard` にしている。しかし deguboard は npm に未公開（`npm view deguboard` は 404）。7 行目は「公開を準備中」と書くが、それまで CLI をどう入れるかの案内がない
