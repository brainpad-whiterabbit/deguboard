## Summary

頼む小窓の edit・close・reopen・abandon・undo_done は Skill を持たず（skill: null）、Skill の形を選んでも文章だけの形になる。guide-change.md を新設して dg skill install で dgchange を配り、5 つの頼むことの Skill を dgchange にして、呼び出しだけでは頼むことが決まらないので頼みごとの 1 行（intent）を添える。free は Skill なしのまま。

## Acceptance criteria

- [ ] `dg guide change` が、操作ごとの前提の確認（close は未完了の知らせ、Iteration の reopen はほかの active の知らせ、abandon の理由、undo_done の戻す Status と理由、edit の前後）・前後を示した承認・dg の 1 回の呼び出し・TRANSITION_REJECTED のときに人へコマンドを渡すことを示す
- [ ] `dg skill install` で dgchange の SKILL.md ができ、SKILL_SUMMARY に ja・en の文がある
- [ ] 5 つの頼むことの Skill の形が `/dgchange <ID>` と頼みごとの 1 行になることをテストが確かめる
- [ ] actor.human_only に当たる操作は、今までどおり人が打つコマンドを返すことをテストが確かめる
- [ ] guide-overview の段階の表と dg ask の --help の文が、Skill のない頼むことは free だけという今の形に合う
