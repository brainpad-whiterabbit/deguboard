## 概要

観点は依存。どの package.json も license MIT を宣言しているのに、リポジトリに LICENSE がなく、npm の 3 パッケージと VSIX に MIT の本文と著作権表示が入らない（vsce は --skip-license で黙らせている）。packages/cli/web/assets と packages/vscode/dist/extension.cjs に束ねた react・react-dom・@dnd-kit/core・yaml・zod のライセンス表示も minify で落ちている

## 受け入れ条件

- [x] リポジトリのルートに著作権者を入れた LICENSE があり、npm に出す cli・core・server の tarball と VSIX に入る（npm pack と vsce の出力で確かめる）
- [x] 束ねた第三者のライセンスを集めた表示がビルドで出て、cli の web と VSIX に入る
- [x] packages/vscode の package script から --skip-license が外れる
- [x] README にライセンスの 1 行がある
