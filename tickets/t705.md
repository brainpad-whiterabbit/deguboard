## Summary

左パネルのバックログの Epic の札（番号・題・進捗）を、ID（e21）だけの札にする。題と進み（done/全体）はツールチップで読む。カンバンにも同じ札を出す（後続のチケット）ので、札を 2 つの画面で使える部品にする。UI 案: https://claude.ai/artifact/PnGAQ65zEa45X1BZtuW5xT

## Acceptance criteria

- [x] バックログの Epic の札は ID だけを出し、ツールチップで題と進み（done/全体）を読める。絞っている札のツールチップは、題と進みに「押すと絞り込みを外す」を添える
- [x] 札の読み上げ名（aria-label）に ID と題を入れる（例「e21 マウスだけの選択」）
- [x] 札を押すとその Epic に絞り、もう一度押すと外れる動きは今と同じ
- [x] 「Epic なし」の札は「なし」と件数（なし 3）を出す。件数の数え方は今と同じ
- [x] 札の部品をカンバンからも使える場所に置く
- [x] 上の動きを画面のテストで確かめる
- [x] requirements.md の UI-10 が今の画面と食い違わない
