## 概要

README.md と README.ja.md の冒頭の 1 文を「Agentic-Agile を実践するための、Git リポジトリの中で動くカンバンボード」（英語は "A Git-native kanban board for practicing Agentic-Agile"）に合わせ、特長を「仕様で任せる・依存に沿った並列・ガバナンス・計測と改善」の順に並べ直す。Microsoft 公式ではないことがわかる書き方にする。拡張の説明（package.nls.json・package.nls.ja.json の description）と、npm のパッケージの説明（packages/cli/package.json の description と packages/cli/README.md の冒頭）も合わせる。

2026-11-10 にユーザと決めたこと：

- 公式でないことは、冒頭の段落のすぐ後に 1 文で明記する（"deguboard is an independent project. It is not made, endorsed, or supported by Microsoft."）
- 特長はマニフェストの価値に合わせた 4 項だけにする。価値 2（Human-agent partnership）は冒頭の文に置く。今の 3 項のうち「サービスがいらない」は導入の節の末尾、「エージェントを選ばない」は導入の手順 4 に移し、「VS Code で完結」は冒頭と「ボードを開く」で足りるので移さない
- 特長には今ある機能だけを書く（ガバナンスは Plan の承認・品質ゲート dg gate・actor.human_only と Workflow の by・フックの拒否、計測は dg metrics と振り返り。t494・t495 の分析はまだ書かない）
- 範囲を広げ、食い違う説明の CLAUDE.md の 1 行目・ルートの package.json の description・dg --help の説明（packages/cli/src/program.ts）も同じ PR で直す。packages/cli/package.json の description は npm の入口なので英語にする
- 拡張の日本語の description を変えるので、packages/vscode/src/l10n.test.ts の MANIFEST_JA_BEFORE も合わせる

文案は計画のファイル（~/.claude/plans/t493-t492-mighty-tarjan.md）にある。
