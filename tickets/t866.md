## Summary

見直し（s31、テスト）。t825 の受け入れ条件（`release: published` のときだけ走る、pre-release は出さない、build と検査を回さない、Marketplace は trusted publishing、秘密は `OVSX_PAT` だけ、権限は最小）は、ファイルを読んで確かめただけで、テストがない。あとの変更で ADR-008 の判断が黙って崩れても気づけない。

## Acceptance criteria

- [ ] テストが、ワークフローのきっかけが Release の published だけで、pre-release を除くことを確かめる
- [ ] テストが、どの step も build・`mise run check` などの検査・VSIX の作成を回さないことを確かめる
- [ ] テストが、使う秘密が `OVSX_PAT` だけで、`id-token: write` が Marketplace の job だけにあり、既定の権限が空であることを確かめる
