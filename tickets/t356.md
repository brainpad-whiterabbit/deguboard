## 概要

観点=テスト。対象=packages/core/src/commands/setup.ts の config.set（clearsToDefault と coerce）。食い違い：enum の項目（commit.mode など）を空文字か null で空にすると弾く（t331 でテストした）が、undefined を渡すと弾かずに既定へ戻る。値を省いて呼ぶ HTTP や MCP からの config.set では enum も既定に戻ることになり、約束がない。弾くか、既定に戻すことを約束にするかの判断が要るので、Iteration には入れない。
