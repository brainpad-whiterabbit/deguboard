## 概要

左パネル（surface=sidebar）のカンバンで、チケットより上の段を詰め、節の枠と空の節の場所を減らす。案のページ（https://claude.ai/artifact/249SVeNZJYfbtyZLoh1vup）の A に B の帯を足した形。
Iteration の開始・閉じるは画面では一旦やらず、Skill の手順で行う（別のチケット）。広い画面のカンバンは変えない。

## 受け入れ条件

- [x] 見出しが「番号・名前（Iteration の選択欄）・状態・件数」と「期間・目標（1 行で省略）」の 2 段で、その下に状態ごとの色の帯と「n/m done」がある
- [x] 見出しに「詳細」「…」と、開始・閉じるの操作を出さない
- [x] 「+ Iteration を作る」は Iteration の選択欄の中から選べる
- [x] 状態の節は枠と背景のないペイン風の見出しと件数バッジで、空の節は見出し 1 行だけになる。空の節の見出しにドロップすると Status が変わる
- [x] カンバンの行は状態の丸印を出さず、優先度の印（high・low）を右に出す。バックログの行は変わらない
- [x] requirements.md の UI-2 を直す
