## 概要

バックログの表を Iteration ごとの区画に分けて積む。並びは active、planned（番号の順）、最後に Iteration なし。区画の中は今と同じ優先度と番号の順。
区画の見出しに期間・目標・件数・詳細へのリンクを出し、active には「終了」、planned には「開始」を置く。「Iteration なし」の区画から Iteration を作れる。
改善案：https://claude.ai/artifact/Sy4j28W4Vkee96x6WtNagu


## 受け入れ条件

- [ ] バックログが active → planned（番号の順）→ Iteration なしの区画で出て、区画の中は優先度と番号の順に並ぶ
- [ ] 区画の見出しに番号・名前・期間・目標・件数と詳細へのリンクがあり、active は「終了」、planned は「開始」でカンバンの見出しと同じ操作ができる
- [ ] 「Iteration なし」の区画から Iteration を作れる
- [ ] 検索・Status・優先度・ラベル・担当・Epic の欄の絞り込みがすべての区画に効き、0 件の区画は見出しだけ出す
- [ ] バックログの絞り込みの欄から Iteration のセレクトを外す
- [ ] サイドバーでは区画が折りたたみの節になり、開閉が host.state に残る
- [ ] Iteration がない Project では区画に分けず今の 1 つの表で出す
- [ ] requirements.md の UI-3 を書き換える
