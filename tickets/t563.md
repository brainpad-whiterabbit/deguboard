## 概要

t562 の検査は日本語の「dg guide <topic> の「節」」の形だけを拾う。英語の brief などの文は the "<節>" section of `dg guide <topic>` のように節の名前がトピックより前に来るので拾われず、guide の節を改名すると黙って切れる。英語の形も集めて、日本語の形と同じ照らし方（見出し・括弧の補足を除いた名前・太字の項目・一覧の先頭のコード）で照らす

## 受け入れ条件

- [x] check:docs が .md と packages の .ts の文字列とコメントにある英語の形（the "<節>" section of dg guide <topic>。バッククォートの有無によらない）の参照を集め、guide-<topic>.md に無ければ失敗する
- [x] 切れた英語の参照を入れたテストで失敗し、直すと通る
- [x] ADR-001 の検査の一覧と mise.toml の check:docs の説明が英語の形を書いている
- [x] 今のリポジトリで mise run check が通る
