## 概要

guide を縮める前に、guide にだけ書いてある手を、その場面で必ず目に入るエラーの文・警告・lint の message に移す。エージェントは `--help` を自分から読まないので、ヘルプへ移すのでは届かない。

- `SYNC_CONFLICT` と sync の競合の警告（`CONFLICT_REMEDY`）は guide の「同期が止まったとき」を指すだけで、人の戻し方（deguboard worktree での `git rebase` の解き方と `git reset --hard` で捨てる方法）を書いていない
- ブランチを記録する前にマージされた PR を照合から外したときの警告に、その PR がこのチケットのものなら `ticket update --pr` で記録して sync し直す、という手がない
- `lint_commit_outside_run`・`lint_run_fix_missing` の message に、人の push・rebase・別のマシンで開いた Run でも出ること、Run の記録は書き換えずにコミットの内容を人に伝えることがない

guide の文はこのチケットでは消さない（後のチケットで消す）。

## 受け入れ条件

- [ ] `SYNC_CONFLICT` のエラーと sync の競合の警告の文に、自分では解かずに人に伝えること、人の戻し方（解いて続けるか、ローカルのコミットを捨てるか）が書いてある
- [ ] 記録する前にマージされた PR を外した警告に、その PR がこのチケットのものなら `ticket update <id> --pr <番号>` で記録して sync を回し直す、と書いてある
- [ ] `lint_commit_outside_run`・`lint_run_fix_missing` の message に、Run の記録を書き換えずにコミットの内容を確かめて人に伝えること、人の push・rebase などでも出ることが書いてある
- [ ] 変えた文をテストが確かめている
