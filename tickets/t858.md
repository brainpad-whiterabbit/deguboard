## Summary

拡張を使わず CLI だけで dg を使う利用者（`npx deguboard`・`mise run dg --` など）は、dg を更新しても `.claude/skills/` の Skill が古いまま残り、気づく手段がない。`dg hooks check`・`dg next`・`dg brief` の警告で（t697 のフックが届いていない警告と同じ場所）、入れてある dg の Skill が今の dg の Skill と違えば、名前と `dg skill install` で更新できることを知らせる。SessionStart のフックは標準出力に何も出さない作り（`packages/cli/src/hook-print.ts`）なので使わない。

## Acceptance criteria

- [ ] `dg hooks check` が、リポジトリか `~/.claude/skills` に入れてある dg の Skill のうち今の dg と違うものの名前を出し、`dg skill install` で更新できることを案内する（古いものがなければ何も足さない）
- [ ] `dg next` と `dg brief` が、同じ条件のときだけ `warnings` に古い Skill の名前と `dg skill install` を出す
- [ ] 手で直した Skill は、古いことと `--force` で上書きできることを分けて出す
- [ ] 古いかどうかの判定は `dg skill install` と同じ処理を通り、t857 の拡張も同じ判定を使える形にする
- [ ] 上の振る舞いをテストで確かめる
- [ ] 利用者に見える約束が変わるなら、requirements の AG-2 を 1 文で直す
