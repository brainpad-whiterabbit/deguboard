## Summary

拡張を使わず CLI だけで dg を使う利用者（`npx deguboard`・`mise run dg --` など）は、dg を更新しても `.claude/skills/` の Skill が古いまま残り、気づく手段がない。`dg hooks check` と SessionStart のフックで、入れてある dg の Skill が今の dg の Skill と違えば、名前と `dg skill install` で更新できることを知らせる。

## Acceptance criteria

- [ ] `dg hooks check` が、リポジトリか `~/.claude/skills` に入れてある dg の Skill のうち今の dg と違うものの名前を出し、`dg skill install` で更新できることを案内する（古いものがなければ何も足さない）
- [ ] SessionStart のフックが、同じ条件のときだけエージェントに古い Skill と `dg skill install` を伝える
- [ ] 手で直した Skill は、古いことと `--force` で上書きできることを分けて出す
- [ ] 古いかどうかの判定は `dg skill install` と同じ処理を通る
- [ ] 上の振る舞いをテストで確かめる
- [ ] 利用者に見える約束が変わるなら、requirements の AG-2 を 1 文で直す
