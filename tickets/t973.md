## Summary

振り返り（s35）の Try。このリポジトリの Claude は mise run dg（メインの worktree の packages/cli/bin/dg.js、ビルド済みの dist）で dg を呼ぶ。s35 では dist が 11 月 12 日のビルドのまま残り、マージした t944（読みの git が index.lock を取らない）の直しが効かず、t954・t956 の受け入れ条件の印を付ける書き込みが index.lock で落ちた。振り返りの手引き（t959）や作業時間（t958）も、ビルドし直すまで使えなかった。`mise run build` が dist に元のコミットを記録し、dg.js（mise run dg とフックの両方の入口）が呼ばれたときに、dist のある worktree の今の HEAD と比べる。違えば `mise run build` を案内する警告を stderr に出す。あわせて、マージの後に main の worktree でビルドし直す手順を guide.notes.done に書く。次の Iteration で index.lock による dg の書き込みの失敗を 0 件にすることをねらう。
