## Summary

s44 の見直し（観点：アーキテクチャ）の指摘。core の `initCommandLine`（packages/core/src/commands/setup-check.ts）は、`noDataRemote` のときもコードのリモートが渡されれば `--remote <名前>` を付け、`dg setup check` の文もその 1 行を案内する。画面の写し（packages/web/src/components/setup-checklist.tsx の `initCommandLine`）は `remote` を受けず、`dg init --no-data-remote` だけを返す。コードのリモートが origin 以外のリポジトリでは、画面のボタン（localBoard）が流す 1 行と core の案内の 1 行が違う。写しを core と照らすテスト（setup-checklist.test.tsx）の入力に `remote` がないので、このずれを捕まえない。

## Acceptance criteria

- [x] 画面の「このマシンだけ」のボタンとターミナルの 1 行が、コードのリモートが origin 以外のときも core の `initCommandLine` と同じ 1 行になる
- [x] 写しを core と照らすテストの入力に、`remote` を渡す場合（`noDataRemote` との組を含む）がある
