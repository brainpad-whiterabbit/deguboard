## 概要

実行中の Run は deguboard-local/runs/ に置き、finish したときに完了時の集計だけを runs/ にコミットする。同じチケットと step の二重起動は deguboard-local/locks/ のロックで防ぐ。コマンドは packages/core/src/commands/ に定義し、CLI・MCP・HTTP に写す（RN-3、SY-5、EX-2、CL-2）

## 受け入れ条件

- [x] run start から run finish までで runs/ に 1 ファイルがコミットされ、実行中の詳細は deguboard-local/runs/ にだけ置かれる（RN-3）
- [x] 同じチケットと step の Run を二重に start すると拒否される（SY-5）
- [x] 終わっていない Run が run list に出て、run finish --result interrupted で閉じられる（EX-2）
- [x] CLI・MCP から同じ操作ができ、dg --help と requirements.md の CL-2 の Run の行が「あり」になる
