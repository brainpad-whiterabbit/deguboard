## 概要

起票時に調べた参照先が本文に残らず、着手したエージェントが同じ調査をやり直している。guide import（packages/cli/src/guide-import.md）の「よいチケットの書き方」に、任意の「## 参考」節に書いてよいもの（要件の ID・ADR の番号・関連するチケット・ファイルのパス・関数名とコマンド名）を足す。行番号と docs の書き写しは入れず、直し方は書かない。節は任意で、dg lint の指摘の対象にしない

## 受け入れ条件

- [ ] dg guide import の「よいチケットの書き方」に、任意の「## 参考」節に書いてよいもの（要件の ID・ADR の番号・関連するチケット・ファイルのパス・関数名とコマンド名）が書いてある
- [ ] 同じ箇所に、行番号と docs の書き写しを入れないこと、どう直すかを書かないことが書いてある
- [ ] 「## 参考」節がないチケットに dg lint が指摘を出さない
- [ ] mise run check が通る
