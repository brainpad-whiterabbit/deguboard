## Summary

観点はテスト。next.ts の stageOf は、low・free で PR があると、実行中の見直しの Run を見る前に reviewed か ready を返す。そのため、見直しの Run が開いたまま段を low に下げると、dg next は見直しの終わりを待たずに pr ready を返す（ready の手は待つ Run の対象でない）。また、見直しなしで ready にしたチケットを high に上げたときの手（implemented → review に戻るはず）にもテストがない。開いた見直しを待つか置いていくかは計画で決め、なぜをコメントに書く。

## Acceptance criteria

- [ ] 見直しの Run が開いたまま段を low・free にしたときの dg next の手が決まっていて、テストとコメントで示されている
- [ ] 段のないまま ready にした low のチケットを high に上げると、dg next が review の手を返す（テスト）
