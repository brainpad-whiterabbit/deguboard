## Summary

チェックボックスの列を常に置かずに、マウスだけで行を選べるようにする（UI 案 B の前半）。丸も余白も足さず、行の今の左の余白と行頭の印のあたりを左端の帯にする。帯を押すとその行を選ぶ・外し、選んだ行は今の選択の色で出す。選ぶ・外すは帯（と t704 のなぞり）だけで行い、行の本体のクリックと Enter は今と同じく詳細を開く。UI 案（丸は出さない）: https://claude.ai/artifact/RDUothivMbJrmhtxkquLYP

## Acceptance criteria

- [x] 行の見た目と並びは今と同じ（余白を足さない）。行に乗ると左端の帯に色が付く
- [x] 帯を押すと、その 1 件を選ぶ・外すの切り替えになり、詳細は開かない
- [x] 選んだ行は今の選択の色（[data-selected]）で出す。行の本体のクリックと Enter は今と同じく詳細を開き、選択を外す
- [x] Ctrl/⌘・Shift+クリックと Esc は今と同じに動く
- [x] カンバン・バックログ・Epic と Iteration の詳細の中の行・履歴の行で使える
- [x] タッチの画面（hover のない画面）では、帯を常に薄く色付けする
- [x] 上の動きを画面のテストで確かめる
