## Summary

チェックボックスの列を常に置かずに、マウスだけで行を選べるようにする（UI 案 B の前半）。行の左の余白に選択の丸を出し、丸を押すとその行を選ぶ・外す。選んでいる間は行のどこを押しても選ぶ・外すの切り替えになる。UI 案: https://claude.ai/artifact/RDUothivMbJrmhtxkquLYP

## Acceptance criteria

- [ ] 選んでいないときは行の見た目が今と同じで、行に乗ると左の余白に丸が出る
- [ ] 丸を押すと、その 1 件を選ぶ・外すの切り替えになり、詳細は開かない
- [ ] 選んでいる間は全部の行に丸が出て、行のどこを押しても選ぶ・外すの切り替えになり、詳細は開かない
- [ ] Ctrl/⌘・Shift+クリックと Esc は今と同じに動く
- [ ] カンバン・バックログ・Epic と Iteration の詳細の中の行・履歴の行で使えて、丸の入る余白のぶん行の中身がずれない
- [ ] 上の動きを画面のテストで確かめる
