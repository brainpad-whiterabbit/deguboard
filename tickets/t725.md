## Summary

t703・t704 の左端の帯（styles.css の [data-select-id]::before）は幅 6px で狙いにくい。当たりの幅も見える帯の幅も 12px に広げる（押せる範囲がそのまま見える）。帯が番号や題の文字に重ならないよう、帯を持つ行の左の余白も同じだけ広げる。なぞりの開始の判定（ask-menu.tsx の STRIP_PX）も同じ値に揃える。幅の値は CSS と STRIP_PX の 2 か所に置き、互いを指すコメントを付ける。2 つが揃っていることは帯の端の画面のテストで確かめる。題のクリックで詳細を開く動きは変えない

## Acceptance criteria

- [x] 帯の当たりの幅と見える幅が 12px になり、なぞりの開始の判定（STRIP_PX）も 12px に揃う。CSS と STRIP_PX に互いを指すコメントがある
- [x] 帯を持つ行（カンバン・バックログ・詳細の中の行・履歴）の左の余白が帯の幅以上になり、帯が番号や題の文字に重ならない
- [x] 帯の外（番号・題）を押したときは今までどおり詳細を開き、帯を押したときは 1 件を選ぶ・外す
- [x] 帯の幅を前提にしたテストを新しい幅に合わせ、帯の端（12px の内側と外側）の当たりを画面のテストで確かめる
- [x] PR の本文に、変えた 4 か所の行のスクリーンショットを載せる
