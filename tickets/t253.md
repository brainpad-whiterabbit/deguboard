## 概要

見直し（audit-s8、観点：README の確かめで見つけた）。既にリモートに deguboard ブランチがあるリポジトリの 2 人目の clone で `dg init` を実行すると、worktree: from_remote・created: [] で何も書いていないのに「作業ツリーに残した（dg commit か dg sync でコミットする）」と出る。git status は clean で、メッセージが誤解を招く。

## 受け入れ条件

- [x] 書き込みのない dg init では「作業ツリーに残した」を出さない
- [x] 書き込みのある dg init のメッセージは今のまま
- [x] 2 人目の clone の init をテストで確かめる（一時ディレクトリの bare リモート付きのリポジトリ）
- [x] mise run check が通る
