## Summary

見直し（実装。t1073 のレビューで範囲外とされたもの）：packages/web/src/host.tsx の HostBridge は store.onSetupEvent と reload を useEffect で ref に写す。描画のコミットと副作用の間に event が届くと、古い handler に渡り、setup の event は needsSetup が古い値のまま捨てられる。まれにしか起きないが、製品の画面でも起きうる。

## Acceptance criteria

- [x] 描画のコミットの後、副作用より前に届いた setup と reload の event が、最新の handler に渡る
- [x] その順序で event が届く場合をテストが確かめる
