## 概要

観点：アーキテクチャ。AG-5 と ADR-007 は、Skill の置き場所の差を Agent Adapter が吸収するとする。
`dg skill install`（cli/skill.ts）は Adapter を通らず `.claude/skills` を自分で決め、頼むことの判定（t364）は Adapter の skillDirs を見る。2 つを揃えるのはコメントだけで、テストがない。
HOME の解決も違い、HOME が空文字のとき install は cwd から見た相対の場所に書き、判定は os.homedir() の下を見るので、入れたのに既定が文章になる。

## 受け入れ条件

- [x] `dg skill install` が書く場所（repo と personal）と、頼むことが Skill の有無を見る場所が、同じ定義から決まる
- [x] install が書く場所が判定の見る場所に入っていることをテストで確かめている
- [x] HOME が空か未設定のとき、install と判定が同じホームディレクトリを使う
