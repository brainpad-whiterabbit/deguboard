## Summary

観点は設定ファイルと README。t655 で追跡した .claude/settings.json のフックは、どれも PATH の dg を呼ぶ。しかし PATH に入れる手順は development.md:16 の手打ちの ln -sf だけで、mise の task がない。dg が PATH にないと各フックは 127 で終わり、Claude Code は止めない誤りとして扱う。そのため PreToolUse の守り（gh の直のマージや .git/deguboard への書き込みを止める）が、黙って効かなくなる。README の手順 4 と開発の始め方には、確かめ方の dg hooks check もない。
