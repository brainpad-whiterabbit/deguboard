## Summary

見直し（s30、テスト）。`mise run test:vscode` の計画のグラフのテストは、テストのプロセスから fixture のリポジトリ（cloneA）に dg で何度もコミットする。同じフォルダを開いている VS Code は組み込みの Git 拡張が有効で、変更を見て `git status` を回し `.git/index.lock` を一瞬取るので、重なると dg のコミットが `index.lock: File exists` で落ちる（s30 の作業中に 1 度起きた）。dg の withLock は dg 同士しか直列にしない。

- [x] `mise run test:vscode` が通る
