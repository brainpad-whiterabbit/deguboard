## 概要

優先度（high・medium・low）の判断基準は、今はリリース前の見直しの重大度の表（packages/cli/src/guide-audit.md）にしかなく、ふだんの起票では選び方が決まっていない。値ごとの判断基準を core の既定と config.yaml の priority に置き、dg guide import と dg guide audit がそれを使うようにする。画面のツールチップ（別チケット）もこの基準を読む。

既定の基準：

- high：利用者に見える不具合・利用者を誤らせる文書・悪用できる脆弱性・ライセンスの漏れ・検査が通らない・ほかのチケットを止めている
- medium（既定）：機能の追加と改善・テストの抜けと不安定なテスト・内部の文書の食い違い・今は害のない規約違反・大きく古い依存
- low：使われていないコードと依存・設定の重複・言い回しの揺れ・急がない調査と検討

## 受け入れ条件

- [ ] core に high・medium・low の既定の判断基準（概要の文）がある
- [ ] config.yaml の priority で、値ごとに基準を書き換えられる
- [ ] dg guide import の出力に、値ごとの基準（config にあればその値、なければ既定）が出る
- [ ] guide-audit.md の重大度の表が、この基準を使う形に置き換わっている
- [ ] requirements.md の Ticket と設定の節に書いてある
