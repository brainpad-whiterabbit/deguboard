## 概要

dg ask の abandon・undo_done は、ticket.move が actor.human_only に入っているかだけを見ている（packages/core/src/commands/ask.ts）。Workflow の by で人に限った遷移（requirements の WF-1）は判定に入らず、依頼文を出してもエージェントは TRANSITION_REJECTED で拒否される。チケットの Workflow の遷移の by も見て、人に限るなら人が打つ dg のコマンドを返す。t295 の見直し（PR #287）で出た。

## 受け入れ条件

- [ ] abandon・undo_done の頼むことで、対象のチケットの Workflow のその遷移の by に agent が入っていなければ、依頼文の代わりに人が打つ dg のコマンド（kind が command）を返す
- [ ] by に agent が入っている遷移では今までどおり依頼文を返す
- [ ] by が人に限る遷移と、agent を含む遷移の両方をテストで確かめる
