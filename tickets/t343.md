## 概要

チケットの見方だけ検索欄の横に「結果」の select が並び、検索欄が狭くなって案内の文字が切れる。中止の件数も開くまで分からない。
検索欄を全幅に戻し、その下に「すべて N · 完了 N · 中止 N」を見方の切り替えと同じ文字の切り替えで出す（改善案 R5、https://claude.ai/artifact/EJMeuuZdJfmTPNRgWgoHWH ）。

## 受け入れ条件

- [ ] チケットの見方の検索欄が Iteration・Epic の見方と同じ全幅になる
- [ ] 結果の絞り込みが select ではなく「すべて・完了・中止」の件数付きの文字の切り替えで、選んだものを aria-pressed と太字で示す
- [ ] 検索中は件数が当たった数になり、中止が 0 件なら中止を出さない
- [ ] 結果の絞り込みは今と同じくハッシュの ?result= に残る
