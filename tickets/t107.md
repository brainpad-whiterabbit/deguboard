## 概要

観点は設定ファイル。packages/core/package.json と packages/server/package.json の exports は development 条件で ./src/index.ts を指すが、files は dist だけなので、npm から取り込んだ利用者が Vite や --conditions=development で解決すると存在しないファイルに行き着く

## 受け入れ条件

- [x] 公開した tarball の exports が dist だけを指す（独自の条件名にするか publishConfig で外す）
- [x] 開発時のテスト・型検査・vscode のビルドは今までどおり src を見る
- [x] npm pack の中身で確かめる
