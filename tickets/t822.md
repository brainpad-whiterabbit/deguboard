## Summary

カンバンとバックログの行は、PR があるときチケット番号のすぐ下に PR の印と #番号のリンクを出す（RowPrLink・prRowClass・.pr-row）。履歴の行は PR を 2 段目の付記に文字で書くだけで、押せず、位置もほかの画面と違う。履歴の行もカンバンと同じく番号のすぐ下に PR のリンクを置き、付記から PR を外す。番号と PR を番号の列に縦に積み、PR のために行を増やさない（タイトルが 2 行なら 2 行目の横、1 行なら付記の横）。PR のないチケットで今の「PR なし」をどうするかは着手前に決める。

## Acceptance criteria

- [ ] 履歴の行で、PR のあるチケットの番号のすぐ下に PR の印と #番号が出て、GitHub の PR を開くリンクになる
- [ ] PR のリンクを出しても、行の高さ（行数）が PR のない行と変わらない
- [ ] 2 段目の付記から PR の番号が消える
- [ ] PR のリンクを押しても、行の選択と開いている詳細が変わらない
- [ ] PR のないチケットの出し方が決まり、テストで示されている
