## Summary

見直し（s36）のテストの観点。packages/core/src/commands/run.test.ts の closedRuns の transcriptFor を使う refresh のテストと started のテストは、本物の時計で Run を開いて閉じ、そのすぐ後に会話記録を utimes なしで書く。Adapter の fresh は更新時刻が started_at（秒に切り捨て）より前のファイルを外すので、書き込みが秒の境目に当たると会話記録が見つからず落ちうる。t977 が withModelTranscript だけで直したのと同じ原因が残っている。
