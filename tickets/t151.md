## 概要

いまエージェントが手を動かしているチケットと、着手しただけのチケットを見分けられるようにする（案のページの H2）。

## 受け入れ条件

- [x] 実行中（running）の Run があるチケットの行は、頭のリングが回り「実行中」と出る
- [x] 実行中の Run のない in_progress の行は、止まった半分塗りの丸が出る
- [x] 動きを減らす設定（prefers-reduced-motion）のときは回さない
- [x] Run の記録が増えたり終わったりすると、読み直しで表示が変わる
- [x] requirements.md の UI-2 を直す
