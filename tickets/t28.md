## 概要

VS Code の Webview は <a href="#…"> のクリックを横取りしてページ内アンカーのスクロールにし preventDefault するため、サイドバーのタブ、Epic・Iteration の一覧の行、「← Epic 一覧」「← Iteration 一覧」「この Epic でカンバンを見る」、エディタのパネルのチケットリンクがどれも遷移しない。JavaScript でハッシュを書く経路（起動時の data-route、カンバンの Epic の select、拡張ホストからの navigate）は動く。App の根の要素で click を受け、ハッシュのリンクなら自分で window.location.hash を書いて直す。TicketLink がサイドバーで先に preventDefault したもの（defaultPrevented）には触らない。

## 受け入れ条件

- [ ] サイドバーとエディタのパネルで、4 つのタブ・Epic と Iteration の行・一覧へ戻るリンクを押すと画面が切り替わる
- [ ] app.test.tsx に、document に VS Code と同じ preventDefault するリスナーを付けた状態でタブを click し location.hash が変わるテストがある
- [ ] サイドバーのチケットのリンクは今までどおり拡張ホストに頼んでエディタに開く（ハッシュは書き換えない）
- [ ] 選ばれているタブに aria-current="page" が付く
- [ ] router.ts 先頭の「Webview では遷移できないため」のコメントを、この横取りの説明に書き直す
