## 概要

s1 の done のチケット（t7〜t36 の大半）は受け入れ条件が未チェックのまま done になっている。ticket check が入ったら、PR とコードで満たしたと確認できた項目に印を付け、確認できない項目は人に報告する。

## 受け入れ条件

- [ ] s1 の done のチケットの受け入れ条件を PR とコードで確認し、満たした項目に ticket check で印を付ける
- [ ] 確認できない項目は人に一覧で報告し、印を付けない
- [ ] 確認を終えたチケットで dg lint の lint_acceptance_unchecked が出ない
