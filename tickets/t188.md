## 概要

左パネルの履歴の Iteration の行は、Epic の内訳が Epic に入ったチケットしか数えないので、s4 では完了 29 件のうち 12 件分しか見えない。名前（sprint4 など）は区別がつかず、目標は期間の後ろに押し出される。内訳と見出しを直す（改善案 H1）。改善案のページ：https://claude.ai/artifact/RPsNUSkt3w9SboDy5XQAwd


## 受け入れ条件

- [x] 行の内訳に「Epic なし N」が出て、内訳の合計が Iteration に入っている終わったチケットの件数と合う
- [x] 完了の件数をチップで出し、中止と持ち越しは 1 件以上のときだけ色付きのチップで出る
- [x] 目標のある Iteration は目標が 1 段目に出て、名前は 2 段目に小さく出る
- [x] 期間の記録がない Iteration には「期間の記録なし」を書かない
- [x] 幅 320px で行が読める（mise run test:layout）
