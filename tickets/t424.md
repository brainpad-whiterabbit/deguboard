## 概要

Plan の詳細の画面（`#/plans/p55`）を足し、チケット・Epic・Iteration と同じくエディタのパネルに開く。中身は plan.show を表示だけで出し、今は CLI でしか読めないチケットごとの範囲（scope）・進め方（approach）・tier も見られるようにする。カンバンの実行計画の帯の Plan の番号と、Iteration 詳細の Plan の節の番号を、この画面へのリンクにする。承認・閉じるは書き込まず、吹き出しから頼む（UI-15）。core と HTTP は変えない。

## 受け入れ条件

- [x] `#/plans/<id>` を開くと Plan 詳細が出て、VS Code ではエディタのパネルに開く（詳細のルートとして扱われる）
- [x] Plan 詳細に、状態・進み・Iteration・承認者と承認の日時（閉じた Plan は閉じた日時）・次のチケット・依存グラフと、Plan の順のチケットごとの範囲・進め方・tier が出る（details のないチケットは題と状態だけ）
- [x] 実行計画の帯で Plan の番号を押すと、グラフを開閉せずに Plan 詳細を開く。番号以外の場所を押すと今と同じくグラフを開閉する（閉じた計画の節の行も同じ）
- [x] Iteration 詳細の Plan の節の番号から Plan 詳細を開ける
- [x] requirements.md の UI-12・UI-13 に Plan 詳細が書かれ、ルートの往復と Plan 詳細の表示のテストと、test:layout の Plan 詳細のパネルがある
