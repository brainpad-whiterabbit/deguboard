## Summary

config の `merge.delete_branch` が有効なとき、`dg pr merge` は worktree とブランチを消している。それなのに `dg guide done` の手順 4 がエージェントにもう一度消させ、毎回 3 つのエラーになる（t844 で起きた）。人が GitHub の画面でマージしたときに残る worktree とブランチも、エージェントが git を直接呼んで消すことになっている。片付けを dg に寄せ、照合でチケットを done にするときに残りを消す。guide からは片付けの手順をなくす。

## Acceptance criteria

- [ ] `dg pr merge` の結果に、消した worktree とブランチが出る
- [ ] `merge.delete_branch` が true のとき、`sync` の照合でチケットを done にすると、残っている worktree・ローカルとリモートのブランチを消し、消したものを `reconciled` に添える
- [ ] コミットしていない変更があるか、ブランチの先端がマージした PR の先端と違うときは消さず、理由と消し方を warnings に出す
- [ ] `merge.delete_branch` が false のときは消さない
- [ ] 消す・消さない・設定が false の場合を、一時ディレクトリの bare リモート付きリポジトリのテストで確かめる
- [ ] `dg guide done` から片付けの手順を消し、片付けの warnings を人に伝える指示に替える
- [ ] requirements.md の照合の項（ST-4）に、done にするときの片付けの約束を足す
