## 概要

「依存先が終わっていない」は右の列の依存先の下に小さく出るだけで、依存元には Status が出ない。deps_done が偽なら本文の上に帯を出し、どの依存先が何の Status かを書く。依存先・依存元の両方に Status の丸印を付け、Done の依存先は薄くする。依存元の Status は store.tickets から引くので core は変えない。改善案 D8（https://claude.ai/artifact/RQHwi7v1k3rJx2Rvcin2Uo）

## 受け入れ条件

- [x] deps_done が偽のとき、本文の上に、終わっていない依存先の ID と Status を書いた帯が出る。真なら出ない
- [x] 依存先と依存元の両方に Status の丸印が出て、Done の依存先は薄く出る
- [x] 帯の出る・出ないをテストで確かめる
- [x] 変えた画面のスクリーンショットを PR に載せている
