## 概要

`dg guide overview`（約 6,600 字）は毎回最初に読まれる。エラーの文に同じ手があるもの・エージェントの判断に使わないものだけを消し、削ると挙動が変わるものは残す。

消してよいのは、次をすべて満たす文だけ。(1) その場面で必ず目に入るエラーの文・警告・`dg next` の出力に同じ手がある (2)「しない」の決まりではない (3) エラーにならずに黙って起きることではない (4) どのトピックを読むかを選ぶ材料ではない。

- 消す候補：「dg の外の変更」の人向けの戻し方と版違いの説明（`OUTSIDE_CHANGES` の文にある）、ユーザの決まり方の順（`whoami` の `user_source` が出る）、「同期が止まったとき」の人の戻し方（先のチケットでエラーの文に移したもの）、トピック表の「内容」の列を短くする
- 残す：自分では競合を解かない・自分では adopt せず人に決めてもらう、`PUSH_FAILED` のやり直し、仮番号が振り直されたら人に伝え直す、トピック表の「読むとき」の列、人だけに限られうる操作

## 受け入れ条件

- [x] PR の本文に、消した文ごとに同じ手がどこで届くか（エラーの文・警告・出力のどれで、どのファイルか）と、上の (2)〜(4) に当たらないことを書いた対応表がある
- [x] 「残す」に挙げた決まりが guide に残っている
- [x] guide.test.ts の断言を消していない（消したなら、その語が要らなくなった根拠が対応表にある）

- [x] 減った字数を PR の本文に書いた
