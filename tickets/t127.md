## 概要

t110 の判断（案 C）。別のサブエージェントの見直しは、今は --auto で auto.merge が true のマージ前の条件にしかない（guide-all）。dg guide work でも PR を出す前に、実装したのとは別のサブエージェントで見直し、指摘は同じブランチで直して見直し直す。回数に上限を置き、超えたら Run を --retries 付きの failure で閉じて人に報告する。guide-all の「マージの前の条件」を品質ゲートとして 1 か所にまとめ、PR を出す前とマージの前の両方から参照する（EX-3）

## 受け入れ条件

- [x] dg guide work に、PR を出す前の別エージェントの見直しと修正ループの手順と回数の上限がある
- [x] 上限を超えたときの Run の結果・チケットの置き場所・人への報告の扱いが書いてある
- [x] 品質ゲート（検査・受け入れ条件・見直し・衝突なし）が 1 か所に書かれ、guide-all と重複しない
- [x] guide.test.ts で節があることを確かめている
- [x] requirements.md の EX-3・README を直している
