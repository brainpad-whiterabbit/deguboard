## Summary

新しいリポジトリで始める人が、導入の画面で「チームで共有する」と「このマシンだけに置く」を選べるようにする。導入したあとは、手元だけで使っていることが画面から分かるようにする。既定は今と同じ「チームで共有する」。

## Acceptance criteria

- [x] リモートにボードがないとき（`remote_no_board`）、ボードの項目は「チームで共有する」（既定）・「このマシンだけに置く」・「チームのボードは別のリポジトリにある」から選ばせ、それぞれの下に選んだときの影響を 1 行で書く。共有の道には、リポジトリを読める人は誰でも読めることを書く
- [x] リモートがないとき（`no_remote`）、あとでリモートを足したらボードも push するか（既定）、このマシンだけに置くかを選ばせる
- [x] リモートに届かないとき（`remote_unreachable`）、今の `--new-board` のボタンの文を、届いたら push することが分かる文に直し、「このマシンだけのボードを作る」を別の道として足す
- [x] 「このマシンだけ」を選んだときのボタンとターミナルの 1 行は `dg init --no-data-remote` を打ち、VS Code 拡張のボタンも同じ 1 行を流す
- [x] 導入のあと、`git.data_remote` が `none` のときだけ、ボードの上に「このマシンだけ」の印を出し、共有への切り替え方を示す。足した文は英語の訳も持つ（UI-11）
- [x] usage.md と usage.ja.md の、導入の画面のボードの項目のボタンを説明する記述を、今の画面に合わせる
