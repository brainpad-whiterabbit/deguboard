## Summary

監査（文書と実装）と s45 の PR の見直しの軽い指摘をまとめたもの。
- ADR-031 の要約と最初の決定、guide-work.md の「Before and after claim」は、Iteration の開始（と worktree の作成）が lint.require_iteration に従うと書くが、コードで設定に従うのは Iteration への追加だけで、開始と拒否はいつも行う（IT-4）
- guide-plan.md は、ほかの Iteration が active のうちに planned の Iteration の Plan を作っても着手できない（claim が拒否し、dg next が wait_human）ことを承認の前に知らせない
- guide-check.md は sync の警告をすべて dg guide done で確かめるよう案内するが、照合が前進を止めた警告（境目の方針と Iteration のもの）は done の対象ではない
- requirements の ST-3「名前は dg が `<id>` から作る」は、どの名前のことか読み取りにくい

## Acceptance criteria

- [x] ADR-031 と guide-work.md が、lint.require_iteration に従うのは Iteration への追加だけで、開始と拒否は設定によらないと書く

- [x] guide-check.md が、照合が前進を止めた警告を done の手順と分け、警告の出口を人に伝えるよう案内する
