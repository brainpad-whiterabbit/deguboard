## 概要

docs と README と CLAUDE.md の相対リンクと見出しアンカー（`#節名`）が存在する対象を指しているかを check-docs.mjs で検査し、切れていれば `mise run check:docs` を失敗させる。依存なしで動かす方針は保つ

## 受け入れ条件

- [ ] 相対リンクの先のファイルがないとき `mise run check:docs` が失敗し、ファイルと行を出す
- [ ] `#見出し` のアンカーが対象の見出しに合わないとき失敗する（GitHub 流のアンカー変換に従う）
- [ ] 外部 URL は検査しない
- [ ] 現状の文書で通り、依存を増やさない
