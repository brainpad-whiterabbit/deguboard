## 概要

PR #158（t170）の見直しで見つけた、範囲の外の指摘。main に前からある。

- .oxlintrc.json:138-142 は、web から `@deguboard/core` を型だけ取り込めるよう `allowTypeImports: true` 付きで制限している（ADR-007）
- oxlint ではこの規則が効かず、web の本体のファイルに `import { progressOf } from "@deguboard/core"` を書いてもエラーにならない（`deguboard-vscode` の制限は効く）
- packages/web/src/pages/board.test.ts:3 はテストで core の実行時のコード（progressOf）を import しており、規則を効かせたらテストだけを例外にする必要がある

## 受け入れ条件

- [x] web の本体（テスト以外）で `@deguboard/core` から値を import すると `mise run lint` が落ちる
- [x] `import type` は今までどおり通る
- [x] テストのファイルの core の import は、意図した例外として通る
