## 概要

拡張はデータのファイルの見張り（packages/vscode/src/extension.ts の watchData）を、起動したときに status が返す data_dir（<common>/deguboard/）に仕掛けるが、仕掛け直さない。clone した直後に拡張を開き、データ worktree が後から作られると、見張りが効かず、ウィンドウを再読み込みするまでボードが自動で更新されない（2026-11-05 の新しい環境で起き、Reload Window で直ることを確かめた）。status が失敗したときも、拡張を再起動するまで見張らない。

## 受け入れ条件

- [ ] data_dir がまだ無いときは <common>/deguboard ができるのを見張り、できたら本来の見張りを仕掛けて、ボードを読み直す
- [ ] status が失敗して見張りを仕掛けられなかったときも、後で（次の読み直しなどで）もう一度試す
- [ ] 見張りの仕掛け方を決める部分を VS Code API に触れない関数にし、データ worktree が無いときと有るときをテストで確かめる
- [ ] mise run check が通る
