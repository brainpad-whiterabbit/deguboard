## 概要

Workflow を足す・変える dg の手段がなく、dg init は既にある Workflow を上書きしない。同梱のテンプレートの変更（t174 の fix など）を init 済みのリポジトリに入れるには、データのファイルを直接編集するしかない（t174 では人の許可を得て deguboard ブランチの workflows/software-development.yaml に steps を直接足した）。dg workflow set <id> --file <yaml> でファイルの定義を検証し（WF-3）、通れば workflows/<id>.yaml を 1 回のコミットで置き換える（なければ作る）。dg workflow set <id> --template <name> で同梱のテンプレートで置き換える。コマンドの定義は core に置き、CLI・HTTP・MCP は写すだけにする。変わる前と後の差を出力に載せる。

## 受け入れ条件

- [x] --file で検証を通った定義だけが書き込まれ、通らなければ何も書かずに WF-3 の指摘を返す
- [x] --template で同梱のテンプレートの定義に置き換わる
- [x] 使っている Project の Workflow を置き換えても既存のチケットが読め、transitions・reconcile の誤りは拒否する
- [x] CLI・HTTP・MCP で同じ操作ができる
- [x] requirements.md の WF 節に約束を足し、ADR-003 を書き換えてある
- [x] 書き込み・拒否・テンプレートのテストが一時リポジトリにある
