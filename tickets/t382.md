## 概要

Marketplace の一般の利用者に向けて、VS Code の表示言語が英語のとき、拡張の manifest（コマンド名・ビュー名など）と拡張ホストの通知を英語で出す。

## 受け入れ条件

- [ ] 表示言語が英語のとき、コマンドパレット・メニュー・ビューの名前が英語で出る
- [ ] 表示言語が英語のとき、拡張ホストの通知と警告が英語で出る
- [x] 表示言語が日本語のときは、今と同じ文言で出る
- [x] 文言が manifest とコードに直書きされず、言語ごとのファイルにある
