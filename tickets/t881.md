## Summary

UI 案の D2。カンバンの左パネルの行の右端の下の段（今「実行中」と出ている場所）に、そのチケットの Run を古い順に丸で並べる。丸の色と形は Run の結果（成功・失敗や重い指摘・中断・実行中・返事待ち）を、最後の丸の横の短い文字はいまの手と経過の時間を表す。todo でも実行中の Run があれば今と同じく出す。

## Acceptance criteria

- [ ] 丸は 3 個までにし、それより古い分は「+n」にまとめる。最後の丸は少し大きく、色だけでなく形（塗り・中抜き・半分塗り）でも結果を見分けられる
- [ ] 最後の丸の横に「手 · 経過」「返事待ち · n分」「中断 · n時間前」のような文字を出す。手の名前は Workflow の step の表示名（なければ id）で、経過の時間は 1 分ごとに描き直す（dg は呼ばない）
- [ ] 丸にマウスを重ねるか、Tab で丸に移ると、手・結果・時刻とかかった時間（手直しは直した指摘の数、見直しは指摘の数、失敗・中断は理由）が出る。丸の並び全体に読み上げ用の名前がある
- [ ] 返事待ちと失敗・中断の行は地の色を変え、行の頭の印（ActivityMark）は外す
- [ ] 動きを減らす設定（prefers-reduced-motion）では明滅しない
- [ ] requirements.md の UI-2 に、行の右端に Run の並びを出すことを 1 文足す
