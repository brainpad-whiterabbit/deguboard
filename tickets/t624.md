## 概要

dg は呼ぶたびに 292 モジュール（zod・core・yaml）を読み込んでコンパイルし、起動だけで約 0.8 秒かかる。PreToolUse のフックは Bash・Edit・Write のたびにこの分を払う（1 回約 0.9 秒）。Node のコンパイルキャッシュを使い、2 回目以降の起動を速くする（試しに NODE_COMPILE_CACHE で dg --version が 0.85 秒から 0.22 秒になった）。検討は 2026-11-09 の検討書（dg 起動コスト検討）の案 A。

## 受け入れ条件

- [x] dg の起動でコンパイルキャッシュを有効にする
- [x] dg --version と PreToolUse のフックの 2 回目以降の時間を、入れる前と比べて測り、PR の本文に書く
- [x] キャッシュの置き場所に書けないときも、dg はエラーにならずに動く
