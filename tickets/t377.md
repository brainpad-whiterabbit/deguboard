## 概要

チケット詳細の本文のチェックボックスを押して、本文の編集を開かずに受け入れ条件の印を付け外しできるようにする（UI-7 の本文の編集の範囲）。

## 受け入れ条件

- [x] 詳細の本文のチェックボックスを押すと、その行だけ [ ] と [x] が切り替わって保存される
- [x] ほかの行と本文の残りは変わらない
- [x] 保存の間に別の書き込みがあったときは、拒否の理由を出して画面を元に戻す
- [ ] VS Code の詳細のパネルとブラウザの両方で同じように動く
