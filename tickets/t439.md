## 概要

拡張の Webview の色・CSP・拡張ホストとのやり取りは、今は人が実機で見ている。試作では、Xvfb 上で `@vscode/test-electron` が落とした VS Code を Playwright の `_electron` で操作して、テーマごとのスクリーンショットが撮れた。これを mise のタスクにし、PR のスクリーンショットと動作確認に使えるようにする。

## 受け入れ条件

- [x] `mise run test:vscode` が一時リポジトリ（bare リモート付き）で拡張開発ホストを Xvfb 上に起動し、左パネルの Webview の中を操作してチケットの行が出ることを確かめる（`check` には入れない）
- [x] ライトとダークのテーマのスクリーンショットを決まった場所に出す
- [x] Webview の CSP 違反と例外を検出したら失敗する（わざと違反を起こした場合に落ちることを確かめる）
- [x] 起動前に `ELECTRON_RUN_AS_NODE` などの環境変数を外し、Claude Code の中からでも起動できる
- [x] ダウンロードした VS Code（`.vscode-test/`）が git と VSIX に入らない
- [x] development.md の「Webview に固有の色や CSP は人が見る」と PR のスクリーンショットの手順を、この方法に合わせて書き換える
