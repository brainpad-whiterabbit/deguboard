## Summary

Marketplace への初回の上げ（t840）が「This extension display name is taken」で拒否された。Remove した拡張が表示名 deguboard を押さえたままのため。packages/vscode/package.json の displayName を「deguboard for VS Code」にする。Activity Bar の view container・view・コマンドの category など、画面に出る deguboard はそのままにする（表示名だけを変える）。表示名を deguboard と書いている文書（development.md など）があれば直す。

## Acceptance criteria

- [ ] packages/vscode/package.json の displayName が deguboard for VS Code で、mise run vsix で作った VSIX の extension.vsixmanifest の DisplayName も同じになっている
- [ ] Activity Bar の view container・view・コマンドの category の deguboard は変わっておらず、品質ゲートの検査が通る
