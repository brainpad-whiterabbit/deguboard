## Summary

同期のボタン（$(sync)）は、同期が要るときも見た目が変わらず、未 push・未取り込みは Activity Bar のバッジにしか出ない。fast-forward で済む取り込みは t1085 で自動になるので、残る人の手が要る状態（未 push のコミットがある・未取り込みと未 push の両方がある）の間だけ、t1084 と同じ作り（context key で点付きの自作 SVG アイコンのコマンドに差し替える）で同期のボタンに点を付ける。競合は後から見える状態として残らない（rebase を中止してコミットを残す）ので別の色にはせず、同期したときの通知（remote か local を選ぶボタン）で知らせる。未コミットの変更だけでは点を出さない。

## Acceptance criteria

- [x] 未 push のコミットがある間、または未取り込みと未 push の両方がある間、同期のボタンが点付きのアイコンに替わり、同期を済ませると元のアイコンに戻る
- [x] 自動で取り込める状態（t1085）と、すべて同期済みの状態では点を出さない
- [x] 点付きのアイコンのツールチップに、何が残っているか（未 push の件数・未取り込みの件数）が出る（表示言語で訳す）
- [x] 点付きのアイコンを押すと、元と同じく同期する。差し替え用のコマンドはコマンドパレットに出ない
- [x] 点付きのアイコンは light と dark のテーマのどちらでも見分けられる
- [x] 要件 UI-6 の 1 文を、同期のボタンでも知らせる約束に合わせて直す
- [x] 画面の見た目を変えるので、PR の本文に変えたタイトル行のスクリーンショットを載せる
