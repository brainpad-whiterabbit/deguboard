## 概要

e13 で対象をソフトウェア開発に絞ったので、ADR-006 がブラウザを残した理由（VS Code を使わない業務）がなくなった。人の画面は VS Code 拡張、エージェントは CLI と MCP にし、ブラウザ（`dg serve`）は利用者向けの入口から外して開発用（配置の確認とスクリーンショット）にする。Run の画面は消し、Run はチケット詳細の Run の節、集計は `dg metrics show` で見る。コードの削除は別のチケット（t497）で行う。

ADR は決めたら書き換えない（ADR-001）。画面の入口の判断は新しい ADR に書き、ADR-006 の該当の節か項に置き換えの印を付ける。
