## 概要

test/e2e/routes.test.ts の CLI の経路は runCli を env なしで呼ぶため、process.env の DEGUBOARD_ACTOR を拾う。DEGUBOARD_ACTOR=agent を export したシェルで mise run check を流すと、CLI の経路だけ created_by が e2e/agent になり、HTTP・Webview との一致の比較で落ちる（2026-11-01 の s4 のリリースで起きた）。テストの側で主体を決める環境変数を外して渡し、ほかのテストにも同じ漏れがないかを確かめる

## 受け入れ条件

- [ ] DEGUBOARD_ACTOR=agent DEGUBOARD_USER=someone mise run check が通る
- [ ] routes.test.ts の CLI の経路が、主体を決める環境変数を含まない env を runCli に渡す
- [ ] runCli を env なしで呼ぶほかのテストを洗い出し、漏れがあれば同じく直す（なければ PR に書く）
