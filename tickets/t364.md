## 概要

頼む小窓の形式の既定は Skill に固定されていて、Skill を入れていない人が /dgimport などを貼っても動かない。dg の Skill が入っているかを見て、なければ既定を文章の形式にする。

## 受け入れ条件

- [x] `<リポジトリ>/.claude/skills/` と `~/.claude/skills/` のどちらにも dg の Skill がなければ、頼む小窓の形式の既定が文章になる
- [x] どちらかにあれば、形式の既定は Skill のまま
- [x] 人が切り替えた形式は、Skill の有無にかかわらずそのまま使う
- [x] Skill の有無の判定は core のコマンド定義に置き、CLI・HTTP・Webview はそれを写す
