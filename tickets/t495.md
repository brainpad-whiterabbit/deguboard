## 概要

頼む小窓（ask）の選択肢に、Run の履歴を分析するコマンドの結果から、ボトルネックと改善の案（手順・モデルの tier・チケットの切り方）を挙げるようエージェントに頼む依頼を足す。対象は Iteration と Epic。「振り返る」の依頼文も分析のコマンドの数を使うようにする。日本語と英語の両方で出す。

## 受け入れ条件

- [ ] Iteration と Epic の頼む小窓に「分析する」が出る
- [ ] 依頼文が分析のコマンドを使うよう書き、データを書き換えないと明記している（日英）
- [ ] 「振り返る」の依頼文が分析のコマンドの数を使うよう書いている（日英）
- [ ] ask のテストがあり、`mise run check` が通る
