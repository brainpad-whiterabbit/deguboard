## 概要

VS Code の主画面は左パネルにし、エディタのパネルは左パネルから開いたチケット・Iteration・Epic の詳細だけを出す（2026-11-01 の方針）。Epic の詳細の Status ごとの列（カンバン）は、パネルでは 1 本の一覧にする。改善案の P1・E1（https://claude.ai/artifact/3tAZVL4UG8wiNNXijUbZhu）。ブラウザ版（dg serve）は変えない。要件を変えるので、同じ PR で requirements.md と ADR-006 を書き換える

## 受け入れ条件

- [ ] コマンド「画面を開く」（deguboard.open）がなくなり、パネルにカンバン・バックログ・履歴・Run を出す道がない
- [ ] パネルの詳細に「← バックログ」「← カンバン」の戻るリンクが出ない
- [ ] パネルの Epic の詳細で「この Epic でカンバンを見る」を押すと、左パネルのカンバンがその Epic で絞られてフォーカスが移り、パネルの中身は変わらない
- [ ] パネルの Epic の詳細のチケットが、未完了・完了・中止の小見出しと件数の付いた 1 本の一覧で出る。0 件の段は出ず、完了と中止は既定で畳まれる
- [ ] ブラウザ版の画面は変わらない
- [ ] requirements.md の UI-10・UI-12 と ADR-006 が、パネルは詳細だけという方針に合っている
