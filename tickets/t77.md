## 概要

カンバンの「Iteration なし」と Iteration のない Project の表示で、done・abandoned のチケットが溜まる。入っている Iteration か Epic のどちらかが閉じている終わったチケットは出さない（OR）。閉じた Sprint のチケットは今も選択肢に出ないので、実際に効くのは閉じた Epic のチケット。done・abandoned 以外のチケットは Epic が閉じていても出す（EP-4 の強制で閉じた場合に作業が残るため）。隠したチケットは履歴（t73・t75）でたどる。2026-11-01 の時点で「Iteration なし」の表示から 7 件減る見込み。

## 受け入れ条件

- [x] カンバンで、Epic か Iteration が closed の done・abandoned のチケットが列に出ない（done の列の件数・abandoned の列にも数えない）
- [x] Epic が closed でも、todo・in_progress・review のチケットは出る
- [x] Epic が open か Epic なしで、Iteration に入っていない done・abandoned のチケットは今どおり出る
- [x] Iteration のない Project の全チケットの表示にも同じ規則が効く
- [x] Epic の絞り込みで closed の Epic を選んだとき（URL で指定したとき）は、その Epic の終わったチケットも出す
- [x] 規則を web のテストで確かめる
- [x] requirements.md の UI-2 に規則を書き足す
