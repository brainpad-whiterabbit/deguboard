## 概要

左パネルのカンバン・バックログ・履歴で、行や見出しにマウスを載せると右端に吹き出しのボタンを出し、押すと頼むことの一覧を直接出す。右クリックのメニューにも「エージェントに頼む ›」を足す。選ぶと左パネルの下に入力欄が出る。

案のページ：https://claude.ai/artifact/DsZs7PgafyAdNmmb64k6q5

## 受け入れ条件

- [x] カンバンの行・状態の節の見出し・Iteration の見出し・Plan の帯、バックログの行・区画の見出し・Epic の札、履歴の行から頼める
- [x] 吹き出しはマウスを載せたときと選んだときに出し、タッチの画面では常に出す。ふだんは行の右端の印を隠さない
- [x] 吹き出しを押すと頼むことの一覧が直接出て、場所と状態に合うおすすめが先頭にある
- [x] 右クリックのメニュー（webview/context）のサブメニューにも同じ一覧が出る。カンバンのカード・見出し・履歴の行にも webviewSection を載せる
- [x] 行にフォーカスがあるとき Shift+F10 で同じ一覧が出る
- [x] 初めて左パネルを開いたときに 1 度だけ「行の吹き出しか右クリックでエージェントに頼めます」と出し、× で消したら出さない
