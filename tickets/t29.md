## 概要

KanbanForge と同じく、ビューのタイトル行（view/title の navigation）に再読み込み（$(refresh)、deguboard.reload）と同期（$(sync)、deguboard.sync）を並べる。再読み込みはリモートがなくても使える。サイドバーでは画面の中の SyncIndicator（同期ボタンと印の行）を描かず、2 行目を空ける。ブラウザ（dg serve）とパネルではそのまま残す。印はビューのバッジとそのツールチップに寄せ、ツールチップに未コミットの変更と読めないファイルも足す。コマンドは拡張ホストで client を呼んでから、サイドバーとパネルの両方に reload の event を送る（いまの sync はサイドバーの Webview に event を投げるだけで、サイドバーが描かれていないと何も起きない）。

## 受け入れ条件

- [ ] ビューのタイトル行に再読み込みと同期のアイコンが並び、再読み込みはリモートがなくても押せて store を読み直す
- [ ] 同期はリモートがないとき通知で「リモートがない」と知らせる
- [ ] 同期と再読み込みのあと、サイドバーとエディタのパネルの両方が新しい内容になる
- [ ] サイドバーでは画面の中の同期ボタンと印の行が出ない。ブラウザとパネルでは今までどおり出る
- [ ] core の WebviewEvent に reload を足し、webview.test.ts と app.test.tsx で検査する
- [ ] requirements.md の UI-12 を「再読み込みと同期のボタン」に直し、packages/vscode/README.md も合わせる
