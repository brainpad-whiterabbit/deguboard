## 概要

`--auto` で自動で選んでよい判断の一覧は、guide-all の文にある。config の `auto.decisions` と `flow.skip` にし、dg flow next の `auto_ok` と段階の判定がそれを読む。

## 受け入れ条件

- [ ] config に `auto.decisions` と `flow.skip` があり、既定値で今の guide-all と同じ振る舞いになる
- [ ] dg flow next の `auto_ok` が `auto.decisions` と `auto.merge` に従い、`flow.skip` の段階を返さない
- [ ] 人が決める判断（abandoned・閉じる・リリースの PR のマージ）は、config によらず `auto_ok` が false
- [ ] guide-all の「`--auto` で自動で選ぶ」の一覧を消した
- [ ] 設定の説明（`dg config` の項目の説明）とテストがある
