## Summary

起動ファイルが消えたとき、dg hooks check は「VS Code を一度開く」とだけ案内する。拡張を消した後（vscode:uninstall が起動ファイルと current を片付けた後）は、この案内に従えない。拡張が残っているかどうかで案内を分ける（p106・t735/t736 の見直しで残した指摘）。

## Acceptance criteria

- [x] 拡張がもうないとき（起動ファイルも current もない）は、フックを入れ直すか外す案内を出す
- [x] 拡張が残っていて起動ファイルだけが消えたときは、今の「VS Code を一度開く」の案内のまま
- [x] 両方をテストで示す
