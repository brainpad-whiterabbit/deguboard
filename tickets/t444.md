## 概要

claim で開いた実装の Run を、手順書の `run finish` に頼らずに閉じる。PR の記録・PR の発見・unclaim・PR の要らない作業の done と review を閉じる契機にする。使用量は「ID が会話記録に出てから finished_at まで」で数えるので、後から閉じても finished_at を PR の作成時刻にすれば数え方は変わらない。

## 受け入れ条件

- [x] `ticket update --pr` か、`dg sync` が作業ブランチの PR を見つけたとき、実装の Run を success で閉じ、finished_at を PR の作成時刻にする
- [x] `ticket unclaim` で開いている実装の Run を failure で閉じる
- [x] `--without-branch` の作業の Run を、`ticket move` の done・review で success で閉じる
- [x] 閉じた Run に `run finish` を呼んでも記録を壊さない
- [x] 閉じ方を一時ディレクトリの bare リモート付きリポジトリでテストし、`dg guide` の work・run と requirements・ADR-005 を合わせて直す
