## 概要

`mise run test:vscode` の Webview は VS Code の既定の英語で表示される。`--locale=ja` は日本語の言語パックがないと `vscode.env.language` に効かない。日本語の画面の見た目は `test:layout`（ブラウザ）でしか確かめられないので、言語パックを入れて日本語でも撮れるようにし、言語を引数で選べるようにする。p63 の t439 の見直しで出た範囲の外の指摘。

## 受け入れ条件

- [ ] test:vscode に表示言語を渡す口があり、日本語を指定すると Webview の見出し・ボタンが日本語で出る
- [ ] 日本語の言語パックの入れ方（ダウンロードの場所と git・VSIX から外すこと）が test/vscode のコメントか development.md にある
- [ ] 日本語で撮ったスクリーンショットが英語と別の名前で出る
- [ ] mise run test:vscode が英語・日本語の両方で通り、mise run check が通る
