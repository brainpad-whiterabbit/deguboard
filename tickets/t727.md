## Summary

PR のリンクが右端（Plan の番号と待ちの 2 段）の下の 3 段目に出て、PR のある行が 3 行の高さになっている。番号のすぐ下（2 段目）に出す。

## Acceptance criteria

- [ ] PR のリンクが番号のすぐ下の段に出る
- [ ] 右端が 2 段・タイトルが 2 行の行でも、PR のある行が 2 行の高さに収まる
- [ ] PR のリンクを押しても行の選択と詳細は変わらず、2 段目の番号の列の外を押すと行を選べる
