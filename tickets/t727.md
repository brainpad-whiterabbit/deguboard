## Summary

PR のリンクが右端（Plan の番号と待ちの 2 段）の下の 3 段目に出て、PR のある行が 3 行の高さになっている。番号のすぐ下（2 段目）に出す。

置き方は案 B（人が選んだ）：番号は 1 段目、タイトルと右端は 2 段にまたがり、PR の印と #番号は番号の列の 2 段目に置く。PR の文字が番号より広い行は番号の列を広げる（タイトルの左端が行ごとにずれるのは受け入れる）。比べた案：https://claude.ai/artifact/6J4ArtzximsnA1zeiQcPCd

## Acceptance criteria

- [x] PR のリンクが番号のすぐ下の段に出る
- [x] 右端が 2 段・タイトルが 2 行の行でも、PR のある行が 2 行の高さに収まる
- [x] PR のリンクを押しても行の選択と詳細は変わらず、2 段目の番号の列の外を押すと行を選べる
