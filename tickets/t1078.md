## Summary

Git を使うテストは既定の設定（push.mode auto）のまま書き込むので、書き込みのたびに fetch・merge-base・rebase・push が走る。commands-flow-ticket.test.ts の 37 件では git を 4662 回起動し、そのうち fetch・merge-base・rebase・push が 150〜180 回ずつだった（2026-11-17 に測った）。同期を確かめないテストファイルでは、push しない設定（push.mode manual）で回す。

## Acceptance criteria

- [ ] push を止めるテストファイルと、既定のまま残すファイル（同期・取り込み・push・リモートを確かめるもの）を、理由とともにテストのコメントに書く
- [ ] 既定の push.mode auto の経路を確かめるテストが残る
- [ ] 全体のテストの時間と、遅い上位 5 ファイルの時間の変更前後を PR に載せる
