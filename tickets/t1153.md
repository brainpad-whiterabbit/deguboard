## Summary

今の品質ゲートは、見直しが記録した SHA が作業ブランチのリモートの先端と一致するときだけ見直しを数える。マージの前に main を取り込むと先端が変わり、見直しのやり直しが要る。base を取り込んだだけで base からの変更が見直しのときと同じなら、前の見直しを数える。

## Acceptance criteria

- [ ] base の取り込みだけで base からの差分が見直しのときと同じなら、`dg gate` の review の条件が満たされる（判定の組み合わせを純粋な関数のテストで網羅する）
- [ ] 取り込みと一緒に別の変更が入ったとき、または競合を解いて差分が変わったときは、前の見直しを数えない
- [ ] `dg gate --help` の review の条件の説明を直す
