## 概要

PreToolUse のフックの advancesPrOutsideDg（packages/core/src/commands/hook.ts）は、gh・pr と merge か ready の語がコマンド行のどこかにあれば、引用符やヒアドキュメントの中でも止める。s23 では t615・t617 の実装役が gh pr create のタイトルに「merge」を入れて止められ、タイトルを言い換えて --body-file で渡した。親がこのチケットを起票するときも、本文の文字列で止められた。README（t612）は拒む操作を「dg を通さない gh pr ready・gh pr merge」と書いているので、利用者が驚く。

## 受け入れ条件

- [ ] gh pr create・gh pr edit の --title・--body、dg ticket create の --body に merge・ready の語を含めても拒まない
- [ ] dg を通さない gh pr merge・gh pr ready（gh api での同じ操作を含む）は今までどおり拒む
- [ ] 上の 2 つをテストで確かめている
