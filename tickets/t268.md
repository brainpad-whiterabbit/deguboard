## 概要

経過は毎行に同じ日付が繰り返され、Status の変わらない行は丸印の場所が空いて列がずれて見える。誰がしたかはツールチップでしかわからない。日付が変わるところに日付の行を挟んで各行は時刻だけにし、Status の変わらない行には中の空いた丸を置く。行の右にコミットの作者（author）を薄く出す。人か agent かを分けて出すのは core の変更が要るので、このチケットでは扱わない。改善案 D6（https://claude.ai/artifact/RQHwi7v1k3rJx2Rvcin2Uo）

## 受け入れ条件

- [ ] 経過で日付が変わるところに日付の行が入り、各行には時刻だけが出る
- [ ] Status の変わらない行に中の空いた丸が出て、丸印の列がそろう
- [ ] 各行にコミットの作者が出る
- [ ] 日付の区切りをテストで確かめる
- [ ] 変えた画面のスクリーンショットを PR に載せている
