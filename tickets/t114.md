## 概要

観点は設定ファイル。packages/vscode/vite.config.ts と vitest.layout.config.ts がどの tsconfig にも入らない。packages/web の dev script がどこからも使われない。mise.toml の vsix:install は説明が「ビルド済みの VSIX を入れる」なのに depends で毎回ビルドする。Skill は PATH の dg を先に使うので、このリポジトリでは CLAUDE.md の mise run dg と食い違いうる

## 受け入れ条件

- [ ] 2 つの設定ファイルが型検査に入る

- [ ] vsix:install の説明と depends が合っている
- [ ] CLAUDE.md に Skill の中の dg も mise run dg -- で呼ぶことが書かれている
