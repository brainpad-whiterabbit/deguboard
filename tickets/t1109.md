## Summary

見直し（文書と実装）：t1095 で ADR-034 の止まる約束を「止まるのは config を取り込んだそのコマンドだけで、画面の自動の取り込みが先に取り込んだときは次のコマンドは止まらずに新しいリモートを使う」に直したが、docs/requirements.md の 5.10 の `git.data_remote` の項は「取り込んだ config でこの値が変わったときは、push する操作は止まって次の手を示し」のままで、同じ PR で直していない（`git.data_branch` の項も「`git.data_remote` と同じく止まり」）。実装は ADR-034 の側（packages/core/src/git/write.ts の stopIfDataRemoteChanged はコマンドの開始時の config を基準にする）。あわせて、docs/adr/ADR-003-status-and-workflow.md の「採らなかった案」の任意フィールドの行が「1011 件のチケットで 1 件も使われなかった」と時点の数を書いていて、ADR-001 の「今の判断と理由だけを書く」に合わない。

## Acceptance criteria

- [x] docs/requirements.md の 5.10 の `git.data_remote` と `git.data_branch` の項が、画面の自動の取り込みが先に取り込んだときは次のコマンドが止まらないことと矛盾しない
- [x] ADR-003 の「採らなかった案」の任意フィールドの行が、時点の件数を書かずに理由を述べている
- [x] mise run check:docs が通る
