## Summary

`dg metrics show` は工程ごとのトークン（input・output・cache_read・cache_write）を集計しているが、guide-retro.md の数字の要約と観点はトークンを使っていない。README は「要約に所要時間・トークン・やり直しを出す」と書いており、ずれている。要約に工程ごとのトークンを足し、観点（流れ・比較）でトークンを根拠に使えるようにする。トークンを読まない設定（`metrics.read_transcripts` が off）では計測の欠け（`missing`）として注記する。

## Acceptance criteria

- [x] guide-retro.md の数字の要約に、工程ごとのトークンとその割合があり、どの項目（input・output・cache）をどう数えるかが書いてある
- [x] 観点の「流れ」と「比較」で、トークンを根拠に挙げられる
- [x] トークンが計測されていないとき（`missing` や `read_transcripts` が off）は、計測の欠けとして注記するとガイドにある
- [x] README.md・README.ja.md の History の節の記述が、ガイドの要約と食い違わない
