## 概要

`dg skill install` が、`skill` を持つ guide のトピックごとに `.claude/skills/dg<topic>/SKILL.md` を作る。名前・説明・argument-hint は guide-<topic>.md の frontmatter に 1 か所で持つ。SKILL.md は `dg guide <topic>` を実行して `$ARGUMENTS` を渡す薄い包み。ハッシュの印で手を加えていない Skill を --force なしで更新し、手を加えたものは残して知らせる。旧 deguboard Skill は廃止する。トピックは create→import、finish→done に改め、共通の「選択肢で聞く」節（{{choices}}）と、各 guide の「対象を決める」「次の手順を選ぶ」を揃える。


## 受け入れ条件

- [ ] dg skill install が dgimport・dgassign・dgplan・dgwork・dgdone を作り、旧 deguboard Skill を消す（手を加えてあれば残して知らせる）
- [ ] 手を加えていない Skill は再実行で更新され、手を加えたものは conflicts に出る。--force はすべて上書きする
- [ ] Skill の名前・説明・argument-hint は guide の frontmatter だけに書いてあり、dg guide の出力に frontmatter が残らない
- [ ] 各 guide に「対象を決める」「次の手順を選ぶ」があり、{{choices}} が共通の節に置き換わる
- [ ] リポジトリの .claude/skills/ を作り直し、requirements.md の AG-2・CL-5 と ADR-004 を直している
