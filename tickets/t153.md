## 概要

t149（実行計画の帯の「次」）と t150（カンバンの行の「着手可・待ち」）は、着手できるかを web で depends_on から判定している。web は選んだ Project のチケットしか読まないので、別の Project の依存先を正しく判定できない（t149 は待ちに数え、t150 は数えない、と扱いも分かれている）。判定の処理も plan-graph.ts と board.tsx の 2 か所にある。core の `ticket.list` の出力に `deps_done` を載せ、web はそれを使って 1 か所で決める。

## 受け入れ条件

- [ ] core の `ticket.list` の出力に、各チケットの `deps_done` が載る（`ticket.show` と同じ意味。別の Project の依存先も見る）
- [ ] CLI・HTTP・Webview の 3 経路で同じ値が返る
- [ ] 実行計画の帯の「次」と行の「着手可・待ち」は、どちらも `deps_done` と 1 つの関数で決まり、web の判定の重複がなくなる
- [ ] 別の Project の依存先が done のとき、帯と行のどちらにも着手できると出る（テストで確かめる）
- [ ] requirements.md の該当の約束（EX-3 など）を直す
