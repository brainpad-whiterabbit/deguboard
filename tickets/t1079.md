## Summary

docs/usage.md と docs/usage.ja.md には、振り返りの観点と指標の説明がない（Skill 表の dgretro の 1 行と Count tokens の節だけ）。両方に同じ構成の節を足し、既定の観点、指標とは何か、推薦と承認、変え方と見方を利用者に伝える。

## Acceptance criteria

- [x] docs/usage.md に振り返りの観点と指標の節があり、次を説明している：既定の観点 7 つの名前（問いの文は写さない）と、最初はどれにも指標がないこと。指標は dg が計算する式ではなく、数え方の文と出どころのコマンドの組で、振り返りのたびにエージェントが計算し、値は保存しないこと。指標のない観点には推薦の指標が提案され、人が承認したものだけが記録されること
- [x] 変え方として dg retro perspective・dg retro metric・dg retro remove と dg config unset retro.perspectives（既定に戻す）を案内している。config set と設定画面では書けず、見るのは dg config show か設定画面だと書いている
- [x] 節を Count tokens の直前に独立した節として置き、トークンを使う指標は metrics.read_transcripts が要ることを、Count tokens の節へのリンクで示している（#count-tokens のアンカーは変えない）
- [x] 推薦の指標の一覧と各指標の定義を写さず、細部を dg retro --help と dg guide retro に任せている
- [x] docs/usage.ja.md に英語版と同じ構成の節があり、mise run check:docs が通る
