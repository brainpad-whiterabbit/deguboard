## Summary

見直し（s41）の観点「アーキテクチャ」。s41 で入った決める関数のまわりの片付け。

- `packages/core/src/commands/run.ts` の run-close-judge.ts からの再 export のコメントが「前からの import 先を変えないため」としているが、今は core の入口（commands/index.ts の export *）に RECONCILE_TODO_ERROR などを出す唯一の経路になっていて、理由が今と合わない
- 同じ名前の型 `RunningFact` が orphan-review-judge.ts と reconcile-judge.ts に別の形で定義され、どちらも export されている
- judge モジュール（gate-judge.ts・orphan-review-judge.ts・reconcile-judge.ts・claim-judge.ts・run-close-judge.ts・git/facts-judge.ts）に、同じファイルとテストの外で使わない export がある
- --branch の値の案内（書式と字数の上限）が ticket.ts の BRANCH_NAME_HELP と next.ts の文の 2 か所にある

## Acceptance criteria

- [ ] run.ts の再 export が、今の理由をコメントに書いているか、run-close-judge.ts を core の入口から直接出して再 export をなくしている
- [ ] 形の違う 2 つの RunningFact が別の名前になっている
- [ ] judge モジュールの export が、ほかのファイルかテストが使うものだけになっている
- [ ] --branch の値の案内の文が 1 か所に置かれ、ticket と next の両方がそれを使う
