## Summary

文書と実装の観点・README の観点（監査 s39）。docs/usage.md と usage.ja.md は「--auto でもほかの場面は止まって聞く」の例に、リリースとチケットの削除を挙げています。しかし既定の `flow.release` と `governance.delete` は human_only なので、エージェントは承認があっても実行できず、人にコマンドを頼みます。同じファイルの Workflow の節（「Only a person may close an Iteration」）とも食い違っています。dgrelease の description（guide-release.md の冒頭）、usage の Skill の表の dgrelease の行、README の Tips の「assignment to release in one go」も、「承認を得てリリースする・閉じる」と書いています。

## Acceptance criteria

- [ ] usage.md と usage.ja.md の --auto の説明が、聞いて止まる場面と、既定で人だけが行う操作（リリースと削除）を分けて書いている
- [ ] dgrelease の description、usage の Skill の表、README と README.ja の Tips が、既定では関所と Iteration を閉じる操作を人に頼むと読める
