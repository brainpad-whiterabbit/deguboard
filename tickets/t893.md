## Summary

Codex には SessionStart のフックから以後の Bash の環境に変数を入れる仕組み（Claude Code の CLAUDE_ENV_FILE）がなく、フックで DEGUBOARD_ACTOR=agent を入れられない。--actor の申告が抜けた呼び出しが human として通り、by: [human] と actor.human_only の制限を素通りする（ADR-028 の理由と同じ穴）。Adapter の detect が 1 つの製品に決まり、--actor も DEGUBOARD_ACTOR もなければ agent とする。Claude Code でフックが届かないサブエージェントにも効く。

## Acceptance criteria

- [ ] CODEX_THREAD_ID がある環境で --actor も DEGUBOARD_ACTOR もなく dg を呼ぶと、主体が agent になることをテストで示す
- [ ] 明示した --actor と DEGUBOARD_ACTOR は判定より優先することをテストで示す
- [ ] 判定できない（当たる製品がない、または 2 つ以上）ときは今までどおり human になることをテストで示す
- [ ] 人がエージェントの中で打つコマンド（Claude Code の ! など、製品の環境変数が付く端末）の扱いを決め、テストかコメントに理由を書く
- [ ] ADR-028 の主体の決め方、requirements の AG-1、dg --help の --actor の説明を同じ PR で直す
