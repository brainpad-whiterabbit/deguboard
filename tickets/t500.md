## 概要

Run は claim から PR の記録か unclaim まで開いたままで、エージェントが止まっても「実行中」と見える。会話記録の最後の書き込み時刻と最後の行の種類、作業ツリーとコミットの時刻から、実行中の Run を 4 つの状態に分けて core が返す。画面と lint はこの結果を写すだけにする。表示と案内だけで、Run を自動では閉じない（ST-7 の生存監視はしないを守る）。

- 作業中：会話記録が閾値以内に書かれている
- あなたの番：会話記録の最後の行が許可の確認か質問
- 止まっている：会話記録が閾値（既定 15 分）以上書かれていない
- 空回り：会話は進むが閾値（既定 30 分）以上コミットも作業ツリーの差分も増えない

UI 案：https://claude.ai/artifact/4uh7s7Dr2X2MEcdDHRWYq6

## 受け入れ条件

- [ ] 実行中の Run に last_activity_at と状態（working・waiting・stalled・spinning）が付き、dg run の一覧と dg ticket show の JSON に出る
- [ ] Claude Code の Adapter が会話記録の最後の書き込み時刻と最後の行の種類（許可の確認・質問か）だけを返し、会話の中身・パスは返さない（MT-4）
- [ ] 結び付けた会話記録のパスを deguboard-local/runs/ の実行中の記録に残し、2 回目以降の判定では会話記録を探し直さない
- [ ] 閾値を config.yaml の runs.stall_after_minutes（既定 15）と runs.spin_after_minutes（既定 30）で変えられる
- [ ] 会話記録を読めないとき（metrics.read_transcripts が false・Adapter のない agent）は作業ツリーの変化と最後の push の時刻で判定し、推定であることが結果で分かる
- [ ] requirements.md の Run の節と ADR-005 に、状態の分け方と「表示と案内だけで自動では閉じない」を書く
