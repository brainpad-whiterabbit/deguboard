観点：設定。packages/vscode の engines.vscode は ^1.123.0 だが、devDependency の @types/vscode は 1.120.0 で、下限より古い。型が古いと、1.121〜1.123 で入った API の使い方を型検査が見落とす。テストのホストは 1.145.1 に固定している。どちらに合わせるか（型を上げるか、下限を下げるか）は計画で決める。

## Abandoned

2026-11-13 の議論で abandoned にした。@types/vscode には 1.123 の版がない（1.120.0 の次は 1.125.0）ので、「同じ minor」は満たせない。engines の下限は Node 24 の拡張ホストのために 1.123 に上げた（t109）ので下げられない。型が engines の下限より古いのは安全側で、1.121 以降の API は型検査で落ちる（vsce が拒むのは型が engines より新しい場合）。概要の「型検査が見落とす」は成り立たない。
