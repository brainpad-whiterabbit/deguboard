## 概要

観点：アーキテクチャ・設定ファイル。次の重複と使われないコードがある。MERGE_METHODS（actions/software.ts）と PR_MERGE_METHODS（model/config.ts）。actions の defaultWorktreePath・MERGE_METHODS の再 export と pr.ts の PR_MERGE_METHODS の再 export（読む箇所がない）。actor.human_only の判定が claim-setup.ts の allowedFor と define.ts の runCommand の 2 か所。ブランチがあるときの worktree add の分岐が commands 側にある（ADR-031 は git の層）。NOTE_TOPICS と GUIDE_TOPICS、FLOW_SKIPS と FLOW_STAGES の二重の一覧（トピックを足すときの development.md の案内も足りない）。dg のコマンドの文字列（next.ts・flow.ts）と検査の時間切れの定数（software.ts・gate-check.ts）。

## 受け入れ条件

- [x] マージの方法・guide のトピック・Flow の段階の一覧がそれぞれ 1 か所で定義されている
- [x] 読む箇所のない再 export がなくなっている
- [x] human_only の判定とブランチがあるときの worktree の作成が 1 か所にある
- [x] development.md の guide のトピックを足すときの案内が、直す箇所を漏れなく挙げている
