## 概要

見直し（`dg guide review` の「見直す」）で、チケットに ## 参考 節があれば、そこに書いたファイルと PR で変えたファイルを見比べる。参考節にないところへ大きく広がった変更や、参考節のファイルに触れていない変更を、人がレビューで確かめられるように見直し役の一覧と PR の本文に残す。食い違いそのものは不具合ではないので、修正ループの回数を増やす重い指摘にはしない。参考節がなければ何もしない。

## 受け入れ条件

- [ ] `dg guide review` の「見直す」の「見る」に、参考節と変更ファイルの見比べが入っている
- [ ] 食い違いは軽い指摘か別の欄として返し、重い指摘に数えないと書いている
- [ ] 食い違いと理由を PR の本文に残すことが書かれている（実装者が直すか、親が書き足すかのどちらかが決まっている）
- [ ] 参考節のないチケットでは見比べないと書いている
- [ ] guide の文面のテストが通り、`mise run check`（check:docs の予算を含む）が通る
