## Acceptance criteria

- [x] lint は、in_progress・review のチケットの Iteration が active でないものを新しい指摘で示し、lint のヘルプにも書く
- [x] dg next は、Iteration が planned でほかに active がある todo のチケットに、claim ではなく wait_human と理由を返す
