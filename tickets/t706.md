## Summary

カンバンで Epic に絞るのに漏斗を開いてセレクトから選んでいるのを、Iteration の札の下の「Epic」の札の列に替える（UI 案 A）。札はバックログと同じ ID だけの札を使う。UI 案: https://claude.ai/artifact/PnGAQ65zEa45X1BZtuW5xT

## Acceptance criteria

- [x] カンバンの見出しで Iteration の札の下に「Epic」の札の列が出て、押すとその Epic に絞り、もう一度押すと外れる。開いた Epic がなければ列を出さない
- [x] 列に出すのは、選んでいる Iteration（または「すべて」）にチケットがある開いた Epic と、末尾の「なし」と件数（バックログと同じ札。件数は選んでいる範囲の Epic のないチケット）。絞っている Epic はチケットがなくなっても札を残す。Epic が多いときは、バックログと同じく 2 行を超える分を「ほか N」に畳む
- [x] 漏斗の中は担当の絞り込みだけになり、担当がいなければ漏斗を出さない
- [x] Epic の札が見えている間は、× で外す絞り込みの札に Epic を出さない
- [x] 上の動きを画面のテストで確かめる
- [x] requirements.md の UI-2 が今の画面と食い違わない
