## 概要

PR #154（t164）の見直しで見つけた、範囲の外の指摘。

- packages/vscode/src/dg.ts:14 の INSTALL_HINT は、`dg` が PATH にないとき「npm i -g deguboard（mise なら mise use npm:deguboard）」と案内する
- deguboard は npm に未公開で、この案内に従うと 404 で失敗する。README（t164 で直した）は、公開までは clone してビルドし `dg` を PATH に通す手順を案内している
- mise の案内は `-g` が抜けていて、README の `mise use -g npm:deguboard` と合わない
- テストは packages/vscode/src/dg.test.ts:22（案内に `npm i -g deguboard` を含むことを確かめている）

## 受け入れ条件

- [x] `dg` が PATH にないときの案内が、npm に未公開の今でも従えば入れられる内容になっている（README の「使い始める」を指すなど）
- [x] mise の案内が README と同じコマンドになっているか、案内から外れている
- [x] dg.test.ts が新しい案内を確かめている
