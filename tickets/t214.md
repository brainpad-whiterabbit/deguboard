## 概要

Iteration に入れずに進めたチケットは、カンバンの「Iteration なし」の done に溜まり続ける（e9 で片付けた）。このリポジトリでは todo・abandoned 以外に進めるチケットを Iteration に入れる運用にした（t213）が、守られなくても気づけない。すべての利用者の決まりではないので、config.yaml の設定で有効にしたときだけ lint が指摘し、dgcheck の表に出るようにする。

## 受け入れ条件

- [ ] config.yaml の設定（例 lint.require_iteration、既定は false）を足し、dg config で読み書きできる
- [ ] 有効なとき、Iteration のない todo・abandoned 以外のチケットを dg lint が code 付きで指摘する。無効なときは指摘しない
- [ ] 閉じた Epic に入っている done のチケット（e9 など）は指摘しない
- [ ] requirements.md の lint と config の節、dg lint のヘルプを直す
- [ ] core のテストで、有効・無効と閉じた Epic の扱いを確かめる
- [ ] このリポジトリの config.yaml で有効にする
