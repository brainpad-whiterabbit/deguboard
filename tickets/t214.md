## 概要

Iteration に入れずに進めたチケットは、カンバンの「Iteration なし」の done に溜まり続ける（e9 で片付けた）。このリポジトリでは todo・abandoned 以外に進めるチケットを Iteration に入れる運用にしたいが、すべての利用者の決まりではない。config.yaml の設定で有効にしたときだけ、dg guide work が claim の前に Iteration に入れるよう案内し、守られなかったものを lint が指摘して dgcheck の表に出す。CLAUDE.md には書かない（t213 は取りやめた）。

## 受け入れ条件

- [x] config.yaml の設定（例 lint.require_iteration、既定は false）を足し、dg config で読み書きできる
- [x] 有効なとき、Iteration のない todo・abandoned 以外のチケットを dg lint が code 付きで指摘する。無効なときは指摘しない
- [x] 閉じた Epic に入っている done のチケット（e9 など）は指摘しない
- [x] dg guide work の claim の手順に、設定が有効なら claim の前に Iteration に入れる（active、なければ次の planned）ことを書く
- [x] requirements.md の lint と config の節、dg lint のヘルプを直す
- [x] core のテストで、有効・無効と閉じた Epic の扱いを確かめる
- [x] このリポジトリの config.yaml で有効にする
