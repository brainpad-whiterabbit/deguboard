## Summary

観点：テスト。t796 で vitest.config.ts の maxWorkers を既定 50% にし、DEGUBOARD_TEST_MAX_WORKERS で上書きできるようにしたが、その既定と上書きを確かめるテストがない。値は検査せずに vitest に渡すので、数でも百分率でもない値や 0 では NaN や 0 になり、テストが回らないことがある。また vitest 自身の VITEST_MAX_WORKERS は百分率を受けず（75% は 75 として読まれる）、config より優先されるが、このリポジトリの変数を使う理由がコメントにない。

## Acceptance criteria

- [ ] 環境変数がないときの既定と、DEGUBOARD_TEST_MAX_WORKERS を設定したときの値を、テストが確かめる
- [ ] 数でも百分率でもない値と 0 を、既定に戻すか、理由を示すエラーで止める（テストで示す）
- [ ] vitest.config.ts のコメントが、VITEST_MAX_WORKERS ではなくこの変数を使う理由を書いている
