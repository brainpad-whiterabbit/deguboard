## Summary

Iteration を閉じると done・abandoned 以外のチケットの iteration を外す（IT-2）が、閉じた後に残った done・abandoned を ticket move で todo に戻すと iteration が残り、閉じた Iteration に終わっていないチケットができる。

## Acceptance criteria

- [ ] 閉じた Iteration の done・abandoned を todo に戻した後、チケットはその Iteration に属さない（IT-2 の閉じるときに外す扱いと揃える）
- [ ] その振る舞いをテストで示し、ticket move のヘルプに書く
