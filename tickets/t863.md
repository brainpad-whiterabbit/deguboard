## Summary

見直し（s31、設定ファイル・テスト）。vitest.config.ts は t858 で HOME を一時ディレクトリにしたが、ほかの切り離しが足りない。

- `test:vscode`（test/vscode/host.ts）は本物の HOME を拡張開発ホストに渡す。t857 から拡張は起動時に個人の置き場所の Skill を更新するので、回すと作業ブランチの Skill が開発者の `~/.claude/skills` に書かれうる（コードからの推論）
- vitest.config.ts は `CLAUDECODE`・`AI_AGENT`・`CLAUDE_CODE_SESSION_ID`・`CLAUDE_CONFIG_DIR`・`CODEX_THREAD_ID`・`CODEX_HOME`・`COPILOT_HOME` を残すので、env を渡さないテストはエージェントの中と人の端末とで見えるものが違う。`CLAUDE_CONFIG_DIR` があると会話記録の置き場所が本物の場所に戻る
- git のグローバル設定を当てにするテストは、自分で `user.name` と `user.email` を書く必要があるが、vitest.config.ts のコメントに書いていない（t858 の見直しの軽い指摘）
- run.test.ts の MT-4 の確かめは、`os.homedir()` が一時ディレクトリになったので、本物のホームのパスがコミットに入らないことを見なくなった（t858 の見直しの軽い指摘）

## Acceptance criteria

- [x] `mise run test:vscode` が本物の HOME の下（`~/.claude/skills`・`~/.local/share/deguboard/`）に書かない
- [x] vitest のテストが、エージェントの中で回しても人の端末で回しても、エージェントの環境変数に左右されない
- [x] git のグローバル設定を当てにしないことが、vitest.config.ts のコメントかテストの helper に書かれている
- [x] MT-4 の確かめが、本物のホームのパスを見るか、見なくてよい理由がテストのコメントにある
