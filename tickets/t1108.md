## Summary

見直し（文書と実装・README）：docs/usage.md の「Notifications」の節（日本語版 docs/usage.ja.md は「承認待ちの通知」）に t1090 で足した段落が、「VS Code か `dg serve` でカンバンを開いている間」と書き、手直しで「（`dg serve` では `dg sync` を実行する）」を足した。一方 `dg serve --help` は「For development」で、画面は VS Code 拡張で開くとしている。dg serve の画面には押せる同期のボタンもなく、packages/web/src/app.tsx の SyncMark は印だけを出す。同じ節の「データを別のリポジトリに置く」手順 3 も「VS Code or `dg serve`」と書く。また、足した 3 段落（自動の取り込み・同期のボタンの点・セットアップのアイコンの点）は通知ではないので、節の見出しと内容が合わず、日本語の見出し「承認待ちの通知」と英語の「Notifications」もずれている。

## Acceptance criteria

- [x] docs/usage.md と docs/usage.ja.md が、`dg serve` を利用者がカンバンを開く入口として書いていない（通知の節の自動の取り込みの段落と、データを別のリポジトリに置く手順 3）
- [x] 自動の取り込み・同期のボタンの点・セットアップのアイコンの点の段落が、内容に合う見出しの節にあり、英語版と日本語版で節の構成と見出しの対応がそろっている
- [x] mise run check:docs が通る
