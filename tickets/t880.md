## Summary

カンバンの画面は今、実行中の Run のあるチケットの集合しか読めない（`run.list` の `running: true`）。行に Run を 1 回 1 つの丸で並べるために（t881）、チケットごとに新しい順の Run 3 件の要約と、全部の Run の件数を返す読み取りの新しいコマンド（例 `run.recent`）を core に足す。`run.list` は変えない。CLI・HTTP・Webview は写すだけにする。

## Acceptance criteria

- [x] `run.list` と同じく Iteration か Project で絞れ、チケットごとに `{ticket, total, runs}`（runs は新しい順に 3 件まで）を返す
- [x] 要約の 1 件に step・result・started_at・finished_at・review・error が入り、実行中の Run には waiting_since・settling_since も入る
- [x] 実行中の記録（deguboard-local）と閉じた Run の両方から要約を作る
- [x] total はそのチケットの全部の Run の件数である
- [x] 返す形が `--json` の出力のテストで固まっている
