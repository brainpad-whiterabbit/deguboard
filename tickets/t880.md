## Summary

カンバンの画面は今、実行中の Run のあるチケットの集合しか読めない（`run.list` の `running: true`）。行に Run を 1 回 1 つの丸で並べるために（後続のチケット）、チケットごとに新しい順の Run 3 件の要約と、全部の Run の件数を返す core のコマンドを足す。CLI・HTTP・Webview は写すだけにする。

## Acceptance criteria

- [ ] 要約の 1 件に step・result・started_at・finished_at・review・error が入り、実行中の Run には waiting_since・settling_since も入る
- [ ] 実行中の記録（deguboard-local）と閉じた Run の両方から要約を作る
- [ ] チケットごとに全部の Run の件数を返す
- [ ] 返す形が `--json` の出力のテストで固まっている
