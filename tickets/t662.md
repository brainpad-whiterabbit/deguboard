## Summary

観点は設定ファイル。dg の config の actions.light_paths には `docs/**` と `CLAUDE.md` が入っている。mise.toml の check:light の説明と CLAUDE.md:20 は、これを「テストが読まない文書」としている。しかし test/scripts/check-docs.test.ts は、本物の docs・CLAUDE.md・README を写して中身を確かめている（最後の ADR 番号「ADR-034」、ADR-008 の状態の行、要件の接頭辞の行、README の見出しのアンカーなど）。そのため、文書だけの PR（例：ADR-035 を足す）が軽い検査でマージされると、次の全体の検査が main で落ちる。どちらに合わせるか（テストを本物の値から独立させるか、そのテストを check:light に入れるか）は計画で決める。

## Acceptance criteria

- [x] light_paths に入る文書だけを変えた PR が check:light を通れば、main の mise run check も落ちない（テストか検査で確かめる）
- [x] mise.toml の check:light の説明と CLAUDE.md の軽い検査の記述が、実際の扱いと合っている
