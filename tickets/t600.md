## 概要

今は親が見直し役の文を読み、重い指摘を `brief --role fix --findings` に写し、直さなかった軽い指摘を `gh pr edit` で PR の本文に書き足している。どちらも見直しの記録から dg が作る。

## 受け入れ条件

- [ ] `--findings` を渡さない `brief --role fix` と `dg next` の fix の brief に、最新の見直しの重い指摘と、受け入れ条件の文言に当たる軽い指摘が入る
- [ ] `dg pr ready` が、直さなかった軽い指摘を PR の本文に書き足し、もとの本文を残す
- [ ] guide-review の「指摘を直す」から、指摘を写す手と PR の本文に書き足す手を消した
- [ ] テストがある
