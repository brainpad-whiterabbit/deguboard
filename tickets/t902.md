## Summary

dg のヘルプ（`next`・`gate`・`brief`・`ticket`・`workflow`・`setup`・`flow`）と `run` のエラー（RN-4）に、EX-3・TK-9・WF-3・RN-6・SY-4・EX-7 などの要件番号がある。エージェントと利用者が読む文に、手元にない要件を指す番号を残さない。要件 ID は定義の直前のコメントへ移し、再び入らないよう check:docs で検査する。

## Acceptance criteria

- [ ] dg のヘルプ・エラー・警告の文に要件番号と ADR 番号がなく、外した要件 ID は定義の直前のコメントにある
- [ ] 同じ文を写した訳・スナップショットも直してある
- [ ] `mise run check:docs` が、packages のテスト以外の文字列にある要件 ID を指摘する（コメントとテスト名は対象外）
- [ ] ADR-001 の「正本と各文書の書く範囲」の表で、`--help`・dg の出力に要件 ID と ADR 番号を書かないことが分かる
