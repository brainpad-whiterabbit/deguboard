## Summary

左パネルの Setup 画面（導入のチェックリスト、UI-12）の末尾に「アンインストール」の節を足す。消すものと止める理由を見せ、画面の中で確かめてから、今のチェックリストのボタンと同じく deguboard のターミナルで `dg uninstall` を実行する。UI 案は検討の 7 章の図 4。

## Acceptance criteria

- [x] 必須を満たした後の SetupChecklist の末尾に、閉じた節「アンインストール」があり、推奨の帯（SetupBand）には出ない
- [x] 節を開くと範囲（このリポジトリだけ／個人の Skill とフックも）を選べ、`dg uninstall --dry-run` の結果から消すもの・残すもの・止める理由を出す。止める理由がある間は実行のボタンを押せず、「同期する」ボタンを出す
- [x] 画面の中で 2 段階に確かめた後、選んだ範囲の引数を付けた `dg uninstall` を deguboard のターミナルで実行する（setupCommands・setupAct）。dg serve の画面には出さない
- [x] 実行後はチェックリストに戻り、拡張は最後に消すことを知らせ、拡張の画面を開くボタンを置く
- [x] コマンドパレットに「deguboard: このリポジトリからアンインストール」（英語は Uninstall from This Repository）を足す。Setup 画面の節の名前は「アンインストール」のままにする
- [x] 文言に日本語と英語の訳があり、要件 UI-12 に外せることを足し、PR の本文に変えた画面のスクリーンショットを載せる
