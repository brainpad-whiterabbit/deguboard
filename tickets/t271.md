## 概要

ブランチ名は code の小さな文字で、選んでコピーしにくい。ブランチ名の右にコピーのボタンを置き、押したら「コピーした」と短く出す。VS Code の Webview で navigator.clipboard が使えないときは、host を通して拡張にコピーを頼む。改善案 D9（https://claude.ai/artifact/RQHwi7v1k3rJx2Rvcin2Uo）

- [x] navigator.clipboard が使えないときは host を通してコピーする。その道をテストで確かめる
