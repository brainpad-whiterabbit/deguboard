## 概要

観点：アーキテクチャ。ADR-007 は「すべての操作は core のコマンド定義に置く」と書くが、requirements の AG-4 が CLI だけとする操作（guide・skill・serve・open）の例外を書いていない。t365 の見直しで迷いが出た。
CLAUDE.md は core を HTTP に依存させないとするが、検出の正本の .oxlintrc.json は vscode と react だけを禁じ、node:http・node:https・node:net・node:http2 を禁じていない（今は違反なし）。

## 受け入れ条件

- [ ] ADR-007 に、CLI だけの操作（AG-4）は core のコマンド定義に置かない例外だと書いてあり、予算に収まる
- [ ] .oxlintrc.json の packages/core の import 制限に node:http・node:https・node:net・node:http2 があり、写し（oxlint-copies のテストが照らす側）も揃っている
