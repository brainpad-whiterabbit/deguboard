## Summary

今は拡張が 60 秒おきに fetch して未取り込みの数をバッジに出すだけで（UI-6、packages/core/src/commands/local.ts）、取り込むには人が同期のボタンを押す。書くコマンドは書く前に取り込む（SY-2）ので、古いのは画面の表示だけ。データは専用の worktree にあり、取り込んでも利用者のコードの作業ツリーには触らない。そこで、fetch で未取り込みが見つかり、手元に未 push のコミットも未コミットの変更もないときは、fast-forward だけで黙って取り込み、画面を読み直す。未 push がある・競合で止まっている・dg の外の変更（SY-7）があるときは取り込まず、今までどおり人の同期に任せる（知らせ方は別のチケット）。

## Acceptance criteria

- [ ] 未取り込みがあり、手元に未 push のコミットと未コミットの変更がないとき、次の fetch の後に人の操作なしで取り込まれ、左パネルとエディタのパネルが新しいデータを映す
- [ ] 取り込みは fast-forward に限り、未 push のコミット・未コミットの変更・競合の中断（SY-4）・dg の外の変更（SY-7）のどれかがあるときは取り込まない
- [ ] 自動の取り込みは同じマシンの dg の書き込みとロック（SY-5）で直列になり、途中の dg のコマンドとぶつからない
- [ ] リモートに届かないとき・取り込みが失敗したときは、通知を出さずに今の印（バッジ）を出し続ける
- [ ] Git 操作のテストを一時ディレクトリの bare リモート付きリポジトリで足す
- [ ] 要件 UI-6 の 1 文を、fast-forward で済むときは自動で取り込む約束に直す
