## 概要

観点=アーキテクチャ。対象=packages/core/src/commands/setup.ts（1001 行に init・sync の照合と Run の閉じ方・lint の Run の抜けの検査・config の set/unset が同居）。ADR-007 の「モジュールが肥大化したら分ける」に当たる。lint の Run の抜けの判定は純粋関数に出せばテストも軽くなる。PR 1 つで終えるには大きく、run-close・run-steps のチケットと同じファイルを触るので、それらの後に進める。Iteration に入れない。

## 受け入れ条件

- [ ] init・sync・lint・config がそれぞれ別のモジュールにあり、コマンドの名前と振る舞いは変わらない
- [ ] lint の Run の抜けの判定が純粋関数になり、Git を使わないテストがある
- [ ] mise run check が通る
