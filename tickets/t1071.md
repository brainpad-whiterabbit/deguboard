## Summary

今の README は「カンバンボード」として始まるので、Jira・Redmine に MCP を足した構成との違いが伝わらない。英語版と日本語版の冒頭・箇条書き・新しい節で、Agentic-Agile の開発の流れを守るツールであることを先に出す。

## Acceptance criteria

- [ ] 英語版と日本語版の冒頭が、「AI エージェントに開発を任せるための開発の流れを Git リポジトリに組み込むツールで、カンバンはその窓口」と説明している
- [ ] 箇条書きが 4 つになっている。先頭に「決まりを仕組みで守る」がある。「主導権は人」から根拠のない約束（振り回されない）が消えている。「チームで共有」「測って改善」は今のまま
- [ ] 「仕組み」の節のすぐ上に、新しい節「なぜ deguboard か」（英語版は Why deguboard）がある。Jira・Redmine・GitHub Projects に MCP を足した構成との比較表（進め方・止まったとき・マージ・チケットとコード・エージェントの実績・置き場所）と、フックがすべて効くのは今は Claude Code だということが書いてある。向かない場面は書かない
- [ ] 表の各行が、docs/usage と docs/how-it-works に書いてある振る舞いだけで書かれている（ない機能を約束しない）
- [ ] ヒントの「カンバンの操作はエージェントに頼む」が、決まりの点検を通すためという理由つきで「使い方」の冒頭に移っている。動作環境の「エージェント」の項から、新しい節と重なる部分が消えている
- [ ] 英語版に相対リンクがない。`mise run check:docs` が通る（節の構成・アンカー・重複）
