## Summary

見直し（s30、設定）。このリポジトリの dg の設定（deguboard ブランチの config.yaml）の `guide.notes.work` が `docs/work-notes.md` を指すが、そのファイルはどのコミットにもなく、`dg guide work` のたびに「guide.notes.work file docs/work-notes.md cannot be read」と警告が出て、work の手順に差し込む文書も入らない。設定は 2026-11-13 の「Commit batched changes」で入った。意図（空に戻すか、文書を足すか）を人に確かめてから直す。PR の要らない設定の整備で済む場合がある。

## Acceptance criteria

- [ ] 設定した人に意図を確かめ、どちらにしたかがチケットに書かれている
- [ ] `dg --json guide work` が guide.notes.work の読めない警告を出さない
- [ ] 文書を足した場合は、その文書が `mise run check:docs` を通る
