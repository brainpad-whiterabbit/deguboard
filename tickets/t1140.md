## Summary

バックログとカンバンの行に、チケットのラベルをタイトルの下の段に出す。検索欄（カンバンは見出し）の漏斗の隣に「表示」ボタンを置き、そのメニューでラベルを出すか出さないかを切り替える。履歴タブは扱わない。UI 案は https://claude.ai/artifact/9tzVnGspKszMECd4WWei6L の第 2 版（A 案）。

## Acceptance criteria

- [ ] バックログとカンバンの行で、ラベルのあるチケットはタイトルの下の段にラベルを札で出す。3 つまで出し、残りは「+N」にまとめ、触れると全部の名前が出る。PR のリンクがある行では PR の右に並ぶ
- [ ] 行のラベルを押すとそのラベルで絞り込み、もう一度押すと外れる。行の選択と詳細は変えない。カンバンでは漏斗の欄にラベルの絞り込みを足し、Epic・担当と同じく値をハッシュに持ち、絞っている間は札（× で外す）を出す。ラベルの札は PR のリンクと同じく行のリンクの外に置き、Tab では止めない。ラベルで絞っている間の札は、スクロールしたときに上の端に貼り付く帯（バックログの BacklogBand、カンバンの BoardBand）にも出す
- [ ] ラベルの色は名前から決まる 6 色のどれかで、データにも config にも持たない。明暗の両方のテーマで読める
- [ ] バックログは検索欄の漏斗の隣、カンバンは見出しの漏斗の隣に「表示」ボタンを置き、メニューの「ラベルを出す」で入り切りできる。既定は出す。値は useUiState に残り、2 つのタブで共有する
- [ ] 既定と違う表示を選んでいる間は、「表示」ボタンを色付きにする
- [ ] docs/requirements.md の UI-2 と UI-3 に、行にラベルを出し、表示で出す・出さないを切り替えられることを足す
