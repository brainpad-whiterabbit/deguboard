## 概要

Core に history のコマンドを足す。deguboard ブランチで git log -p -U0 を tickets/・epics/・iterations/ に 1 回走らせ、frontmatter の status・iteration・epic・assignee・pr の変化を、時刻・コミット・変えた主体とともに拾う。データの形は変えない。
1 コミットに複数の変更がある（変更をまとめてコミット）場合も差分から読む。履歴が浅い clone では欠けたことを結果に出す。CLI は dg history（--ticket・--epic・--iteration で絞る）で写し、HTTP・Webview からも同じコマンドを呼べるようにする。
改善案：https://claude.ai/artifact/Sy4j28W4Vkee96x6WtNagu
