## Summary

`dg skill install` と対になる `dg skill uninstall` を足す。dg が配った Skill だけを消し、利用者が自分で置いた Skill は残す。どれが dg の Skill かは dg しか知らないので、手で消す手順を文書に写さずに済むようにする。`dg uninstall`（このクローンから外す）の部品になる。

## Acceptance criteria

- [x] `dg skill uninstall` がリポジトリの `.claude/skills/` から dg が配る Skill（今の版で配るものと、やめた Skill の名前）を消し、名前が dg で始まる利用者の Skill は残すことをテストが確かめる
- [x] 手を加えた dg の Skill は既定では消さずに結果で知らせ、`--force` を付けると消す
- [x] `--personal` で `~/.claude/skills` を対象にし、`--dry-run` は何も消さずに消すものの一覧を返す
- [x] `.claude/.gitignore` は書き換えない（チームでコミットしているファイルで、ほかの人はまだ使っているため）。その理由をヘルプかコメントに書く
- [x] 要件 AG-2 に、Skill を外せることを足す
