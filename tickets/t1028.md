## Summary

`workflow.yaml` の flow に、同梱の 6 つ以外の段階を、誰が決めるか（decide）・位置（after）・手順の文書（guide）の 3 つで足せるようにする。独自の段階はいつも関所。

## Acceptance criteria

- [x] 独自の段階の `decide`・`after`・`guide` を `dg workflow validate` が検査し、`after` に書けるのは同梱の段階と work だけであることがテストで示されている
- [x] `dg flow next` が `after` の位置（同じ位置は書いた順）で独自の段階を返し、文書の本文・関所のコマンド・承認の要否を返す
- [x] 文書がない・読めないときは警告を出して段階を返す
- [x] requirements の 5.8 に独自の段階が書かれている
- [x] 独自の段階の名前が小文字・数字・`-` だけであることを `dg workflow validate` が検査する
- [x] config の `guide.notes` が、今までどおり同梱の段階の手順に補足を足す
