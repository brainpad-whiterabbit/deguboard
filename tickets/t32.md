## 概要

サイドバーの幅に合わせる。バックログは検索と件数だけ常に出し、絞り込みの select は <details> で閉じて summary に効いている条件と件数を出す。Epic・Iteration の作成フォームはサイドバーでは「+ 作る」の 1 行にし、押したときだけ開く。Epic 詳細のチケットはサイドバーでもカード（.card）のままなので、TicketRow と「外す」ボタンの 1 行表示にして Iteration 詳細（TicketTable の extra）と揃える。広い画面は今のまま。

## 受け入れ条件

- [ ] サイドバーのバックログは、初期表示で検索欄と件数と畳んだ「絞り込み」だけが見え、開くと Status・優先度・Iteration・Epic・ラベル・担当の select が出る
- [ ] 絞り込みを畳んでいても、効いている条件が summary に見える
- [ ] サイドバーの Epic と Iteration の作成フォームは「+ 作る」を押したときだけ開く
- [ ] サイドバーの Epic 詳細のチケットが 1 行表示になり、「外す」が行の右に出る
- [ ] ブラウザ（広い画面）の表示は変わらない
