## Summary

頼む小窓の status（様子を聞く）は Skill を持たない（skill: null）。guide-status.md を新設して dgstatus を配る。対象は今までどおり in_progress のチケットだけで、読み取りだけにする。carry は予定の期間をやめる検討のチケットの中でなくし、retro は別のチケットで頼める場所を History タブの Iteration の見出しに限る（retro の中身は後で決める）。

## Acceptance criteria

- [ ] `dg guide status` が、読む材料（ticket show・dg next・run list・worktree の最近のコミット・PR の状態）と、今どこにいるか・止まっていれば理由・次の一手を 3〜5 行で返すこと、データを書き換えず止まっていれば「再開する」を勧めるだけなことを示す
- [ ] `dg skill install` で dgstatus の SKILL.md ができ、SKILL_SUMMARY に ja・en の文がある
- [ ] status の Skill の形が `/dgstatus <ID>` になることをテストが確かめる
- [ ] guide-overview の段階の表と dg ask の --help の文が、Skill のない頼むことは free・retro・carry だけという形に合う
