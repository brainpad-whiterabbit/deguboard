## 概要

s5 の作業の見直しで範囲の外として出た小さな指摘をまとめる。(1) .oxlintrc.json の core の overrides にも「上を変えたらここも揃える」写しがあるが、検査がない（web は t201 で検査した）。(2) 各 ADR の「更新日」と docs/adr/README.md の一覧の更新日の一致を check-docs が検査しない（t197 の食い違いの再発を防ぐ）。(3) 版を固定する方針（ADR-008）を pnpm の設定（pnpm-workspace.yaml の savePrefix など）で強制していない。(4) docs/development.md の「`pnpm pack` で確かめる」が pnpm を直接案内している（`mise run pack` がある）


## 受け入れ条件

- [ ] core の overrides の制限が効くことを確かめる検査があり、`mise run check` から走る
- [ ] check-docs が ADR の更新日と一覧の更新日の食い違いで落ちる
- [ ] `-E` を付けずに依存を足しても固定の版で書かれる設定になっているか、しない理由を ADR-008 に書く
- [ ] development.md が pack の確かめを `mise run pack` で案内する
- [ ] `mise run check` が通る
