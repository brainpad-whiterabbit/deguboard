## 概要

いまは capabilities.untrustedWorkspaces を宣言しておらず、VS Code の既定で制限モードでは無効になっている。拡張はワークスペースの git を実行し、リポジトリの git の設定（core.fsmonitor など）は任意のコマンドになり得るので、動かない理由を manifest に明示して利用者が判断できるようにする。

## 受け入れ条件

- [x] packages/vscode/package.json の capabilities.untrustedWorkspaces が supported: false で、description に理由（リポジトリの git の設定に従ってコマンドを実行するため）を書いている
- [x] capabilities.virtualWorkspaces を false と明示している
- [x] テストで manifest の値を確かめている
