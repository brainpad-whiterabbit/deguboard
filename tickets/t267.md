## 概要

Run の表は 7 列で、パネルの幅では「終了」が切れて横スクロールになる。agent はほぼ毎行同じ。1 行を step・結果の丸印・model（と再試行）・開始時刻と所要の 4 つにし、見出しに件数・成否・トークンの合計を出す。行を開くと agent・入力 / 出力 / cache のトークン・終了時刻・Run ID が出る。Run の画面（runs.tsx）の表は変えず、チケット詳細だけ別の部品にする。改善案 D5（https://claude.ai/artifact/RQHwi7v1k3rJx2Rvcin2Uo）

## 受け入れ条件

- [ ] パネルのチケット詳細の Run が 1 行に step・結果・model と再試行・開始時刻と所要で出て、パネルの幅で横にスクロールしない
- [ ] Run の見出しに件数・成否・トークンの合計が出る
- [ ] 行を開くと agent・入力 / 出力 / cache のトークン・終了時刻・Run ID が出る
- [ ] 取れなかったトークン数（null）は合計でも 0 と見せず「—」を含むことを示す（RN-2）
- [ ] Run の画面の表と、ブラウザ版のチケット詳細の Run は今のまま
- [ ] 変えた画面のスクリーンショットを PR に載せている
