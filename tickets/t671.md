## Summary

頼む小窓に discuss（検討する）を足す。対象の内容を Claude の plan モードのように読み取りだけで調べ、論点を選択肢で人と相談し、決まったら前後の差を示して承認を得てから update で反映する。guide-discuss.md を新設して dgdiscuss を配り、相談の頼むこと status・retro・carry の Skill も dgdiscuss にする（頼みごとの 1 行を添える）。

## Acceptance criteria

- [ ] `dg guide discuss` が、議論の間はファイルとデータを変えないこと・論点を選択肢で相談すること・前後の差で承認を得てから ticket/epic/iteration update で反映すること（分けるなら dg guide import に従う）を示し、status・retro・carry の節を持つ
- [ ] discuss が todo・in_progress・review のチケットと開いている Epic・Iteration の候補に出て、先頭（おすすめ）にならず、done・abandoned・closed の対象には出ないことをテストが確かめる
- [ ] discuss・status・retro・carry の Skill の形が `/dgdiscuss <ID>` と頼みごとの 1 行になることをテストが確かめる
- [ ] dgdiscuss の SKILL.md ができ、SKILL_SUMMARY と画面の英語の表示名（l10n-core の「検討する」）がある
- [ ] 頼む小窓で「検討する」が出るスクリーンショットを PR に載せる
