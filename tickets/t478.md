## 概要

設定画面の `saving` は 1 項目しか持てない。2 つの項目をほぼ同時に保存すると、先に終わった保存の finally の `setSaving(null)` で、後の保存の欄の busy の印と錠が外れる。t466 で保存の読み直しに連番を付けたが、「保存中」の印はそのまま。項目ごとの集合にして、自分の保存が終わったときだけ外す。p63 の t466 の見直しで出た範囲の外の指摘。

## 受け入れ条件

- [ ] 2 つの項目の保存が重なったとき、先の保存が終わっても後の項目の「保存中」の印と錠が残る
- [ ] 自分の保存が終わったとき、その項目の印だけが消える
- [ ] 上をテストで確かめる
- [ ] mise run check が通る
