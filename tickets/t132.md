## 概要

MCP は Bash のないクライアント（Claude Desktop）で起票・閲覧・状態の更新をする入口として残す。Desktop はリポジトリの外から起動するため -C が要り、mise の shim は外で node を決められない。instructions は Bash を前提にしている

## 受け入れ条件

- [ ] README の「MCP で使う」に Claude Desktop の設定例（-C でリポジトリを指す・command は絶対パスか npx）がある
- [ ] requirements.md の AG-4 に、Bash のないクライアント向けの入口という位置づけと -C での対象の指定が書かれている
- [ ] ADR-007 の MCP を残す理由が Claude Desktop の用途に合っている
- [ ] MCP の instructions が Bash のないクライアントでも誤った案内をしない
- [ ] mise run check が通る
