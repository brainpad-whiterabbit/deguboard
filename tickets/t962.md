## Summary

左パネルのカンバンをスクロールすると、見出し（Iteration の札・Epic の札・名前・目標・進みの帯）が流れて、どの Iteration のどの状態を見ているか分からなくなる。見出しが上に抜けたら、1 行の帯に縮めて上の端に残す。状態の節の見出しも帯の下に残す。画面の案は見本の案 B（論点 1-a・2-a・5）。dg serve とエディタのパネルの広い画面は、状態が列で並び列の見出しがあるので対象にしない。

## Acceptance criteria

- [x] 見出しの進みの帯の行が見えなくなったら、上の端に 1 行の帯（Iteration の番号・名前・小さな進みの帯・n/m）を出し、見えたら消す。帯は動かさずに切り替える
- [x] 「すべて」を選んでいるときは、帯に番号の代わりに「すべて」を出し、名前は出さない（進みは planned と active の合計）
- [x] 状態の節の見出しが帯の下に貼り付き、次の節の見出しに押し出されて入れ替わる。貼り付いた見出しでも節を開閉できる
- [x] 帯の名前を押すと、一覧が一番上へ戻る
- [x] 帯と貼り付いた節の見出しは、エージェントに頼める場所になる（吹き出し・Shift+F10）
- [x] requirements.md の UI-2 に、スクロールしても見出しを 1 行に縮めて残すことを書く
