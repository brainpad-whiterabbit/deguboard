## 概要

サイドバーと詳細のパネルの画面の文言を、VS Code の表示言語に合わせて英語でも出す。チケットの中身は書いた言葉のまま出す。

## 受け入れ条件

- [ ] 表示言語が英語のとき、サイドバーと詳細のパネルの見出し・ボタン・ラベルが英語で出る
- [ ] 表示言語が日本語のときは、今と同じ文言で出る
- [ ] チケットのタイトルと本文は訳さずにそのまま出す
- [ ] ブラウザの画面（dg serve）は今の日本語のまま動く
