## 概要

観点：テスト。t364 の受け入れ条件は「CLI・HTTP・Webview は判定を写す」だが、形式の既定のテストは CLI と HTTP だけを比べる。
頼む小窓は ask の結果が届くまで形式のボタンが押せないが、テストはすぐ返るモックでこの間を通らない。
t344 の formatShortDay は手元の日付で数え夏時間も考えるが、テストの時差は UTC に固定され、日付が UTC と手元で変わる境目と夏時間の切り替え日を試していない。

## 受け入れ条件

- [ ] 形式を省いた ask の結果が、CLI・HTTP・Webview（ローカルのクライアント）の 3 つで Skill を入れる前と後とも一致することをテストで確かめている
- [ ] 頼む小窓で ask の結果が届く前は形式のボタンが押せず、届いたら既定の形式が出ることをテストで確かめている
- [ ] formatShortDay の今日・昨日の境目を、UTC 以外の時差（日付が UTC と変わる時刻）と夏時間の切り替え日で確かめている
