## Summary

拡張のフォルダは版付きで、更新でパスが変わる。拡張は起動のたびに、版の付かない場所に起動ファイルと行き先（current）を書き、拡張の外からは起動ファイルだけを呼べばよいようにする。node は VS Code のものを使い、利用者に Node.js を入れてもらわない。

## Acceptance criteria

- [ ] 拡張は起動のたびに ~/.local/share/deguboard/ に起動ファイル dg（sh、中身は固定）と current（node と dg.mjs の場所、版）を書く
- [ ] current は一時ファイルから rename して書き、複数のウィンドウが同時に書いても壊れない
- [ ] node は、デスクトップでは VS Code 本体を ELECTRON_RUN_AS_NODE で、リモート（SSH・WSL・Dev Containers）では server の node を使う
- [ ] 版の古い拡張（Insiders・Cursor など）は、新しい版が書いた current を書き換えない。ただし current の node か dg.mjs がもうなければ、版が古くても書き直す
- [ ] 起動ファイルは current の node、PATH の node 24 以上、英語の案内（VS Code を一度開く）の順に試す
- [ ] Linux と macOS のデスクトップ、リモート SSH で、起動ファイルから dg --version が動くことを PR の本文に書く
- [ ] ADR-027 と UI-11 を「同梱し、起動ファイルで外にも出す」に書き換え、「npm に公開する」を採らなかった案に 1 行で残す
