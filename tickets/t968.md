## Summary

設定画面の各項目の行から Ask を開き、その項目を渡して `/dgconfig`（t967）を呼ぶ依頼文を出す。項目は `dg ask --action config --key <項目>` で渡す。`--key` はスキーマで項目の名前を確かめ、Ask の対象の種類（チケット・Iteration・Epic・Plan）は増やさない。Ask の場所（`askSections`）に設定の行を足し、項目の行ごとに吹き出しを出す。

振り返りの観点（`retro.perspectives`）の行からは、その観点の ID を渡して `/dgretro` を頼む（`dg guide retro` は Iteration の後ろの観点の ID でその観点だけを扱う。Iteration は Skill が直近に閉じたものを示して聞く）。

## Acceptance criteria

- [ ] 設定画面の項目の行ごとに Ask を開け、その項目のキーを入れた `/dgconfig` の依頼文を返す
- [ ] `dg ask --action config --key <項目>` が CLI・MCP でも同じ依頼文を返し、スキーマにない項目は使い方の誤りになる
- [ ] 振り返りの観点の行からは、その観点の ID を渡して `/dgretro` を頼む依頼文を返す
- [ ] 候補と依頼文は core の ask コマンドが組み、画面は写すだけにする
- [ ] 変えた約束が requirements.md の UI-14・UI-15 に反映されている
- [ ] 候補と依頼文と `--key` の検査をテストで確かめている
