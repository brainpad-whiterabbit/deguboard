## Summary

設定画面の各項目の行から Ask を開き、その項目を対象にして `/dgconfig`（t967）を呼ぶ依頼文を出す。Ask の対象（今はチケット・Iteration・Epic・Plan）に設定の項目を足すことになるので、対象の渡し方は着手のときに決める。

## Acceptance criteria

- [ ] 設定画面の項目の行から Ask を開け、その項目のキーを入れた `/dgconfig` の依頼文を返す
- [ ] 候補と依頼文は core の ask コマンドが組み、画面は写すだけにする
- [ ] 変えた約束が requirements.md の UI-14・UI-15 に反映されている
- [ ] 候補と依頼文をテストで確かめている
