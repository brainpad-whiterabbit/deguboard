## 概要

今のカンバンは、開いた Iteration がないと選択が「すべて」になり（packages/web/src/pages/board.tsx の selection）、全チケットを出す。帯（plansInScope、packages/web/src/components/plan-graph.ts）は渡されたチケットを 1 枚でも含む Plan を出すので、閉じた Plan がすべて「閉じた計画」に並ぶ（s8 を閉じた後、開いた Iteration がなく、閉じた Plan 25 本が出た）。「すべて」は札として選べず、開いた Iteration がないときの裏の選び方でしかない。「Iteration なし」の札では、Iteration に入っていないチケットと、それを含む閉じた Plan が出る。UI-13 は「選んだ Iteration のチケットを含む Plan を出す」としていて、選んでいないときの扱いが決まっていない。

2026-11-03 に人と決めた：カンバンは planned と active の Iteration とそのチケットだけを出す。「すべて」は札として常に出し、planned と active の Iteration すべてを意味する。Iteration に入っていないチケットはバックログで見る。

## 受け入れ条件

- [x] 左パネルの Iteration の札の列とブラウザの Iteration の選択に「すべて」が常にあり（開いた Iteration がないときも）、選ぶと planned と active の Iteration すべてのチケットを出す（Iteration に入っていないチケットと閉じた Iteration のチケットは出さない）
- [x] 「Iteration なし」の札と選択肢はなくなる
- [x] 開いた Iteration がないときは、カンバンの列も帯も出さず、開いた Iteration がないことと、バックログ（と Iteration の作成）への案内を出す
- [x] 帯は選んだ範囲（1 つの Iteration か「すべて」）のチケットを含む Plan だけを出し、その範囲の閉じた Plan は今までどおり「閉じた計画」に畳む
- [x] 札を選んでいないときの既定（active、なければ番号の小さい planned）と、ハッシュの `iteration=` が閉じた Iteration・存在しない Iteration・「なし」を指したときに既定に戻ることが決まっていて、テストで確かめる
