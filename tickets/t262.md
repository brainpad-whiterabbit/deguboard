## 概要

今のカンバンは、開いた Iteration がないと選択が「すべて」になり（packages/web/src/pages/board.tsx の selection）、全チケットを出す。帯（plansInScope、packages/web/src/components/plan-graph.ts）は渡されたチケットを 1 枚でも含む Plan を出すので、閉じた Plan がすべて「閉じた計画」に並ぶ（s8 を閉じた後、開いた Iteration がなく、閉じた Plan 25 本が出た）。「Iteration なし」の札でも、Iteration に入っていないチケットと、それを含む閉じた Plan が出る。UI-13 は「選んだ Iteration のチケットを含む Plan を出す」としていて、選んでいないときの扱いが決まっていない。

2026-11-03 に人と決めた：カンバンは planned と active の Iteration とそのチケットだけを出す。「すべて」は残し、planned と active の Iteration すべてを意味する。Iteration に入っていないチケットはバックログで見る。

## 受け入れ条件

- [ ] カンバンの札は planned と active の Iteration と「すべて」で、「すべて」は planned と active の Iteration すべてのチケットを出す（Iteration に入っていないチケットと閉じた Iteration のチケットは出さない）
- [ ] 「Iteration なし」の札はなくなる
- [ ] 開いた Iteration がないときは、カンバンも帯も出さず、開いた Iteration がないことと、バックログ（と Iteration の作成）への案内を出す
- [ ] 帯は選んだ範囲（1 つの Iteration か「すべて」）のチケットを含む Plan だけを出し、その範囲の閉じた Plan は今までどおり「閉じた計画」に畳む
- [ ] ハッシュの `iteration=` が閉じた Iteration・存在しない Iteration・「なし」を指したときは、既定の選び方に戻る
- [ ] UI-2・UI-13 が新しい振る舞いに合っている（requirements は予算の 99% なので書き換えで）
- [ ] web のテストで確かめ、変えた画面のライトとダークのスクリーンショットを PR に載せる
- [ ] mise run check が通る
