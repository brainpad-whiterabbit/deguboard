## 概要

左パネルのカンバンで Iteration の札を選ぶと緑に塗られ、s7 などの番号の文字が背景に負けて読みにくい。札の中の code の色が塗りの文字色に揃っていない（件数は inherit で揃っている。board.tsx の IterationChips、styles.css の .iteration-chip[aria-pressed="true"]）。

## 受け入れ条件

- [ ] 選んだ札の番号が、件数と同じくボタンの文字色で描かれる
- [ ] 選んでいない札の番号の見た目は変わらない
- [ ] ライトとダークのテーマで、選んだ札の番号が読めることをスクリーンショットで確かめる
