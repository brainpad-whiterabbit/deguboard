## 概要

左パネルのカンバンで Iteration の札を選ぶと緑に塗られ、s7 などの番号の文字が背景に負けて読みにくい。札の中の code の色が塗りの文字色に揃っていない（件数は `.iteration-chip[aria-pressed="true"] .chip-count { color: inherit }`（styles.css:1882）で揃っている。札は board.tsx:433 の IterationChips、番号は 477 行の `<code>`、`.iteration-chip code`（styles.css:1848）は background と padding だけを打ち消す）。VS Code の webview は既定で code に `--vscode-textPreformat-foreground` の色を付けるので、塗りの上で番号がその色になる。ブラウザの styles.css は code に色を付けないので再現しない

## 受け入れ条件

- [ ] styles.css で、選んだ札（`.iteration-chip[aria-pressed="true"]`）の code の色を件数と同じく inherit にし、VS Code の既定の code の色に負けない
- [ ] 選んでいない札の番号の見た目は変わらない
- [ ] mise run check が通る
