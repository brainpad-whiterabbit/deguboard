## 概要

`dg metrics show` の単位（Run・Ticket・Epic・Iteration・Project・Agent/Model）に step がなく、実装と見直し・手直しにかかった量を分けて見られない。単位に `step` を足し、`--by step` と `--step <id>` を使えるようにする。

## 受け入れ条件

- [x] `dg metrics show --by step` で step ごとの集計が出る
- [x] `dg metrics show --step review` で、その step の Run だけを集計する
- [x] MCP と HTTP の写しでも同じ操作ができる
- [x] requirements.md の MT-3 と ADR-005 の集計の単位が step を含む
- [x] 集計と絞り込みのテストがある
