## Summary

観点：アーキテクチャ（重複した処理）。

- packages/core/src/commands/run.ts の `run.recent` が、`run.list` の Run を集める処理（走っている Run と記録した Run を合わせ、置き場所を決め、Iteration と Project で絞り、警告を作る）を写している。help の「run.list と同じ」は、両方が同じである間しか成り立たない
- 承認で越えられない条件の文が pre-tool-use.ts・pr.ts（proceedHint と prMerge の summary）・gate.ts の 4 か所に手で書いてあり、pre-tool-use.ts だけ pr が抜けている
- packages/cli/src/program.ts の `version()` が、core の `coreVersion()`（bundle-layout.ts）とほぼ同じ手順で版を取る
- pr.ts は、回していない検査を、理由の文字列が gate.ts の `CHECK_NOT_RUN` と同じかどうかで見分けている。文を変えると黙って前の振る舞いに戻る（t884 の見直しで残った指摘）
