## Summary

見直し（s41 の 2 回目）の観点「テスト」。packages/core/src/git/git.test.ts の「gh がない環境では PR の事実がすべて不明になる」は、PATH を空のディレクトリと /usr/bin:/bin にして gh がない状態を作ろうとしているが、gh は /usr/bin にあることが多く、そのとき本物の gh が呼ばれる。gh にログイン済みの機械では PR がないことが missing と読まれ、pr_open が undefined でなくなって落ちうる。

## Acceptance criteria

- [x] この件が、本物の gh の有無とログインの状態に頼らずに gh のない状態を作っている（facts.test.ts や metrics.test.ts の偽の gh の形に倣う）
- [x] 変えた PATH がテストの後に戻る
