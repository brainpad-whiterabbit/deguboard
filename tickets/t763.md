## Summary

品質ゲートの「最後の push より後の見直し」は、作業ブランチのリモートの先端のコミット日時を push の時刻の近似として比べる。別の clone で先に作ったコミットを見直しの後に push したとき、時計のずれ、古いコミットへの force-push では、見直していないコミットで条件が通る。Run のデータの形と ADR-011 を変えるので、着手の前に dgdiscuss で方針を決める。

## Acceptance criteria

- [ ] 見直しの Run は、始めたときの作業ブランチの先端の SHA を記録する
- [ ] 品質ゲートは、最後に通った見直しの SHA がリモートの先端と同じかで判定する
- [ ] 見直しの前に作ったコミットを見直しの後に push したとき、ゲートが落ちることをテストで示す
- [ ] requirements.md の Run の項と ADR-011 の本文を、SHA で判定する形に直す
