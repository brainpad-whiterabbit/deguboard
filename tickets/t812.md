## Summary

設定画面が core のスキーマの説明（describe）を全文出していて長すぎる（44 項目で 8,462 字、うち guide.notes.* の同じ 264 字の繰り返しが半分）。画面で短く出せるよう、項目の定義に 1 行の要約（summary）・例（example）・空のときの動き（empty）・選択肢ごとの説明を足し、config.show の fields で渡す。今の describe は詳しい説明として残し、CLI のヘルプは変えない。最初の 1 文を自動で切り出す案は、最初の 1 文が 300 字ある項目があるので採らない。

## Acceptance criteria

- [x] config.show --fields の各項目が summary（1 行の要約）を持ち、description は今の全文のまま変わらない
- [x] 例のある項目は example、空にできる項目は empty（空のときの動き）、選択肢のある項目（commit.mode・push.mode など）は選択肢ごとの説明を持つ
- [x] guide.notes.* は要約と詳しい説明を 1 つの定義で共有する
- [x] 足した文の日本語の訳があり、core の文と訳に過不足がないことをテストが確かめる
- [x] どの項目にも summary があることをテストが確かめる
