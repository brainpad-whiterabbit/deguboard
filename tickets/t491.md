## 概要

guide 14 本を英語にしたあとで、Skill の雛形を英語にする。雛形が名指す guide の見出し（いまは「対象を決める」）を英語の見出しに合わせる。SKILL.md の差し込み（skill.ts の buildSkills）を英語にそろえる：PATH に dg がないときの案内はいまの DG_PATH_NOTE（日本語）から、すでにある英語の DG_PATH_NOTE_EN に替え、冒頭の 1 文は SKILL_SUMMARY の en から出す（いまは skillSummary の既定の ja）。日本語の DG_PATH_NOTE と SKILL_SUMMARY の ja は、日本語の依頼文と頼む小窓のツールチップが使うので残す。リポジトリの .claude/skills を dg skill install で入れ直す（手を加えたとみなして残した Skill があれば、加えた文を guide.notes へ移してから --force で上書きする）。

## 受け入れ条件

- [x] packages/cli/src/skill.md が英語で、名指す見出しが英語にした guide の見出しと一致する
- [x] Skill の PATH の案内が DG_PATH_NOTE_EN から、冒頭の 1 文が SKILL_SUMMARY の en から出る
- [x] .claude/skills の dg* 9 本が dg skill install で更新され、英語の文面になっている
- [x] packages/cli/src/skill.test.ts・packages/core/src/commands/ask.test.ts が英語の文面に合わせて直してある
- [x] mise run check が通る
