## 概要

手引きを変えて効いたかを確かめるために、Run の会話記録から、エージェントの調べた量を数えて残す。2026-11-05 に ## 参考 節の効果を会話記録で手で数えた（最初に書くまでの読む・探すの回数）。その数え方を、会話記録の取り込み（MT-2）に入れる。写すのは数だけ（MT-4）で、コマンドの文字列やパスは写さない。Bash は読むものと書くものに分けず、1 つの種類として数える。

## 受け入れ条件

- [x] Run に、ツールの呼び出しの種類ごと（読む・探す・書く・Bash・ほか）の回数と、最初に書くまでの読む・探すの回数が入る。取れなければ null で、書かずに終わった Run では全体の数になる。この項目より前の Run は読めるまま
- [x] Claude Code の Adapter が、使用量と同じ範囲（Run の ID が出てから finished_at まで）の会話記録から数える。数えられない Adapter は null にする
- [x] `metrics show` がこれを足し、欠けた Run の数を出す（MT-3）
- [x] requirements の 5.9・RN-1・MT の節と ADR-005（記録するもの・写すのは数だけ）を直す
- [x] Adapter と集計のテストを足し、`mise run check` が通る
