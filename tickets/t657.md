## Summary

チケットに品質ゲートの段 `gate`（high・low・free、ないときは high）を持たせ、`dg gate`・`dg pr ready`・`dg pr merge` は段に応じた条件だけを判定する。high は今と同じ（pr・acceptance・review・fix_rounds・mergeable・check）、low は pr・acceptance・mergeable・check、free は pr・mergeable。段を下げるのは人の指示によるもので、守りは規約にし、コードで人に限らない。フックは今のまま。

## Acceptance criteria

- [ ] ticket create・import・update で gate を付けられ、update では外せる。不正な値は拒まれる（テスト）
- [ ] low のチケットは、見直しの Run がなくても pr・acceptance・mergeable・check で dg pr merge が通る（テスト）
- [ ] free のチケットは、pr・mergeable だけで dg pr merge が通る（ready のときは pr だけ。テスト）
- [ ] gate のないチケットの判定は今の high と変わらず、dg gate の出力に判定した段が出る
- [ ] requirements.md に段の項（TK）を足し、EX-6 を段に応じた条件に直す
- [ ] ADR-026 の「例外は Core に持たせず人が gh を打つ」を段の判断に書き換え、採らなかった案（Plan の details に持つ・パスで決める・コードで人に限る）を 1 行ずつ足す
