## 概要

観点：文書と実装。AG-2・ADR-010・README（t365）は Skill を任意とし、文章の形式の依頼文（t363・t364）は dg guide を読んで進めさせる。
一方 guide-choices.md と各 guide の「次の手順を選ぶ」は、Claude Code では Skill（`/dgwork p3` など）を起動すると無条件に書いている。Skill を入れていないエージェントは、次の段階で存在しない Skill を起動しようとする。

## 受け入れ条件

- [x] guide-choices.md が、Skill が入っていればその Skill を起動し、なければそのトピックの `dg guide <topic>` を読んで続けると案内する
- [x] 各 guide の「次の手順を選ぶ」の `/dg…` の例が、Skill がないときの続け方と食い違わない
- [x] guide-overview.md に Skill は任意であることが書いてある
- [x] guide の文面のテスト（あれば）が新しい文面に合っている
