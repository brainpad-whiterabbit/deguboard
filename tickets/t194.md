## 概要

Run の実績は履歴に出さず Run の画面（#/runs?by=iteration）で見る方針だが、履歴の Iteration の行からそこへのリンクがない。行にリンクを置き、その Iteration に絞った Run の集計を開く（改善案 H7）。数字は履歴に持ち込まない。改善案のページ：https://claude.ai/artifact/RPsNUSkt3w9SboDy5XQAwd


## 受け入れ条件

- [x] 閉じた Iteration の行に「Run の集計」のリンクが出る
- [x] リンクを押すと Run の画面が開き、その Iteration の集計が出る
- [x] 履歴の画面には Run の数字を出さない
