## Summary

見直し（s41）の観点「テスト」。packages/core/src/commands/gate.test.ts は review の時刻を Date.now() から n 分後に固定する一方、同じテストで後から作るコミットは実時刻なので、review の started_at とコミットの時刻の前後が実行のたびの時計に頼っている。今は Run に head を記録しているので時刻で比べる経路を通らず表に出ていないが、時刻で比べる経路に入ると結果が揺れうる。
