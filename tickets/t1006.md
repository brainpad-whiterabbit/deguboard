## Summary

左パネルのチェックリスト（後のチケット）と CLI が同じ判定を使えるよう、導入の項目を上から順に確かめて返すコマンドを core に置く。拡張でしか確かめられない項目（フォルダ・OS・PATH の dg）は含めず、拡張が足す。

## Acceptance criteria

- [x] dg setup check --json が、git の版・Git リポジトリ・ボード・Skill と hooks・.claude/.gitignore の項目を上から順に、満たすか・状態の文・必須か推奨か・直すコマンド（コマンドで直せるときだけ。接続の不調などは空）とともに返す
- [x] dg init 前のボードの項目は、remote に届かない・届いてボードがない・届いてボードがある、のどれかを返す
- [x] 前の必須の項目を満たさないとき、後の項目は確かめずに待ちとして返す
- [x] Skill と hooks の項目は、入っているか（設定に dg の hooks があるか、Skill があって古くないか）だけを確かめ、動くかどうかは dg hooks check に任せる。状態の文で dg hooks check を案内する
- [x] 判定は packages/core/src/commands/ のコマンド定義に置き、CLI は写すだけで、拡張が core から呼べる
- [x] 各項目の満たす・満たさない場合をテストで確かめる
