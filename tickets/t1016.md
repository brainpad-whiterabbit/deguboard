## Summary

見直し（s38）の観点「構成」。拡張の setup の通知（packages/vscode/src/extension.ts の postSetupTo）は左パネルとエディタのパネルの両方に届き、帯を出さないパネルも packages/web/src/store.tsx の recheckSetup で確かめ直す。拡張の checkSetup が重ねて走り（init の前なら ls-remote、ready なら dg --version）、パネルは別のリポジトリのボードの指定を持たないので、指定のない結果が左パネルの確かめた結果を上書きし、自動の確かめ直しの判断が入口によって変わる。

## Acceptance criteria

- [x] 帯もチェックリストも出していないエディタのパネルは、setup の通知で確かめ直さない（拡張の側か web の側のどちらかで止める）
- [x] パネルを開いている間も、左パネルが別のリポジトリのボードを指定して確かめた結果が上書きされない
- [x] 上の 2 つをテストが確かめる
