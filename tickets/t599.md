## 概要

今は見直し役が `dg run review-result` に指摘の数（heavy・light・passed）を自己申告で書き、指摘の一覧は文で親に返している。一覧を JSON（severity・category・file・line・reason・fix）で受けて検証し、数と passed を dg が求める。

## 受け入れ条件

- [x] `dg run review-result <id> --findings-file <file>` がスキーマで検証し、誤りには場所を示して拒否する
- [x] heavy・light・passed を一覧から求め、`review.heavy_categories` の category は重いとみなす
- [x] 一覧の置き場所（Git の Run の記録か deguboard-local か）を ADR-025・ADR-029 に照らして決め、理由をコードのコメントに書いた
- [x] guide-review の「返す」が一覧の形と `--findings-file` を指している
- [x] 数だけを渡す今の呼び方の扱い（残すか拒否するか）が `dg run review-result --help` とテストにある
