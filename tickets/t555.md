## 概要

t545 の advancesPrOutsideDg は、止めすぎを減らすために、引用符・ヒアドキュメント・コメントの中を文字として伏せる（maskTextArguments）。伏せた所が抜け道の候補になり、見直しのたびに条件分岐が増えて、t532 と同じく指摘が尽きない形に戻っている。わざと隠した形まで個々に塞ぐのは、ADR-019 が事後の検査（t546）に任せた範囲と重なる。伏せる処理をやめて生のコマンドで粗く判定し、止めすぎは拒む文の逃げ道（Write でファイルに書いて --body-file・git commit -F で渡す）で受け止める。提案：https://claude.ai/artifact/RmmXg9hrARFaBL9qLMxvEA

## 受け入れ条件

- [ ] advancesPrOutsideDg は引用符・ヒアドキュメント・コメントの中を伏せずに判定し、maskTextArguments とそれだけが使う一覧（TEXT_COMMANDS・GH_TEXT_SUBCOMMANDS・GIT_TEXT_SUBCOMMANDS など）がない
- [ ] gh pr merge・gh pr ready・gh api の同じ操作が、2>&1・$PR・python -c の中でも止まり、dg pr ready・dg pr merge（mise run dg -- pr … も）と gh pr ready --undo は通ることを、テストで確かめる
- [ ] 本文の引用符・ヒアドキュメントの中に gh pr merge・ready の語があるコマンドは止まり、拒む文がファイル渡し（--body-file・git commit -F）の道を案内することを、テストで確かめる
- [ ] わざと隠した形（g\h・"mer""ge"・$(which gh) など）を個々に見ず、t546 の事後の検査で補うことを、コメントに書く
