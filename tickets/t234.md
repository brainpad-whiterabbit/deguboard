## 概要

見直し（文書と実装）。packages/core/src/commands/setup.ts 526〜533 行の coerce は、config.set の値の "2026" を数値に、"true" を真偽値に変えてから検証するので、文字列の項目（git.base_branch・git.remote など）に数字だけ・true・false だけの名前を入れると VALIDATION_FAILED で保存できない。v0.5.0 からの CLI の挙動だが、設定画面は入力欄の文字列をそのまま送るので気づきやすくなった

## 受け入れ条件

- [x] 文字列の項目に "2026"・"true" を config.set で保存でき、真偽値・数値・リストの項目は今のとおり変換して保存できる
- [x] core のテストで、文字列・真偽値・数値・リストの項目それぞれの保存を確かめる
- [x] mise run check が通る
