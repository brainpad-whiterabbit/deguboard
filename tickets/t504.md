## 概要

印を見て詳細を開いた人が、本当に止まっているかを自分で確かめられるよう、実行中の Run の根拠の時刻を出す。操作のボタンは置かない（依頼は頼む小窓に寄せる）。

## 受け入れ条件

- [ ] 実行中の Run に、最後の会話・最後のコミット・最後の push・作業ツリーの変更の 4 つが出る
- [ ] Run の状態の印が、カンバンの行と同じ形と説明で出る
- [ ] Run の節に操作のボタンを足さない
