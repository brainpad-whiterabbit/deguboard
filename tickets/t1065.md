## Summary

このクローンから deguboard を外す（検討の B の範囲）ことを 1 回でする `dg uninstall` を足す。消す順序は dg が守り、`--dry-run` で消すものを先に確かめられる。リモートとチームで共有しているものには触れない。人だけが実行できる。

## Acceptance criteria

- [x] リポジトリの dg のフック（dg hooks uninstall と同じ判定）・dg の Skill（dg skill uninstall と同じ判定）・データの worktree とローカルのデータブランチ・git の共通ディレクトリの deguboard-local・git config の merge.deguboard.* を消すことを、bare リモート付きの一時リポジトリのテストが確かめる。`--personal` を付けると、個人の設定のフックと `~/.claude/skills` の Skill も消す
- [x] リモートのデータブランチ・データのリモートの登録（dg init が足した deguboard-data も）・コミットした `.claude/.gitignore`・`.claude/settings.json` のフックは消さない。結果では、リモートにデータが残ることと、手で消すときのコマンドを示す
- [x] 送っていないデータのコミット・dg の外の変更・作業中のチケットの worktree があるときは、何も消さずに理由と次にすること（dg sync など）を返して止まる。`--force` を付けると越えられる
- [x] `--dry-run` は何も消さずに、消すもの・残すもの・止める理由を返し（`--json` で画面が読める形）、agent からの呼び出しでも通る
- [x] 人だけが実行できる。Core の固定（CORE_FIXED）に足し、agent の呼び出しは TRANSITION_REJECTED で断る。`dg workflow show` の fixed に出る
- [x] 要件に 1 項を足す。リモートに触れないことと人だけに限ることの理由は、今の判断を書いた ADR（ADR-026 など）に書き足すか、ADR を書く場面に当たらなければテストとコメントに置く
