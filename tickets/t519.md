## 概要

観点=アーキテクチャ・テスト。対象=ask.ts（label は日本語のみ、skill_summary・meaning・text は language で core が選ぶ）、web の l10n-en.ts（CORE_EN・CONFIG_DESCRIPTIONS_EN・CORE_MESSAGES_EN）と l10n.ts の trCoreMessage。食い違い：UI-11 の表示言語を core と web で別々に実装し、同じ AskCandidate の中でも label は web、meaning は core が訳す。CORE_MESSAGES_EN は s19 で書き込みのコマンド（move・update）が返すようになった Run の警告を持たず、client/http.ts にはテストがない。core が language を受けるか、core は code と引数を返し web が訳すかを決める。方針の判断が要るので Iteration に入れない。

## 受け入れ条件

- [ ] core の文の英語化の分担が決まり、ADR-007 か UI-11 に書いてある
- [ ] ask の候補の label と meaning が同じ仕組みで英語になる
- [ ] 画面が受けうる書き込みのコマンドの Run の警告が英語の表示で英語になるか、対象外と決めて書いてある
- [ ] mise run check が通る
