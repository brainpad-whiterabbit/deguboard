## 概要

チケット詳細の PR 欄は #番号 の文字だけで、PR を開けない。リモートの URL から PR のページへのリンクにする。

## 受け入れ条件

- [ ] リモートが GitHub の形（https・ssh）のとき、チケット詳細の PR 欄が PR のページへのリンクになる
- [ ] リモートがない・URL に直せないときは今までどおり #番号 の文字だけを出す
- [ ] VS Code のパネルとサイドバーでもリンクから PR をブラウザで開ける
- [ ] requirements.md に PR 欄のリンクを書く
