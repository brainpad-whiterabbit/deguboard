## Summary

動いている途中で落ちたセッションのサブエージェントの Run は、同じチケットの次の起動が interrupted で閉じるまで開いたままで、閉じる時刻はその起動の時刻になる。そのため、落ちてから次の起動までの時間が Run の時間に入る。待ちの印とは原因が違う（止まったことをフックが見ていない）ので、待ちを数える変更とは別に直す。

## Acceptance criteria

- [x] 落ちたセッションの残りとして閉じた Run の時間に、落ちてから閉じるまでの時間が入らないことをテストが確かめている
- [x] 閉じる時刻の決め方の変更が、dg hook のヘルプと requirements.md の RN-6 に反映されている
