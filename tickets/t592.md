## 概要

サブエージェントは brief が指す 1 節のために guide の全体を読んでいる（guide-work は約 4,700 字、「実装する」は約 620 字）。`dg guide <topic> --section <節>` で、指定した節の本文だけを出す。置き場所は adr のチケットの決定に従う。

## 受け入れ条件

- [x] 見出しの名前でも、見出しの「（…）」の補足を除いた名前でも、その節の本文が出る（`dg guide work --section 実装する`）
- [x] ない節を指定すると、使い方の誤りとしてそのトピックの節の一覧を返す
- [x] 節の本文でも `{{choices}}` の差し替えと config の値の埋め込みが効く
- [x] `--json` の `data` に topic・section・text が入る
- [x] CL-5 の約束と `dg guide --help` を直した
