## Summary

Codex のフックは正式版で、SessionStart・PreToolUse・PostToolUse・SubagentStart・SubagentStop・Stop・SessionEnd を持ち、入力は session_id・transcript_path・cwd など Claude Code に近い形。Codex の Adapter に HookSupport を足し、ADR-025 の Run の開け閉めを Codex でも行う。Codex には git が追跡しないプロジェクトの設定の層がないので、.codex/hooks.json に書いて無視する。プロジェクトのフックは /hooks で信頼の承認を経ないと動かない。主体は actor のチケットの判定で agent にする。

## Acceptance criteria

- [ ] dg hooks install --agent codex が .codex/hooks.json にフックを書いて .gitignore に足し、uninstall が外す
- [ ] dg hooks check --agent codex が届かないフックを警告し、/hooks での信頼の承認を案内する
- [ ] Codex のフックの入力（SessionStart・spawn_agent の PostToolUse・SubagentStart・SubagentStop・SessionEnd）を Core の出来事に写すことをテストで示す
- [ ] CODEX_THREAD_ID がサブエージェントの Bash でも親のセッションの ID かを本物の Codex で確かめ、確かめられれば sessionFromEnv を足し、確かめられなければその旨をコメントに書く
- [ ] 本物の Codex で、印で頼んだサブエージェントの Run が開いて閉じ、使用量が入ったことを PR の本文に書く
