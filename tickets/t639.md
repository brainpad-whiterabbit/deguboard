## 概要

`dg pr ready` は、見直しの記録の軽い指摘のうち手直しに渡さなかったものを PR の本文に書き足す。手直しに渡したかどうかは指摘の category（受け入れ条件を含むか）だけで決まるので、親が依頼文で手直しに渡し、手直しが直した軽い指摘まで「直さなかった」と載る。PR #580（t634）は 7 件中 3 件、PR #583（t636）は 4 件中 3 件が直し済みだった。本文が実際と食い違い、人が残りの指摘を読み違える。

## 受け入れ条件

- [ ] 手直しに渡して直した軽い指摘は、`dg pr ready` が本文の「直さなかった軽い指摘」に載せない
- [ ] 手直しに渡さなかった軽い指摘と参考節との食い違いは、今までどおり載る
- [ ] 上の 2 つをテストで確かめている
- [ ] 親が手直しに渡す軽い指摘を dg に伝える道が、guide（review の修正ループ）に書かれている
