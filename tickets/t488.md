## 概要

方針（英語に統一）に沿って、guide 6 本を英語にする。frontmatter を持つのは import・assign・check・plan の 4 本（overview と choices は持たない）。frontmatter の説明は Skill の説明の正本なので英語にし、日本語の依頼でも起動するよう日本語の起動の例を残す。overview に、エージェントが書く文章の言語の規則を入れる。

見出しを英語にすると、その見出しを名指す参照（`dg guide <topic>` の「節」）が check:docs で切れる。このチケットの 6 本の見出しを名指すのは、core のコード（setup.ts・git/outside.ts・git/write.ts が overview の「dg の外の変更」「同期が止まったとき」を指す）と guide-assign（import の「起票者と担当者」）なので、同じ PR で英語の見出しの形（``the "節" section of `dg guide <topic>` ``）に直す。逆に、この 6 本が指すまだ日本語の guide の節（overview → run の「親が自分で進めるとき」、check → work の「claim の前後」）はそのまま残してよい。

## 受け入れ条件

- [ ] guide-overview・guide-choices・guide-import・guide-assign・guide-check・guide-plan の本文が英語である
- [ ] frontmatter を持つ 4 本（import・assign・check・plan）の description と argument-hint が英語で、description に日本語の起動の例が残っている
- [ ] guide-overview に、チケット・PR・コミット・人への返答をリポジトリの既存の文章と人の依頼の言語で書く規則がある
- [ ] 英語にした見出しを名指す参照（core の setup.ts・git/outside.ts・git/write.ts、ほかの guide）が新しい見出しに直してある
- [ ] 日本語の文を照合していたテスト（guide.test.ts・skill.test.ts・ask.test.ts など）が英語の文に合わせて直してある
- [ ] mise run check が通る
