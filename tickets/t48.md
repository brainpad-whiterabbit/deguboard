## 概要

Iteration を閉じる操作は取り消せず、誤って閉じた s2 を active に戻せなかった。Epic には epic reopen があるので、Iteration にも同じ形で reopen を足す。再開した Iteration は active に戻り、closed_at・completed・carried_over は消す。閉じたときに外した持ち越しのチケットは記録がないので戻さず、iteration add で入れ直す。

## 受け入れ条件

- [x] core に iteration.reopen を足す。closed 以外は REJECTED。再開後は status が active で closed_at・completed・carried_over がない。持ち越しが 1 件以上あったときは入れ直しを促す警告を返す
- [x] CLI の dg iteration reopen <iteration>（sprint のエイリアスを含む）で呼べ、ticket add が再開後の Iteration に入れられる
- [x] web の Iteration の詳細で、closed のときに「再開する」ボタンが出て iteration.reopen を呼ぶ
- [x] commands.test.ts に close → reopen → add の流れと、閉じていない Iteration の reopen が拒否されるテストを足す
- [x] requirements.md の IT-1 とコマンドの表、guide（assign・finish・overview）、CLAUDE.md の人の指示が要る操作に reopen を書く
- [x] mise run check が通る
