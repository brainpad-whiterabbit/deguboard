## 概要

拡張の紹介ページ（特長・導入・GIF の使い方・セキュリティとプライバシー）をルートの README.md の先頭に置き、ルートを紹介の正本にする。今のルートにしかない情報は「ほかの使い方」と正本へ移す。

## 受け入れ条件

- [x] README.md が紹介・特長・導入・使い方（GIF）・セキュリティとプライバシーの順で始まり、文体がです・ますにそろう
- [x] 公開前の clone してビルドする導入が、導入の節から README の中で辿れる
- [x] 「ほかの使い方」の節に、ブラウザ（dg serve）と MCP（Claude Desktop の設定）が残る
- [x] Run の記録と Plan の段階の細部は README から消え、requirements.md か dg guide への案内になる。消した内容で正本にないものは正本へ移してある
- [x] 開発中・未公開の注記、ドキュメントの一覧、ライセンスが残る
- [x] mise run check が通る
