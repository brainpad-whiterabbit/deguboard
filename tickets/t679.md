## Summary

左パネルの一番上の ask（対象なし）は、作成 3 種・点検・自由にの 5 枚しか出さない。Skill の頼むことはどれも Skill の側で対象を聞けるので、流れの順にすべて出す。対象がないと意味のないもの（外す・分ける・done の取り消し・再開する・承認）と、Skill のない status・retro・carry は出さない。

## Acceptance criteria

- [ ] 対象なしの候補が create・create_iteration・create_epic・assign・check・plan・work・all・done・release・edit・close・reopen・abandon・discuss・free の順で、先頭が create になることをテストが確かめる
- [ ] 対象なしの Skill の形は ID のない Skill の呼び出しを返し、呼び出しで頼むことが決まらないもの（dgchange の直す・閉じる・再開・やめる、dgassign の割り当てと作成）には短い頼みごとを添えることをテストが確かめる
- [ ] 対象なしの文章だけの形は、どれを対象にするかを聞いてから進める依頼文を ja・en で返し、ID の入る場所が空の文にならないことをテストが確かめる
