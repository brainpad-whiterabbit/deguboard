## 概要

左パネルの履歴の検索語・結果の絞り込み・開いた行は useState に持つので、カンバンなど他のタブへ移って戻ると消える。見方と同じく戻ったときに残す（改善案 H6）。検索語と絞り込みはハッシュのクエリに、開いた行は Webview の state にホストの抽象を通して持つ。改善案のページ：https://claude.ai/artifact/RPsNUSkt3w9SboDy5XQAwd


## 受け入れ条件

- [x] 履歴で検索語と結果の絞り込みを入れて他のタブへ移り、戻ると同じ検索語と絞り込みで出る
- [x] 開いた Iteration・Epic の行が、他のタブから戻っても開いたまま出る
- [x] 検索語と絞り込みはハッシュ（#/history?view=…）に入り、開いた行はハッシュに入らない
- [x] ブラウザ（dg serve）でも検索語と絞り込みがハッシュから戻る
