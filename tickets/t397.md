## 概要

起票の手引き（`dg guide import`）は、## 参考 節を「着手するエージェントに渡す」ものとだけ書いている。2026-11-05 の調べでは、着手する実装役には依頼文（Plan の範囲・方針）で同じ置き場所がほぼ伝わっていた（参考節の 68 項目のうち 47 項目が依頼文にもあった）。一方、参考節と PR の変更ファイルを並べると、範囲の広がり（t335・t386）や見込みの外れ（t336）が見えた。参考節の目的に「人が PR と見比べる、起票したときの見込み」を足し、それに合う書き方にする。

## 受け入れ条件

- [ ] `dg guide import` の ## 参考 節の説明が、着手するエージェントに渡すことに加えて、人（と見直し役）が PR と見比べる起票時の見込みであることを書いている
- [ ] 説明が、見込みとして直すと考えたファイルのパスを書くよう促している（書いてよいもの・書かないもの〔行番号・docs の書き写し・実装の手段〕と、節が任意で lint が指摘しないことは変えない）
- [ ] guide の文面のテストが通り、`mise run check`（check:docs の予算を含む）が通る
