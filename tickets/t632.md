## 概要

今の品質ゲートは、変更の中身によらず actions.test（このリポジトリでは mise run check。テスト 1446 件で約 4 分）を回す。t631 では SVG 1 つの変更で、コミット前とゲートで 2 回回った。config に「軽い検査のコマンド」と「対象のパス」を足し、作業ブランチの差分のファイルがすべて対象のパスに入るときは軽い検査だけを回す。このリポジトリでは軽い検査を書式の検査と check:docs にし、コミット前の検査も同じ扱いにする（2026-11-09 に人が決めた）。

対象のパスに文書を入れるときは、テストが読む packages/core/src/guide/ の Markdown を外す。

## 受け入れ条件

- [ ] config の actions に、軽い検査のコマンドと対象のパス（glob）を書ける。既定は空で、空なら今までどおり actions.test を回す
- [ ] 作業ブランチの差分（base との）のファイルがすべて対象のパスに入るとき、品質ゲートは軽い検査を回し、どちらの検査を回したかを判定の詳細に出す
- [ ] 差分に対象のパスの外のファイルが 1 つでもあれば actions.test を回すことを、テストで押さえる
- [ ] 通った検査の結果の使い回し（ready で通ったら、同じコミットの merge では回し直さない）が、回したコマンドごとに今までどおり効く
- [ ] このリポジトリの config と mise.toml に軽い検査と対象のパスを設定し、CLAUDE.md のコミット前の検査の規約を同じ扱いに直す
- [ ] requirements の品質ゲートの検査の項（EX-6）、設定画面の actions の説明、dg guide review の「検査」を新しい振る舞いに合わせる
