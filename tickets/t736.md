## Summary

ターミナルやシェルを使うエージェントから dg を打てるよう、利用者が明示したときだけ PATH にリンクを置く（VS Code の「Install 'code' command in PATH」と同じ形）。利用者の環境に勝手に手を入れない。

## Acceptance criteria

- [x] 「deguboard: Install dg command」で ~/.local/bin/dg に起動ファイルへのリンクを置く
- [x] 別の dg（mise run dg:link など）がすでにあれば上書きせず、どこを指しているかを示して止める
- [x] ~/.local/bin が PATH になければ、足し方を案内する
- [x] 「deguboard: Uninstall dg command」は ~/.local/bin/dg のリンクだけを外す（フックが使う起動ファイルは残す）
- [x] 拡張を消したとき（vscode:uninstall）は、current がこの拡張を指すときだけ、起動ファイル・current・リンクを片付ける（ほかのエディタの拡張が使っているものは消さない）
- [x] PATH に dg がないときの拡張の案内を、README の手順を指す形からこのコマンドを勧める形に変える
