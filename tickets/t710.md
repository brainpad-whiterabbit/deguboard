## Summary

ボード・バックログ・履歴の Iteration と Epic の見出しでも、右クリックで「詳細を開く」「ID をコピー」を出す。拡張のコマンドがチケット以外の ID も受けるようにする。VS Code の中だけ。

## Acceptance criteria

- [ ] ボード・バックログ・履歴の Iteration と Epic の見出しが、右クリックの文脈にその ID を載せる（テスト）

- [ ] 右クリックで見出しの開閉が起きない
- [ ] PR に、見出しで右クリックのメニューを出したスクリーンショットがある
