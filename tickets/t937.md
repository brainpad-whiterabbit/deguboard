## Summary

設定画面（#/config）の振り返りの節で、表示言語が英語でも既定の観点の名前と問いが日本語で出る。既定の観点を config の既定の値として日本語で持っているため。既定の 7 観点の名前と問いを core で英語で持ち、日本語の表示では、名前と問いがどちらも既定のままの観点だけを日本語の訳で出す。どちらかを書き換えた観点と、チームが足した観点は書いたまま出す。既定のままかは、`config.show` が返す観点の既定と比べて決める（t938 の「変更あり」も同じ既定を使う）。

## Acceptance criteria

- [ ] 既定の 7 観点の名前と問いを、core で英語で持つ
- [ ] 英語の表示で、既定の観点が英語で出る
- [ ] 日本語の表示で、名前と問いがどちらも既定のままの観点は日本語の訳で出る
- [ ] 名前か問いを書き換えた観点と、チームが足した観点は、どちらの表示でも書いたまま出る（一覧を日本語で書いたリポジトリの観点も含む）
- [ ] `config.show` が観点の既定を返し、画面は既定の写しを持たない
- [ ] 上の 5 つをテストが確かめる
