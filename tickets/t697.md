## Summary

2026-11-11、PATH の dg（~/.local/bin/dg → dg.js、#!/usr/bin/env node）が Claude Code の環境で node を見つけられず、フックが毎回失敗していた。mise run dg -- hooks check は dg 自身の環境（mise が node を PATH に足す）で確かめるので、どのイベントも handler: ok で、received_at はすべて null なのに警告がなかった。サブエージェントの実装の Run（t686〜t688）は黙って記録されなかった。mise に限らず、nvm・volta・fnm・Homebrew などでも、ターミナルとハーネスの PATH が違えば同じことが起きる。

ツールに依らずに気づけるよう、届いた記録（received_at）で判定する。

## Acceptance criteria

- [x] dg hooks check が、入れてあるのに一度も届いていないイベントを warnings に出すことをテストが確かめる
- [x] Claude Code の中（CLAUDE_CODE_SESSION_ID がある）で、そのセッションにフックが 1 つも届いていないとき、next・brief・ticket claim --no-run が「サブエージェントの Run は記録されない」と warnings に出すことをテストが確かめる
- [x] 届いているときは、これらの警告が出ないことをテストが確かめる
- [x] README と development.md のフックの確かめ方が、届いた記録で判定する形に合っている
