## 概要

バックログ・カンバン・Sprint と Epic の詳細の行を、VS Code の一覧と同じく Ctrl/⌘+クリックと Shift+クリックで複数選べるようにし、選んだ行をまとめて頼む。バックログの絞り込みの件数の右クリックで、絞った結果もまとめて頼めるようにする。

案のページ：https://claude.ai/artifact/DsZs7PgafyAdNmmb64k6q5

## 受け入れ条件

- [x] Ctrl/⌘+クリックで 1 行ずつ、Shift+クリックで範囲を選べ、ふつうのクリックは今までどおり詳細を開く
- [x] 選ぶと「n 件を選択 ・ 頼む」の帯が出て、「選択を外す」と Esc で外せる
- [x] 選んだ行の吹き出し・右クリックは、選んだ全件を対象にした一覧を出す
- [x] バックログの絞り込みの件数（n / m 件）の右クリックで、絞った結果を対象にした一覧が出る
