## Summary

s44 の見直し（観点：アーキテクチャ）の指摘。web は core の実行時のコードを import できないので写しを持つ（規則上は許される）。そのうち 2 つは照らし方が足りない。(1) packages/web/src/components/setup-checklist.tsx の `initCommandLine` の中の引用の処理は packages/core/src/shell-quote.ts の `shellQuote` の写しだが、shell-quote.ts の先頭のコメントは「ただ 1 つの処理」と書き、写しがあることが分からない。照らすテストの入力も 8 通りで、`=`・空文字・改行を含まない。(2) packages/web/src/components/label-vocab.ts の `PROCEDURE_LABEL_PREFIXES`・`isProcedureLabel` の写しは、テストが代表の名前だけで照らすので、core の接頭辞が変わったときに検出できるかが確かめられていない。

## Acceptance criteria

- [ ] shell-quote.ts の先頭のコメントから web の写しが辿れ、写しを照らすテストの入力に `=`・空文字・改行を含む値がある
- [ ] label-vocab.ts の手順のラベルの写しを照らすテストが、core の接頭辞をすべて含む
