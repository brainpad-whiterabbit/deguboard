## 概要

config.yaml は deguboard ブランチで全員が共有し、利用者ごとの上書きがない。マシンの配置・作業の好み・使えるモデル・自分のマシンで許すことのように人ごとに違ってよい項目を、Git に入らない `<git-common-dir>/deguboard-local/config.yaml` で上書きできるようにする。CLI・dg serve・VS Code 拡張は Core 経由で同じ値を読む（VS Code の settings.json は使わない）。

上書きできる項目：`default_project`・`git.remote`・`worktree.root`・`commit.mode`・`push.mode`・`models.light`・`models.standard`・`models.heavy`・`actions.shell`・`notify.approvals`。ほかはチーム専用（`metrics.read_transcripts` の個人の拒否は従来どおり `DEGUBOARD_NO_TRANSCRIPTS`）。

## 受け入れ条件

- [ ] 上書きできる項目を `dg config set --local` で `.git/deguboard-local/config.yaml` に書け、`config show`・`dg guide`・各コマンドが「個人 > チーム > 既定」の値を使う
- [ ] `--local` でチーム専用の項目を指すと `VALIDATION_FAILED` で拒否し、個人の書き込みは deguboard ブランチにコミットも push もしない
- [ ] `dg config unset <key> [--local]` で個人の上書きを外せ、チームの値を既定に戻せる
- [ ] 個人のファイルにチーム専用の項目や未知の項目があれば、無視して `dg validate` で警告する
- [ ] `config show --fields` が項目ごとの `scope` と、チームの値・個人の値を返す
- [ ] requirements.md の 5.10 と ADR-006 を、個人の上書きを設ける方針に書き換える
