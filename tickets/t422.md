## 概要

t419（PR #391）で、譲る相手の ID が探す範囲のほかのファイルで先に出ていれば譲らないようにした。しかし探す範囲（Claude Code では session・自分の worktree・主の worktree とその上位の projects ディレクトリ）の外、たとえば別の worktree の会話記録で始まった Run は見えないので、その Run の ID が 1 分以内に親のファイルに載ると、親の Run は応答を譲り、譲られた Run はそのファイルを数えないので量が落ちる。`dg run start` は、このマシンで開いたままのほかの Run の ID を警告に出すので、並行して作業すると起きうる。t419 の 2 回目の見直しで、再現スクリプト（sb.jsonl を別の worktree の projects ディレクトリに移したもの）で output が 11 から 1 に落ちることを確かめた（finish と refresh では揃う）。

## 受け入れ条件

- [ ] 探す範囲の外の会話記録で始まった Run の ID を 1 分以内に表示しただけでは、その Run に応答を譲らない（テストで確かめる）
- [ ] 同じファイルで始めた 2 本の Run は今までどおり片方だけに数える（t417・t419 のテストが通る）
- [ ] run refresh --dry-run で、t417・t419 で取り直した Run の値が変わらない
- [ ] mise run check が通る
