## 概要

`dg gate <ticket>` が、guide-review の品質ゲートのうち記録と Git・PR の事実で判定できるもの（受け入れ条件がすべて付いている、最後の push より後に見直しの Run があり通っている、PR が draft でなく `mergeable`、修正ループが上限内）をコードで判定し、結果と満たさない条件を返す。PreToolUse のフックが、`gh pr merge`・`gh pr ready` の前に `dg gate` を呼んで満たさなければ止め、`.git/deguboard/` の下への Edit・Write を拒む。「人の指示があるときだけ」の操作（abandoned・done の取り消し・Epic と Iteration の閉じる再開）は、今の方針どおり拒否しない。

## 受け入れ条件

- [x] `dg gate <ticket>` が条件ごとの判定と満たさない理由を返し、`--json` の形が CL-1 に合う。判定の条件は `dg gate --help` が正本
- [x] PreToolUse のフックが `gh pr merge`・`gh pr ready` を `dg gate` の結果で止め、止めた理由をエージェントに返す
- [x] PreToolUse のフックが `.git/deguboard/` の下への Edit・Write・Bash の書き込みを拒む
- [x] guide-review の「品質ゲート」の表が `dg gate` を正本として参照し、`mise run check` が通る
