## 概要

履歴の見出しに「Iteration / Epic / チケット」の切り替えを置き（チケットは後のチケットで足す）、検索欄は共通にする。見方はハッシュ（例：#/history?view=epic）に持たせる。
Iteration の見方は今の行に、含む Epic と件数を足し、行を開くと中の done・abandoned のチケットを出す。Epic の見方は closed の Epic を閉じた新しい順に、進捗とチケットが入っていた Iteration を出す。
改善案：https://claude.ai/artifact/Sy4j28W4Vkee96x6WtNagu


## 受け入れ条件

- [x] 履歴に Iteration と Epic の見方の切り替えがあり、選んだ見方がハッシュに残って読み直しても保たれる
- [x] Iteration の行に含む Epic ごとの件数が出て、Epic の番号から Epic の詳細を開ける
- [x] Iteration の行を開くと中の done・abandoned のチケットが出て、番号からチケット詳細を開ける
- [x] Epic の見方に closed の Epic が閉じた新しい順に出て、番号・タイトル・進捗・閉じた日と、チケットが入っていた Iteration へのリンクがある
- [x] 検索（チケットの番号・タイトル）がどちらの見方にも効く
