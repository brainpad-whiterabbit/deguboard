## 概要

ticket import の下書きで、本文の項目の行末にコメントがあると拒否する判定が、CLI の側（packages/cli/src/program.ts）にある。core にはテストがない。これは、操作を core のコマンドに置き入口は写すだけにする規約（ADR-007）に反する。判定を core に移し、テストも core に移す。

## 受け入れ条件

- [x] 行末コメントを拒否する判定が packages/core/src/commands/ にあり、CLI はそれを呼ぶだけになる
- [x] 判定のテストが core にあり、program.test.ts の同じ確認は、CLI からエラーと終了コードが出ることを見る 1 件に絞る
- [x] `mise run check` が通る
