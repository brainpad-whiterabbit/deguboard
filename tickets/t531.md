## 概要

見直し役の Run を閉じるときに、重い指摘の数・軽い指摘の数・通ったか（`passed`）を記録する（`run finish --heavy N --light M` のような項目）。今は見直しの結果が記録に残らず、修正ループの回数と品質ゲートを親の LLM が数えている。段階（stage）とゲートはこの記録を読む。

## 受け入れ条件

- [ ] Run のスキーマに見直しの結果（重い・軽い指摘の数、通ったか）があり、`run finish` が受け取って記録する。見直し以外の step では受け付けない
- [ ] `run list`・`run show` の出力と `metrics show` の集計に見直しの結果が出る
- [ ] requirements.md の RN-1 と ADR-005 に記録する項目が足され、`mise run check` が通る
