## 概要

review・done のチケットの多くで pr が空のまま。sync の照合は gh でブランチ名から PR を引いているのに番号を残していないため。照合で見つけた PR 番号を pr に記録し、guide work でも PR 作成後に ticket update --pr で記録する手順を示す。既存の review・done のチケットの pr は PR の本文の ID と head ブランチで埋め戻す

## 受け入れ条件

- [ ] sync の照合で、pr が未記録のチケットの PR を gh がブランチ名で見つけたら、状態が進まないときも pr に番号を記録する
- [ ] gh が使えないとき・PR が見つからないとき・pr が記録済みのときは pr を書き換えない
- [ ] dg guide work が、PR を作ったあとに ticket update --pr で番号を記録する手順を示す
- [ ] requirements.md の照合の節と ADR-004 に、照合が pr を補うことが書かれている
- [ ] 既存の review・done のチケットのうち PR のあるものすべてに pr が入っている
