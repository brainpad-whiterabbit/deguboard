## 概要

implement・review・fix の brief は「`dg guide work` の『実装する』に従う」のように節を名指しし、サブエージェントが guide を読みに行く。brief に節の本文を入れ、サブエージェントが `dg guide` を呼ばずに済むようにする。

## 受け入れ条件

- [x] implement・review・fix の brief に、指す節（work の「実装する」、review の「見直す」「指摘を直す」）の本文が入り、`dg guide` を読ませる文がない
- [x] CLI・HTTP・MCP の `dg next` と `dg brief` が同じ本文を返す
- [x] guide-work・guide-review・guide-parallel の「brief を渡す」の案内が、本文が brief に入ることと食い違わない
- [x] 1 回の implement・review の brief の字数が、前後でいくつ変わったかを PR の本文に書いた
- [x] EX-5 の約束を直した
- [x] `dg flow next` の `guide.text` に段階の節の本文が入る（t596 で null のまま残したもの）
