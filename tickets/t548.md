## 概要

t543（PR #486）は、別のセッションで開いたままの手直しの Run を、もう一度の claim が interrupted で閉じるようにした。ただし、もう一度の claim は手直しのサブエージェント自身が呼び、サブエージェントの Bash には DEGUBOARD_SESSION がない。そのため claim 側のセッションが分からず、開く fix の Run も session が null になる（2026-11-07 以降の fix の Run はすべて null）。今は ADR-015 と RN-5 に制限として書き、前の手直しの Run は区切りとして success で閉じている。サブエージェントのもう一度の claim でもセッションが分かるようにし、落ちたセッションの手直しを interrupted で記録する。

## 受け入れ条件

- [x] サブエージェントが開く手直しの Run に、起動したセッションの ID が入る（テストで確かめる）
- [x] 別のセッションで開いたままの前の手直しの Run を、サブエージェントのもう一度の claim が interrupted で閉じる。同じセッションの前の手直しは今の区切りの規則のまま（テストで確かめる）
- [x] ADR-015 の制限の記述・RN-5・ticket claim の help がコードに合う（判断を変えるなら ADR の書き方に従う）
- [x] mise run check が通る
