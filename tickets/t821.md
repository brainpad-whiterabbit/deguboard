## Summary

開いた Iteration の中は done と abandoned が番号の順に混ざり、何をやめたかは一覧を全部なめないと分からない。持ち越しはすでに最後に「持ち越し N 件」として分けているので、中止も同じ形でまとめる。

## Acceptance criteria

- [ ] 開いた Iteration の中が「完了 → 中止 → 持ち越し」の順に並ぶ
- [ ] 中止は「中止 N 件」の小見出しの下にまとまり、0 件なら小見出しを出さない
- [ ] 検索中に当たったチケットだけを出すときの並びが決まっている
- [ ] 並びと小見出しをテストが確かめる
