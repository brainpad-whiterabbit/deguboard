## 概要

`ticket unclaim` は `branch` を外すが `pr` を消さない。unclaim して新しく claim し直した後も前の PR 番号が残るので、t445 で入れた「自分が claim 済みで `pr` のあるチケットのもう一度の claim は手直しの Run を開く」の判定と警告（「PR #n があるので」）に前の作業の PR が出る。別の PR を作り直す使い方では `ticket update --pr` で直さないと判定がずれる。unclaim で `pr` も外すか、`branch_at` より前の PR を判定に使わないかを決めて直す。p63 の t445 の見直しで出た範囲の外の指摘。

## 受け入れ条件

- [x] unclaim → 新しい claim の後の claim で、前の作業の PR を理由に手直しの Run を開かない
- [x] もう一度の claim の判定は、今の周期で記録された PR だけを見る（照合の判定は t498 で揃える。この PR では変えない）
- [x] `ticket unclaim --help` と requirements の RN-5・ST-6 を決めた振る舞いに合わせる
- [x] bare リモート付きのテストで確かめる
- [x] mise run check が通る
