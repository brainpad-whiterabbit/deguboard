## 概要

README（と、そこから作る拡張の README）に載せる使い方の GIF（packages/vscode/images/ の open-board・ask-agent・import・run-all・retro の 5 本）は、日本語の画面で、760x460 の等倍で撮っているため文字がにじんで読みにくい。英語の画面に変え、README の表示幅でも読める解像度で作り直す。実画面の録画でなく、実際の UI に近い画面を生成した GIF でよい。README.ja.md も同じ英語の GIF を使う。

## 受け入れ条件

- [ ] 5 本の GIF に映る文言（左パネル・チケット詳細・外枠のターミナルの入出力・レポート）がすべて英語で、日本語が映っていない
- [ ] GIF の幅が 1120px 以上（README の表示幅 560px の 2 倍以上）で、文字の輪郭がにじまない
- [ ] 画面は実際の deguboard の UI（左パネル・チケット詳細）と同じ配置・色・部品になっている
- [ ] mise run gifs で 5 本を作り直せて、秒数と大きさの上限に収まる（上限を変えたら、スクリプトのコメントと docs/development.md も直す）
- [ ] README.md・README.ja.md・拡張の README に新しい GIF が出る
