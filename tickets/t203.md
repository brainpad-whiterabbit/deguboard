## 概要

見直し（設定ファイル）。docs/development.md:78 は「依存を足すときは `pnpm install` で lockfile を更新」と pnpm を直接案内しているが、CLAUDE.md と ADR-008 は mise を唯一の入口にすると定めていて、依存を足す mise タスクもない。規約に書かれていない例外になっている

## 受け入れ条件

- [ ] 依存を足す手順を、ADR-008 に例外として書くか、`mise exec -- pnpm ...` か mise タスクを通す案内にするかを決め、development.md と ADR-008 をそろえる
- [ ] `mise run check` が通る
