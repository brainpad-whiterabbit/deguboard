## 概要

t496・t497 でブラウザを利用者向けの入口から外し、`dg serve` は開発用にした（ADR-027）。npm の CLI の description と server パッケージの README に、`dg serve` を利用者の画面や使い始めの手順のように読める書き方が残っているので直す。

## 受け入れ条件

- [x] packages/cli/package.json の description が「画面（dg serve）と…を同梱する」と書かず、`dg serve` を利用者の画面のように読ませない（同梱を書くなら開発用と分かる書き方にする）
- [x] packages/server/README.md が「deguboard を使うには…`dg serve` を呼ぶ」と書かず、使い始めの入口を VS Code 拡張と CLI にし、`dg serve` は開発用と書く
- [x] `mise run check` が通る
