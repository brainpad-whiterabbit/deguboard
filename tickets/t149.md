## 概要

左パネルのカンバンの実行計画の帯（UI-13）は、畳むと進みしかわからない。畳んだ行で、計画ごとに作業中のチケットと次に着手できるチケットを読めるようにする（案のページの E）。開いたときの依存グラフは今のまま。

## 受け入れ条件

- [x] 畳んだ行に、計画ごとに in_progress のチケットの番号と、着手できる先頭のチケット（番号とタイトルの頭）が出る
- [x] 承認待ちの計画は、次のチケットの代わりに承認を待っていることが出る
- [x] 「実行計画」を押すと、今と同じ依存グラフが開く
- [x] 帯の見出しがカンバンの節の見出しと同じ見た目になる
- [x] requirements.md の UI-13 を直す
