## 概要

t636 で packages と scripts のコメントの ADR 番号を、先頭のコメントの 1 つまでに寄せた。範囲の外だったルートの test/ に、先頭のコメントの外の ADR 番号が残る（test/layout/sidebar.layout.ts の ADR-027 が 2 か所、test/vscode/host.ts の ADR-008）。ADR-001 の規則（コードから指すのは要件 ID と「なぜ」、ADR 番号は先頭のコメントの 1 つまで）はコード全体に当たる。

## 受け入れ条件

- [x] ルートの test/ のどのファイルも、ADR 番号を指すのは先頭のコメントの 1 か所までになっている（check-docs のテストのフィクスチャは除き、理由をコメントに書く）
- [x] 外した参照には、対応する要件 ID か「なぜ」のコメントが残っている
- [x] mise run check が通る
