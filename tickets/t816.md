## Summary

チケットの見方は history の結果（このリポジトリで約 1.2 秒）が届くまで updated_at の順で並べ、日付に ~ を付けて出す。データを一括で直したあとは updated_at がそろって新しくなるので、805 件がどれも「~今日」と出て、すべて今日終えたように見える。届くと順も日付も入れ替わって一覧が跳ねる。届くまでは日付を出さず、番号の新しい順で出す。

## Acceptance criteria

- [x] history の結果が届くまで、行の終えた日の欄が日付ではなく読み込み中の印（スケルトンなど）になる
- [x] 届くまでの並びが番号の新しい順になる
- [x] ~ は、届いたあとに履歴から終えた時刻が分からない行にだけ付く
- [x] 読み込み中と届いたあとの出し方をテストが確かめる
