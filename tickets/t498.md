## 概要

t480 から分けた。照合（facts.ts）は branch_at より前にマージされた PR を外すが、もう一度の claim の判定（ticket.ts の isReclaim）は PR の有無だけを見る。ブランチ名の使い回しで別の作業の PR を拾う誤判定を両方で防ぐ基準を決めて揃える。

## 受け入れ条件

- [ ] 照合が前の作業の PR を拾わない基準と、もう一度の claim の判定の基準が同じになる
- [ ] ブランチ名を使い回した場合の照合と claim のテストで確かめる
- [ ] mise run check が通る
