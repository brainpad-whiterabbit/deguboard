## 概要

PR の要らない作業（チケットのデータの整備）。このリポジトリの Workflow（software-development）は `transitions: []` で、todo → in_progress に `requires: [deps_done]` がない。そのため、`depends_on` の依存先が終わっていなくても claim できる。今は手引き（`--ready` や `plan show` の `waiting` が空になるまで待つ）だけで順が守られている。`dg workflow set` で、このリポジトリの Workflow にこの制約を足す。同梱のテンプレートの既定（制約なし。WF-1・ADR-003）は変えない。照合（reconcile）による todo → in_progress や `claim --without-branch` が、この制約でどう扱われるかを先に確かめ、困る形なら足さずに報告する。

## 受け入れ条件

- [ ] このリポジトリの Workflow の todo → in_progress に `requires: [deps_done]` があり、`dg workflow validate` が通る
- [ ] 依存先が終わっていないチケットの claim が `TRANSITION_REJECTED` で拒まれ、依存先が done か abandoned なら claim できることを、一時的なチケットか既存のチケットで確かめた（確かめに使ったものは元に戻す）
- [ ] 照合の todo → in_progress（`branch_exists`）と `claim --without-branch` が、この制約でどうなるかを確かめて報告した
- [ ] labels・reconcile・fields・steps は変わっていない（`workflow show` の前と後を比べた）
