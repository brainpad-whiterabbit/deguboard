## 概要

チームのタブの保存は `setView((v) => ({...v, team: res.data}))` で画面を直し、自分のタブと違って読み直しの連番（`showSeq`）を進めない。保存の前に始まった読み込み（開いたときの `load` や `store.reload()`）の古い応答が後から返ると、チームの値が保存前に戻って見える。t466 で自分のタブに入れた連番の仕組みをチームのタブにも効かせる。p63 の t466 の見直しで出た範囲の外の指摘。

## 受け入れ条件

- [ ] チームのタブで保存した後に、保存の前に始まった読み込みの応答が返っても、画面は保存した値のまま
- [ ] 保存の後に始まった読み込みの応答は、今までどおり画面に反映される
- [ ] 上をテストで確かめる
- [ ] mise run check が通る
