## 概要

受け入れ条件のチェックボックスは並ぶが、残りがいくつかは数えないとわからない。本文の節ごとにタスクリストを数え、その節の見出しに「済 / 全」と細いメーターを出す。見出しの名前（受け入れ条件）には頼らない。改善案 D4（https://claude.ai/artifact/RQHwi7v1k3rJx2Rvcin2Uo）

## 受け入れ条件

- [x] タスクリストのある節の見出しに「済 / 全」（例 4 / 5）とメーターが出る
- [x] 見出しの名前に関係なく、タスクリストのある節で数える。タスクリストのない節には出さない
- [x] 数え方を markdown のテストで確かめる
