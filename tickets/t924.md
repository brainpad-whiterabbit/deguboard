## Summary

拡張機能は起動のたびに `dg --version` を cwd を渡さずに動かすので、拡張機能のプロセスの cwd（`/` や `~`）で動く。mise などの shim は cwd の設定（mise.toml・.node-version）で node の版を選ぶ。そのため、ワークスペースでは node 24 で動くのに「needs Node.js 24」の警告が reload のたびに出る。逆に、ワークスペースの設定だけ古い node を指しているときは、ワークスペースで失敗するのに警告が出ない。確かめる場所を、ターミナル・エージェント・フックが dg を使う場所（ワークスペース）と揃える。

## Acceptance criteria

- [ ] `dg --version` を、ワークスペースのフォルダを cwd にして動かす
- [ ] ワークスペースがないときと、フォルダが複数あるときの扱いが決まっていて、コードのコメントに理由がある
- [ ] cwd にワークスペースのフォルダが渡ることを、`dg.test.ts` のテストで示す
