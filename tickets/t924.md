## Summary

拡張機能は起動のたびに `dg --version` を cwd を渡さずに動かすので、拡張機能のプロセスの cwd（`/` や `~`）で動く。mise などの shim は cwd の設定（mise.toml・.node-version）で node の版を選ぶ。そのため、ワークスペースでは node 24 で動くのに「needs Node.js 24」の警告が reload のたびに出る。逆に、ワークスペースの設定だけ古い node を指しているときは、ワークスペースで失敗するのに警告が出ない。確かめる場所を、ターミナル・エージェント・フックが dg を使う場所（ワークスペース）と揃える。確かめはウィンドウで 1 回のまま、最初に使ったフォルダで行う（フォルダごとには確かめない）。

## Acceptance criteria

- [x] サイドバーかパネルを最初に使ったとき、そのフォルダを cwd にして `dg --version` を動かす（サイドバーは最初のフォルダ、パネルは開くフォルダ）。理由をコードのコメントに書く
- [x] フォルダがないときは cwd を渡さず、今と同じくウィンドウで 1 回だけ確かめる
- [x] フォルダが複数あるときだけ、失敗の警告に確かめたフォルダの名前が入る
- [x] cwd が渡ることと、警告にフォルダの名前が入る条件を、`dg.test.ts` のテストで示す
