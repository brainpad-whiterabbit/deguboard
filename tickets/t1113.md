## Summary

見直し（設定ファイル）：vitest.layout.config.ts と vitest.vscode.config.ts は、vitest.config.ts が持つ TZ の固定・エージェントの環境変数の除去・ワーカー数の上限（resolveMaxWorkers）を持たない。どちらも check に入らない別の実行で、test/vscode/host.ts が自分で環境を作るので害はないが、違う理由がどこにも書かれていない。また test/lint/vitest-max-workers.test.ts の冒頭のコメントが、既定のワーカー数（全体のテストで CPU 数の半分、test:related で 4 分の 1）を言い直していて、t1097 で正本にした vitest.workers.ts の冒頭のコメントの外に写しが残る。

## Acceptance criteria

- [ ] vitest.layout.config.ts と vitest.vscode.config.ts に、vitest.config.ts の TZ・環境変数の除去・ワーカー数を持たない理由が書かれているか、持つようになっている
- [ ] test/lint/vitest-max-workers.test.ts のコメントが既定のワーカー数を言い直さず、vitest.workers.ts の冒頭のコメントを指している
