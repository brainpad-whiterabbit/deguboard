## Summary

t673 で決めた形の前半。Iteration に started_at（日時）を足し、active になるとき（iteration start と、claim で自動で active になるときの両方）に書く。reopen では started_at を変えず、closed_at と件数だけを消す。

画面の期間（Iteration 詳細・ボード・バックログ・History）は started_at 〜 closed_at の日時だけで出し、「残り n 日」「n 日超過」は出さない。active は開始の日時だけ、planned は期間を出さない。started_at のないもの（今ある s1〜s24）は開始を「不明」と出す。予定の start・end を外すのは後続のチケット。

## Acceptance criteria

- [ ] iteration start と claim による自動の active で started_at が書かれ、reopen では変わらないことをテストで示す
- [ ] Iteration 詳細・ボード・バックログ・History の期間が started_at 〜 closed_at の日時で出て、残り・超過の日数が出ない
- [ ] started_at のない Iteration は開始を「不明」と出す
- [ ] requirements.md の IT-1・UI-5 を、実績の期間（started_at・closed_at）を記録して出す約束に直す
