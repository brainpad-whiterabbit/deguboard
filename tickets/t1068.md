## Summary

dg flow next に Iteration（s3 など）を指定すると、割り当ての段（assign）がどの Iteration にも入っていない todo をボード全体から集めて、その Iteration に入れるか聞く（packages/core/src/commands/flow-records.ts の flowCandidates）。dgall は Iteration の中のチケットを最後まで進める流れであり、ほかの todo を Iteration に入れる判断は dgassign で人が頼んだときにすればよいので、この候補集めをやめる。チケットか Plan を指定したときに、Iteration にないチケットを入れる Iteration を決める割り当ては、流れの関所の記録の置き場所を決めるために残す。

## Acceptance criteria

- [x] Iteration を指定した dg flow next は、Iteration にない todo を割り当ての候補にせず、割り当ての段を返さない（テストで確かめる）
- [x] チケットか Plan を指定した dg flow next は、今までどおり Iteration にない対象のチケットを候補にして割り当ての段を返す
- [x] --no-assign はチケットか Plan を指定したときにだけ意味を持つことが、dg flow next --help・guide-all.md（「Deciding the target」の節）・dgall の Skill の説明に書かれている
- [x] 要件 EX-8・ADR-030・docs/usage.md と usage.ja.md の割り当ての説明が今の振る舞いに合っている（mise run check:docs が通る）
