## Summary

今は `--auto` を付けないと、`dg next` の `wait_merge` で人にマージを頼んで待つだけで、マージしてよいかは聞かない。品質ゲートを通った PR は、マージしてよいかを選択肢で聞き、承認されたら agent が `dg pr merge` を打つようにする。

## Acceptance criteria

- [ ] `--auto` なしの `dg next` の `wait_merge` は、マージしてよいかを聞く問い（`ask_human`）と、承認後に打つ `dg pr merge <id>` を返す。`auto.merge` が false でも同じ
- [ ] guide（work・all・done）は、承認されたときだけマージし、断られたときはマージせずに待つと書いている
- [ ] `--auto` で `auto.merge` が true のとき、品質ゲートを通った PR を聞かずにマージする振る舞いは変わらない
- [ ] requirements.md の EX-7 を直し、`next` が返す形をテストで固める
