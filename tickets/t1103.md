## Summary

Epic e40 の方針を、持ち主のない見直しの保留（orphan review）に当てはめる。`orphanReviewRuns`（`packages/core/src/commands/orphan-review.ts`）は、開いている review の Run と、サブエージェントが動いているか（`isLiveSubagent`、I/O）を読み、待ちの印（waiting_since・settling_since）で外し、保留の結果と `branchCommitTimes` を読んでから数える。数える部分の `orphanReviewsOf` と `adoptableReviewRecord` はすでに純粋な関数。

サブエージェントが動いているかを事実の値として先に集め、数える判定を読まない関数にする。orphan-review.test.ts（21.3 秒・28 件）には、next と gate の数え方を確かめる件や警告の件など、判定の組み合わせを確かめている件がある。orphan-review.test.ts は雛形に寄せるチケット（t1100）でも直すので、その後に進める。

## Acceptance criteria

- [ ] 持ち主のない見直しの保留を数える判定が、git・ファイルを読まない関数にあり、サブエージェントが動いているかは事実の値として受け取る
- [ ] dg next・dg gate・dg sync・dg pr ready が数える結果と書く記録が変わらない
- [ ] 判定の組み合わせ（待ちの印、書き終わりの待ち、動いているサブエージェント、push の区切り）をその関数のテストで確かめ、orphan-review.test.ts から判定だけを確かめていた件を移す。移した件と残した件の対応を PR に載せる
- [ ] orphan-review.test.ts の時間の変更前後を PR に載せる
