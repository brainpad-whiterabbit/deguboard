## Summary

pr merge は品質ゲートを通した後に gh pr merge を呼ぶが、検査したコミットを渡していない（--match-head-commit がない）。ゲートの検査の間や後に別の worktree や人が push したコミットが、検査されないままマージされる。段が low だとゲートは作業ブランチを fetch しないので、古い SHA で検査が回り、窓が広い。

## Acceptance criteria

- [ ] 品質ゲートは判定したコミットの SHA を結果に含める
- [ ] pr merge は、ゲートが判定した SHA を --match-head-commit で gh に渡す
- [ ] PR の今の head が判定した SHA と違うとき、ゲートを落としてマージしない
- [ ] ゲートの判定の後に別のコミットを push したとき、マージされないことをテストで示す
