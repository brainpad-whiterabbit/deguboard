## 概要

頼む小窓の Skill の札と候補のボタンのツールチップ（`title`）は Skill 名だけで、`dgdone` が何かは分からない。各 Skill の説明の 1 文を core が `ask` の候補に `skill_summary` として添え、小窓は Skill の札と候補のボタンの `title` に出す。言語は `language` に従う。札の下の説明行（meaning）が「今回この対象に何をするか」、ツールチップが「Skill そのものの説明」と役を分ける。

## 受け入れ条件

- [x] `candidates` の各項目に `skill_summary` が入る（Skill を使わない候補は null）
- [x] 9 本の Skill すべてで `skill_summary` が空でなく、`language` が en のときは英語になる
- [x] 小窓の Skill の札と候補のボタンのツールチップにその文が出る
- [x] Skill の説明の文は 1 か所に置き、SKILL.md の冒頭と小窓が同じ正本から出る
