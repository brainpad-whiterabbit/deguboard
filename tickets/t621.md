## 概要

t608 で actions.test に mise run check を設定し、dg gate・dg pr ready・dg pr merge が作業ブランチの worktree で検査を回すようになった。claim は worktree を作るだけで、mise trust・依存のインストール・ビルドはしないので、実装役が mise run setup を回さなかった worktree では検査と mise run dg（dist を読む）が落ちる（s23 の見直し役が worktree で mise run dg が ERR_MODULE_NOT_FOUND になったと報告）。claim が worktree を作った後に、config で決めた準備のコマンドを回せるようにする。

## 受け入れ条件

- [ ] config に worktree の準備のコマンド（引数配列）を書け、claim が worktree を作った後にそれを worktree で回す。空なら何も回さない
- [ ] 準備が失敗しても claim は成功し、warnings に失敗と手で回すコマンドが出る
- [ ] このリポジトリの config で準備のコマンドが mise run setup を回す値になっている
- [ ] 一時ディレクトリの bare リモート付きリポジトリで、claim が準備のコマンドを worktree で回すことと、失敗したときの警告をテストで確かめている
