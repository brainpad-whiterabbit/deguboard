## Summary

t673 で決めた形の後半。Iteration は予定の期間を持たず、started_at・closed_at だけを記録する。model から start・end を外し、iteration create・update の --start・--end と、start・close での日付の書き換えをなくす。今あるデータ（s1〜s24 など）の start・end は消す。

claim で入れる先は、active がなく planned が複数あるとき自動で決めず、warnings で人に頼む（planned が 1 つならそこに入れる）。overdue の next、carry（持ち越しを相談する）の頼むことと画面の文、edit の頼むことの文の「期間」をなくす。

## Acceptance criteria

- [ ] Iteration の model・create・update・start・close から start・end がなくなり、ヘルプにも出ない
- [ ] 今あるデータの Iteration のファイルから start・end が消える
- [ ] active がなく planned が複数あるとき、claim はどれにも入れず、人に頼む warnings を出すことをテストで示す
- [ ] overdue の next と carry の頼むこと・画面の文がなくなり、edit の頼むことの文から期間が消える
- [ ] ADR-009 に「期間は実績だけを記録する」の決定と理由、採らなかった案「予定の開始日・終了日を持ち、超過を案内する」を書き、requirements.md の IT-1 から予定の期間を消す
