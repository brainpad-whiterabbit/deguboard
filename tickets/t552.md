## 概要

t536（PR #487）の要件 ID の検査は、requirements.md に定義が 1 つでもある接頭辞だけを対象にする。節ごと消して接頭辞の定義がなくなると、残った参照を指摘しない。誤検出を出さずに、その参照も拾う。

## 受け入れ条件

- [x] requirements.md に定義が 1 つもない接頭辞の要件 ID をコードかテストが参照しているとき、mise run check:docs が指摘する（テストで確かめる）
- [x] ADR-001・UTF-8・SHA-256 など、要件 ID でないものは指摘しない（テストで確かめる）
- [x] mise run check が通る
