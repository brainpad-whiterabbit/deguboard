## 概要

観点=テスト。対象=commands.test.ts の Run の開閉のテスト、ticket.ts の ticketMove・ticketUnclaim・reclaim・ticketUpdate。抜け：t481 の「閉じた Run はチケットの変更と同じ書き込みに入る」を unclaim・move（review・done・abandoned）で確かめていない（update --pr と sync は確かめている）。reclaim に --no-run を付けたとき Run を開かず前の fix の Run も閉じないこと、retry_reasons と no_run を併せたときと人の claim に渡したときの UsageError、空の配列、claim 側の retryReasons のスキーマを確かめていない。拒否される update に pr を併せたとき Run だけ閉じないこと（コードのコメントの約束）を確かめていない。

## 受け入れ条件

- [ ] unclaim と move で閉じた Run が、チケットの変更と同じコミットに入り、メッセージに Run の記録が入ることをテストで確かめる
- [ ] reclaim の --no-run・retry_reasons の拒否の組み合わせ・空の配列・スキーマをテストで確かめる
- [ ] 拒否される ticket update --pr で、実行中の Run が残り runs/ に集計ができないことをテストで確かめる
- [ ] mise run check が通る
