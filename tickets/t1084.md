## Summary

VS Code の左パネルのタイトル行にあるセットアップのアイコン（$(checklist)）は、項目が欠けていても見た目が変わらない。推奨の帯を「出さない」で閉じると、欠けていることを知る手がかりがなくなる。タイトル行のボタンは Webview の外なので光らせられないため、context key（deguboard.setupAttention）で点付きの自作 SVG アイコン（light / dark）のコマンドに差し替える。帯を閉じた後も点は残す（人が決めた案 A + i。UI 案: https://claude.ai/artifact/SyAeWd5XUquFkGBseL39Fe）。Activity Bar のバッジは未 push・未取り込みに使っているので使わない。

## Acceptance criteria

- [ ] 必須か推奨の項目が 1 つでも欠けている間、タイトル行のセットアップのアイコンが右上に警告色の点の付いたアイコンに替わり、すべて満たすと元のアイコンに戻る
- [ ] 推奨の帯を「出さない」で閉じた後も、推奨が欠けている間は点が残る
- [ ] 点付きのアイコンのツールチップに、欠けている件数が出る（表示言語で訳す）
- [ ] 点付きのアイコンを押すと、元のアイコンと同じくチェックリストを開閉する。差し替え用のコマンドはコマンドパレットに出ない
- [ ] 点付きのアイコンは light と dark のテーマのどちらでも見分けられる
- [ ] 要件 UI-12 の 1 文を、アイコンでも知らせる約束に合わせて直す
- [ ] 画面の見た目を変えるので、PR の本文に変えたタイトル行のスクリーンショットを載せる
