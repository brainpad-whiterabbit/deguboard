## Summary

見直し（s35）と t942 の見直しの指摘。t942 は Workflow の雛形の名前と step・項目のラベルを、雛形と同じ文なら画面で訳すようにしたが、Status の表示名（core の既定 `DEFAULT_LABELS` と、雛形の `labels`、例：review の "Review"）は訳していない。日本語の表示で、Review の step は「見直し」と出るのに、Review の Status は "Review" のまま出る。雛形の分だけ訳すと、カンバンの列で 1 つだけ日本語になる。既定の値の決まり（ADR-001 の「言語」）に合わせ、Status の表示名も、core の既定か雛形の labels と同じ文のときだけ画面で表示言語に訳し、書き換えた表示名は書いたまま出す。訳すのは画面だけで、dg の出力と保存する値は変えない。

## Acceptance criteria

- [x] 既定のまま（core の既定か雛形の labels と同じ文）の Status の表示名が、画面（カンバンの節の見出し・バックログの絞り込み・チケット詳細・経過）で表示言語の訳で出る
- [x] Status の表示名の訳が、step のラベルの訳（Review の step の「見直し」）と食い違わない
- [x] 既定のままの表示名は訳され、Workflow で書き換えた表示名は書いたまま出ることをテストが確かめる
