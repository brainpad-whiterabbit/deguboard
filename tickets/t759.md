## Summary

CLI はマージドライバのコマンドを渡すが、拡張は渡さない。拡張だけで使うと、属性ファイル（merge=deguboard）は置かれるが git config にドライバが登録されず、git は行単位のマージに落ちる。近い行がぶつかって同期が止まり、フィールド単位でマージする約束（SY-4）が効かない。CLI が登録したパスも、node を上げると壊れうる。

## Acceptance criteria

- [ ] 拡張の同期と始め方は、拡張に同梱した dg を呼ぶマージドライバを git config に登録する
- [ ] 登録がない、または登録されたコマンドが見つからないとき、status か sync が警告する
- [ ] 拡張だけで使ったリポジトリで、同じチケットの近いフィールドを両側で変えても同期が止まらないことをテストで示す
