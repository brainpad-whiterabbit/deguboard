## 概要

core の commands を HTTP のエンドポイントに写す薄い層。既定で 127.0.0.1 にバインドし認証は持たない（UI-8）。web ができるまでは API だけ。フレームワークは依存の少ないものを選び ADR-008 に書く

## 受け入れ条件

- [x] `GET /api/commands` が store を要するコマンドの一覧と入力の JSON Schema を返し、`POST /api/commands/<name>` が CLI の --json と同じ形で結果を返す
- [x] `dg serve` は既定で 127.0.0.1:7474 にバインドし、認証を持たない（UI-8）
- [x] 選んだフレームワークと理由が ADR-008 に書かれている
