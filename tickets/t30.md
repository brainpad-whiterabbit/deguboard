## 概要

CLI やエージェントが dg で書いた変更が画面に出ない。15 秒ごとに取りに行くのは同期の状態（status）だけで、チケットは書き込みのあとにしか読み直さない。拡張ホストで .git/deguboard/（データ worktree。core の GitRepo.dataDir）を vscode.workspace.createFileSystemWatcher で見張り、200ms まとめてから Webview に reload の event を送る。KanbanForge の planning.ts と同じ形。ブラウザ（dg serve）は対象外。

## 受け入れ条件

- [ ] dg ticket create や dg ticket move をターミナルで実行すると、数秒以内にサイドバーとパネルの表示が変わる
- [ ] 1 回の書き込みで複数のファイルが変わっても reload は 1 回にまとまる（デバウンス）
- [ ] 監視は拡張の deactivate で止まる
- [ ] reload の event は t29 で足すものを使う（依存）
