## Summary

設定画面の見出しの横にある「前の画面に戻る」（Back to the previous view）は、歯車と同じ toggleRoute を呼ぶだけです。VS Code ではタイトル行の歯車で戻れ、どの環境でも上のタブで画面を移れるので、このリンクを消します。

## Acceptance criteria

- [x] 設定画面に「前の画面に戻る」のボタンがなく、訳（l10n-en.ts）と専用の CSS（config-back）も残っていない
- [x] config.tsx の冒頭のコメントに、このリンクの記述が残っていない
- [x] 歯車で設定画面を開いて閉じると来る前の画面（なければカンバン）に戻ることを、テストで確かめている
- [x] PR の本文に、変えた設定画面のスクリーンショットがある
