## 概要

`/dgall` の `--auto` で、戻せる判断（割り当て・点検の本文の修正・Plan の承認・見直しの表の承認）の勧める選択肢を自動で選ぶ。マージと公開は config で明示して有効にしたときだけ、マージの前の条件（検査が通る・受け入れ条件がすべてチェック済み・別のサブエージェントの見直しで重い指摘がない・base と衝突しない）を満たした PR に限って自動にする。削除・abandoned・閉じる操作・Plan の待ちの変更は自動にしない。KanbanForge の kfall --auto と auto.full にならう（EX-3）。


## 受け入れ条件

- [ ] dg guide all に --auto の節があり、自動で選ぶもの・承認を残すものが分かれている
- [ ] 自動マージは config で明示して有効にしたときだけで、マージの前の条件を確かめる手順がある
- [ ] 自動で選んだ判断と自動でマージした PR を、流れの終わりの報告にまとめる
- [ ] requirements.md の EX-3 と関係する ADR を直している
