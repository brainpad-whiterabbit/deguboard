## Summary

エージェントに頼む小窓（ask-composer）は、今は × ボタンと Esc でしか閉じない。小窓の外をクリックしたら閉じるようにする。行・見出しの吹き出しや頼むことのメニューから別の対象で開き直すクリックは、閉じずにその対象で開く。

外のクリックが一覧の行やボタンに当たったときは、閉じたうえでその操作も効かせる。Webview の外（ターミナル・エディタ）に移っても閉じない。小窓の中で押し始めた選択を外で離しても閉じない（押し始めた場所で決める。端のケースなのでテストとコメントで示す）。

## Acceptance criteria

- [x] 小窓の外（一覧・見出し・タブ・選択の帯）をクリックすると小窓が閉じ、そのクリックの操作（行の詳細を開くなど）もそのまま効く
- [x] 小窓の中（候補・札・指示の欄・ボタン・送り先の選択）のクリックでは閉じない
- [x] 吹き出しや頼むことのメニューから開き直すと、閉じたままにならず新しい対象で開く
- [x] 外のクリックで閉じても、指示の下書きは残る
- [x] Webview の外（ターミナル・エディタ）に移っても小窓は閉じない
- [x] 上のことをテスト（ask-composer.test.tsx か app.test.tsx）で示す
