## Summary

t1153 の判定は、先端が見直した SHA に base を取り込んだマージコミットのあいだ、`dg ticket show`・`dg next`・`dg gate` を呼ぶたびに一時の worktree を checkout して自動マージの tree を作る。t1155 が入ると、ready からマージまでの間はこの形が普通になる。git 2.38 以上では `git merge-tree --write-tree` で作業ツリーなしに tree を作り、2.30〜2.37 だけ今の一時の worktree を使う。結果は覚えない（ローカルの状態を増やさない）。

## Acceptance criteria

- [ ] git 2.38 以上では、自動マージの tree を一時の worktree を作らずに作る（git を通すテストで確かめる）
- [ ] 2.38 より前の git では今の一時の worktree の経路を使い、どちらの経路でも競合したときは数えない
- [ ] git の版でどちらの経路を使うかを、純粋な関数のテストで確かめる
