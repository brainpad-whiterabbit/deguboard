## 概要

チケット詳細の経過（history --ticket）は、deguboard ブランチの全履歴（このリポジトリで 2,882 コミット・差分 2.8MB）を git log -p で読んで組み立ててから 1 枚に絞るので、常駐時でも約 0.75〜0.95 秒かかり、詳細画面の表示を遅くしている。履歴が伸びるほど遅くなる。チケットを指定されたときは、そのチケットのファイルの履歴だけを読む。

## 受け入れ条件

- [x] history --ticket のときの git log は、そのチケットのファイルに絞って走る
- [x] 絞る前と同じ経過（起票・Status の遷移・Iteration と Epic の出入り・担当者・PR 番号、消えたチケットを含む）を返すことをテストで示す
- [ ] history --epic・--iteration の結果は変わらない
- [ ] このリポジトリで、常駐したクライアントの history --ticket が 200ms 以下で返る
