## Summary

dg serve は、壊れた percent-encoding（例 /%E0%A4%A）を decodeURIComponent が投げる URIError として 500 にする。要求の先頭が //a:b のときは、try の外の new URL が投げ、async の handler の reject が拾われずにプロセスが落ちる。1 回の要求でローカルのサーバが止まる。

## Acceptance criteria

- [x] 壊れた percent-encoding の要求に、API と静的ファイルの両方で 400 を返す
- [x] URL として読めない要求先（//a:b など）に 400 を返し、プロセスが落ちない
- [x] 上の 2 つをテストで示す
