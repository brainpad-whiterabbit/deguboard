## Summary

見直し（s38）の観点「構成」。t1003 で書き換えた ADR-033 の「core/commands が 3 つの入口の正本」は、skill と hooks は判定と書き込みを core/commands の関数に置き、cli は引数と結果を写すと書く。一方 packages/cli/src/skill.ts の installSkill は、置き場所の選択、追跡済みのファイルからの dg の Skill の選び出し、書く・廃止した Skill を消す・.gitignore に足す順番、警告の文の組み立て（skillInstallWarnings）を cli の中で行っている。hooks は t1003 で core の hook-settings.ts に移したが、skill は移っていない。

## Acceptance criteria

- [ ] dg skill install の判定と書き込みと警告の組み立てが packages/core/src/commands/ の関数にあり、cli は引数と結果を写すだけになる
- [ ] dg skill install の振る舞い（書くファイル・消すファイル・.gitignore・警告の文）が変わっていないことをテストが確かめる
- [ ] ADR-033 の例外の項の記述と、置き場所が合っている
