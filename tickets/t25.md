## 概要

KanbanForge と同じく、Activity Bar のアイコンを押すとサイドバーに画面（web）が開くようにする。サイドバーでチケットを押すと詳細はエディタ領域のパネル（フォルダごとに 1 枚、使い回し）に開く。タイトル行に同期ボタン（$(sync)）と未 push・未取り込みのバッジを置く。既存の「画面を開く」はエディタ領域に開く経路として残す（将来の拡大ボタンの受け皿）。core の client.ts に Webview→ホストの action（openTicket）とホスト→Webview の event（sync・navigate）の形を足し、web は host.tsx（HostContext・useHost・HostBridge）で受ける。surface（sidebar / panel / browser）と初期ルートは <html> の data 属性で渡す。フォルダごとの CommandClient はサイドバーとパネルで共有する。要件（UI-12）・ADR-006・development.md・README を同じ PR で直す

## 受け入れ条件

- [ ] Activity Bar に deguboard のアイコンが出て、押すとサイドバーに画面が開く
- [ ] サイドバーでチケットを押すと、エディタ領域にチケット詳細のパネルが開く。別のチケットを押すと同じパネルの中身が変わる
- [ ] タイトル行の同期ボタンで dg sync と同じ同期が走り、未 push・未取り込みがあるとバッジに件数が出て同期後に消える
- [ ] サイドバーを隠して戻しても選んだ画面が残り、右クリックで非表示→再表示しても開く
- [ ] 同じフォルダの CommandClient はサイドバーとパネルで 1 つを共有する
- [ ] ブラウザ（dg serve）と「画面を開く」のパネルでは、チケットのリンクが今までどおりハッシュ遷移で開く
- [ ] webview.ts（属性付与とエスケープ・action・badgeOf）と client/webview.ts（event の配送・postAction）にテストがある
