## 概要

VS Code 拡張のビューのタイトル行には再読み込みと同期の 2 つのボタンがあるが、同期は実行後に必ず読み直す（リモートがなくても、失敗しても）ので再読み込みの上位互換になっている。t30 のファイル監視で CLI やエージェントの書き込みは自動で映り、ブラウザとパネルの UI はすでに同期ボタンだけ（UI-6）なので、サイドバーも同期ボタンだけにして揃える。Webview 間の reload イベント自体は監視と同期が使うので残す。

## 受け入れ条件

- [ ] package.json から deguboard.reload のコマンドと view/title・commandPalette のメニューを消し、ビューのタイトル行は同期ボタンとバッジだけになる
- [ ] extension.ts の deguboard.reload の登録と、「2 つのボタン」「手の再読み込みで動く」などの古いコメントを直す。reload イベントの broadcast と HostBridge の受け口は残す
- [ ] requirements.md の UI-12 を「同期のボタン」に直し、再読み込みボタンへの言及を文書から消す
- [ ] mise run check が通る
