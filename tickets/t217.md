## 概要

VS Code 拡張は createLocalClient に user を渡さず（packages/vscode/src/extension.ts）、core の defaultUser（packages/core/src/git/repo.ts）が git の user.name を使うため、 DEGUBOARD_USER が効かず whoami が CLI と食い違う。拡張ホストの環境変数は起動のしかた（GUI 起動・Remote SSH）で変わるので、env だけでは当てにならない。 人ごとに設定でき共有されない git config の deguboard.user を core の既定に足し、どの入口でも同じに効かせる。VS Code の settings.json の設定は足さない

## 受け入れ条件

- [x] VS Code 拡張が DEGUBOARD_USER を createLocalClient に渡す
