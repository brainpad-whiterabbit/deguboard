## 概要

p16 の作業で見つかった不具合。t205 を `--branch chore/config-cleanup` で claim した直後の `dg sync` が、t114 が 2026-11-01 に同じブランチ名で出してマージ済みの PR #105 を拾い、t205 を in_progress から done に進め、pr に 105 を記録した（受け入れ条件はすべて未チェック）。ブランチ名の使い回しで、チケットの作業と関係のない古い PR を根拠にしている。claim（または branch を記録した時刻）より前にマージされた PR は照合の根拠にしない、などで防ぐ


## 受け入れ条件

- [ ] claim より前にマージされた同じブランチ名の PR があっても、sync はそのチケットを done にせず pr も記録しない
- [ ] claim の後に出してマージした PR は、今までどおり照合で done になり pr が記録される
- [ ] 上の 2 つを、一時ディレクトリの bare リモート付きのリポジトリ（gh は差し替え）でテストする
- [ ] `mise run check` が通る
