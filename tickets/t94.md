## 概要

Workflow に steps を足し、step ごとに使える Action と承認の要否を書けるようにする。同梱の 3 テンプレートに steps を書き、run start の step を語彙で確かめる。手続きは YAML に書かず dg guide が持つ（WF-5、ADR-003）

## 受け入れ条件

- [ ] 未知の step・Action を読み込み時と dg workflow validate が指摘する（WF-3）
- [ ] software-development・consulting・general の 3 テンプレートに steps がある
- [ ] run start が Workflow の steps にない step を拒否するか警告する
- [ ] ADR-003 と requirements.md の WF-5 を直す
