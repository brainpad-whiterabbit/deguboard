## 概要

Skill を入れていない人は文章の形式で頼むが、今の文章の形式には dg の呼び方しか付かず、承認や品質ゲートの手順をエージェントが知らないまま進めてしまう。Skill を持つ頼むことの文章の形式に、その段階の dg guide を読んで進める一文を入れ、Skill と同じ結果にする。

## 受け入れ条件

- [x] Skill を持つ頼むことの文章の形式（--format text）に、その Skill のトピックの `dg guide <topic>` を読んで進める一文が入る
- [x] Skill を持たない頼むことの文章の形式は変わらない
- [x] `dg ask --format text` のテストで、頼むことごとに読む guide のトピックを確かめる
- [x] ADR-010 の文の形の記述が、入れた一文と合っている
