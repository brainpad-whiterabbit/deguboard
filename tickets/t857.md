## Summary

拡張を更新しても `.claude/skills/` の Skill は前の版のまま残り、何も知らされない（t849 のあと、`mise run install` をしても dgdone が古いままだった）。拡張は起動のたびに、同梱している dg の Skill と比べて、古い Skill を自動で更新して通知する。版が同じまま VSIX を入れ直す開発の場合も拾う。Skill を入れるかどうかは利用者が決める（AG-2）ので、入れていない場所には書かない。

## Acceptance criteria

- [ ] 拡張が起動するたびに、リポジトリか `~/.claude/skills` に入れてある dg の Skill の中身を同梱の dg の Skill と比べ、違うものを更新して、更新したものを通知で出す（同じ版の入れ直しでも拾う。変えるものがなければ通知しない）
- [ ] 手で直した Skill は書き換えず、古いことと `dg skill install --force` で上書きできることを通知で出す
- [ ] dg の Skill を入れていない場所には書かない
- [ ] 古いかどうかの判定は t858 の判定を、更新は `dg skill install` と同じ処理を使う（入口にロジックを持たない）
- [ ] 上の 3 つの振る舞いをテストで確かめる
- [ ] requirements の AG-2 か UI-11 に、拡張が Skill を最新に保つ約束を 1 文で足す
