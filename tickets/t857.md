## Summary

拡張を更新しても `.claude/skills/` の Skill は前の版のまま残り、何も知らされない（t849 のあと、`mise run install` をしても dgdone が古いままだった）。拡張は起動時に、同梱している dg の Skill と比べて、古い Skill を更新する。Skill を入れるかどうかは利用者が決める（AG-2）ので、入れていない場所には書かない。

## Acceptance criteria

- [ ] 拡張の版が変わってから最初に起動したとき、リポジトリか `~/.claude/skills` に入れてある dg の Skill のうち、同梱の dg と違うものを更新し、更新したものを通知で出す（変えるものがなければ通知しない）
- [ ] 手で直した Skill は書き換えず、古いことと `dg skill install --force` で上書きできることを通知で出す
- [ ] dg の Skill を入れていない場所には書かない
- [ ] Skill の判定と更新は `dg skill install` と同じ処理を通る（入口にロジックを持たない）
- [ ] 上の 3 つの振る舞いをテストで確かめる
- [ ] requirements の AG-2 か UI-11 に、拡張が Skill を最新に保つ約束を 1 文で足す
