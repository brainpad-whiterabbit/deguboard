## Summary

導入の案内を、通知・エラーの通知・始め方の画面・README に散らさず、左パネルのチェックリスト 1 か所にまとめる。項目を自動で確かめ、満たさない項目にボタンかコマンドを出し、必須（フォルダ〜ボード）を満たすといつもの画面に変える。Skill と hooks・dg コマンド・.claude/.gitignore は推奨として帯で示し、Claude Code 以外のエージェントの人を閉め出さない。

## Acceptance criteria

- [x] dg init 前・Git リポジトリの外・git がないとき、左パネルは始め方の代わりにチェックリスト（フォルダ・OS・git・Git リポジトリ・ボード）を出し、満たさない最初の項目に状態・ボタン・コマンドを出す
- [x] ボタンを押すか、ターミナルで自分で直すと、自動で確かめ直し、必須をすべて満たすといつもの画面に変わる。手で確かめ直すボタンもある
- [x] 推奨（Skill と hooks・dg コマンド・.claude/.gitignore）が欠けている間は、いつもの画面の上に帯を出し、開くと項目をその場で直せ、このリポジトリでは出さないこともできる
- [x] PATH に dg がないときの通知と、左パネルでの Git リポジトリの外のエラーの通知を出さない。dg のメジャー版が拡張と違うことは推奨の項目で示す
- [x] 満たさない項目の文言を、状態（事実の 1 文）→ すること → ターミナルで行うなら → 条件を書いた別の道、の順にそろえる
