## 概要

ADR の運用の改訂（直接書き換え・不要な ADR は削除）に合わせて、`scripts/check-docs.mjs` の ADR の検査を変える。更新日の照合は書き換えのたびに 2 か所を合わせる手間なのでやめる。削除した番号を指す参照は、いまの検査（Markdown のリンクと先頭のコメント）では地の文やコメントの `ADR-0xx` を見つけられない。長さは文を詰めさせる予算ではなく、分割の時期を知らせる合図にする（要件の 1 項の 250 字と同じ扱い）。

## 受け入れ条件

- [x] ADR の「- 更新日：」と一覧の更新日の照合がなくなり、一覧に更新日の列がなくても check:docs が通る
- [x] docs・CLAUDE.md・README・guide・packages・scripts（dist を除く）に、実在しない ADR 番号の参照があると、ファイルと行を付けて check:docs が落ちる
- [x] docs/adr/README.md の「最後に使った番号」より大きい番号の ADR があるか、その番号が実在の最大の番号より小さいと check:docs が落ちる
- [x] 1 本の ADR が 8,000 字を超えると check:docs が警告を出し（落とさない）、分割・整理の起票を促す
- [x] 上の検査それぞれにテストがある
