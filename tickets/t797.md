## Summary

`dg hooks install` はマシンごとの絶対パスを `.claude/settings.local.json` に書くが、git がそれを無視するかは利用者の設定次第で、いまは警告するだけ。dg が入れる Skill（`dg*`）も、版を上げるたびに差分が出る。2 つのコマンドが `.claude/.gitignore` に自分の行を足し、Skill は各自が入れるものにする（手で加える内容は `guide.notes` に置く。AG-2）。

## Acceptance criteria

- [ ] project スコープの `dg skill install` は `skills/dg*/` を、local スコープの `dg hooks install` は `settings.local.json` を `.claude/.gitignore` に足す。利用者の行は残し、何度実行しても重ならず、`--personal`・`--shared` では書かない（テストで示す）
- [ ] `dg hooks install` の「git が無視していない」警告は、`.gitignore` で防げない場合（すでに追跡されているなど）にだけ出る
- [ ] このリポジトリの `.claude/skills/` を追跡から外し、ルートの `.gitignore` から `.claude/settings.local.json` の行を消す
- [ ] README・README.ja・walkthrough（init・agent の英語と日本語）が、`.claude/.gitignore` のコミットと、clone した人が `dg skill install` を動かすことを案内する
- [ ] requirements.md の AG-2・AG-9 に無視の設定を 1 句ずつ足し、「Skill を追跡して共有する」案を ADR（ADR-025 か ADR-030）の「採らなかった案」に 1 行残す
