## 概要

VS Code のパネルのチケット詳細で、右の列の「作業」の節と見出しの帯（Status・優先度・Iteration・担当・PR が並ぶ行）に、入っている開いた Plan の番号（Plan 詳細へのリンク）と段階（tier）の札を出す。ticket show の出力には plan_tier を足す。Plan の範囲・進め方は出さない。段階の正本は Plan の details のままで、チケットのデータの形（PL-1）と ADR-004 は変えない。見た目はモック https://claude.ai/artifact/XeRMYVVJn9XH2fwXZpzAkL の案 2 に従う

## 受け入れ条件

- [ ] ticket show の出力に plan_tier がある。開いた Plan に入っていれば details[id].tier（指定がなければ standard）、入っていなければ null
- [ ] パネルのチケット詳細の「作業」の節に、Plan の番号のリンクと段階の札の行が出る。Plan に入っていなければ行は出ない
- [ ] 見出しの帯にも同じ Plan の番号のリンクと段階の札が出る。Plan に入っていなければ出ない
- [ ] ticket.update で属性を直した後も Plan の行と帯の表示が残る
- [ ] 表示と非表示をテストで確かめ、PR にパネルのスクリーンショットを載せる
- [ ] requirements の UI-13 にチケット詳細にも Plan の番号と段階を出すことが書いてある
