## 概要

観点：文書と実装。Skill（skill.md）には「PATH に dg がなければ、リポジトリの案内（CLAUDE.md など）が書く呼び方で置き換える」がある。
Skill の代わりになる文章の形式の依頼文（ASK_DG_USAGE）と guide にはこの行がない。Skill なしで頼むと、`mise run dg --` で呼ぶリポジトリでもエージェントが PATH の dg を呼び、版が食い違いうる。

## 受け入れ条件

- [ ] Skill と文章の形式のどちらで頼んでも、PATH に dg がないときの置き換えの案内がエージェントに届く
- [ ] 案内の文面は 1 か所にあり、Skill と文章の形式が写す
- [ ] `dg ask --format text` か guide の文面のテストで、案内が入ることを確かめている
