## Summary

作業ブランチとの照合は、ブランチを記録する前にマージされた PR だけを前の作業のものとして除外する（t206）。マージされずに閉じた PR は除外しないので、同じブランチ名で claim し直して新しい PR を出す前に照合が走ると、閉じた古い PR を記録する。以後は記録した番号で引くので新しい PR が見つからず、review にも done にも進まず、gate も落ち続ける。

## Acceptance criteria

- [x] ブランチで PR を探したとき、開いていない PR のうち作成がブランチの記録より前のもの（マージされずに閉じたものも含む）を前の作業のものとして除外する
- [x] 開いたままの古い PR は除外しないことをテストで示す
- [x] マージされずに閉じた PR が残るブランチ名で claim し直して新しい PR を出すと、新しい PR を記録して review に進むことをテストで示す
