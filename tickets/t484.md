## 概要

t439 の `mise run test:vscode` は、左パネルのカンバンとチケット詳細のパネルしか撮らない。バックログ・履歴・設定の画面と、Iteration・Epic・Plan の詳細のパネルも撮れるようにし、PR に載せるスクリーンショットを全部これで撮れるようにする。あわせて development.md のスクリーンショットの手順を、実機で撮る画面の一覧に合わせる。p63 の t439 の見直しで出た範囲の外の指摘。

## 受け入れ条件

- [ ] test:vscode が左パネルのバックログ・履歴・設定と、Iteration・Epic・Plan の詳細のパネルをライト・ダークで撮る
- [ ] 撮った画面ごとに CSP 違反と捕まえていない例外がないことを確かめる
- [ ] development.md の PR のスクリーンショットの手順が、撮れる画面の一覧と一致する
- [ ] mise run test:vscode が通り、mise run check が通る
