## 概要

guide-review の品質ゲートの「検査」は、`dg gate` が判定せず親が回して確かめている。マージの方法も「リポジトリの規約のマージの手順に合わせて」LLM が選んでいる。config の `actions.test`（今ある）を gate の条件にし、`merge.method`・`merge.delete_branch` を足す。

## 受け入れ条件

- [ ] `dg gate` に検査の条件があり、`actions.test` を最新のコミットで回した結果で判定する。`actions.test` が空なら判定しないと detail に出る
- [ ] 検査が通らなければ、`dg pr ready`・`dg pr merge` が GATE_FAILED と出力の末尾を返す
- [ ] `dg pr merge` が `--method`・`--delete-branch` を省いたとき、`merge.method`・`merge.delete_branch` に従う
- [ ] guide-review の「`dg gate` は判定しないので、親が確かめる」と、guide-all の「規約のマージの手順に合わせて」を直した
- [ ] EX-6 の約束を直し、テストがある
