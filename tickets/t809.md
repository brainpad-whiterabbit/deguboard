## Summary

履歴の Iteration・Epic・Tickets の切り替えと、Tickets の結果の絞り込み（すべて・完了・中止）の件数は、VS Code のバッジの色で塗った札で出ていて、見方の名前より目立つ。札をやめ、説明文の色の少し小さい数字にする（案 1）。案: https://claude.ai/artifact/D2YKXeU9noSjuy1ng8RygY

- [ ] 絞り込み中の「当たった数 / 全体」の出し方と、押したときの動きは今と同じ
