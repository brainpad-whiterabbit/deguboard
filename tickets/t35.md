## 概要

KanbanForge の History タブ（SH-1・SH-2）に寄せる。closed の Iteration を closed_at の新しい順に 2 段の行で出す。1 段目に番号・名前と、閉じたときに記録した完了・持ち越しの件数（completed・carried_over）、2 段目に期間と目標。タブの名前に件数を添える（「履歴 2」）。チケットの番号かタイトルで探すと、そのチケットが入っている Iteration の行だけに絞る（チケットは iteration を持っていて store に全件あるので Webview の中で済む）。行を押すとチケットと同じ経路でエディタのパネルに詳細（IterationDetailView）を開く。拡張ホストへの action を openTicket から open(route) に広げ、#/iterations/s3 を渡す。パネルの題は「s3 名前」。閉じた Iteration の詳細はチケットの表と「再開する」だけ。output tokens（e3）は出さず、1 段目の右側を空けておく。

## 受け入れ条件

- [ ] タブに「履歴 n」があり、closed の Iteration が新しい順に番号・名前・完了・持ち越し・期間・目標で並ぶ
- [ ] 検索欄にチケットの番号かタイトルを入れると、そのチケットを含む Iteration の行だけになる
- [ ] 行を押すとエディタのパネルにその Iteration の詳細が開き、パネルの題が「s3 名前」になる。ブラウザではハッシュ遷移で同じ詳細に移る
- [ ] core の WebviewRequest の action が open(route) になり、openTicket はそれで実装される。webview.test.ts で検査する
- [ ] t34 の後に行う（依存）
