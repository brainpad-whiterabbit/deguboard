## 概要

MCP で対話的に確かめていた決まった確認を、毎回同じ結果が出るテストにする。対象は t27 の受け入れ条件のような配置の確認（サイドバーの幅 300px で横スクロールが出ない、260px 以下でタブとタイトルが折り返さない、ライトとダークで崩れない）。一時リポジトリに dg serve を立てて Chromium で開く。mise run check に入れるかは実行時間を見て決める

## 受け入れ条件

- [ ] サイドバーの配置で幅 300px と 260px のとき、横スクロールが出ずタブとチケットの行が 1 行に収まることを確かめるテストがある
- [ ] ライトとダーク（prefers-color-scheme）の両方で同じテストが通る
- [ ] mise.toml にタスクがあり、mise run で回せる。check に入れるかどうかと理由を development.md に書く
- [ ] テストは一時ディレクトリの bare リモート付きリポジトリで動き、開発者のデータを触らない
