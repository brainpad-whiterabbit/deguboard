## 概要

自動で開くようにした後も、agent 名を判定できない環境などで Run が抜けうる。抜けたチケットを `dg lint` で見つけられるようにする。

## 受け入れ条件

- [x] agent が claim して（`assignee` が `<ユーザ>/agent`）PR まで進んだのに実装の Run がないチケットを指摘する
- [x] 実装の Run を閉じた後に作業ブランチへ push されたコミットのうち、どの Run の期間にも入らないものがあるチケットを指摘する
- [x] 指摘の振る舞いをテストで確かめ、指摘の一覧（requirements・`dg lint --help`）に足す
