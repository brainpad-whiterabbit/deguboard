## 概要

方針（英語に統一）に沿って、guide 4 本を英語にする。frontmatter を持つのは guide-work だけ（run・parallel・review は持たない）。work の frontmatter の説明は英語にし、日本語の起動の例を残す。

見出しを英語にすると、その見出しを名指す参照（`dg guide <topic>` の「節」）が check:docs で切れる。このチケットの 4 本の節は多くの場所から名指されているので、同じ PR で英語の見出しの形（``the "節" section of `dg guide <topic>` ``）に直す：ほかの guide（overview・all・done・release）と core の git/write.ts のコメント（run の「止まった Run」）。core の brief.ts（work の「実装する」、review の「見直す」「指摘を直す」）と flow.ts（work の「流れ」）は節を名前で引いて本文を手に入れる（ADR-030）ので、これも英語の見出しに直す。逆に、この 4 本が指すまだ日本語の guide の節（work → done の「Plan を閉じる」）はそのまま残してよい。

## 受け入れ条件

- [ ] guide-work・guide-run・guide-parallel・guide-review の本文が英語である
- [ ] guide-work の frontmatter の description と argument-hint が英語で、description に日本語の起動の例が残っている
- [ ] 英語にした見出しを名指す参照（ほかの guide・core の git/write.ts）と、節を名前で引く brief.ts・flow.ts の表が新しい見出しに直してある
- [ ] 日本語の文を照合していたテストが英語の文に合わせて直してある
- [ ] 見直しの指摘のうち受け入れ条件に当たるものを、guide の言語によらず見分けられる（run/findings.ts の isAcceptanceFinding が日本語の語だけに頼らない。s23 の見直しの指摘）
- [ ] mise run check が通る
