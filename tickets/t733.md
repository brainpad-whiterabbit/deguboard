## Summary

vscode のビルドで core・server・cli と MCP SDK を 1 つの JS ファイル（dist/cli/dg.mjs）にまとめ、VSIX に入れる。Web の画面と guide は拡張がすでに同梱しているものを共有する。利用者が npm も clone もせずに dg を手に入れるための最初の段（e22）。

## Acceptance criteria

- [ ] VSIX の dist に入れた dg.mjs を VS Code の node で動かすと、dg --version・dg guide・dg serve（Web の画面）・dg mcp・dg init・dg skill install が動く
- [ ] import.meta.url からの相対で引く場所（web・guide・skill.md・版・自分のパス・store-cache の印）を、束ねた配置でも引けるようにする
- [ ] ネイティブのモジュールを含まず、プラットフォームごとに分けない 1 つの VSIX で済む
- [ ] Web の画面と guide は拡張がすでに同梱しているもの（dist/web・dist/guide-*.md）を共有し、二重に入れない
- [ ] vsix-files のテストで dg.mjs が入っていることを確かめる
- [ ] PR の本文に VSIX の大きさの増分を書く
- [ ] ADR-033 の依存の決まりを、拡張が CLI を同梱することに合わせて書き換える
