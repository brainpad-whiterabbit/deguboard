## 概要

左パネルの履歴の Epic の行は開けず、中身を見るにはパネルで詳細を開くしかない。Iteration と同じく行を開くと中のチケットを 1 本の一覧で出す（改善案 H5）。改善案のページ：https://claude.ai/artifact/RPsNUSkt3w9SboDy5XQAwd


## 受け入れ条件

- [x] Epic の行を押すと、中の終わったチケットが番号の順の 1 本の一覧で開く
- [x] 行の 2 段目に Iteration と PR が出て、Iteration に入っていないチケットは「Iteration なし」と出る
- [x] Epic の行のチップは Iteration の行と同じ形（完了の件数、中止は 1 件以上のときだけ）で出る
- [x] チケットのない Epic は薄く出て、開けない
- [x] 番号を押すと今のとおりパネルで詳細が開く
