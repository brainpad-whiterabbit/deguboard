## 概要

ADR-007 の「逆向きの依存は lint で検出する」に対応する oxlint の規則（import の制限）を足す。core が cli/server/web/vscode を import しない、server/vscode が core 以外を import しない

## 受け入れ条件

- [x] oxlint の設定に import の制限があり、core から cli/server/web/vscode を import すると `mise run lint` が失敗する
- [x] server と vscode が core 以外のパッケージを import すると失敗する
- [x] 違反を一時的に入れて失敗を確かめたうえで、現状のコードは `mise run check` が通る
- [x] ADR-007 に検出の手段（規則名）が書かれている
