## Summary

README の文章量を減らし、Backlog・Board・History のタブごとに「起票 → 割り当て → 計画 → 並列の実装 → 振り返り」の流れで使い方を見せる。節の構成は冒頭（Features を吸収した 2〜3 文の紹介文と GIF）・Installation（3 手順を短く）・Usage・Tips・Security and privacy（短く）・Documentation・License。キーボード操作と「Other ways to use it」は消す。/dgall・ゲートの段・同期の競合・通知・Go to Ticket・CLI・MCP の設定は日本語の docs/usage.md に移し、開発者の始め方は development.md にあるので消す。GIF は今あるものを当てておき、新しい GIF への差し替えは後続のチケットで行う。VSIX の README は README の全文をそのまま使う。Installation は今の手順（GitHub Releases の VSIX）のまま短くし、対応する OS（Linux・macOS）は残す。ストアからの入れ方への差し替えは t826 で行う。docs/usage.md は人がする操作を短く書き、細部は dg のヘルプ・`dg guide`・requirements へ案内して写さない（文書の重複の検査に当たらないように）。計画は https://claude.ai/artifact/GZRDM9MhWqJqitixmedcmD（2026-11-13 の会話で決めた内容）。
