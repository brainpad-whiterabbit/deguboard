## Summary

今はタイトル行の Ask ボタン（deguboard.askInSidebar）が Webview の外にあり、小窓の外を押したら閉じる処理が働かないため、開いている間に押すと閉じずに開き直す。また指示の下書きは閉じても見た目の状態（ask.note）に残り、開き直すと戻る。これを、押すたびに開閉が切り替わり、開くたびに指示の欄が空になるように変える。

## Acceptance criteria

- [x] 小窓が開いている間にタイトル行の Ask ボタンを押すと閉じ、閉じているときに押すと開く
- [x] 小窓を開くたびに指示の欄は空で始まる（閉じてから開く・行の吹き出しで対象を替える・開いたままコマンドパレットから開く、のどれでも。ウィンドウの再読み込みで開いていた小窓を戻すときだけ指示を残す。形式の選択は今のまま残す）
- [x] 下書きが残る前提のコメント（ask-composer.tsx・host.tsx・app.tsx）とテストを今の振る舞いに直す
