## 概要

版上げのチケット（リリースの PR）は、今は 5 件が暗黙に見直し（dg guide review の別のサブエージェントの見直し）から外れている。外すなら、その決まりを guide（dg guide review か dg guide release）に書く。あわせて、版上げでない t212 で見直しが抜けているのが、決まりのない本当の漏れかを確かめて報告する。

## 受け入れ条件

- [x] 版上げのチケットを見直しから外すかどうかと、外すときの条件が dg guide review か dg guide release に書いてある
- [x] 見直しから外れた 5 件がどのチケットかと、そのすべてが書いた決まりに当たるかを PR の本文に書く
- [x] t212 の見直しが抜けたのが本当の漏れかを確かめ、結果（漏れなら理由）を PR の本文と人への報告に書く
