## Summary

詳細の画面は、「編集」を押した時点の写しから題と本文を全文で ticket.update に送る。ticket.update は読んだときの本文を照らさないので、編集中にエージェントが書いた変更（受け入れ条件の印など）を黙って上書きする。ticket.check には読んだ本文（base）を照らして拒否する仕組みがある。

## Acceptance criteria

- [ ] ticket.update は任意の読んだときの本文を受け取り、今の本文と違えば書き込まずに拒否する
- [ ] 読んだときの本文を渡さない呼び出し（CLI など）は今までどおり書ける
- [ ] Web と VS Code の詳細の画面は、編集を始めたときの本文を渡し、拒否されたら変更を残したまま、ほかで書き換わったことを知らせる
- [ ] 編集の途中に本文が書き換わったとき、保存がその変更を消さないことをテストで示す
