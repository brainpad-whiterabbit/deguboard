## Summary

観点：文書と実装。文章だけの形で対象がないとき、ask.ts は noTargetOk のない頼むことに ASK_FIRST（先にどれを使うか聞いて）を前置する。done では、guide-done.md の「対象がなければ sync が done にしたもの（reconciled）と自分の review のチケットを対象にする」と食い違う。release では、依頼文が自分で「リリースする Iteration を聞いてから」と聞かせるので、対象を 2 度聞く（t679 の PR #627 に残した軽い指摘）。

人の判断（2026-11-11）で ASK_FIRST の前置は残し、guide の側を人に対象を聞く形に直す。guide-all の対象なしは guide-release を引くので一緒に変わる。

## Acceptance criteria

- [x] guide-done の「No target given」が、sync が done にしたもの（reconciled）と自分の review を候補に示し、どれにするかを人に聞く形になっている
- [x] 対象なしの release の依頼文から自分で Iteration を聞かせる文を削り、文章だけの形では ASK_FIRST だけが対象を聞くことをテストが確かめる
