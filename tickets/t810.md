## Summary

左パネルのカンバンの見出しは、名前・期間・目標を 1 行に詰めていて、目標は数文字で切れる。目標を次の行に折り返して出し、名前の行に何日目かを、進みの帯の下に状態ごとの件数を足す（案 A）。案: https://claude.ai/artifact/HMNYU9TrS3vCzXSQdqfrh1

## Acceptance criteria

- [ ] 目標を名前・期間の次の行に折り返して出す。3 行を超える分は「…」で省き、全文はツールチップで読める。目標の中の ID（e24・t12 など）は詳細へのリンクにする
- [ ] active の Iteration は期間の横に「N 日目」（開始日を 1 日目）を出す。planned・「すべて」では出さない
- [ ] 進みの帯の下に、状態ごとの件数（done・in progress・review・todo のうち 1 件以上のもの）を帯と同じ色の印と数字で出す。数え方は帯と同じ（Epic・担当の絞り込みの後）
- [ ] 目標のない Iteration と「すべて」では、目標の行を出さない
- [ ] PR に変えた画面のスクリーンショットを載せる
