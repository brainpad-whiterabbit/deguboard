## 概要

core の actions モジュールに、ソフトウェア開発向けの Action（worktree の作成・ブランチ・テスト実行・PR 作成・マージ）を登録する。任意のシェルの Action は actions.shell が true のときだけ使え、実行前に確認する。呼び方を決めて requirements.md と ADR-007 を直す（AG-6・AG-7）

## 受け入れ条件

- [ ] Core の汎用部分（commands・storage・workflow）が Action に依存しない（AG-6）
- [ ] actions.shell が false のとき、任意のシェルの Action が拒否される
- [ ] 任意のシェルの Action は確認なしでは実行されない（AG-7）
- [ ] Action の呼び方が requirements.md と ADR-007 に書かれ、AG-6・AG-7 の「予定」が外れる
