## 概要

Copilot SDK の session usage と model を Run に紐づけ、`run finish` で取り込む Agent Adapter を実装する。SDK の usage event を Run に対応づけて finish 時に参照できるデータフローも定める。会話内容は保存・転記せず、既存の `metrics.read_transcripts` と `DEGUBOARD_NO_TRANSCRIPTS` の許可を守る。対応範囲を AG-5 と利用者向け文書に反映する。

## 受け入れ条件

- [ ] `copilot` の Agent Adapter が登録され、Copilot SDK の公式 session usage / model 情報を対象 Run に対応づけて `run finish` に渡す。SDK のデータを finish 時に利用できるようにする保存・受け渡し方式も実装されている
- [ ] 取得できた input / output / cache_read / cache_write と model が Run に記録され、欠けた値は null のまま警告される。別 session / 別 Run の使用量を混ぜない
- [ ] `metrics.read_transcripts` が false、または `DEGUBOARD_NO_TRANSCRIPTS` が設定されているときは Copilot の session 記録を読まない。会話内容・コマンド文字列・パスは Git 管理の Run に記録しない
- [ ] Adapter の session 選択・使用量の集計・欠損・許可設定・プライバシー境界をテストで確かめる
- [ ] requirements の AG-5 と利用者向けの使用量取り込みの記述が Copilot 対応に更新される
