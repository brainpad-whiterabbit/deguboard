## 概要

設定画面（packages/web/src/pages/config.tsx）の `clearsToDefault` は、core の `config.set` が空文字を「既定に戻す」と読む条件（setup.ts の resolveLeaf）を画面に写している。同じ条件が 2 か所にあり、core の条件が変わると確認の文がずれる。web は core の実行時のコードを取り込めない（ADR-007）ので、core の `config show --fields` が返す項目の定義に「空にすると既定に戻る」を持たせ、resolveLeaf と画面がどちらもそれを使うようにする。p62 の t438 の見直しで出た範囲の外の指摘。

## 受け入れ条件

- [ ] `config show --fields` の各項目に、空にすると既定に戻るかを示す値が出る
- [ ] core の resolveLeaf がその値で空文字の扱いを決める
- [ ] 設定画面が同じ条件を自分で持たず、その値を読む
- [ ] 既定が空でない文字列の項目と、それ以外の項目の両方で、値と画面の振る舞いをテストで確かめる
- [ ] mise run check が通る
