## 概要

受け入れ条件は本文の - [ ] 行だが、review → done は照合（PR のマージ）で自動で進むので agent がチェックを付ける機会がなく、done のチケットの条件が未チェックのまま残る。項目を番号でチェックする ticket check を足し、show に acceptance を出し、guide work で PR を出す前に 1 項目ずつ確かめて付ける手順にする。lint と sync は未チェックのまま done のチケットを警告する（遷移は止めない）。

## 受け入れ条件

- [x] dg ticket check <id> <番号…> が受け入れ条件の該当項目だけを - [x] にし、--undo で戻し、--all で全項目を対象にする。節や項目がない・範囲外の番号は NOT_FOUND
- [x] dg ticket show --json の data に acceptance（index・text・checked）が出る
- [x] dg guide work が PR を出す前に受け入れ条件を確かめて ticket check で付ける手順を持ち、dg guide finish から本文全体を --body で書き戻す手順が消える
- [x] dg lint が done で未チェックの項目が残るチケットを lint_acceptance_unchecked で指摘する
- [x] dg sync の照合で done に進めたチケットに未チェックが残れば warnings に出る（遷移は止めない）
- [x] requirements.md（TK-3・TK-5・CL-2・ST-4）と ADR-003 が新しい振る舞いに合っている
- [x] mise run check が通る
