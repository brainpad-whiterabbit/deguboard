## Summary

s43 の見直し（観点：構成）の指摘 2 件。

- packages/web/src/pages/config.tsx が、軸の状態（undecided・off・on）を、core の model/label-axes.ts の `labelAxesState` と同じ式で自分で判定している。`config.show` が状態を返さないためで、ADR-033 は web が core から型だけを取ると定める
- リリースのラベルの判定が、packages/core/src/commands/flow.ts の `isRelease` と packages/core/src/commands/flow-records.ts の `releaseLabeled` の 2 か所に同じ中身で書かれている。`release-` の接頭辞は model/labels.ts の `PROCEDURE_LABEL_PREFIXES` にもある（前からある重複）

振る舞いは変えない。

## Acceptance criteria

- [x] `config.show` の値が軸の状態を持ち、設定画面はその値を出すだけで、状態を自分で判定していない
- [x] リリースのラベルの判定が core の 1 か所にあり、flow.ts と flow-records.ts はそれを使っている
- [x] 設定画面の軸の表示と `dg flow next` の結果が変更の前と同じであることを、既存のテストか足したテストで確かめている
