## Summary

見直し（s41）の観点「README」。docs/usage.md と docs/usage.ja.md の Security and privacy の節は「拡張が起動するのは git・gh・dg --version だけ」と書いている。一方、拡張は設定や外す操作のボタンで deguboard のターミナルに dg のコマンドを入れて Enter で実行し（extension.ts の setupCommandLine を sendText）、頼む文も開いているターミナルに入れる（Enter は押さない）。同じページの Uninstall の節も、ターミナルで dg uninstall が動くと書いていて、節どうしが食い違う。README の Security and privacy もこの節へ案内している。

## Acceptance criteria

- [x] docs/usage.md の Security and privacy の節が、拡張が直接起動するコマンドと、ターミナルに入れて動かすコマンド・文を、今の実装どおりに区別して書いている
- [x] docs/usage.ja.md の同じ節が英語版と同じ内容になっている
- [x] README.md・README.ja.md の Security and privacy の記述が、直した usage の節と食い違わない
