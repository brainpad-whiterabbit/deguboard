## Summary

Codex は Agent Skills を、リポジトリの .agents/skills/ と個人の ~/.agents/skills/ から読み、$<名前> で呼ぶ。今の Codex の Adapter は skillDirs を持たず、dg skill install は claude-code の置き場所にだけ書く。Codex にも同じ薄い Skill（dg guide を読む）を入れられるようにする。

## Acceptance criteria

- [ ] Codex の Adapter が skillDirs（project は .agents/skills、personal は ~/.agents/skills）を持つ
- [ ] dg skill install --agent codex が Codex の置き場所に書き、project では .agents/.gitignore に dg の Skill ごとの無視の行を足す（--agent の既定は claude-code のまま）
- [ ] dg hooks check・next・brief の古い Skill の警告と、VS Code 拡張の起動時の更新が Codex の置き場所の Skill も対象にすることをテストで示す
- [ ] dg ask の依頼文が、Codex の Skill を Codex で呼べる形（$dg…）で示せることを ask のテストで示す
- [ ] requirements の AG-2、README.md・README.ja.md、docs/usage.md・usage.ja.md の Skill の案内を同じ PR で直す
