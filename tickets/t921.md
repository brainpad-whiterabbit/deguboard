## Summary

設定画面（Web の `#/config`）の「チーム」タブに「振り返り」の節を足し、`retro.perspectives` の観点と承認した指標の定義を読むだけで見られるようにする。今は入れ子のため設定画面に出ず、`dg config show` でしか読めない。UI は案 A2（最初は観点の行だけを出し、観点 → 指標の 2 段で開く）。指標の 1 行の要約は、数え方の最初の文（「。」まで）を出す（データの形は変えない）。

## Acceptance criteria

- [x] 「チーム」タブに「振り返り」の節があり、観点ごとに名前・問い・指標の数（ないときは「定義なし」）を 1 行で出し、最初は閉じている
- [x] 観点を開くと指標が ID と要約（数え方の最初の文）の 1 行ずつ並び、指標を押すと数え方の全文・数字の出どころ・測れないものが出る
- [x] 節は読むだけで入力欄がなく、定義は振り返り（`dg retro metric`）で書くと案内する。「自分」タブには出さない。節の文字列には英語の訳がある
- [x] 設定の検索が、観点の名前・問いと、指標の ID・数え方・出どころ・測れないものに当たり、当たった観点と指標を開いて出す
- [x] 開閉と、検索で当たったものが開くことをテストで確かめる
- [x] requirements.md の `retro.perspectives` の項と UI-14、`config.tsx` の冒頭のコメントを、設定画面で読むだけで出すことに合わせて直す
