## 概要

優先度の見せ方が画面ごとに違う（カンバンは medium を出さず low を灰色の文字、バックログは 3 つとも札、一覧の行は high だけ）。印を矢印と文字の 1 つの部品にそろえ、マウスを載せると値ごとの判断基準を出す。

- 記号は 10px の SVG（high は上向きの矢印、medium は =、low は下向きの矢印）、文字は 11px の等幅
- 色は high が --vscode-errorForeground の太字、medium が --vscode-foreground、low が --vscode-descriptionForeground
- 行では medium を出さず、high・low を右端の 1 段目の左端（担当の印と Plan の番号の左）に出す。2 段目は着手可・待ちだけにする
- ツールチップは 1 行目に値と並び方、2 行目から判断基準（config、なければ既定）

## 受け入れ条件

- [x] カンバン・バックログ・一覧の行で、high と low を矢印と文字で右端の 1 段目の左端に出し、medium は出さない
- [x] チケット詳細の帯、Epic、ブラウザのボードのカードで、3 つの値を矢印と文字で出す（medium は =）
- [x] 印のツールチップに、値と並び方と判断基準が出る
- [x] 詳細の優先度の select は選択肢を「記号と値」にし、下に選んでいる値の基準を出す
- [x] PriorityBadge・.row-low・.badge.priority-* が消えている
- [x] PR に変えた画面のスクリーンショットがある
