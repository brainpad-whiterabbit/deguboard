## 概要

dg ask の各頼むことの human の check（ticket.move、plan.approve など）は文字列で書いてあり、名前を変えたり打ち間違えたりすると、人のコマンドに切り替わらないまま黙って依頼文を返す。すべての頼むことの check を、core のコマンドの登録（registry）の名前と照合するテストを足す。t295 の 2 回目の見直し（PR #287）で出た。

## 受け入れ条件

- [x] ask のすべての頼むことの human の check の名前が、registry のコマンドの名前にあることを確かめるテストがある
- [x] 存在しない名前を混ぜるとそのテストが落ちることを確かめた
