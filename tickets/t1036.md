## Summary

docs/guide-notes の plan.md と import.md は、過去の Iteration の数字とチケット ID の根拠の段落が本文の大半を占め、計画・起票・dg flow next のたびにエージェントが読む。規則ごとに外す条件がないため、振り返りのたびに足されるだけになっている。各規則を規則の文と根拠 1 行に縮め、根拠の行の末尾に外す条件を続け、振り返りで外す条件を確かめるようにする。done.md からは古い dist の警告の文と重なる部分を消す。PR を出す作業。

## Acceptance criteria

- [x] docs/guide-notes/plan.md と docs/guide-notes/import.md の各規則が、規則の文（1〜2 文）と根拠 1 行（Iteration・指標の値・代表のチケット ID 1 つまで）になり、ほかの経緯の段落がない
- [x] docs/guide-notes の各規則の根拠の行の末尾に、外す条件（例：指標が目標内に続いた Iteration の数、対象の経路が変わらなかった Iteration の数）が 1 文で続いている
- [x] docs/guide-notes/done.md から、警告の文（packages/cli/bin/build-info.mjs の staleDistWarningOf）がすでに言っている内容が消え、警告にない内容だけが残る
- [x] ADR-001 の文書の配置の表の docs/guide-notes の行と、docs/development.md の「guide.notes の文書」の節が、新しい書き方（規則・根拠 1 行・外す条件）と、振り返りで外す条件を確かめること、guide.notes.retro が指す文書に合っている
- [x] 規則が求める行動は変えない（外すのは、外す条件に当たったときの見直しで行う）
- [x] docs/guide-notes/retro.md があり、振り返りで各規則の外す条件を指標で確かめ、当たった規則を消すチケットを Try として出すことが書いてある。config の guide.notes.retro がそれを指す
