## 概要

観点=アーキテクチャ。対象=core の model/config.ts（LOCAL_KEYS・scope・clears_to_default）と web の pages/config.tsx（GROUPS・CONFIRM_KEYS）、l10n.ts の storedConfigValue。食い違い：t465 で clears_to_default は core が決めると寄せたが、保存前に確かめる危険な項目とその理由・まとまりは web が持ち、CLI の config set に同じ確認がない。英語の表示で訳の文と同じ文字列を打つと web が既定の日本語の値に置き換えて保存する（保存する値の判断が UI にある、ADR-007）。設計の判断が要るので Iteration に入れない。

## 受け入れ条件

- [ ] 保存前に確かめる項目とまとまりが core の項目の定義にあり、web は訳して出すだけになる
- [ ] 保存する値を web が表示の文から置き換えない
- [ ] ADR-006（設定画面）の記述がコードと一致する
- [ ] mise run check が通る
