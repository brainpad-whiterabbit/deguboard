## Summary

config の models.*（tier からモデル名への対応）は 1 系統しかなく、Claude Code と Codex を混ぜて使うチームでは、もう一方の agent に合わないモデル名を渡してしまう。agent ごとに tier のモデル名を指定でき、なければ今の models.* を使うようにする。形は `models.<agent>.<tier>`（例: `models.codex.heavy`）にする。

## Acceptance criteria

- [ ] config の `models.<agent>.<tier>`（例: `models.codex.heavy`）で agent ごとに tier のモデル名を指定でき、指定がなければ今の `models.<tier>` を使うことをテストで示す
- [ ] dg next がサブエージェントに渡すモデル名を、呼んだ agent の設定から返すことをテストで示す
- [ ] 呼んだ agent を判定できないとき（Copilot CLI など）は、今の `models.<tier>` を使うことをテストで示す
- [ ] agent ごとのキーも、今の `models.<tier>` と同じく個人の設定で上書きできる
- [ ] config の検査と説明、requirements の該当項、ADR-028 の本文（`models.*` の置き場所）を同じ PR で直す
