## Summary

config の models.*（tier からモデル名への対応）は 1 系統しかなく、Claude Code と Codex を混ぜて使うチームでは、もう一方の agent に合わないモデル名を渡してしまう。agent ごとに tier のモデル名を指定でき、なければ今の models.* を使うようにする。

## Acceptance criteria

- [ ] config で agent ごとに tier のモデル名を指定でき、指定がなければ今の models.* を使うことをテストで示す
- [ ] dg next がサブエージェントに渡すモデル名を、呼んだ agent の設定から返すことをテストで示す
- [ ] config の検査と説明、requirements の該当項を同じ PR で直す
