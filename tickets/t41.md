## 概要

t34 で入れた担当者の絞り込み（カンバンの見出しの下とバックログの select、カードの担当の表示）は claimed_by を軸にしている。t37 で起票者（created_by）と担当者（assignee）が分かれ、主体の ID が <ユーザ> / <ユーザ>/agent の形になるので、絞り込みの軸を assignee にする（ユーザーの決定、2026-10-31）。ID は @ の前を切る必要がなくなるので actorLabel はそのまま出す形にし、選択肢は出てくる assignee と「なし」。ハッシュの鍵は claimed_by から assignee に。

## 受け入れ条件

- [ ] カンバンとバックログの担当の select が assignee で絞り、選択肢は出てくる assignee（eiki / eiki/agent の形のまま）と「なし」
- [ ] ハッシュは #/board?assignee=… になり、claimed_by の鍵は読まない
- [ ] カードと 1 行表示の担当の表示も assignee
- [ ] types.ts の claimOptions / matchesClaim / actorLabel と、app.test.tsx・backlog.test.ts を assignee に合わせる
- [ ] requirements.md の UI-2・UI-3 の「担当者（claimed_by）」を assignee に直す
