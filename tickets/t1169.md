## Summary

観点：文書と実装。guide-work.md の Implement の手順は、どのリポジトリにも配る guide と Skill・brief の本文になるのに、「Use `mise run test:related` while you work」「run `mise run format`」と deguboard 自身の mise のタスクを案内している（v1.2.0 からある）。ほかの検査は config の値を埋めるか `dg gate --help` を指す形で書いている。また guide-all.md の「Going ahead without asking with `--auto`」は `--auto` の例に `iteration add … --auto` を挙げているが、今の既定（`flow.assign: always_ask`）ではこのコマンドは `--auto` を拒まれる。
