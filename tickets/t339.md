## 概要

コピーする依頼文は、Skill の呼び出しのあとに説明の 1 文と「対象:」の一覧（ID・題・Status・Iteration）が続き、文章の形式では頭に dg の呼び方の前置きも入るので長い。エージェントは題も本文も dg で読めるので、Skill の形式は呼び出しと指示だけにする（人が 2026-11-04 に決めた形）。

例：

```text
/dgplan t333 t334
見出しを先にやって
```

## 受け入れ条件

- [ ] Skill の形式で Skill のある頼みごとは、1 行目の Skill の呼び出しと、あれば次の行の指示だけになり、説明の文と「対象:」の一覧を含まない
- [ ] 文章の形式と Skill のない頼みごとは、対象の ID を含む頼む 1 文と、dg の呼び方の短い 1 文と、あれば指示だけになる
- [ ] 人が打つコマンドを返す場合（actor.human_only・Workflow の by）は今のまま変わらない
- [ ] ADR-010 と requirements.md の AG-8 の依頼文の形の記述を新しい形に直す
- [ ] core の ask のテストと、CLI・HTTP・Webview の 3 経路のテストが新しい形で通る
