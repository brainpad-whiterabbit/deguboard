## 概要

t487 の方針（dg の出力は英語、2 本立てにしない）に沿って、エージェントが読む dg の文と、dg が書く定型の文を英語にする。brief は日英を持っているが、エージェントが読む文なので英語だけにし、language の入力を外す。dg がデータのブランチに書くコミットの 1 行目と、dg pr ready が PR の本文に足す節も英語にする。古いコミットの 1 行目は日本語のまま残るので、1 行目を読む処理は両方を読む。

## 受け入れ条件

- [ ] dg next・dg flow next が返す段階の理由と案内の文が英語である
- [ ] brief の定型の文が英語だけになり、dg brief と dg next に language の入力がない（findingText も英語だけ）
- [ ] フックが止めるときの文（cli の hooks.ts と claude-code-hooks.ts）が英語である
- [ ] dg がデータのブランチに書くコミットの 1 行目と、dg pr ready が PR の本文に足す節が英語で、コミットの 1 行目を読む処理は古い日本語の 1 行目も読める
- [ ] 画面に出る短い文（札の添え字など）は、表の ja 訳で今の日本語のまま出る
- [ ] mise run check が通る
