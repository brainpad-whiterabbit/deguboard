## 概要

マウスを使わずに、カンバン・バックログ・履歴の行を移って詳細を開き、選んで頼めるようにする。

## 受け入れ条件

- [ ] サイドバーの行を ↑↓ で移れ、今の行がフォーカスの枠でわかる
- [ ] Enter で今の行の詳細のパネルが開く
- [ ] Space で行を選べ、決めたキーで選んだ行の「エージェントに頼む」が開く
- [ ] 使えるキーが拡張の README に書いてあり、VS Code の既定のキー割り当てとぶつからない
