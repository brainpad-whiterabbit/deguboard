## 概要

`dg pr ready` は、直さなかった軽い指摘を PR の本文に書き足すときに `gh pr edit --body-file` を呼ぶ。この呼び出しは GitHub の Projects (classic) の廃止で GraphQL のエラー（`repository.pullRequest.projectCards`）になり、`GIT_ERROR` で止まって ready にできない。直さなかった軽い指摘が 1 件でも残る PR は毎回ここで止まる。PR #579（t633）で起き、人が `gh pr ready` を打って回避した。本文の読み書きを GraphQL の経路に頼らない道に変える。

## 受け入れ条件

- [x] Projects (classic) の GraphQL のエラーを返す環境でも、`dg pr ready` が直さなかった軽い指摘を本文に書き足して ready にできる
- [x] 本文の読み取りと書き込みが `gh pr view`・`gh pr edit` の GraphQL の経路を通らないことをテストで確かめている
- [x] 本文の書き込みに失敗したときは、今までどおり ready を呼ばずに `GIT_ERROR` を返す
