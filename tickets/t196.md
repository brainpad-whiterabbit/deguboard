## 概要

見直し（文書と実装）。packages/cli/src/guide-review.md:131 は fix・review の step を足す手段として `dg workflow set <id> --template <名前>` か `--file` を挙げるが、WF-6 と workflowSet では `--template` は labels・transitions・fields・独自の steps を捨てて定義全体を置き換える。また consulting のテンプレートは steps に fix を持たないので、consulting の Workflow では「fix を足すよう人に伝える」が出続け、`--template consulting` でも足せない。consulting に fix を足すか、伝える対象を絞るかの判断が要る

## 受け入れ条件

- [ ] guide-review の「合う step がない」の項が、手を加えた Workflow は `workflow show` の definition に steps を足して `--file` で書くこと、`--template` は定義を丸ごと置き換えることを書く
- [ ] consulting の Workflow で fix の step をどう扱うか（テンプレートに足す、または伝える対象から外す）を決め、テンプレートか guide のどちらかに反映する
