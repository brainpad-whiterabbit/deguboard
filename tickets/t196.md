## 概要

見直し（文書と実装）。packages/cli/src/guide-review.md:44（「合う step がない」）は fix・review の step を足す手段として `dg workflow set <id> --template <名前>` か `--file` を挙げるが、WF-6 と workflowSet（packages/core/src/commands/workflow.ts:110–124）では `--template` は labels・transitions・fields・独自の steps を捨てて定義全体を置き換える。また consulting のテンプレート（packages/core/src/workflow/templates/consulting.ts:21–26）は steps に fix を持たないので、consulting の Workflow では「fix を足すよう人に伝える」が出続け、`--template consulting` でも足せない。consulting に fix を足すか、伝える対象を絞るかの判断が要る。guide-work.md:39 の「合う語がないとき」も同じ前提で書いている

## 受け入れ条件

- [x] guide-review の「合う step がない」の項が、手を加えた Workflow は `workflow show` の definition に steps を足して `--file` で書くこと、`--template` は定義を丸ごと置き換えることを書く
- [x] consulting の Workflow で fix の step をどう扱うか（テンプレートに足す、または伝える対象から外す）を決め、テンプレートか guide（guide-review と guide-work:39）のどちらかに反映する
- [x] `mise run check` が通る
