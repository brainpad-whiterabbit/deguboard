## Summary

リリース前の見直し（設定ファイルの観点）の指摘。前からあるもの。`mise.toml` の `[tasks.setup]` と `[tasks.install]` が、どちらも `pnpm install --frozen-lockfile` と `pnpm run build` を直接書いている。CLAUDE.md の「新しいタスクは mise.toml に足し、pnpm scripts を呼ぶだけにする」と、ADR-008 の「同じ内容を 2 か所に書かない」に合わない。

## Acceptance criteria

- [x] `setup` と `install` のタスクが、package.json の script を呼ぶだけになり、同じコマンドを 2 か所に書いていない
- [x] `mise run setup` と `mise run install` が今と同じことをする（docs/development.md の「開発の始め方」の手順が変わらないか、変わるなら同じ PR で直す）
