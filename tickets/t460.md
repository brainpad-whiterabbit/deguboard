## 概要

VS Code の表示言語が英語のとき、設定画面が core のスキーマの describe（日本語）をそのまま出している。表示言語に合わせて項目の説明を英語でも出し、UI-11 の「設定の項目の説明は core の言語のまま」の約束を直す。

## 受け入れ条件

- [x] 表示言語が英語のとき、設定画面の全項目の説明が英語で出る
- [x] 表示言語が日本語のときは、今と同じ説明が出る
- [x] 設定の検索が、英語表示では英語の説明にも当たる
- [x] 説明の訳の抜けをテストが指摘する
- [x] requirements.md の UI-11 を直す
