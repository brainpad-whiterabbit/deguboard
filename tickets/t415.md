## 概要

2026-11-05 の検討で、計画を立てる親・サブエージェントを進める親の使用量は、一旦 Run で測らないと決めた。t400 のチケットごとの plan の Run は、start と finish を 1 回のシェルにまとめると何も取れず、正しく呼んでも計画の重さを表さないのでやめる。Plan に Run を結び付ける形（Run に project・plan を持たせ、orchestrate を予約の step にする）は考慮事項が多く、親の割合（15 セッションで約 3 割）を見たうえで見送った。この判断と理由、後で測るときの案を ADR-005 に残す。t400 の手順・テンプレートを戻すのは別のチケット。

## 受け入れ条件

- [x] ADR-005 から plan の Run の記述を外し、別の Run にするのを実装・見直し・手直しにしている
- [x] 親の使用量を Run で測らない判断と、2026-11-05 に測った親の割合と、後で測るときの案（期間の集計、Plan に結び付ける Run の形と気をつける点）を書いている
- [x] 採らなかった案に、チケットごとの plan の Run・Plan に結び付ける親の Run・Run をすべて Plan に結び付ける統一を、理由とともに書いている
- [x] ADR の一覧の更新日が合い、mise run check が通る
