## 概要

全件 done の active な Iteration でも、詳細には次にリリースすることが示されない。Iteration の状態に応じて次の操作を案内し、エージェントに頼む依頼文をコピーできるようにする。画面からは書き込まない（UI-7・UI-15）。

## 受け入れ条件

- [ ] active で全件が done か abandoned なら「リリースできる」と出し、リリースを頼む依頼文をコピーできる
- [ ] active で終了日を過ぎ未完了があれば、未完了の件数と、持ち越しを相談する依頼文を出す
- [ ] planned なら、最初のチケットの claim で active になると一言出す
- [ ] closed なら、持ち越したチケットの今の Iteration へのリンクを出す
- [ ] 案内から Iteration・チケットに書き込まない
- [ ] requirements.md の UI-5 に案内を書き足す
