## 概要

行・見出しの吹き出しから小窓を開いて頼めるので、拡張の右クリックに出しているサブメニュー（`deguboard.askMenu` と `deguboard.ask.*` のコマンド）は要らない。吹き出しを置いていないバックログの Epic の札と、絞り込み中の「n / m 件」は、頼む入口ごと外す。バックログの行の「詳細を開く」「ID をコピー」は残す。

## 受け入れ条件

- [ ] 拡張の package.json に、エージェントに頼むサブメニューと `deguboard.ask.<頼むこと>` のコマンドがない
- [ ] web が `data-vscode-context` に頼む対象・候補・おすすめを載せず、core の `WEBVIEW_CONTRACT.askContext` とそれを読むコードがない
- [ ] バックログの Epic の札と絞り込みの件数からは頼めない（右クリック・Shift+F10 とも）。件数の title から「右クリックでまとめて頼む」が消えている
- [ ] 吹き出し・Shift+F10・選択の帯の「頼む」は今までどおり使える
- [ ] ADR-010・README・初回の案内（ASK_HINT）・コードのコメントから右クリックで頼む記述が消えている
- [ ] `mise run check` が通る
