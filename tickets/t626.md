## 概要

常駐の入口（VS Code 拡張・dg mcp）は、ファイルの印（inode・大きさ・更新時刻）を比べて変わったファイルだけを読み直している。CLI はプロセスが毎回終わるので、全 2,131 ファイルを毎回解析する（約 1.2〜2 秒、データの量に比例して増える）。今の読みのキャッシュをプロセスをまたいで使えるようにディスクに残し、CLI でも変わったファイルだけを読む（試作では、読み込みと全ファイルの stat で約 85ms）。ADR-007 の「索引はメモリ上に持つ」の判断を変えるので、置き換えの ADR を書く。検討書の案 C。

## 受け入れ条件

- [x] 2 回目以降の CLI の呼び出しでは、変わっていないファイルを読み直さず、解析もしない（テストで示す）
- [x] dg の版かスキーマが違うキャッシュは捨てて読み直す
- [x] キャッシュを消しても壊れたものを置いても、ストアの結果は同じになる
- [x] 複数の dg が並んで動いても、古いキャッシュを使わない
- [x] ADR-007 の「索引はメモリ上に持つ」を置き換える ADR を書き、ADR の一覧を直す
- [x] dg ticket show の 1 回の時間を入れる前と比べて測り、PR の本文に書く
