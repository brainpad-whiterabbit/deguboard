## Summary

統合したあとも古い名前が使われる場面を受け止める。書くときは統合先に置き換え、絞るときは統合先で探す。どちらも警告を添えて、古い習慣が戻らないようにする。あわせて、点検で語彙の統合を勧める手順を足す。

## Acceptance criteria

- [x] `ticket create`・`ticket update`・`ticket import` のラベルに統合済みの名前があれば、統合先に置き換えて書き、警告を返す
- [x] `ticket list --label` と画面の絞り込みで、統合済みの名前を統合先に読み替え、警告を添える
- [x] `dg guide check` が、lint の指摘と語彙の説明から意味の重なる語彙を判断し、統合・改名・削除の案を書き換えるチケットの件数つきで表にし、承認のあとに `dg label merge` などで行う手順を持つ
