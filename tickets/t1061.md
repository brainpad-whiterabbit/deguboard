## Summary

アーキテクチャの観点（監査 s39）。t1023 で Workflow の steps と ACTION_NAMES が消えた後、`packages/core/src/actions/`（actions・listActions・runAction・software・shell）を import しているのはテストだけになりました。設定の `actions.shell` も効く先がありません。`merge_pr` は `commands/pr.ts` の gh の呼び出しを写したもので、品質ゲートを通しません。それでも ADR-033 の「Action の呼び方」・要件 AG-6・AG-7・.oxlintrc.json のルールとメッセージは、Action がまだあることを前提に書かれています。**方針：消す**。`packages/core/src/actions/` と設定の `actions.shell` を消す。品質ゲートが使う `actions.test`・`actions.light_test`・`actions.light_paths` は残す。
