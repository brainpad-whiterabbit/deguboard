## Summary

t624 はコンパイルキャッシュを bin/dg.js でだけ有効にしていて、VSIX に同梱する dist/cli/dg.mjs（入口は packages/cli/src/bundle.ts）では使っていない。拡張の利用者の dg（フックを含む）は毎回すべてをコンパイルし直している。計測では同梱の dg.mjs の PreToolUse が約 182 ms から約 158 ms になった。

## Acceptance criteria

- [ ] 同梱の dg.mjs は起動のたびにコンパイルキャッシュを有効にし、使えない Node や書けない置き場所では黙って飛ばす（bin/dg.js と同じ）
- [ ] 同梱の dg.mjs で PreToolUse を 5 回測り、有効にする前と後の中央値を PR の本文に書く
