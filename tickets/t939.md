## Summary

振り返りで指標の定義のない観点に提案する候補は、今は `dg guide retro` の表に文章で書いてあるだけで、数え方が 1 文に決まっていない。このリポジトリで承認した 11 指標（outcome・review・spec・slicing・stability・cost・improvement の各観点）を、英語の推薦の指標として core に持ち、guide の候補の表をそこから作る。振り返りでは、採用した指標が 1 つもない観点にだけ、推薦の指標を対象の回で計算した値を添えて提示し、人が承認したものを `dg retro metric` で書く。既定の観点は今と同じく指標を持たず（ADR-035）、設定画面には推薦を出さない。推薦の指標は `dg guide retro` の候補の表に差し込んで渡し、読みのコマンドは足さない。既定の 7 観点の名前と問いも、今は日本語で持っていて英語の表示で日本語が出るので、英語で持つ。画面は既定のままの観点を t940 の仕組みで表示言語に訳し、書き換えた観点は書いたまま出す（t937 から移した）。

## Acceptance criteria

- [x] 11 指標の ID・数え方・出どころ・測れないものを、英語の推薦の指標として core に持つ
- [x] `dg guide retro` の候補の表が推薦の指標から作られ、今の表にあって 11 指標にない候補（spec のやり直しの割合、stability のやり直しの数、cost の段階ごとの割合）は残さない
- [x] 採用した指標が 1 つもない観点にだけ推薦を提示することが `dg guide retro` に書かれる
- [x] 既定の 7 観点は名前と問いを英語で持ち、今と同じく指標を持たない
- [x] 日本語の表示で、既定のままの観点が日本語の訳で出て、書き換えた観点は書いたまま出る
- [x] requirements.md の MT-7 に、定義のない観点には推薦を参照して提案することを書く
