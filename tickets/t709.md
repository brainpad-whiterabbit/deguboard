## Summary

右クリックの「詳細を開く」「ID をコピー」は、今はバックログの行だけに出る。ボード・履歴・Iteration と Epic の詳細の中のチケットの行でも、同じメニューを出す。VS Code の中だけで、dg serve のブラウザでは出さない（今のバックログと同じ）。頼む入口は右クリックに置かない（ADR-027）。

## Acceptance criteria

- [ ] ボード・履歴・Iteration と Epic の詳細の中のチケットの行が、バックログの行と同じ右クリックの文脈（webviewSection とチケット）を載せる（テスト）
- [ ] 拡張の「詳細を開く」「ID をコピー」が、これらの行から呼ばれても動く（テスト）
- [ ] 右クリックのメニューを出す場所を書いたコメント（context-menu.ts・ask-menu.tsx・parts.tsx の「バックログの行だけ」）が、今の場所に合っている
- [ ] PR に、ボードと履歴で右クリックのメニューを出したスクリーンショットがある
