## Summary

右クリックの「詳細を開く」「ID をコピー」は、今は左パネルのバックログの行だけに出る。左パネルのボード・履歴のチケットの行と、ボード・バックログ・履歴の Iteration・Epic の見出しでも同じメニューを出す（t710 をまとめた）。右クリックの文脈は場所によらない 1 つの名前（webviewSection）と ID にし、コマンド名も `deguboard.backlog.*` から場所によらない名前に変える。VS Code の左パネルの中だけで、エディタのパネル（詳細）と dg serve のブラウザでは出さない。Plan の見出しと詳細のタイトルにも出さない。頼む入口は右クリックに置かない（ADR-027）。

## Acceptance criteria

- [ ] 左パネルのボード・バックログ・履歴のチケットの行と Iteration・Epic の見出しが、右クリックの文脈に場所によらない 1 つの webviewSection と ID を載せる。ID のない見出しと Plan の見出しには載せない（テスト）
- [ ] 「詳細を開く」がその ID の詳細（チケット・Iteration・Epic）を開き、「ID をコピー」がその ID をコピーする（テスト）
- [ ] package.json の webview/context の when が 1 つの webviewSection を見て、コマンド名が場所によらない名前になり、core の WEBVIEW_CONTRACT と package.json が合っていることをテストが確かめる
- [ ] 右クリックで見出しの開閉が起きない
- [ ] 右クリックのメニューを出す場所を書いたコメント（context-menu.ts・extension.ts・ask-menu.tsx・parts.tsx・client.ts の「バックログの行だけ」）が、今の場所に合っている
- [ ] PR に、ボードと履歴の行と見出しで右クリックのメニューを出したスクリーンショットがある
