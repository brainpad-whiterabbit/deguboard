## Summary

待った秒数（waited_seconds）は、それを記録するようになった後に閉じた Run にしか入らない。会話記録のパスが残る 30 日の間の Run は、閉じるときと同じ関数で記録から数え直せるので、run refresh が使用量と一緒に待ちも数え直すようにする。進行中の Iteration の振り返りで、作業時間を使えるようにするため。

## Acceptance criteria

- [ ] run refresh が閉じた Run の waited_seconds を、閉じるときと同じ関数で数え直し、何度数えても同じ値になり、期間を過ぎた Run は今の値を残して警告することをテストが確かめている
- [ ] requirements.md の MT-5 の項が、待ちも数え直すことに合っている
