## Summary

dg は CLAUDE.md を書かないので、Skill を通さずに頼んだ作業（「このバグを直して」）はチケットを通らない。また release・audit などの guide は、リポジトリの規約（CLAUDE.md・AGENTS.md・README）からリリース手順や検査を探す。導入した人が CLAUDE.md（AGENTS.md）に足すとよい最小限の数行と、書かないほうがよいもの（dg の手順の写し。手順を変えるのは guide.notes）を usage guide で案内する

- [ ] docs/usage.ja.md に同じ構成の節があり、英語版と節の構成が揃っている
- [ ] README.md と README.ja.md の Tips から、その節へのリンクがある
