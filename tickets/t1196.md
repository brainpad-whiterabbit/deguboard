## Summary

s43 の見直し（観点：README、文書と実装）の指摘。docs/usage.md と docs/usage.ja.md の「Label axes and vocabulary」の節に、この Iteration で入った利用者に見える振る舞いのうち次が書かれていない。

- 軸を決めた後の画面：起票と編集でラベルを軸ごとに語彙から選ぶこと、語彙にないラベルに印が付くこと、行のラベルが軸ごとの色で出て手順のラベルが目立たないこと（t1184・t1188）
- 統合の後に古い名前を書くか絞ると、統合先へ読み替えて警告すること（t1187、TK-13）
- 軸を使うと `dg lint` がラベルと語彙のずれを指摘すること（t1185）

あわせて、Names の項の使えない名前の説明が `dg label add --help`（ハイフンで始まる名前も拒む）と合っていない。README.md と README.ja.md の Tips から、この節へのリンクがない。

## Acceptance criteria

- [x] docs/usage.md の「Label axes and vocabulary」の節が、軸を決めた後の画面の変化、統合済みの名前の読み替えと警告、`dg lint` のずれの指摘を、それぞれ 1〜2 文で書いている（細部は `dg lint --help` などのヘルプに任せる）
- [x] Names の項の使えない名前の説明が `dg label add --help` と食い違っていない（列挙をやめてヘルプに任せてもよい）
- [x] README.md の Tips に、この節への 1 行のリンクがある
- [x] docs/usage.ja.md と README.ja.md が英語版と同じ節の構成で同じ内容を持ち、`mise run check:docs` が通る
