## Summary

チケットに元のチケットと原因の種類を残せるようにしたうえで（依存先のチケット）、起票する役が付け忘れないように手順で案内する。付けるのは、マージ済みのチケットの変更から出た不具合（振る舞いの誤りと、変更と同時に直すべきだった文書のずれ）を起票するとき。見直しの中で範囲の外とされた指摘、見直しで残した軽い指摘の片付け、前からのずれ、振り返りの Try、機能の追加には付けない。

振り返りの指標 escaped-defect-rate の定義を origin を数える形に変えるのは、このチケットではしない（マージの後の振り返りで提案して、人が承認してから）。

## Acceptance criteria

- [ ] import と audit の guide に、マージ済みのチケットの変更から出た不具合を起票するときに `origin` と `origin_cause` を付けることと、付けない場合が書いてある
- [ ] review の guide で、範囲の外とされた指摘を起票するときは origin を付けない（見つけ損ねではない）と分かる
- [ ] guide のスナップショットが更新され、`mise run check:docs` が通る
