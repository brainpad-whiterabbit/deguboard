## Summary

カンバンとバックログの行には Epic が出ず、どの行がどの Epic か・Epic なしかは、札で絞らないと分からない。Epic の札（EpicChipRow）にマウスを載せる・Tab で止まると、その Epic の行を光らせ、ほかの行を薄くする。「なし」の札は Epic のない行を光らせる。札を押して絞る動きは今のまま。モック（案F）: https://claude.ai/artifact/CCgGgX4A87fkHGWHFgP6TA

## Acceptance criteria

- [x] 札に触れると該当する行を光らせ、ほかを薄くし、離れると戻る。「なし」の札は Epic のない行を光らせる（カンバン・バックログの両方をテストで示す）
- [x] 行に触れても光らせない。絞り込んでいる間は札に触れても何もしない
- [x] 畳んだ節は開かず、スクロールもしない。「ほか N」に畳まれた札は今のまま
- [x] 札を押したときの絞り込み・解除・ハッシュは今と同じ
- [x] requirements の UI-10 に、札に触れると該当の行が分かることを 1 文で足す
