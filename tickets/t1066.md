## Summary

今は消す手段が場所ごとに散らばっていて、まとまった手順がない。docs/usage.md と docs/usage.ja.md にアンインストールの節を足し、README の導入の節から引く。

## Acceptance criteria

- [ ] docs/usage.md と docs/usage.ja.md に同じ構成のアンインストールの節があり、3 つのやめ方（このマシンで止める・このクローンから外す・チームでやめる）ごとに消すものと手順を書いている
- [ ] VS Code 拡張を最後に消す理由（フックが起動ファイルを呼ぶので、先に消すとフックを外せなくなる）を書いている
- [ ] データブランチは残すことを勧め、消すときは手で消すコマンドを書いている
- [ ] README.md と README.ja.md の導入の節から、その節へリンクしている
- [ ] `mise run check:docs` が通る
