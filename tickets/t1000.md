## Summary

s37 の見直し（観点：文書と実装・構成）で、t990 と t996 が足した docs/how-it-works.md と docs/how-it-works.ja.md（図を含む）に、実装と食い違う記述が見つかった。どちらに合わせるかは計画で決める。

- データの置き場所：Overview は、データを「同じリポジトリの orphan ブランチ `deguboard`」に置くと書く。一方、`git.data_remote` で別のリポジトリに、`git.data_branch` でほかのブランチ名にできる（usage の Keep the data in another repository）
- 次の一手の事実：「How the agent decides the next step」の本文と docs/images/how-it-works-next.svg・.ja.svg は、`dg next` が検査の結果からも段階を求めると書く。一方、packages/core/src/commands/next.ts は検査の結果を読まず、検査は `dg gate` が判定する
- 使用量：Run の節は、どの Run も使用量（トークン）を持つと読める。一方、使用量は `metrics.read_transcripts` が true のときだけ数え、既定は false（注記は「Cases not drawn」にしかない）
- 入口：Overview は `dg hook` を含む入口を「ロジックを持たない」とまとめる。一方、`dg hook` の判定は Core の packages/core/src/commands/hook.ts にあり、`dg hooks install` などの処理は packages/cli/src/hooks.ts にある（後者は別のチケットで扱う）
- 描いていない場合：「Cases not drawn」に、フックが届かないときの見直しの結果（持ち主のない保留として見直しの記録になる。RN-9）と、手直しの Run の閉じ方（RN-6）がない
- Core の一覧：図と本文の Core のモジュールに、packages/core/src/actions/ がない

## Acceptance criteria

- [x] データの置き場所の記述が、`git.data_remote`・`git.data_branch` で変えられることと食い違わない
- [x] 次の一手の本文と図の「事実」が、next.ts が読む事実と食い違わない
- [x] Run の節の使用量の記述が、`metrics.read_transcripts` の既定と食い違わない

- [x] 英語版と日本語版（図を含む）が同じ節の構成で同じことを書いている
