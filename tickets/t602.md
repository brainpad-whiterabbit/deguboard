## 概要

値にできない判断の基準（リポジトリ固有の見直しの観点など）を書き足せる場所が、今はインストールした SKILL.md の書き換えしかない。書き換えると dg skill install の更新を受け取れなくなる。config の `guide.notes.<topic>` が指すリポジトリのファイルを、dg が guide と節の本文の決まった位置に差し込む。

## 受け入れ条件

- [ ] `guide.notes.<topic>` のファイルの中身が、`dg guide <topic>` と、その topic の節の本文の決まった位置に入る
- [ ] 指したファイルがなければ、warnings に出して guide は出す
- [ ] `dg skill install` が手を加えた SKILL.md を残すときの警告で、guide.notes に移すよう案内する
- [ ] AG-2・CL-5 の約束を直し、テストがある
