## 概要

開いている worktree のブランチに紐づくチケットの ID・Status と、Run が実行中かをステータスバーに出し、サイドバーを開かずに今の作業の場所を確かめられるようにする。

## 受け入れ条件

- [ ] 今のブランチがチケットの branch と一致するとき、ステータスバーにその ID と Status が出る
- [ ] そのチケットに実行中の Run があれば、実行中であることがわかる
- [ ] 紐づくチケットのないブランチでは、ステータスバーに出さない
- [ ] 項目を押すと、そのチケットの詳細のパネルが開く
- [ ] チケットの Status やブランチが変わると、開き直さなくても表示が変わる
