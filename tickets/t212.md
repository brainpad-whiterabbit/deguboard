## 概要

Iteration の goal・name・start・end は create のときにしか入れられず、s7 のように目標を空で作ると直す手段がない（.git/deguboard/ の直接編集は禁止）。Epic の epic update にそろえて iteration update を core のコマンドに足し、CLI・HTTP・MCP に写す。マージ後に s7 の目標を入れる。

## 受け入れ条件

- [ ] dg iteration update <iteration> で --name・--goal・--start・--end を指定したものだけ直せる
- [ ] 閉じた Iteration でも直せるか拒否するかを決め、ヘルプと requirements.md に書く
- [ ] core のテストで、指定した属性だけが変わることと日付の形の検査を確かめる
- [ ] マージ後に s7 の goal を入れる
