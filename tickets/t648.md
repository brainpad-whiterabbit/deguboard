## 概要

guide を英語にする前の準備（t488〜t490 の前に入れる）。英語の見出しの補足は半角の「 (…)」になり、同じトピックの中の参照は英語の `the "節" section` の形になる。いまの節の引き方と検査は全角の「（…）」と「」しか読まないので、英語の guide で節を引けず、参照の切れも見つけられない。guide の config の埋め込みが空の値を「なし」で埋めるのも、英語の guide に日本語を混ぜる。

## 受け入れ条件

- [ ] 見出しの末尾の半角の「 (…)」の補足を除いた名前でも節を引ける。sections.ts の guideSectionName と check-docs の guideSectionNames が同じ扱いをする
- [ ] flow.test の、返す本文の参照が閉じているかの検査が、英語の参照（the "節" section）も読む
- [ ] 同じトピックの中の英語の節の参照が実在しない節を指すと、check:docs が落とす
- [ ] guide の config の埋め込みで、空の値と空の配列が none になる
- [ ] mise run check が通る
