## Summary

Workflow の既定値は resolve.ts が正本だが、guide・Skill の雛形・usage（英語版と日本語版）・README・ADR がそれぞれ既定値を文で書いていて、既定値を 1 つ変えるだけで多くの文書を直すことになる（t1144）。guide は config の値と同じくカンバンの今の Workflow の値を埋め込み、利用者向けの文書は既定値を並べずに dg workflow show を指し、ADR は個々の鍵の値でなく既定を決める原則と理由を書く。

## Acceptance criteria

- [ ] guide と Skill の雛形が Workflow の既定値を文で書かず、カンバンの今の値を dg guide の出力に埋め込む（config の値と同じ仕組み）
- [ ] usage.md・usage.ja.md・README.md・README.ja.md・packages/vscode/README.md が既定値の一覧を持たず、dg workflow show と Workflow の節を指す
- [ ] ADR（003・009・011・026・030）が既定を決める原則と理由を書き、個々の鍵の既定値を写さず、値の正本を resolve.ts に案内する
- [ ] 既定値を確かめるテストのほかに、既定値が変わると落ちるテストがない（振る舞いを確かめるテストは Workflow の値を明示する）
- [ ] mise run check:docs が文書の中の Workflow の既定値の書き写しを検出する（できないときは理由を PR に書く）
