## Summary

見直し（s31、構成・テスト）。t857・t858 で Skill の判定と更新を core に移したが、次が残った。

- 拡張の入口（vscode/src/skills.ts の refreshSkillsOf）が、作業フォルダごとに core を呼び、置き場所ごとにまとめて重複を外している（ADR-033 の入口にロジックを持たない、に反する）
