## 概要

packages と scripts のコードに ADR 番号の参照が約 280 か所あり（ADR-025 だけで 108 か所）、ADR を分割・統合するたびにこれを張り替えることになる。新しい運用では、コードから指すのは番号の変わらない要件 ID と「なぜ」にし、ADR 番号はファイルの先頭のコメントの 1 つまでにする。

## 受け入れ条件

- [x] packages（dist を除く）と scripts のどのファイルも、ADR 番号を指すのは先頭のコメントの 1 か所までになっている
- [x] 外した参照のうち約束を守るコードには、対応する要件 ID か「なぜ」のコメントが残っている
- [x] テスト名とテストの文字列から ADR 番号がなくなっている
- [x] mise run check が通る
