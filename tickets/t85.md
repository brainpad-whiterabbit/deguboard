## 概要

対象の Iteration のチケットがすべて done かを確かめ、リポジトリの案内（CLAUDE.md・docs のリリースの節）の手順でリリースする。リリースの PR のマージと公開の前に承認を求め、最後に人の承認を得て iteration close する。

## 受け入れ条件

- [ ] dg guide release があり、dgrelease の Skill が配られる
- [ ] マージ・公開・Iteration を閉じる前に承認を求める手順になっている
- [ ] リリースの手順がないリポジトリでは人に聞く
