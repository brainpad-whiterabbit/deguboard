## 概要

t244 と t245 で細部を正本へ戻し、採らなかった案を絞った後に、ADR ごとの大きさを測り直す。それでも予算の 90% に近い ADR が、実は 2 つのテーマを持っているなら（例：ADR-004「エージェントと状態の記録」がエージェントの手順と照合の 2 つになっていないか）、テーマごとに 1 本の決まり（ADR-001）に沿って 2 本に分ける。分けるのは方針の反転ではないので、元の ADR を置き換えにはせず、テーマを狭めて書き換え、新しい ADR に分けた側を移す

## 受け入れ条件

- [x] 細部を戻して絞った後の各 ADR の大きさを測り、分けるかどうかの判断と理由が PR の本文にある
- [x] 分けた場合、それぞれの ADR が 1 つのテーマの今の決定だけを持ち、docs/adr/README.md の一覧（番号・タイトル・テーマ・更新日）と、ADR を番号で参照する文書・CLAUDE.md・コードのコメントのリンクが直っている
- [x] 分けない場合、このチケットは PR なしで判断を記録して終える
- [x] mise run check が通る
