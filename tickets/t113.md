## 概要

観点はアーキテクチャと設定ファイル。web/types.ts の METRIC_UNITS と pages/runs.tsx の RESULT_KEYS は core に値が増えても漏れを検出できない。history.tsx の countsOf は core の Iteration の集計の写し。core に本番から使われていない export がある（actions の公開 API、METRIC_VALUES・runUsageSchema・stepIdSchema・findAdapter など）。.oxlintrc.json の AG-6 の対象に run と agents が入っていない

## 受け入れ条件

- [x] AG-6 の lint の対象に run と agents が入るか、外す理由が ADR-007 にある
