## Summary

PR #635（t674）の squash マージは済んだのに、リモートのブランチがもう消えていて削除が HTTP 404 になり、gh pr merge が exit 1 を返した。そのため dg は GIT_ERROR を返し、消した worktree を戻し、mise run setup を回し直した。gh が失敗を返しても PR が MERGED なら、マージは成功として扱う。

## Acceptance criteria

- [ ] gh の merge が失敗を返しても PR の状態が MERGED なら、dg pr merge は成功を返し、ブランチの削除の失敗を warnings に出すことをテストが確かめる
- [ ] そのとき worktree を戻さず、準備のコマンドも回し直さないことをテストが確かめる
- [ ] PR が MERGED でないときは、今までどおり GIT_ERROR を返して worktree を戻すことをテストが確かめる
