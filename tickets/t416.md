## 概要

ADR-005（t415）のとおり、t400 で足したチケットごとの plan の Run をやめる。同梱のテンプレートの steps から plan を外し、dg guide の plan・work・parallel・run の記録の案内を消し、このリポジトリの Workflow からも plan を外す。記録済みの plan の Run は実績として残す。

## 受け入れ条件

- [x] 同梱の software-development・general の steps に plan がない
- [x] dg guide の plan・work・parallel・run・all・review が plan の Run を記録するよう案内していない
- [x] このリポジトリの Workflow（software-development）に plan の step がない（workflow set で外す）
- [x] 記録済みの plan の Run があっても、validate・run list・metrics show が警告や失敗を出さない
- [x] requirements.md と guide の記述が ADR-005 と合い、mise run check が通る
