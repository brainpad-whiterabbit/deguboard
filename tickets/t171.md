## 概要

VS Code 拡張の左パネルの view/title に、同期と並べて歯車を置く。押すと同じパネルの中が設定画面（#config）に切り替わり、もう一度押すか「カンバンに戻る」で戻る。 画面は config.show で全項目と既定値を読み、値を変えるたびに config.set で保存する。 設定はチームで共有する config.yaml なので、VS Code の settings.json は使わない（requirements.md 5.10「利用者ごとの上書きは設けない」）。 画面の模型：https://claude.ai/artifact/S2kpmsh8JobMP7w8UzNLi8

## 受け入れ条件

- [ ] 左パネルの右上に歯車があり、押すとカンバンと設定画面が切り替わる
- [ ] config.yaml の全項目を「コミットと push」「エージェント」「計測」「Git」のまとまりで出し、各項目に名前・キー・説明（configSchema のコメントから取る）と型に合う入力欄（選択欄・チェック・テキスト・リスト）を出す
- [ ] 値を変えると config.set で保存し、保存した項目と値を短く出す。拒否されたときは理由を出して値を戻す
- [ ] 既定から変えた項目に印と「既定に戻す」を出す
- [ ] 設定がチーム全員に効くことを示す帯を常に出す
- [ ] 検索欄で項目を絞れる
- [ ] git.remote・git.base_branch・worktree.root は保存の前に確認を挟む
- [ ] dg serve のブラウザ版でも
- [ ] requirements.md の UI の節に設定画面を足す
