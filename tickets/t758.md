## Summary

sync は fetch・rebase・push と、チケットごとに gh を直列に呼ぶ照合の全体で書き込みのロックを持つ。ほかの書き込みはロックを 10 秒待って落ちるので、PR のあるチケットが多く gh が遅いと、フックの Run の記録・run finish・claim・画面からの書き込みが落ちる。フックの失敗は警告に変わるので、Run の記録が黙って欠ける。

## Acceptance criteria

- [ ] sync の照合は、gh と git で事実を集める間は書き込みのロックを持たず、ロックの中で最新の状態に対して判定し直して書く
- [ ] sync が gh を待っている間に、ほかの書き込みが待たずに通ることをテストで示す
