## 概要

dg ask の候補は、Iteration が active でない着手可の todo にすべて「計画を立てる」を先頭にする（packages/core/src/commands/ask.ts の askActions）。closed の Iteration に残った持ち越しの todo は、先に別の Iteration に割り当てるのが合う。t295 の 2 回目の見直し（PR #287）で出た。

## 受け入れ条件

- [ ] closed の Iteration に入った todo のチケットでは、候補の先頭（おすすめ）が割り当てる（/dgassign）になる
- [ ] planned の Iteration の todo は計画を立てる、active の Iteration の着手可の todo は進めるが先頭のまま変わらない
- [ ] 3 つの状態をテストで確かめる
