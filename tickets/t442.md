## 概要

Run を claim で自動で開く（同じ Epic の後続）には、呼んだエージェントの agent 名（Adapter の名前）が要る。各 Adapter が自分の環境変数から判定できるようにし、`run start` の `--agent` も省けるようにする。Claude Code では `AI_AGENT`（`claude-code_…`）と `CLAUDECODE=1` が付いていることを確かめている。

## 受け入れ条件

- [x] Adapter（Claude Code・Codex・Copilot）が環境変数から自分を判定でき、判定できる変数がない Adapter は判定しない
- [x] `run start` で `--agent` を省くと判定した agent 名を使い、判定できなければ今までどおり `--agent` を求める
- [x] 判定の振る舞いをテストで確かめる
- [x] requirements（AG-5・RN 周り）と `run start --help` を判定に合わせて直す
