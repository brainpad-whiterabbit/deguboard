## 概要

吹き出し・右クリック・Shift+F10 のメニューで頼むことを選ぶと小窓が開くだけで、コピーには小窓のボタンか ⌘↵ がもう一度要る。指示を足さないことが多いので、選んだ時点で依頼文をコピーする。

## 受け入れ条件

- [x] 吹き出し・右クリック・Shift+F10 のメニューで頼むことを選ぶと、小窓が開き、その依頼文がクリップボードに入って「コピーしました」が出る
- [x] 小窓の札で頼むことを選び直したときも、その依頼文をコピーする
- [x] 指示を打ったあとは、今のとおりコピーのボタンか ⌘↵ でコピーする
- [x] コピーに失敗したら、小窓は開いたまま理由を出す
- [x] 選んだときのコピーにテストがある
