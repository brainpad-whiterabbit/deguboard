## Summary

同梱の dist/cli/dg.mjs は 2MB を 1 ファイルに束ねていて、毎回全部を評価するので、速い経路（PreToolUse を CLI 全体を読まずに判定する）が効かない。Marketplace の利用者のフックはこれを呼ぶ。dg.mjs を小さな入口にして、本体を別の chunk にする。ADR-008 の「同梱の CLI を 1 つの ESM に束ねる」を変える。

## Acceptance criteria

- [ ] 同梱の dg.mjs は入口だけを持ち、PreToolUse の速い経路は本体の chunk を読まない
- [ ] フックのコマンドの形と同梱の dg のパス（dist/cli/dg.mjs）は変わらず、入れ直しは要らない
- [ ] VSIX に dg の chunk が入り、VSIX から入れた dg で dg --version と PreToolUse が動くことを PR の本文に書く
- [ ] ADR-008 の同梱の CLI を束ねる項を書き換える
- [ ] 同梱の dg.mjs で PreToolUse を 5 回測り、前と後の中央値を PR の本文に書く
