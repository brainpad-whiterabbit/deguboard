## 概要

t481 の見直しで出た判断。branch のあるチケットを PR なしで人が done にしたとき、実装の Run を success で閉じると、ADR-005 の success（PR を作った）とずれ、成功の件数が多く出る。abandoned と同じく failure で閉じ、error に「PR なしで完了」を残す。変更は run.ts の runsClosedByMove の 1 箇所（t544 で ticket.ts から移した）と、ADR-005・RN-6・guide-run.md の「結果」。runsClosedByMove は照合（sync）も使うので、別のマシンで PR なしの done になったチケットの実装の Run も同じく failure で閉じるようになる（t544）。

## 受け入れ条件

- [ ] PR なしで done にした実装の Run が failure で閉じ、error に PR なしで完了したと残る（テストで確かめる）
- [ ] 照合が閉じる PR なしの done の実装の Run も failure になる（テストで確かめる）
- [ ] ADR-005・RN-6・ticket move --help・sync --help・guide-run.md の結果の記述がコードと一致する
- [ ] mise run check が通る
