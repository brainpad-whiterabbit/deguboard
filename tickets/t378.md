## 概要

## 受け入れ条件

- [ ] 承認待ちの Plan と review のチケットの件数が、Activity Bar のバッジかビューのタイトルでわかる

- [ ] 通知は設定で切れる（設定の置き場所は UI-14 に合わせる）
- [ ] 今の未 push・未取り込みのバッジとの見分け方が拡張の README に書いてある
