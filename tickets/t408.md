## 概要

PR の要らない作業（Run のデータの整備）。t396 で足した `dg run refresh` を、このリポジトリの閉じた Run（2026-11-05 時点で 671 件、うちモデル名が null の 63 件など）に流し、会話記録が残っている分のモデル名と使用量を埋め戻す。`--dry-run` で差分を見てから書く。取れない値は今の値を残す（RN-4・MT-5）。`tools`（t399）は refresh の対象外なので埋まらない。

## 受け入れ条件

- [ ] `run refresh --dry-run` の差分（書き換える Run の数と項目）を報告した
- [ ] 差分を確かめてから書き、書いた後に `metrics show` の欠けの数（`missing`）が減ったことを、前と後の数で報告した
- [ ] 取れなかった Run の数と理由（会話記録が残っていない、など）を報告した
