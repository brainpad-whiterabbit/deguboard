## Summary

観点：README。Walkthrough の手順 2 は `dg ticket create` を、手順 3 は `dg skill install` を、それぞれターミナルで打たせる。一方、README.md（21〜22 行あたり）では Skill は「Start with this repository」が入れ、`dg` を PATH に置くのは「Terminal users only」の任意の手順としている。拡張だけを入れた利用者の多くは PATH に `dg` がないので、手順のとおりに打つと command not found になる。手順 1 だけが「dg が見つからないとき」を案内している。あわせて、手順の吹き出しの説明が、開いているターミナルへ送る道（README の「Send」）に触れていない。v0.24.0 より前からあるずれ。
