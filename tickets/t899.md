## Summary

フックを持つのは Claude Code だけ。Codex・Copilot CLI などのほかのエージェントで使うと、Run の記録がエージェントの `dg run` 呼び出し任せになり、dg を通さない ready・マージや直接の書き換えを止めるガードが効かない。今の README には「設定は要らない」としか書いていないので、欠けるものを書いて利用者が選べるようにする。注意書きは製品の名前ではなく、dg のフックが届くかどうかで書く。フックのある製品を挙げるのは usage.md の 1 か所だけにし、t896・t897 が入ったときに直すのはその 1 行で済むようにする。

## Acceptance criteria

- [x] README.md の、ほかのエージェントを案内する項に、dg のフックが届かないエージェントでは Run がエージェントの `dg run` 呼び出しでしか残らず、`dg pr merge` を経由しないマージを止めるものがないことを 1〜2 文で書き、docs/usage.md の「Use other agents」節へ案内している
- [x] docs/usage.md に新しい節「Use other agents」があり、フックのある製品を挙げるのはその節の 1 か所だけで、フックが届くかは `dg hooks check` で確かめると案内している
- [x] 同じ節に、フックが届かないと変わること（サブエージェントの Run の自動の開閉がなく、実装と手直しを親が自分で行う・AG-10 のガードが効かない・応答の終わりに dg の外の変更を知らせない）と、トークン数は会話記録を読めるエージェント（今は Claude Code・Codex・Copilot CLI）だけ、見直し役を起動できない環境では人に見直しを頼むことを書いている
- [x] README.ja.md と docs/usage.ja.md が同じ内容で、英語版と節の構成が合っている
