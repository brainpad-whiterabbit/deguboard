## Summary

フックを持つのは Claude Code だけ。Codex・Copilot CLI などのほかのエージェントで使うと、Run の記録がエージェントの `dg run` 呼び出し任せになり、dg を通さない ready・マージや直接の書き換えを止めるガードが効かない。今の README には「設定は要らない」としか書いていないので、欠けるものを書いて利用者が選べるようにする。t896・t897 が入れば、Codex の分の記述はそれらのチケットで直す。

- [ ] README.md の、ほかのエージェントを案内する項に、フックがあるのは Claude Code だけで、ほかでは Run がエージェントの `dg run` 呼び出しでしか残らず、`dg pr merge` を経由しないマージを止めるものがないことを 1〜2 文で書き、細部は docs/usage.md へ案内している
- [ ] docs/usage.md に、フックがないと欠けるもの（サブエージェントの Run の自動の開閉、AG-10 のガード、トークン数は Claude Code・Codex・Copilot CLI だけ、応答の終わりの dg の外の変更の通知、サブエージェントを使えないときの独立した見直し）を挙げている
- [ ] README.ja.md と docs/usage.ja.md が同じ内容で、英語版と節の構成が合っている
