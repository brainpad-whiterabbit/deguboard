## 概要

チケットの claimed_by は user.name@ホスト名 を書くだけで、起票者も主体の種別（人か AI か）も残らない。起票者（created_by）と担当者（assignee）を分け、識別子をユーザ名＋種別の 1 文字列（eiki / eiki/agent）にする。担当者は claim で自動で付き、create / update でも付けられる。起票者の既定は操作した主体で、ユーザの指示による起票は --created-by human で明示する。

## 受け入れ条件

- [ ] ticket create / import が created_by を記録し、既定は操作した主体の ID、--created-by human でユーザ本人になる
- [ ] ticket create / update / claim で assignee を付けられ、claim は操作した主体で上書きし、unclaim と todo / abandoned への move で消える
- [ ] 主体の ID は <ユーザ> と <ユーザ>/agent の形で、--user / DEGUBOARD_USER で変えられる（--actor-id は廃止）
- [ ] 旧 claimed_by のチケットは assignee として読める
- [ ] web の詳細に起票者と担当が出て、担当を編集できる
- [ ] dg guide・requirements.md・ADR-004・ADR-003・CLAUDE.md が新しい規則に揃っている
