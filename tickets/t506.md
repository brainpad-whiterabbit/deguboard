## 概要

止まった Run への操作は画面のボタンではなく、ほかと同じく頼む小窓の依頼文のコピーで行う。Run の状態に合わせて候補を出す。

## 受け入れ条件

- [ ] 止まっているか空回りの Run のチケットで、頼む小窓に「続きを頼む」と「中断として閉じる」の候補が出る
- [ ] 中断として閉じる依頼文が、dg run finish --result interrupted で閉じる手順に沿う
- [ ] 作業中・あなたの番の Run のチケットでは、これらの候補を出さない
