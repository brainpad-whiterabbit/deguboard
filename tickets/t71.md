## 概要

Epic のタブをなくす。open の Epic は進捗つきでバックログの欄に並べ、押すとバックログをその Epic のチケットに絞る（もう一度押すと解除）。Epic の作成は欄の「+」に移す。
Epic の詳細のページ（#/epics/e2）は残し、欄の番号・チケット詳細の Epic・履歴の Epic の行から開く。詳細を開いているときはバックログのタブを選んだ表示にし、VS Code のサイドバーからは Iteration の詳細と同じくエディタ領域のパネルに開く。
改善案：https://claude.ai/artifact/Sy4j28W4Vkee96x6WtNagu
