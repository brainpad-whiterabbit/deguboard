## 概要

今の check:docs には細部の書き足しを止める検査がない（重複は完全一致で、ADR は比べる対象の外）。コードの ADR 番号の参照も先頭コメントの存在しか見ず、置き換え済みの ADR を指したままでも通る。依存先のチケットで ADR-001 に決めた要件の 1 項の上限と、置き換え済みの ADR への参照を検査する。要件と ADR を削り終えてから入れる。

## 受け入れ条件

- [ ] `mise run check:docs` が、ADR-001 の上限を超えた要件の項を ID 付きで指摘する
- [ ] `mise run check:docs` が、コードとテスト（コメント・テスト名・文字列）にある置き換え済みの ADR への参照を、ファイル付きで指摘する
- [ ] 2 つの検査のテストが test/scripts/check-docs.test.ts にある
- [ ] scripts/check-docs.mjs の冒頭の検査の一覧が合っており、`mise run check` が通る
