## 概要

`dg ask` が組む依頼文の定型の文（頼む 1 文・dg の呼び方・guide を読む 1 文・Skill の次の行の短い頼みごと）が日本語で固定で、表示言語が英語でも日本語の指示文がコピー・ターミナルへ送られる。表示言語が英語なら英語の依頼文を組む。指示（note）とチケットの中身は書いた言葉のまま入れる。UI-11 の「依頼文は書いた言葉のまま」を、定型の文は表示言語に合わせる約束に直す。

## 受け入れ条件

- [ ] 表示言語が英語のとき、作った依頼文の定型の文がすべて英語になる（Skill の形と文章だけの形の両方）
- [ ] 英語の依頼文が、コピーとターミナルへの送りの両方で使われる
- [ ] 表示言語が日本語のときは、今と同じ依頼文になる
- [ ] `dg ask` に言語を渡す口が CLI と HTTP の両方にあり、省けば今までどおり日本語になる
- [ ] requirements.md の UI-11 を直す
