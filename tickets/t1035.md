## Summary

設定画面に書き先の 3 つ目のタブ「Workflow」を足し、今効いている workflow.yaml を今の設定画面の部品（書き先の帯・検索・節の見出しと要約・guide.notes と同じ名前とキーを左に置く表・「変更あり」と左の線・頼む吹き出し）で読むだけで出す。節と行は YAML の構造のまま。変更は画面では行わず、行から /dgconfig に頼む。案は t1030 で決めた（https://claude.ai/artifact/1Us2zHvxxiD6J7W6wFELJY の第 6 版）。

## Acceptance criteria

- [x] 設定画面に「Workflow」のタブがあり、workflow.yaml の 6 つの項目を節（状態・境目・例外・WIP の上限・流れの段階・カンバンの管理）、その下のキーを行（名前とキーが左、値が右）にして読むだけで出す。入力欄と保存の操作はない
- [x] ファイルで省いた項目も既定の値で出し、既定と違う行には今の設定画面と同じ左の線と「変更あり」（title に既定の値）を付け、独自の段階には「独自の段階」の札と after・guide を出すことがテストで示されている
- [x] dg workflow show --json が既定で埋めた値と項目ごとに既定と違うかを返し、画面はそれを写すだけになっている（判定は core のコマンド定義）
- [x] 行と節の見出しの頼む吹き出しから、その項目の説明と変更を /dgconfig に頼め（core の ask に workflow のキーを渡す）、dgconfig の手順が workflow.yaml を扱い、変更は before → after を人に見せて承認をもらってから dg workflow set を呼ぶよう案内している
- [x] 検索で名前・キーから行を絞れ、サイドバー幅でも崩れない。requirements の UI-14 が直り、PR に変えた画面のスクリーンショットがある
