## 概要

surface が sidebar のとき、KanbanForge のサイドバーと同じ構成にする。上部はブランドなしの下線タブ 4 つ（カンバン / バックログ / Epic / Iteration）と小さな Project select と同期の印。カンバンは列を横に並べず、状態ごとの折りたたみ節を縦に積み（見出しに状態名と件数、空なら破線枠「なし」）、チケットは高さ一定の 1 行 TicketRow（状態の丸印・番号・タイトル省略・優先度の印）で出す。ドラッグ＆ドロップは節の間で維持し、ドラッグ直後の click は無視する。バックログも TicketRow の縦並びにし、検索と絞り込みを 2 行に詰める。Epic・Iteration は一覧と選んだものの中身をサイドバーの幅で縦に出す。サイドバーでは ticket ルートを出さずバックログに寄せる。body の背景を sideBar-background にし、.topbar・.column が同化する点を直す。@container (max-width: 260px) で詰める。panel・browser は今の横並びの列とテーブルのまま

## 受け入れ条件

- [ ] サイドバーの幅（300px 前後）でカンバンが状態ごとに縦に積まれ、横スクロールが出ない
- [ ] 行をドラッグして別の節に落とすと Status が変わり、拒否されると通知が出て戻る。ドラッグ直後にチケット詳細が開かない
- [ ] 各節は折りたためて、空の節は破線枠に「なし」と出る
- [ ] バックログ・Epic・Iteration がサイドバーの幅で崩れず、検索と絞り込みが使える
- [ ] panel と browser の表示（横並びの列・テーブル）は変わらない
- [ ] 260px 以下でもタブと行が折り返さずに収まる
- [ ] app.test.tsx に sidebar の描画のテストがある
