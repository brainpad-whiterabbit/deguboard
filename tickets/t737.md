## Summary

dg init 前の始め方の画面から、PATH に dg がなくても、ボタン 1 つで init・Skill・フックの導入まで済ませられるようにする。拡張を入れてから使い始めるまでの手数を 1 回にする。

## Acceptance criteria

- [ ] dg init 前の始め方の画面に、VS Code の中だけ「このリポジトリで始める」ボタンを出す（dg serve のブラウザではコピーのまま）
- [ ] 押すと専用の新しいターミナルを開き、起動ファイルの絶対パスで dg init・dg skill install・dg hooks install を続けて実行する（Enter まで送る。PATH に dg がなくても動く）
- [ ] 終わると始め方の画面が普段の画面に変わる
- [ ] 始め方の画面の「dg が PATH にあれば」の文と、Walkthrough（media/walkthrough/init*.md）の README のビルド手順を指す案内を、ボタンを勧める形に変える
- [ ] ADR-027 の始め方の画面の扱い（コピーだけ）を、ボタンがターミナルで実行する形に書き換える
- [ ] PR の本文に始め方の画面のスクリーンショットを載せる
