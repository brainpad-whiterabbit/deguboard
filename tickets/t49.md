## 概要

t44 のように PR も作業ブランチも要らない作業を開発フローで扱う。claim でブランチを記録せず、照合の対象から外し、受け入れ条件をすべて確かめたら agent が直接 done にする。確かめられない項目があれば review に置いて人に頼む。あわせて、gh が PR がないと答えた形を閉じた PR と誤って警告するのを直し、update で branch を付け外しできるようにする

## 受け入れ条件

- [ ] ticket claim --no-branch で branch を記録せずに in_progress になり、branch との同時指定は拒否する
- [ ] ticket update --branch で branch を付け、none で外せる
- [ ] branch のないチケットは sync の照合で動かず、警告も出ない
- [ ] gh が PR がないと答えた review のチケットに「PR がマージされずに閉じている」と警告しない。閉じた PR には今までどおり警告する
- [ ] guide work に PR の要らない作業の流れ（--no-branch・ticket check・すべて付いたら move done・残れば review と報告）を書き、create・finish・overview も合わせる
- [ ] requirements.md の ST-3〜ST-5 と TK、ADR-004、development.md、CLAUDE.md を直す
- [ ] mise run check が通る
