## Summary

人の方針（2026-11-10）：Iteration の予定の開始日・終了日はやめ、実績として開始日時と終了日時を記録するだけにする。検討して形を決め、実装のチケットに分ける（このチケットは PR なし）。

影響の範囲：iteration create・update の --start・--end、close のときに end を書き換える処理、started_at の新設（今は記録がない。closed_at はある）、「残り n 日」「n 日超過」と終了日を過ぎたときの次の一手（overdue）、carry（持ち越しを相談する）の頼むことと画面の文、edit の「名前・目標・期間を直す」の文、History の期間の表示、今あるデータの start・end の移行、requirements.md の IT の項と ADR。

決めること：今ある start・end の扱い、started_at を記録する時点（最初の claim で active になるとき・iteration start）、History の期間の表示。
