## Summary

ask の小窓は候補を全部並べるので、8 つほどで 2 段に折り返して小窓の上の 3 割を取り、選んでいる候補とおすすめ（★）の区別も弱い。行に出す候補を、おすすめ・選んでいる候補・残りを開く「ほか N ▾」の 3 つまでにする。おすすめの印は、入力欄の ★ と行の吹き出しの一覧の「おすすめ」の文字の札とでそろっていないので、どちらも青い点にそろえる。検討した案は「A-3」と「青い点」（検討資料の artifact）。小窓が 280px ほどに狭いとき「ほか N ▾」が 2 行目に落ちる件は、このチケットに含めず保留する。

## Acceptance criteria

- [x] 候補の行には、おすすめ・選んでいる候補（おすすめと違うとき）・残りの候補を開く「ほか N ▾」だけを出し、残りがなければ「ほか N ▾」を出さない
- [x] 「ほか N ▾」の一覧から選ぶと、その候補が行に出て依頼文をコピーする。一覧はキーボードで選べ、Esc では一覧だけを閉じる
- [x] おすすめの印は ★ をやめて青い点にし、行の吹き出しの一覧（ask-menu.tsx）の「おすすめ」の文字の札も同じ点にする
- [x] 青い点には「おすすめ」の文字をツールチップと読み上げで持たせる
