## Summary

Epic の札は小さく、吹き出しを中に入れられないため、Epic をエージェントに頼む入口がない。Iteration の見出しと同じ作りにそろえ、札で絞っている間、札の下（カンバンは Iteration の見出しの下）に「Epic e12 題 done/全体 ×」の行を出す。触れると吹き出し（Shift+F10）でその Epic を頼める。「なし」で絞ったときは「Epic なし N 件」と出し、頼む対象はその N 件。モック: https://claude.ai/artifact/CCgGgX4A87fkHGWHFgP6TA

## Acceptance criteria

- [x] 絞っている間だけ見出しの行を出し、× で絞り込みを外せる（今の Epic の絞り込みの札をこの行にまとめる）
- [x] 見出しの吹き出しと Shift+F10 で、その Epic を対象に頼める。候補は Epic の詳細のタイトルと同じで、core の候補は変えない。「なし」では、絞って見えている Epic のないチケットの全件が対象になり、行を複数選んで頼むときと同じ候補を出す
- [x] 閉じた Epic で絞ったときも見出しを出す
- [x] requirements の UI-10 に、選んでいる Epic の見出しから頼めることを 1 文で足す
