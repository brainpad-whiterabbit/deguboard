## Summary

閉じた Run が待った秒数（waited_seconds）を持つようになったら、画面の Run の行と振り返りの手引きが、経過時間でなく待ちを除いた作業時間（active_seconds）を主に見せるようにする。待ちを数えられない Run は、経過時間に「待ちは不明」を添えて見せる。

## Acceptance criteria

- [x] 画面の Run の行が作業時間を主に出し、待ちがあれば添えて出し、待ちが不明なら経過時間と待ちが不明なことを出す
- [x] 振り返りの手引きが、step ごとの時間の割合を active_seconds で出すよう案内している
