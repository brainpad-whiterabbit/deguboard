## 概要

claim 直後に origin/main から切っただけのブランチは tip が base と同じなので、collectBranchFacts の merge-base --is-ancestor が真になり、branch_merged の規則で done になる（t8・t12・t14 で発生）。tip が base の先端と同じなら branch_merged を偽にする。ff マージの直後は main が進むまで、または PR の事実で拾う

## 受け入れ条件

- [ ] 作業ブランチの tip が base_branch の先端と同じとき branch_merged が false になり、claim 直後の sync で done にならないテストがある
- [ ] tip が base の真の祖先（マージ後に main が進んだ）なら branch_merged は true のまま
- [ ] requirements.md か ADR-004 の照合の記述に、この判定が書かれている
