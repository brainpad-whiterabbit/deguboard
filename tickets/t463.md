## 概要

設定の保存の拒否・同期・Plan・Run の警告など、core が返すエラー・警告の文を画面がそのまま出しているので、表示言語が英語でも日本語で出る。画面が出す主な文を英語でも出し、訳のない文は core の文のまま出す。UI-11 の「core が出すエラー・警告の文は core の言語のまま」を直す。

## 受け入れ条件

- [ ] 表示言語が英語のとき、設定の保存の拒否の理由と Plan・Run の警告が英語で出る
- [ ] 訳のない文は core の文のまま出て、画面が壊れない
- [ ] 表示言語が日本語のときは、今と同じ文が出る
- [ ] requirements.md の UI-11 を直す
