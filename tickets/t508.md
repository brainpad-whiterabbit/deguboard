## 概要

見直し役の指摘を直す修正ループの fix の Run を、サブエージェントの手順（run start）ではなく、直すエージェント（手直しをサブエージェントに渡すならそのサブエージェント、親が直すなら親）のもう一度の claim（--retry-reason）が開いて sync が閉じる仕組みに寄せる。人のレビューの手直しと同じ仕組み（reclaim）を使う。Run の開き忘れを起きにくくする。決定は ADR-005、手順は guide の review・parallel・work。

## 受け入れ条件

- [ ] 見直しの指摘を直す修正は、直すエージェント（手直しをサブエージェントに渡すならそのサブエージェント、親が直すなら親）のもう一度の claim --retry-reason が fix の Run を開き、sync が push の時刻で閉じる（テストで確かめる）
- [ ] guide の review・parallel・work と ADR-005 の修正ループの記述が、この仕組みに合う
- [ ] mise run check が通る
