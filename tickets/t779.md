## Summary

観点：テスト・アーキテクチャ。t776 で足した VS Code の同期の競合の通知に 3 つのずれがある。
1. core の警告は本文のフィールド名 `本文` を `body lines` に読み替えるが、VS Code の `resolvedSummary` は `field` をそのまま出すので、英語の通知に「本文」が出る
2. ボタンの対応・閉じたときに何もしないこと・`--resolve` の結果ではボタンを出さないこと・押したフォルダを渡すことの分岐が `extension.ts` の `notifySync` に残り、テストがない（sync-resolve.test.ts は純粋関数だけ）
3. `sync-resolve.ts` が core の `ResolveSide`・`ResolvedFile` と同じ形の型、値の上限の字数、値の書き方を写している

## Acceptance criteria

- [x] 英語の通知に日本語のフィールド名が出ない
- [x] 通知の出し方（ボタンの有無）と押したときの次の動作の判定が、vscode の API を呼ばない関数にあり、テストがある
- [x] vscode が、core にある型と値の書き方を写さずに使う
