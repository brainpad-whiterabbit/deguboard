## Summary

印で頼んだサブエージェント（実装など）のセッションが落ちると、SessionEnd が来ないので Run が開いたまま残る。別のセッションの `dg next` はその Run の終わりを待つよう返し続け、印で頼み直しても見直しと手直しのほかの step は `ALREADY_EXISTS` で Run が開かない。その後の PR の記録が古い Run を success で閉じ、使用量は落ちたサブエージェントの記録から数えられ、やり直した作業は記録に残らない。

印で頼んだサブエージェントの Run は親のセッションより長く生きないので、別セッションのものが開いたままなら落ちた残りとみなせる。ただし並行して動いている別のセッションの Run を閉じないよう、記録の最後の更新が一定の時間より新しいものは生きているとみなす。親が自分で開いた実装の Run（サブエージェントの記録に結び付かない）は、今のとおりセッションをまたいで残す。

## Acceptance criteria

- [ ] 印の起動のフックが、同じチケットで別のセッションのサブエージェントの記録に結び付いた開いたままの Run のうち、記録の最後の更新が一定の時間より古いものを、step によらず interrupted で閉じてから新しい Run を開く（テストで示す）
- [ ] `dg next` は、待つ対象の Run が別のセッションのサブエージェントの Run で記録が一定の時間より古いとき、待たせずに印で頼み直す手順を返し、その Run が落ちたセッションの残りで頼み直すと閉じることを添える（テストで示す）
- [ ] 記録の更新が新しいとき、どちらかのセッションが分からないとき、親が自分で開いた Run のときは、`dg next` もフックも今のとおりに扱う（テストで示す）
- [ ] 一定の時間の値とその理由（Bash の上限より長くとる）をコードのコメントに書く
- [ ] requirements.md の RN-6・RN-7 と ADR-025 の「落ちたセッションの残り」の節を今の判断に書き換え、`dg hook --help`・`dg next --help` の説明を合わせる
