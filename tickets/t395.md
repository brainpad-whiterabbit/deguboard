## 概要

見直し役のサブエージェントが --agent claude-code-reviewer のような Adapter のない名前で run start し、finish が会話記録を読まずモデル名と使用量が null になっている（15 件）。start で警告し、guide にサブエージェントの名乗り方を書く。

## 受け入れ条件

- [ ] run start は Adapter のない agent 名でも記録するが、使用量とモデル名を取り込めないことを警告で返す
- [ ] dg guide review と dg guide parallel に、サブエージェントも自分の Adapter の名前（Claude Code なら claude-code）で run start すると書いてある
- [ ] 警告のテストがある
