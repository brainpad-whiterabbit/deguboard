## Summary

node の版が足りないときの dg の文は「Node 24 を PATH の先頭に置く」ように勧める。しかし mise の shim が PATH の先頭にあっても、cwd にもグローバルにも node の設定がなければ、shim は PATH の次の古い node を使う。この場合の原因と直し方が今の文からはわからない。文に、dg を動かした node のパスと、場所で版を選ぶ仕組みのときの直し方を足す。

- [x] パスと直し方が文に入ることを、`nodeVersionProblemOf` のテストで示す
