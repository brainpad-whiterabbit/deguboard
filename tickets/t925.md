## Summary

node の版が足りないときの dg の文は「Node 24 を PATH の先頭に置く」ように勧める。しかし mise の shim が PATH の先頭にあっても、cwd にもグローバルにも node の設定がなければ、shim は PATH の次の古い node を使う。この場合の直し方（グローバルの版を決める、など）が今の文からはわからない。
