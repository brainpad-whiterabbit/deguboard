## 概要

左パネルのカンバンでは、選んだ Iteration 以外の進みは選択欄（▾）を開かないと見えない。 閉じていない Iteration を見出しの上に札で横に並べ、表を使わずにさっと見渡して切り替えられるようにする。 案は https://claude.ai/artifact/VEkpp9mLBhWix864ZNFUtw の O1（期間の帯 O2・▾ の一覧 O3 は採らない）。見出しを触る I の後に置く

## 受け入れ条件

- [x] 左パネルの見出しの Iteration の選択欄（▾）の代わりに、planned と active の Iteration を番号順に札で並べ、押すとその Iteration に切り替わる
- [x] 札は番号・進みの小さな輪・「done/全体」を出し、選んでいる札は塗り、active は実線の枠、planned は破線の枠で見分けられる
- [x] 札にホバーすると名前・期間・目標を読める
- [x] 札の列の最後に「なし n」（Iteration に入っていない終わっていないチケットの数。押すと Iteration なしを選ぶ）と「+」（Iteration を作る）を出す
- [x] 札が幅に入らないときは札の列だけが横にスクロールし、選んでいる札が見える位置にある
- [x] requirements.md の UI-2 を直す
- [x] 変えた画面の幅 300px のライトとダークのスクリーンショットを PR に載せる
