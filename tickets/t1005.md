## Summary

今の dg init は、データの remote に届かない（オフライン・認証切れ・URL の誤り）と、警告を出すだけで新しいボードを作り、成功で終わる。チームのボードがあっても別のボードができ、後の同期で DATA_HISTORY_UNRELATED で止まる。届かないときは作らずに止め、手元だけで始めるのは明示の引数にする。あわせて、Git リポジトリの外で dg を呼んだときのエラーの文に、次の一手（git init で作ってやり直す）を足す。dg が自分で git init はしない（呼ぶ場所の誤りが多いため）。

## Acceptance criteria

- [ ] データの remote に届かないとき、dg init はボードを作らずに失敗し、エラーの文で、接続を直してやり直すか、手元だけで始める引数を付けるかを案内する
- [ ] --new-board を付けると、remote に届かなくても新しいボードを作る。dg init --help とエラーの文で、チームのボードと別のボードになりうることを示す
- [ ] Git リポジトリの外で dg を呼んだときのエラーの文が、git init でリポジトリを作ってやり直す案内を含む
- [ ] remote に届かない・届いてボードがない・届いてボードがある、の 3 つの場合の dg init を、一時ディレクトリの bare リモート付きリポジトリのテストで確かめる
- [ ] docs/requirements.md の SY-1 に、remote に届かないときはボードを作らずに止めることを書く
