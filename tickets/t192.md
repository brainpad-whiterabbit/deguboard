## 概要

左パネルの履歴の Iteration と Epic のタブの検索は、当たるチケットを含む行を残すだけで、どのチケットが当たったかは開いて探さないと分からない。検索語があるあいだは残った行を開き、当たったチケットだけを出す（改善案 H4）。改善案のページ：https://claude.ai/artifact/RPsNUSkt3w9SboDy5XQAwd


## 受け入れ条件

- [x] 検索語があるあいだ、残った Iteration・Epic の行が開き、当たったチケットだけが出る
- [x] タイトルの当たった部分に印が付く
- [x] 「すべて見る」で、その行の全件の一覧に戻せる
- [x] 検索語を消すと、開いた状態が検索前に戻る
