## 概要

t200 の見直しで見つかった。packages/web/src/pages/board.tsx で、実行中の Run を読み終えるまで `store.runningTickets` が null で、その間は rowActivity（board.tsx:719）が undefined を返し running が false になるため、待ちの行の薄くする判定（board.tsx:683–689 の `dimmed={!running && isWaitingReadiness(...)}`）が効き、Run が実行中の待ちの行が開いた直後に一瞬薄く出て、読み終えると戻る。行の頭の回る印は読み終えるまで出さない（rowActivity の注記、app.test.tsx:846 付近のテスト）ので、それとそろえ、読み終えるまでは薄くする判定をしない。テストは app.test.tsx:809・846 付近の、run.list を Promise で止めて後で解く形が使える。run.list の読み込みに失敗したとき（store.tsx:189–198 は null のまま）の扱いは範囲の外とする

## 受け入れ条件

- [x] 実行中の Run を読み終えるまでは、待ち・承認待ちの行を薄くしない
- [x] 読み込み前と後の描画をテストで確かめる
- [x] `mise run check` が通る
