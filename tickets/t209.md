## 概要

t200 の見直しで見つかった。packages/web/src/pages/board.tsx で、実行中の Run を読み終えるまで `store.runningTickets` が null で、その間は running が false になるため、Run が実行中の待ちの行が開いた直後に一瞬薄く出て、読み終えると戻る。行の頭の回る印は読み終えるまで出さないのとそろえ、読み終えるまでは薄くする判定をしない


## 受け入れ条件

- [ ] 実行中の Run を読み終えるまでは、待ち・承認待ちの行を薄くしない
- [ ] 読み込み前と後の描画をテストで確かめる
- [ ] `mise run check` が通る
