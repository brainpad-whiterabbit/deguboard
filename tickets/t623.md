## 概要

常駐するクライアント（VS Code 拡張・dg serve）は、チケット・Epic・Iteration の詳細を開くたびに履歴を git log で読み直して解析している。deguboard ブランチの HEAD のコミットが変わらない間は、前の解析結果を使い回す。

## 受け入れ条件

- [x] HEAD が同じなら、2 回目以降の history は git log を走らせないことをテストで示す
- [x] コミットが増えたら読み直し、新しい経過が出る
- [x] 浅い clone の警告は今と同じに出る
