## Summary

実装（implement）や見直し（review）の Run を開いたセッションが落ちると、Run が実行中のまま残る。dg next はその Run の終わりを待つよう返し続け、サブエージェントに頼み直しても同じチケットと step の Run が開けず（ALREADY_EXISTS）記録が残らない。後で PR を記録すると、残った古い Run が success で閉じられる。手直し（fix）の step だけは、別のセッションが開いた前の Run を interrupted で閉じる規則がある（RN-6）。自動で閉じるか、知らせるだけにするかは決まっていないので、着手の前に検討する。

## Acceptance criteria

- [ ] 同じチケットと step の Run が別のセッションで開いたまま残っているとき、dg next が待たせ続けず、抜け出し方を示すか前の Run を閉じる
- [ ] 頼み直した Run が記録され、落ちたセッションの Run が success で閉じられないことをテストで示す
- [ ] Run を閉じる規則（RN-6）を変えるなら、requirements.md の項を同じ PR で直す
