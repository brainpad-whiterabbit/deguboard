## Summary

sync が競合で止まると、`data.conflicts` と警告はファイル名しか返さない。マージドライバはぶつかったフィールドを知っているのに stderr に書くだけなので、人に remote か local かを選ばせる材料を集めるのに、データのブランチの差分を掘る手間がかかった（s26 の closed_at）。チームで使うとき、競合を短く解けるようにする。

## Acceptance criteria

- [ ] `data.conflicts` が、ファイルごとにぶつかったフィールド（本文は行）と base・local・remote の値を持つ
- [ ] 警告の文が、ファイル名だけでなくフィールドと両側の値を示す
- [ ] `dg guide overview` の「When sync stops」が、その値を表にして人に選ばせる手順になっている
- [ ] bare リモートの 2 つの clone でぶつけたテストで、フィールドと両側の値が返る
- [ ] requirements の SY-4 が、競合で返す内容に合っている
