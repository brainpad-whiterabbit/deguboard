## 概要

観点：設定ファイル。ルートの build は tsc -b と cp を重ねるだけで dist を消さないため、main の checkout の packages/cli/dist/ に、guide の置き場所を core に移す前の guide-*.md（今はない guide-create.md・guide-finish.md を含む 16 本）が残っている。リリースは main で pack と publish を回すので、これらが deguboard の tarball に入る。check-pack は LICENSE しか確かめていない。

## 受け入れ条件

- [x] 前のビルドの生成物が dist に残っていても、pack した cli の tarball に guide-*.md が入らない
- [x] check-pack が、cli の tarball に guide-*.md がないことと、core の tarball に dist/guide/guide-*.md があることを確かめる
