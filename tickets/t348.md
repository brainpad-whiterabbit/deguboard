## 概要

拡張の README の使い方に載せる GIF のうち、エージェントの実行の流れを見せる 3 本を作る。実際の実行の録画は視認性と分かりやすさが出にくいので、紹介ページ案（artifact）の HTML と同じく、仮の GUI（VS Code の左パネル・ターミナルのエージェントの入力と出力を模した画面）を Playwright で動かして録る（2026-11-05 人の判断）。左パネルの中身は、できるだけ実際の `dg serve` の `?surface=sidebar` を使う。録り方は t347 の `scripts/record-gifs.mjs`・`mise run gifs` にそろえる。

- import.gif: 雑な一言に `/dgimport` を付けて頼み、起票の案を承認し、バックログに並んだチケットの詳細（概要・受け入れ条件・依存）を開く
- run-all.gif: `/dgall --auto` を付けて頼み、起票・計画のあと、計画の帯から依存のグラフを開き、チケットが Todo から In Progress を経てすべて Done になる
- retro.gif: 履歴で終わった Iteration の「振り返る」に「ボトルネックを調べてレポートにして」と足して頼み、Run の集計から書いた分析レポートが開く

## 受け入れ条件

- [x] `packages/vscode/images/` に import.gif・run-all.gif・retro.gif がある
- [x] run-all.gif に依存のグラフと、チケットが Todo から Done へ進む様子が映っている
- [x] retro.gif に工程ごとの所要時間かトークンと、ボトルネックの指摘が映っている
- [x] それぞれ 20 秒以下・1MB 以下
- [x] 録り直しの手順が t347 と同じ mise のタスクにあり、同じ手順で作り直せる
