## 概要

拡張の README の使い方に載せる GIF のうち、エージェントの実際の実行を録る 3 本を作る。VS Code とターミナルを並べて画面を録り、早送りする。小さな依頼（チケット 3〜4 件）で録る。

- import.gif: 雑な一言に `/dgimport` を付けて頼み、起票の案を承認し、バックログに並んだチケットの詳細（概要・受け入れ条件・依存）を開く
- run-all.gif: `/dgall --auto` を付けて頼み、起票・計画のあと、計画の帯から依存のグラフを開き、チケットが Todo から In Progress を経てすべて Done になる
- retro.gif: 履歴で終わった Iteration の「振り返る」に「ボトルネックを調べてレポートにして」と足して頼み、Run の集計から書いた分析レポートが開く

## 受け入れ条件

- [ ] `packages/vscode/images/` に import.gif・run-all.gif・retro.gif がある
- [ ] run-all.gif に依存のグラフと、チケットが Todo から Done へ進む様子が映っている
- [ ] retro.gif に工程ごとの所要時間かトークンと、ボトルネックの指摘が映っている
- [ ] それぞれ 20 秒以下・1MB 以下
