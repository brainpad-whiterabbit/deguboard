## 概要

PR #20 で pnpm-workspace.yaml に ignoredBuiltDependencies を書いたが、pnpm 12 はその設定を見ず ERR_PNPM_IGNORED_BUILDS で install が止まる。pnpm 12 の allowBuilds で vsce-sign のスクリプトを拒否する形に直す

## 受け入れ条件

- [ ] main で mise run install（--frozen-lockfile）が通る
- [ ] ADR-008 と development.md の記述が pnpm 12 の設定名に合っている
