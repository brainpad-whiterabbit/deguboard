## Summary

`/dgall t1000 --gate-free` のように段を指定すると、着手の前に対象のチケットへ段を付け、その段の流れで進める。low・free は見直しの段階を飛ばし、free は check も回さない。指定がなければ high（今と同じ）。人がコマンドに書いた指定を人の決定とみなし、--auto ならそのまま進める。

## Acceptance criteria

- [ ] PR がある low・free のチケットでは、dg next が review・fix の手を返さず、ready・wait_merge に進む（テスト）
- [ ] dg brief は low・free のチケットで --role review を求められたら警告を返す
- [ ] dg flow next の --gate <段> で、work の段階の commands に、着手の前の dg ticket update <id> --gate <段> が入る（テスト）
- [ ] dgall・dgwork の Skill の雛形に --gate-high・--gate-low・--gate-free があり、リポジトリの Skill を入れ直してある
- [ ] dg guide all・work・review に、段の指定の受け方と段ごとの流れがある（英語）
- [ ] CLAUDE.md の「コミットの前に mise run check」に、free のチケットは要らないと書いてある
