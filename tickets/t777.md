## Summary

観点：アーキテクチャ。`packages/cli/bin/dg.js` は `../dist/fast-hook.js` を try も代わりの道もなしに読む。一方、main を pull してビルドし直していない clone の dist には `fast-hook.js` がなく（core の `dist/fast-hook.js` も同じ）、dg もすべてのフックも `ERR_MODULE_NOT_FOUND` で落ちる。フックは Bash と書くツールのたびに呼ばれるので、作業がすべて止まる（t768 のマージの後に実際に起きた）。dist が古いことを知らせる仕組みもない。

## Acceptance criteria

- [x] main も読めないときは、dist が無いか古いことと直し方を英語で伝えて終える
- [x] 速い経路のファイルを消した dist で、PreToolUse とほかのコマンドが動くことをテストで確かめる
- [x] 同梱の dg.mjs の入口（bundle.ts）にも同じ扱いが要るかを判断し、その理由をコメントかテストに残す
