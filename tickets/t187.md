## 概要

左パネル（VS Code のサイドバー）の履歴の Iteration / Epic / チケットの切り替え（.segmented）は、選んだものを主ボタンの濃い青で塗るので、上の画面のタブより目立つ。枠も塗りもない文字に件数のバッジを付けた形（改善案 S1）にし、件数の行をなくす。改善案のページ：https://claude.ai/artifact/RPsNUSkt3w9SboDy5XQAwd


## 受け入れ条件

- [x] 左パネルの履歴の切り替えが、塗りのボタンではなく文字と件数のバッジ（Iteration 4・Epic 8・チケット 167 の形）で出る
- [x] 選んだ見方だけ文字が濃く太く出て、aria-pressed などで選択が支援技術に伝わる
- [x] 切り替えの下の「N 件」の行がなくなり、検索中は件数のバッジが「当たった数 / 全体」になる
