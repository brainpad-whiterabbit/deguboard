## 概要

観点=アーキテクチャ。対象=packages/vscode/src/watch.ts の gitCommonDir。食い違い：ADR-007 と CLAUDE.md は Git 操作を core の責務とし、入口にロジックを書かないとするが、拡張が独自に `git rev-parse --git-common-dir` を呼んでいる（core の resolveRepoPaths と重複）。

起票のときは statusbar.ts の currentBranch・headFile・ticketOfBranch も対象だったが、t565 でステータスバーのチケットの表示を消したので、今は無い。core の currentBranch も actions/software.ts の 1 つだけになっている。

## 受け入れ条件

- [ ] 拡張が commonDir を core の関数（resolveRepoPaths など。core の入口から公開する）から得て、自分で git を呼ばない
- [ ] リポジトリでないフォルダと git が動かないときに見張らない振る舞い（今の gitCommonDir が undefined を返す場合）が保たれ、テストがある
- [ ] mise run check が通る
