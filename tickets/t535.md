## 概要

段階・次の 1 手・回数・ゲート・brief が dg に移り、サブエージェントの Run はフックが開閉する（t530）ので、guide の work・run・review・parallel・all を「`dg next` を呼び、返った 1 手を行い、結果を渡す」の細いループと、各手のやり方だけに書き直す。サブエージェントの Run の説明（開く・閉じる・`--agent`・開いたままの警告と `run list`・見直しの前に run start・手直しのもう一度の claim）を消し、親が自分で進める Run（claim が開き、PR の記録と区切りで閉じる）だけを残す。Run の開け閉めの説明が 4 か所に重複している所をなくし、合計を今の半分以下にする。見直しの重い指摘から文書のずれを外す（ADR-001 の新しい方針）。Skill を入れ直す。
