## 概要

セッションが落ちて SessionEnd が来ないと、review と fix の Run が開いたまま残り、自動で閉じる仕組みがない。

- review：次の見直しで、印 step=review の起動は同じチケットと step の二重の開始として拒否され、フックは警告して 0 で返る。run review-result はチケットの実行中の review の Run（古い Run）に今回の結果を書き、SubagentStop は新しい記録に結び付いた Run を見つけられず何もしない。古い Run は前の見直し役の記録を指したまま閉じず、次の見直しの記録が黙って失われ、このマシンではそのチケットの review の Run を開けなくなる
- fix：次のもう一度の claim が前の fix を区切りとして success で閉じ、中断が記録に残らない

別のセッションで開いたままの Run は、そのセッションが落ちた残りとみなして interrupted で閉じてから新しい Run を開く。

## 受け入れ条件

- [ ] 別のセッションで開いたままの review の Run があるとき、印 step=review の起動はその Run を interrupted で閉じてから新しい Run を開き、run review-result は新しい Run に書く（テストで確かめる）
- [ ] 別のセッションで開いたままの fix の Run は、もう一度の claim が interrupted で閉じる。同じセッションの前の fix は今の区切りの規則のまま（テストで確かめる）
- [ ] 同じセッションで同じチケットの review の Run を重ねて開いたときは、今のまま拒否して警告する（テストで確かめる）
- [ ] 判断を変えるので、ADR（ADR-012 の項の置き換え）と requirements の RN-5・RN-6・AG-9 をコードに合わせる
- [ ] mise run check が通る
