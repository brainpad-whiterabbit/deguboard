## 概要

観点：依存（ライセンスの表記）。deguboard・@deguboard/core・@deguboard/server の package.json は "license": "MIT" だが、LICENSE はルートにしかなく、`npm pack --dry-run` の tarball に入らない。
VSIX は package スクリプトでルートの LICENSE を写して入れている。npm 側にはこれに当たる手順がない。

## 受け入れ条件

- [ ] 3 つのパッケージの `npm pack --dry-run` の中身に LICENSE が入る
- [ ] 写した LICENSE は作業ブランチに入らない（.gitignore などで）
- [ ] docs/development.md の tarball を試す手順に、LICENSE が入っていることの確かめがある

## 参考

- packages/cli/package.json・packages/core/package.json・packages/server/package.json の files
- ルートの package.json の pack・release:publish、packages/vscode/package.json の package
