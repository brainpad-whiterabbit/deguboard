## 概要

文書と guide にある「`dg guide <topic>` の『<節>』」形の参照は check:docs が検査しないので、節の改名や削除で切れても検査が通る（t535 では 2 件が見直しまで残った）。check:docs でこの形の参照の切れを見つける。

## 受け入れ条件

- [x] check:docs が「`dg guide <topic>` の『<節>』」形の参照を集め、guide-<topic>.md に同じ名前の見出しがなければ失敗する
- [x] 切れた参照を入れたテストで失敗し、直すと通る
- [x] 今のリポジトリで `mise run check` が通る
