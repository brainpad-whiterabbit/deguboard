## 概要

人が承認する前に、チケットの作業ブランチの変更を VS Code の中で見られるようにする。読むだけで書き込まない。

## 受け入れ条件

- [ ] 作業ブランチのあるチケットの詳細に「変更を見る」が出る
- [ ] 押すと main との間で変わったファイルの一覧が、追加・変更・削除の別と行数つきで出る
- [ ] ファイルを押すと、VS Code の差分エディタで main との差分が開く
- [ ] ブランチがローカルにもリモートにもないときは、理由を出して一覧を出さない
- [ ] 一覧を求める操作は packages/core/src/commands/ のコマンドに置き、データに書き込まない
