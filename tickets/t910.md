## Summary

リリース前の見直し（文書と実装・README の観点）の言い回しの指摘。

- データのブランチ名は `git.data_branch` で変えられるのに、「deguboard ブランチ」を固定の名前として書いている：`packages/cli/src/program.ts` の CLI の説明（"Data lives on the deguboard branch"、利用者に見える）、`packages/core/src/commands/setup.ts` の init と `--data-remote` のヘルプ、`packages/core/src/commands/history.ts` のヘルプ、`packages/core/src/guide/guide-overview.md`、docs/requirements.md 5.10 の config の項、docs/adr/ADR-033-architecture.md
- ADR-034 の要約の「データのリモートでの名前は config で変えられる」の「名前」が、リモートの名前（`git.data_remote`）とブランチ名（`git.data_branch`）のどちらか読み分けにくい
- docs/usage.md・docs/usage.ja.md の「他のエージェントで使う」の節は、`dg hooks check` が「設定と受け取った記録を読むだけ」と書くが、ヘルプでは各フックの dg コマンドを `--version` で実行して確かめる
- README.md の Tips の「Keep the data in another repository than the code's.」が英文として不自然（README.ja.md は自然）

## Acceptance criteria

- [x] 上の箇所で、データのブランチを「データのブランチ（既定は deguboard）」のように既定の名前と断って書いている
- [x] ADR-034 の要約が、変えられるのがデータのブランチ名だと読める
- [x] usage（英日）の `dg hooks check` の説明が、実行して確かめることを含み、英日で同じ内容になっている
- [x] README.md の Tips の文が自然な英文になり、アンカーは変わらない
