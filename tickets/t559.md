## 概要

vitest はファイル単位で並べて回すので、全テストの時間は一番遅いファイル 1 本で決まる。2026-11-08 に手元（8 コア）で計ると、104 ファイル・1373 件で 84 秒、テストの時間の合計は 368 秒だった。commands.test.ts が 83 秒（92 件）で全体の時間をほぼ決めていて、次に run.test.ts が 53 秒、hook.test.ts が 49 秒かかる。store を触る変更では関わるテストに commands.test.ts が入るので、作業の途中に関わるテストだけを回しても待ちが残る。

t546 が commands.test.ts と hook.test.ts を直しているので、t546 が終わってから着手する。

## 受け入れ条件

- [ ] commands.test.ts・run.test.ts・hook.test.ts を分け、どのテストのファイルも単独で 30 秒以内に終わる
- [ ] 分ける前と後でテストの件数が同じ
- [ ] PR の本文に mise run test の前後の時間を書き、後の方が短い
