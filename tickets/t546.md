## 概要

t532 の PreToolUse のフックは、Bash のコマンドの字句から .git/deguboard/ への書き込みを見分けて拒む。python -c・エディタ・スクリプト・変数を通した書き込みは見分けられず、字句の手がかりを足し続けても防ぎきれない。

目標を「書かせない」から「書いたら必ず見つかる」に変える。dg が store を開くときと Stop のフックで、データのリポジトリに dg の外の変更がないかを確かめる。合わせて、フックの書き込みの見分けを粗い形にする。判断は前のチケット（dg pr ready・merge）が書く ADR に従う。

## 受け入れ条件

- [ ] dg が store を開くとき、データのリポジトリに dg の外の変更（未コミットの変更・dg の外のコミット）があれば、どのファイルかを示す。書くコマンドは止め、読むだけのコマンドは警告を返す
- [ ] dg が書いたコミットと、dg の外のコミットを見分けられる
- [ ] Stop のフックでも同じ検査をし、見つけたらエージェントに返す
- [ ] dg の外の変更を戻すか取り込む手順が、help か guide にある
- [ ] PreToolUse の書き込みの見分け（writesDataDir）を、.git/deguboard を含む Bash を dg の読み書きのコマンドへ案内する粗い形にし、取りこぼしは事後の検査が見つけることを help とコメントに書く
- [ ] requirements に、dg の外の変更を見つける約束を書く
