## 概要

styles.css の共通部分を KanbanForge の作りに寄せる。本文色を --vscode-foreground に、状態色 --dg-status-{todo,in_progress,review,done,abandoned} を body に定義（charts-blue / charts-yellow / testing-iconPassed のフォールバック）、枠線は panel-border と contrastBorder のフォールバック、ボタン radius 2px、.notice は左 3px の線で塗り分け、.empty は破線枠、タブは下線、ProgressBar は状態ごとの積み上げ。.app に container-type: inline-size。ブラウザ用の :root 既定値に新しい変数を足す。webview.ts の CSP から style-src の 'unsafe-inline' を外せるか拡張開発ホストで確かめ、違反が出なければ外す。サイドバー固有のレイアウトは別チケットで扱い、ここでは共通部品に限る

- [ ] ライト・ダーク・ハイコントラストの各テーマで、文字・枠・ボタン・帯・バッジが読める
- [x] 状態色は --dg-status-* の変数 1 か所で決まり、カンバン・一覧・進捗バーが同じ色を使う
