## 概要

実行計画のグラフ（UI-13）は、矢印と段を Plan の `after` だけから作っている。チケットの `depends_on` は待ちの印に出るだけで、矢印にも段にもならない。そのため、`depends_on` だけでつながった 2 枚は同じ段に並び、どれを待っているかがグラフからはわからない。Plan の中のチケット同士の `depends_on` も、`after` と見分けられる矢印で描き、段にも入れる。

## 受け入れ条件

- [ ] Plan の中のチケット同士の `depends_on` が、`after` と見分けられる線（点線など）の矢印で描かれる。同じ組に両方があれば 1 本にまとめるか、見分けられる形で描く
- [ ] 段は `after` と `depends_on` の両方から求め、依存先より右（後の段）に置かれる。Plan の外への `depends_on` は描かない
- [ ] 依存先が終わった矢印は、`after` と同じく終わった印になる
- [ ] requirements の UI-13 を直し、plan-graph のテストに `depends_on` だけの組と両方がある組を足して、`mise run check` と `mise run test:layout` が通る
- [ ] 変えたグラフの画面（ライト・ダーク）のスクリーンショットを PR の本文に載せる
