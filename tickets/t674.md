## Summary

retro（振り返る）は今、閉じた Iteration の詳細と閉じた Epic の候補に出る。人の方針（2026-11-10）で、History タブの Iteration の見出しの頼むことにだけ出す（いずれ History 全体の頼むことにも出す）。Epic からは外す。dgretro の中身は後で決めるので Skill なしのままにする。場所によって候補を変える仕組みを ask-menu に足す。

## Acceptance criteria

- [ ] History タブの Iteration の見出しから頼めて、閉じた Iteration なら retro が候補に出ることをテストが確かめる
- [ ] 閉じた Iteration の詳細と閉じた Epic の候補に retro が出ないことをテストが確かめる
- [ ] 場所によって候補が変わることを、ask-menu のテストと dg ask の --help が示す
- [ ] History の Iteration の見出しから頼むスクリーンショットを PR に載せる
