## 概要

ADR-001 は、コードから指すのは要件 ID と「なぜ」で、ADR 番号はファイルの先頭のコメントの 1 つまでと決めている。守らせる検査がなかったため、t636 の前には先頭のコメントの外に 281 か所が積もっていた。機械で守れる判断はツールに守らせる（ADR-001）ので、check:docs に検査を足す。ADR を削除・統合するとき（t635 など）の張り替えの漏れも防げる。

## 受け入れ条件

- [ ] packages（dist と git が無視するものを除く）・scripts・ルートの test/ の追跡ファイルで、先頭のコメントの外に ADR 番号があると、ファイルと行を付けて check:docs が落ちる
- [ ] 先頭のコメントに異なる ADR 番号が 2 つ以上あると、check:docs が落ちる
- [ ] ADR 番号そのものを検査するテストのフィクスチャと、check-docs の正規表現・説明の文は、理由を書いた例外として落とさない
- [ ] 上の検査それぞれにテストがある
- [ ] いまのリポジトリで check:docs が通る
